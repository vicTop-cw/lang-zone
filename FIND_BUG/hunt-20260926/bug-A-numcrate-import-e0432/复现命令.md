## 期望

## 实际
`error[E0432]: unresolved import \`num_bigint\``（codegen/mod.rs:2162-2164 裸发 `use num_bigint::BigInt;`；
`use num_complex::Complex64;` 同族，complex_min.lz 复现同错）。

（grep lz_builtins/src 无 bigint/complex 字样），生成 crate 无法触达。
