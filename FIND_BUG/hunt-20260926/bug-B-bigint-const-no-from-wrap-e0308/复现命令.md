# BUG-B 顶层 BigInt const 缺 BigInt::from 包装（E0308）

## 复现
同 BUG-A 转译出 .rs 后，补 `--extern num_bigint=<deps>/libnum_bigint-*.rlib` 绕过 E0432 再编译：
```bash
rustc --edition 2021 --crate-type lib -L dependency=target/debug/deps \
  --extern lz_builtins=<...> --extern num_bigint=<...> \
  FIND_BUG/hunt-20260926/bug-B-bigint-const-no-from-wrap-e0308/bigint_min.rs -o /tmp/_b.rlib
```

## 期望
`const x: num_bigint::BigInt = num_bigint::BigInt::from(12345678901234567890i128);`（gen_const_def BigInt 臂 mod.rs:6174-6192 有包装逻辑）

## 实际
```rust
const x: num_bigint::BigInt = 12345678901234567890i128;   // 实际发射
```
`error[E0308]: mismatched types: expected BigInt, found i128`。
根因：BigInt 字面量发射点多处（mod.rs 6173 / 14775 / 15040），实际走 const 路径的站点无 BigInt 目标类型上下文，
裸发 `{n}i128`（15040 注释自认「此处无 ty 参数，保守生成 i128」）。

## 备注
与前序 fix（E0046/E0782/Iterator/Dict/af2fa9fe 字符串索引）不重复；与 4cebe6a9（词法层接受超大整数）分层不同——本缺陷在 codegen 层。
