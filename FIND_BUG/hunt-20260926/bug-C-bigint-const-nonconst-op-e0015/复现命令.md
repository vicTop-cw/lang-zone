# BUG-C BigInt 常量运算落入 const 上下文（E0015）

## 复现
同 BUG-B 编译（bigint_min.lz 同一样例的第二层错误）。

## 期望
BigInt 运算非常量可求值——`gen_const_def` 的 needs_lazy 判定（mod.rs:6199-6209）应把 BigInt 归入
LazyLock/static 惰性发射（对齐 Vec/HashMap/catch_unwind 同类）。

## 实际
```rust
const y: num_bigint::BigInt = x * 100i64;
```
`error[E0015]: cannot call non-const operator in constants`——BigInt 的 Mul 实现非常量，const 上下文直接非法。

## 备注
needs_lazy 集合不含 BigInt/IrType::BigInt，属 fix 报告方法论第 2 条（期望类型传播）之外的**惰性判定盲区**。
