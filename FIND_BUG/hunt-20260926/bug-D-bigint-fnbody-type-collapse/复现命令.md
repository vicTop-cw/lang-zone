# BUG-D 函数体内 bigint 类型整体坍塌为 i128（E0308/E0277 + import 缺发）

## 复现
```bash
E:/IDEProjects/AI/lang-zone/target/debug/lang-zone.exe FIND_BUG/hunt-20260926/bug-D-bigint-fnbody-type-collapse/bigint_fnbody.lz
rustc --edition 2021 --crate-type lib -L dependency=target/debug/deps \
  --extern lz_builtins=<...> --extern num_bigint=<...> \
  FIND_BUG/hunt-20260926/bug-D-bigint-fnbody-type-collapse/bigint_fnbody.rs -o /tmp/_d.rlib
```

## 期望
```rust
let x = num_bigint::BigInt::from(12345678901234567890i128);
let y = &x * 100i64;   // 或 BigInt 域内一致运算
```

## 实际
```rust
let y = x * 100i64;    // bigint 注解整体消失，x 坍塌为 i128
```
- `error[E0308]: mismatched types: expected i128, found i64`（`100` 被按 Int→i64 发后缀，与 i128 槽位不符）
- `error[E0277]: cannot multiply i128 by i64`
- 且生成码**连 `use num_bigint::BigInt;` 都未发**：module_uses_bigint 检测（mod.rs:1731-1737）只扫
  函数签名/Const/StructDef 字段，**不扫函数体表达式**。

## 备注
函数体路径的 bigint→i128 静默降级使「BigInt 字面量合法」（4cebe6a9）在函数体内退化为更大的 i128 陷阱。
