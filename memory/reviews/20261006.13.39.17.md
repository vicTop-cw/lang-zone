## 二、BUG-32：块体闭包的前缀语句被丢掉（本轮修，cy 侧）

机制：`gen_expr` 对 `ExprKind::BlockExpr` 的分支注释写着「深嵌套位置（无法语句提升）：降级为尾表达式」，
而闭包体正是这个位置 ⇒ `\|a, b| =>` 的 `{ c = a + b; c * c }` 发成 `lambda a, b: (c * c)`。
本例因为 `c` 从未绑定，Cython 当场拒；**换成被丢的语句不产生未绑定名字时（体里是一条 print/一次累加）就是静默少副作用**。

修复前的拒绝原文有盘上等价证据（不是引用会话记忆）——`TEMP/closure_prefix_loss.py` 手写旧发射形态那一行，
跑门禁同一条命令：
- OLD_SHAPE_REJECT: old_shape.pyx:1:19: undeclared name not builtin: c
- OK: 旧形态被 Cython 逐字拒绝（见上 OLD_SHAPE_REJECT），当前产物走 hoist 且 cythonize 通过（旧形态的那一行确实是 `lambda a, b: (c * c)` 这种形状）
- 当前产物：CURRENT_HAS_DEGRADED=False CURRENT_HAS_HOISTED_DEF=True ＋ CURRENT_CYTHON_RC=0

修法两条通道都要走：函数体侧扩展 `preprocess_lambdas`，模块级 const 初值侧新增 `preprocess_lambdas_expr`
（**第一版只改了函数体，A 组探针仍然红**）；块体闭包 hoist 成 `def __lambda_N(形参):`，前缀语句照常生成、尾值转 `return`，
绑定行引用该名字；单表达式闭包**保持** `lambda`。

顺带补齐 §五 的**写捕获声明**：hoist 出的 def 里按名字归属发 `global`（模块变量）或 `nonlocal`（外层函数已绑定），
块内新绑定的名字不声明。原先 `AssignExpr` 臂是**无条件**发 `nonlocal`，用在模块变量上本身就是 SyntaxError——
这一条是本轮改动的副产品，不是新需求。
