## 三、关键方法论

1. **仪器化优先**：codegen 同一语义存在多个发射点（None 有 3 处 turbofish 站点），静态推理易走错分支。用 `LZ_DEBUG_NONE` 环境变量 + eprintln 定位真实路径，效率远高于纯读代码。
2. **期望类型传播**是本批最大主题：let 注入 `current_expected_ty` 后，嵌套构造（ListLit 元素 / Some 实参 / KwArg）必须逐层下推槽位类型，否则内层借用外层完整类型。
3. **trait/impl where 一致性**（E0276）：合成 trait 的方法签名与 impl 端必须同步补约束，用同一预扫描集合保证两端一致。
4. **工具链陷阱**：FIST-Mbt `_build` 产物被清理/重建后，main.js 由 CJS 变 ESM 且混用 `require()`——通过注入 `createRequire` shim 恢复；重建后须验证产物存在。
