**产物根因（本次实测取证）**：

- `DEMO/lz_std/list.rs:679` → `let evens = (lst).filter(move |x: &i64| -> bool { *(x).clone() % 2i64 == 0i64 });`

  **仅 `filter` 谓词闭包多发射一个解引用前缀 `*`**，对 `&i64` 参数先 clone 再 deref 触发 E0614。

**归因对照实验（关键）**：在隔离副本回退 N1N2 补丁（`codegen/mod.rs` 还原为仓库版本）后重跑同一闸门，
