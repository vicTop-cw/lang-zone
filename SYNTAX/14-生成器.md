# LZ 生成器

> 规范版本: 3.2 · 基于编译器源码 · 最后校订: 2026-07-31

生成器是包含 `yield` 语句的函数。语义与 Python 生成器对齐：调用生成器函数返回一个迭代器，每次 `yield` 暂停执行并产出值。

---

## 一、基本定义

`iterator` 关键词声明生成器函数。调用生成器函数返回一个惰性迭代器，每次 `yield` 暂停执行并产出值。`def` 函数内含 `yield` 同样向后兼容，但 `iterator` 是推荐方式。

```lz
iterator counter(n: int) -> int =
    for i in 0..n:
        yield i
```

调用：

```lz
for x in counter(5):
    print(x)           // 0 1 2 3 4
```

---

## 二、yield 规则

### 2.1 必须有 yield

`iterator` 函数体内**必须**包含至少一个 `yield` 语句。

```lz
// ✅ 生成器
iterator gen() -> int =
    yield 1
    yield 2

// ❌ 不是生成器 — 缺少 yield
def no_gen() =
    return 42        // 这只是普通函数
```

### 2.2 yield 必须在函数体顶层

`yield` 必须直接在 `iterator` 函数体中，**不能嵌套在闭包或内嵌函数内**。

```lz
// ✅ 正确：yield 在 iterator 体顶层
iterator gen() -> int =
    for i in 0..5:
        yield i                // yield 直接在 gen 体内

// 内嵌闭包的函数，bad不是生成器 ：yield 嵌套在闭包内
def bad() =
    f = |x|
        yield x                // 错误：yield 在闭包内不算生成器
    f(1)

// 内嵌inner生成器的函数，bad2不是生成器 ：yield 嵌套在内嵌函数内
def bad2() =
    def inner():
        yield 1                // 错误：yield 在 inner 内不算
    inner()
```

### 2.3 return 在中止生成器中的语义

`iterator` 函数体内支持 `return`，且与 `raise` 语义等价（见 §8.3）。`def` 生成器的 `return` 使用 Python StopIteration 语义。以下 `return` 行为适用于 `def` 生成器（向后兼容）：

```lz
// return 不带值：立即停止（仅 def 生成器支持）
def limited(n: int) -> int =
    for i in 0..10:
        if i >= n:
            return              // 中断，StopIteration
        yield i

// return 带错误类：停止并附加错误信息（仅 def 生成器支持）
def safe_read(items: List<Option<int>>) -> int =
    for opt in items:
        match opt:
            case Some(v):
                yield v
            case None:
                return ValueError("encountered None in stream")
```

> **注意**：`iterator` 函数体内 `return` 与 `raise` 语义等价（均终止迭代+抛出错误）。`def` 生成器的 `return` 使用 Python StopIteration 语义，两者不同。见 §8.3。
>
> **`return ErrorType(msg)` 在 `def` 生成器中的语义**：立即终止生成器，错误信息附加到 `StopIteration` 异常中。与 `raise` 不同，`return` 不触发 `catch` 捕获。Python 3.7+ 等价于 `raise StopIteration`。

`return` 的行为（仅适用于 `def` 生成器）：

| 写法 | 语义 | Python 等价 |
|------|------|-------------|
| `return` | 立即停止生成器 | `return` → `raise StopIteration` |
| `return ErrorType(msg)` | 停止并附加错误信息 | `return ErrorType(msg)` |

示例（仅 `def` 生成器支持 `return`）：

```lz
def count_until(limit: int) -> int =
    i = 0
    while True:
        if i >= limit:
            raise StopIteration("limit reached")
        yield i
        i += 1

// 使用：
for x in count_until(3):
    print(x)             // 0 1 2
```

> 生成器构建块 `func *:` 内同样支持 `return` 中断。

> **注意**：生成器的返回类型标注（`-> T`）表示 **yield 的元素类型**，而非迭代器类型。例如 `iterator counter() -> int = ...` 中 `-> int` 表示每次 yield 出 `int` 值，实际返回 `Iter<int>`。

## 三、yield 形式

| 形式 | 语法 | 说明 |
|------|------|------|
| 裸 yield | `yield` | 暂停，产出 `None`（等价于 `yield None`） |
| yield 值 | `yield expr` | 暂停并产出表达式的值 |
| yield from | `yield from iterable` | 委托给另一个迭代器，逐个产出其值 |
| yield from with | `yield from iterable with PartialFunc` | 委托 + 偏函数变换 |

### 3.1 裸 yield

```lz
iterator signals() -> () =
    yield           // 产出 None
    yield 1         // 产出 1
    yield           // 产出 None
```

### 3.2 yield 值

```lz
iterator fib(limit: int) -> int =
    a = 0
    b = 1
    while a < limit:
        yield a
        a, b = b, a + b
```

### 3.3 yield from

```lz
iterator chain<T>(iter1: Iter<T>, iter2: Iter<T>) -> T =
    yield from iter1     // 逐个产出 iter1 的所有值
    yield from iter2     // 逐个产出 iter2 的所有值
```

等价于：

```lz
iterator chain<T>(iter1: Iter<T>, iter2: Iter<T>) -> T =
    for x in iter1:
        yield x
    for x in iter2:
        yield x
```

### 3.4 yield from ... with PartialFunc

`yield from iterable with func` 在委托迭代的同时，对每个元素应用变换函数。

```lz
iterator transformed<T, R>(iter: Iter<T>) -> R =
    yield from iter with my_transform
```

## 四、PartialFunc 偏函数

`yield from ... with` 接受一个 **PartialFunc** 对象。PartialFunc 定义了三阶段管道：

```
输入元素 → [pre_filter] → map → [post_filter] → 产出
```

### 4.1 PartialFunc 语义

| 阶段 | 签名 | 默认行为 | 说明 |
|------|------|---------|------|
| `pre_filter` | `fn(T) -> bool` | `\|x\| True` | 在 map 之前过滤：返回 `false` 则跳过该元素 |
| `map` | `fn(T) -> R` | `\|x\| x` | 变换函数：将输入类型 T 映射为输出类型 R |
| `post_filter` | `fn(R) -> bool` | `\|x\| True` | 在 map 之后过滤：返回 `false` 则跳过变换后的元素 |

- **只需实现其中任意一个函数即可**，其余使用默认实现
- 全默认的 PartialFunc 等价于恒等管道（不操作任何元素）

### 4.2 PartialFunc 定义

```lz
// 只定义 map，其余默认
let square = PartialFunc(
    map = |x| x * x
)

// 只定义 pre_filter，其余默认
let positives = PartialFunc(
    pre_filter = |x| x > 0
)

// 定义 map + post_filter
let even_squares = PartialFunc(
    map = |x| x * x,
    post_filter = |x| x % 2 == 0
)

// 三阶段全定义
let complex = PartialFunc(
    pre_filter = |x| x != 0,         // 过滤掉 0
    map = |x| 100 / x,               // 取倒数 ×100
    post_filter = |x| x > 0          // 只保留正数
)
```

### 4.3 使用示例

```lz
iterator process(nums: Iter<int>) -> int =
    yield from nums with PartialFunc(
        pre_filter = |x| x % 2 == 1,  // 只处理奇数
        map = |x| x * x,              // 平方
        post_filter = |x| x < 50      // 结果小于 50
    )
```

等价于：

```lz
iterator process(nums: Iter<int>) -> int =
    for x in nums:
        if x % 2 == 1:              // pre_filter
            let y = x * x           // map
            if y < 50:              // post_filter
                yield y
```

### 4.4 执行顺序

```
输入: [1, 2, 3, 4, 5, 6]
  pre_filter(|x| x % 2 == 1)     → [1, 3, 5]
  map(|x| x * x)                  → [1, 9, 25]
  post_filter(|x| x < 50)         → [1, 9]
输出: yield 1, yield 9
```

## 五、生成器构建块 `func *:`

`*:` 是**调用构建块**的生成器变体。`func *:` 将 `func` 的多次调用结果包装为一个**迭代器包**，支持有参/无参函数。

### 5.1 语义

```
func *:              // func 是目标函数（任意签名）
    yield ()         // → 调用 func()，无参
    yield (a, b)     // → 调用 func(a, b)，按位置传参
    yield {k: v}     // → 调用 func(k=v)，按关键字传参
    yield from iter  // → 迭代 iter，每个元素调用 func(e) 一次
```

每个 `yield` 返回一个 **BuildParams**（与 `~:` 调用构建块的拆包协议相同）：
- `()` / 裸 `yield` → 无参调用
- `(a, b)` → 位置参数元组
- `{k: v}` → 关键字参数字典

`func *:` 的结果是 `iter(func(a1,b1), func(a2,b2), ...)`。

### 5.2 无参函数

```lz
def one() -> int = 1

// 每个 yield 调用 one() 一次
xs = one *:
    yield             // → one()
    yield ()          // → one()，等价于上面
    yield             // → one()

for x in xs:
    print(x)          // 1 1 1
```

### 5.3 有参函数

```lz
def add(a: int, b: int) -> int = a + b

xs = add *:
    yield (1, 2)      // → add(1, 2) = 3
    yield (10, 20)    // → add(10, 20) = 30
    yield (5, -1)     // → add(5, -1) = 4

for x in xs:
    print(x)          // 3 30 4
```

关键字参数：

```lz
def greet(title: str, name: str) -> str = f"{title} {name}"

xs = greet *:
    yield {"title": "Mr", "name": "Zhang"}
    yield {"title": "Ms", "name": "Li"}

for x in xs:
    print(x)          // Mr Zhang  Ms Li
```

### 5.4 生成器函数 + 构建块

```lz
// iterator 函数必须有签名
iterator gen() -> int =
    yield 1
    yield 2
    yield 3
    yield from gen()       // 无限循环 1,2,3,1,2,3...
```

> **`yield from gen()` 类型匹配**：`yield from gen()` 将另一个生成器的产出摊平到当前生成器。由于 `gen()` 返回迭代器而非单个值，`yield from` 在编译期展开为 `for __val in gen(): yield __val`，类型与 `-> int` 匹配。

```lz
// 迭代器包：两个独立的 gen() 迭代器
ys = gen *:
    yield                  // → gen()  = iter(1,2,3,1,2,3...)
    yield                  // → gen()  = iter(1,2,3,1,2,3...)

// ys == iter(gen(), gen())
```

### 5.5 yield from 委托

```lz
def add(a: int, b: int) -> int = a + b

// yield from 迭代参数列表，每个元素拆包传给 add
pairs = [(1, 2), (3, 4), (5, 6)]
xs = add *:
    yield from pairs     // → add(1,2), add(3,4), add(5,6)

for x in xs:
    print(x)             // 3 7 11
```

等价于手动展开：

```lz
xs = add *:
    yield (1, 2)
    yield (3, 4)
    yield (5, 6)
```

✅ **关键字参数也支持**：

```lz
configs = [{"title": "Mr", "name": "Zhang"}, {"title": "Ms", "name": "Li"}]
xs = greet *:
    yield from configs   // greet(title="Mr", name="Zhang"), greet(title="Ms", name="Li")
```

❌ **反例：构建块的迭代结果是值，不是参数包**

```lz
batch = add *:
    yield (1, 2)
    yield (3, 4)
// list(batch) == [3, 7]  ← add 的返回值是 int，不是元组

// ❌ 错误：3 和 7 是 int，无法拆包为 BuildParams 传给 add
// xs = add *:
//     yield from batch      // batch 产生 int，需要元组/字典作为参数包
```

> `add *:` 的迭代结果是 `add()` 的**返回值**（这里是 `int`），不是输入的参数元组。yield from 需要可拆包为 BuildParams 的元素。如需复用参数，直接使用原始参数列表即可。

### 5.6 规则总结

| 构建块内写法 | 语义 |
|-------------|------|
| `yield` | 无参调用 `func()` |
| `yield ()` | 无参调用 `func()`（显示空元组） |
| `yield (a, b)` | 位置参数调用 `func(a, b)` |
| `yield {k: v}` | 关键字参数调用 `func(k=v)` |
| `yield from iter` | 委托迭代器，每个元素拆包调用 func |
| `return` | 立即中断生成器构建块 |
| `return ErrorType(msg)` | 中断并附加错误信息 |
| `yield expr`（非元组/字典） | ❌ 非法（必须返回 BuildParams） |
| `yield (2,)` | ❌ 非法（单值元组，应用 (2,) 列表替代或显式用 yield 2） |

### 5.7 惰性求值

```lz
def greet(name: str) -> str =
    print(f"called with {name}")
    return f"Hello {name}"

xs = greet *:          // 此时不执行
    yield ("Alice",)
    yield ("Bob",)

// 迭代时才执行：
for x in xs:            // 打印 "called with Alice" → "called with Bob"
    print(x)            // "Hello Alice"  "Hello Bob"
```

### 5.8 命名生成器 vs 构建块

| | 命名生成器 | 生成器构建块 `func *:` |
|------|-----------|----------------------|
| 定义 | `iterator gen() -> T = ... yield x` | `xs = func *: yield ...` |
| 返回值 | 单个迭代器 | **迭代器包**（多次调用目标函数） |
| yield 语义 | 产出值 | 产出一次目标函数调用 |
| yield from | 委托子迭代器 | ✅ 委托子迭代器（每元素拆包调用 func） |
| 惰性 | ✅ | ✅ |

### 5.9 空白规则

`*:` 是**整体 token**（`*` 和 `:` 之间无空格），操作符**前后留白 + 后换行缩进**：

```lz
xs = func *:                 // ✅
    yield

// ❌ xs=func*:yield        // 错误：必须前后留白 + 换行缩进
// ❌ xs = func * : yield   // 错误：* 和 : 之间不能有空格
```

## 六、与 Python 对齐

| 特性 | Python | LZ |
|------|--------|-----|
| 生成器定义 | `def f(): yield x` | `iterator f() -> T = ... yield x`（推荐）；`def f() = ... yield x`（向后兼容） |
| 生成器构建块 | — | `func *:`（多次调用包装为迭代器包） |
| 委托 | `yield from iter` | `yield from iter` |
| 闭包内 yield | ❌ 不算生成器 | ❌ 不算生成器 |
| 内嵌函数内 yield | ❌ 不算生成器 | ❌ 不算生成器 |
| 委托 + 变换 | — (需手动 for + yield) | `yield from iter with PartialFunc` |
| 偏函数管道 | — (需手动组合) | `PartialFunc(pre_filter, map, post_filter)` |

## 七、语法边界

```lz
// ❌ 无 yield 的函数不是生成器
def not_gen() =
    return 42

// ❌ yield 在闭包内无效
def bad() =
    f = |x| yield x            // 错误

// ❌ yield 在内嵌函数内无效
def bad2() =
    def inner(): yield 1       // 错误

// ✅ 正确：yield 在函数体顶层
iterator good() -> int =
    if cond:
        yield 1
    else:
        yield 2
```

## 八、iterator 关键字生成器函数

### 8.1 概述

`iterator` 是与 `def` 并列的**专用生成器函数定义关键字**。与 `def` + `yield` 的"普通函数隐式升级为生成器"不同，`iterator` 明确声明它是一个生成器，且对函数体施加严格的语法约束。

### 8.2 语法

```lz
iterator name<T, R>(params) -> Y
    where T: Iterable =
    ...
```

| 部分 | 说明 |
|------|------|
| `iterator` | 关键字声明 |
| `name` | 函数名 |
| `<T, R>` | 泛型参数（全部使用尖括号，约束通过 where 子句） |
| `(params)` | 形参列表 |
| `-> Y` | **产出值**的类型。`-> Y` 表示每次 `yield` 产出的值类型为 `Y`。函数实际的 Rust 返回类型为 `Iter<Y>`。签名比 `def` 生成器简化一层——不需要手动写 `Iter<Y>` |
| `where T: Iterable` | 约束子句 |
| `...` | 函数体，只支持特定语句（见 §8.3） |

> **历史**：早期设计使用 `[T: Iterable]` 作为泛型约束的"检查站"语法，现统一为尖括号 + `where` 子句。方括号 `[]` 仅用于运行时检查站（见 [03c-检查站.md](03c-检查站.md)）。

**示例**：

```lz
// 最简单的 iterator：-> int 表示每次 yield int，实际返回 Iter<int>
iterator count_up(n: int) -> int =
    for i in 0..n:
        yield i

// 签名对比：
//   def 生成器：def count_up(n: int) -> Iter<int>
//   iterator：  iterator count_up(n: int) -> int    ← 不用写 Iter<>
```

### 8.3 函数体约束

`iterator` 函数体内的合法语句：

| 语句 | 是否允许 | 说明 |
|------|:-------:|------|
| `yield expr` | ✅ | 产出值（核心操作） |
| `yield from expr` | ✅ | 委托子迭代器 |
| `return expr` | ✅ | 等价于 `raise expr`——终止迭代并抛出错误 |
| `raise expr` | ✅ | 抛出异常中止迭代 |
| `guard cond else: body` | ✅ | 条件守卫——当条件不满足时执行 `body`（典型为 `return`/`raise` 中止迭代） |
| `try / catch / finally` | ✅ | 异常处理 |
| `if / elif / else` | ✅ | 条件分支 |
| `for / while / loop` | ✅ | 循环（可在循环内 `yield`） |
| `let` / `let mut` assign | ✅ | 局部变量绑定 |
| `=` plain assign | ✅ | 变量赋值 |
| `match / case` | ✅ | 模式匹配 |
| `pass` | ✅ | 占位 |
| `print` / 方法调用 | ✅ | 副作用调用 |

> **语义简化**：`guard`、`return`、`raise` 在 `iterator` 体中构成守卫/中止三件套——`guard cond else: raise x` 等价于 `if not cond: return x`，都终止迭代。没有额外限制。

### 8.4 yield 规则

`iterator` 体内的 `yield` 规则与普通生成器一致（见 §二~§四），包括：

- `yield expr` — 产出值
- `yield` — 产出 None
- `yield from expr` — 委托子迭代器
- `yield from expr with PartialFunc` — 委托 + 变换

`yield` 必须直接位于 `iterator` 函数体内（不在闭包或内嵌函数内），否则编译报错。

### 8.5 嵌套迭代器

`iterator` 函数体内可以调用其他 `iterator` 函数并 yield 其结果：

```lz
iterator inner<R>(x: R) -> R =
    yield x

iterator outer<R>(n: int, val: R) -> Iter<R> =
    for i in 0..n:
        yield inner(val)       // yield inner() 返回的 Iter<R>
```

`outer` 的 `-> Iter<R>` 表示每次 yield 的值为 `Iter<R>`。由于 `yield inner(val)` 产出 `Iter<R>`，实际返回 `Iter<Iter<R>>`——即"迭代器的迭代器"。

若外层声明 `-> R`，则 yield 的值类型为 `R`，此时 `yield inner(val)` 必须改用 `yield from` 来摊平嵌套：

```lz
iterator outer_flat<R>(n: int, val: R) -> R =
    for i in 0..n:
        yield from inner(val)  // 摊平，产出 R
```

### 8.6 与生成器构建块 `*:` 的关系

`iterator` 函数**不影响**生成器构建块 `func *:`（见 §五）。两者独立：

- `iterator` 定义**命名生成器函数**（在定义处声明）。
- `func *:` 定义**匿名生成器构建块**（在使用处声明），将多次函数调用包装为迭��器包。

两者 body 内均支持 `yield`，但 `func *:` 的 yield 语义不同（产出调用参数包而非值）。

### 8.7 与 def 生成器的区别

| | `def` 生成器 | `iterator` 关键字生成器 |
|---|---|---|
| 关键字 | `def` | `iterator` |
| 何时成为生成器 | 函数体包含 `yield` 时自动升级 | **始终是**生成器，无条件 |
| 签名 | `def f() -> Iter<T>` | `iterator f() -> T`（签名简化一层） |
| `return` | 允许（中断生成器，StopIteration） | **允许**（等价于 `raise`，终止并抛出错误） |
| `guard` | 允许 | **允许**（简版 `return`/`raise`） |
| 编译期检查 | 无特殊校验 | 无额外限制（guard/return/raise 均允许） |
| 用途 | 通用函数或生成器 | 纯粹生成器，签名更简洁 |
