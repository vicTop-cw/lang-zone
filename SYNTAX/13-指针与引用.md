# LZ 指针与引用

> 版本: 3.1 · 基于编译器源码 · 2026-07-27

本文档定义 Lang-Zong 的指针类型与引用系统。

---

## 一、指针类型

LZ 不要求显式写出 `dyn` 关键字。当你使用 `Box`、`Rc`、`Arc` 等指针包裹一个 trait 类型时，`dyn` **自动隐含**。

### 1.1 内置指针类型

| LZ 指针 | Rust 映射 | 说明 |
|---------|-----------|------|
| `Box<T>` | `Box<dyn T>` | 独占所有权堆分配 |
| `Rc<T>` | `Rc<dyn T>` | 引用计数（单线程） |
| `Arc<T>` | `Arc<dyn T>` | 原子引用计数（多线程） |
| `Cell<T>` | `Cell<T>` | 内部可变性（Copy 类型） |
| `RefCell<T>` | `RefCell<T>` | 内部可变性（运行时借用检查） |

### 1.2 `dyn` 隐式规则

```lz
// LZ 写法：
let x: Box<Drawable> = Box.new(Circle(...))

// 生成的 Rust：
// let x: Box<dyn Drawable> = Box::new(Circle { ... });
```

规则：只要 trait 用于指针内部，`dyn` **自动隐含**，无需手动写 `dyn`。`dyn` 不作为 LZ 关键字存在。

### 1.3 指针 + 具体类型

指针包裹具体类型时不加 `dyn`：

```lz
let x: Box<int> = Box.new(42)            // Rust: Box<i64>
let y: Rc<List<int>> = Rc.new([1,2,3])  // Rust: Rc<Vec<i64>>
let z: Arc<Dict<str, int>> = Arc.new({}) // Rust: Arc<HashMap<String, i64>>
```

## 二、引用

### 2.1 引用绑定

| 语法 | 语义 | Rust 映射 |
|------|------|-----------|
| `ref r = x` | 可变引用 | `let r = &mut x` |
| `let ref r = x` | 不可变引用 | `let r = &x` |

```lz
x = 42
ref r = x           // r: &mut int，可通过 r 修改 x
r = 100             // x 也变成 100
```

### 2.2 参数引用修饰符

| 修饰符 | 语义 | Rust 映射 |
|--------|------|-----------|
| `ref x: T` | 不可变引用参数 | `x: &T` |
| `mut ref x: T` | 可变引用参数 | `x: &mut T` |

```lz
def read(ref data: List<int>) -> int =
    data.len()                           // &List<i64>

def modify(mut ref data: List<int>) =
    data.push(42)                        // &mut List<i64>
```

## 三、所有权 `^`

```lz
let x = "hello"
let y = x^           // x 的所有权转移给 y
// print(x)          // ❌ x 已被移动
```

`^` 是后缀运算符，标记显式所有权转移。参数传递时自动 `owned`（等价于 `^`）。

---

## 四、取指针 `*`

`*` 前缀运算符获取一个实例的指针。

```lz
let x = 42
let p = *x              // p: Box<int>，x 被移动到堆上

let s = "hello"
let ps = *s             // ps: Box<str>
```

`*ins` 默认生成 `Box<T>` 指针。编译器根据上下文推断是否需要 `Rc` 或 `Arc`：

```lz
let x = 42
let p: Rc<int> = *x    // 显式指定 Rc 指针
let q: Arc<int> = *x   // 显式指定 Arc 指针
let b = *x             // 默认 Box<int>
```

**语义**：
- `*` = 将值装箱，返回指针
- `&` = 解引用，从指针中取回值
- `*` 和 `&` 互为逆操作

```
x  →  *x  →  p (指针)
p  →  &p  →  x (还原值)
```

## 五、解引用

指针可以通过 `ptr[0]` 或 `&ptr` 解引用。

### 5.1 索引解引用 `ptr[k]`（首选）

```lz
let x = Box.new(42)
let val = x[0]          // 解引用取索引 0，val = 42

let arr = Box.new([1, 2, 3])
let first = arr[0]      // 解引用后取索引 0，first = 1
let third = arr[2]      // third = 3
```

- `ptr[0]` — 解引用获取指针内部值（推荐，避免与 C/Rust `&` 语义混淆）
- `ptr[k]`（k > 0）— 解引用后对集合类型取索引

### 5.2 `&ptr` 解引用（别名，注意与 C/Rust 相反）

```lz
let x = Box.new(42)
let val = &x            // 等价于 x[0]
```

> **⚠️ 注意**：LZ 中 `&ptr` 是**解引用**（获取内部值），与 C/Rust 的 `&x`（取引用）**语义相反**。这是 LZ 独有的设计选择，建议优先使用 `ptr[0]` 避免混淆。

## 六、设计审视：`*` vs `&` 约定

| 操作 | LZ | C/Rust | 评估 |
|------|:--:|:------:|------|
| 取指针 | `*x` | `Box::new(x)` | 合理，前缀简洁 |
| 解引用 | `ptr[0]` | `*ptr` | 合理，与索引统一 |
| 解引用别名 | `&ptr` | `*ptr` | ⚠️ 与 C/Rust 相反 |

**建议**：
1. `*x`（取指针）和 `ptr[0]`（解引用）作为主要形式，语义清晰
2. `&ptr` 作为 `ptr[0]` 的语法糖保留，但文档中标注其与 C/Rust 语义相反
3. `&` 在类型注解中仍表示引用（`ref x: T` → `&T`），不负责任何运行时操作

---

## 七、`dyn` 设计决策

**LZ 不需要 `dyn` 关键字**。原因：

1. 指针类型（`Box` / `Rc` / `Arc`）包裹 trait 时自动生成 `dyn`
2. 编译器在 codegen 阶段判断指针内部是否为 trait → 自动添加 `dyn`
3. 用户无需关心 Rust 的 `dyn` 概念

```
LZ:  Box<Drawable>      → Rust: Box<dyn Drawable>
LZ:  Rc<Clone>          → Rust: Rc<dyn Clone>
LZ:  Box<int>           → Rust: Box<i64>          (具体类型，无dyn)
```

---

## 八、语法边界

```lz
// ❌ dyn 不是 LZ 关键字
let x: Box<dyn Drawable> = ...     // 错误：dyn 不是有效标识符

// ✅ 正确
let x: Box<Drawable> = ...

// ❌ ref 不能用于裸值绑定后又转移
let ref r = x
let y = r^                         // 错误：引用不能转移所有权
```
