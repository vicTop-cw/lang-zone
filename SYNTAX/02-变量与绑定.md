# LZ 变量与绑定

> 版本: 3.1 · 基于编译器源码 · 2026-07-27

本文档定义 Lang-Zong 的变量绑定语义：默认可变、`let` 不可变、`const` 常量、`ref` 引用。

---

## 一、核心语义

Lang-Zong 的变量绑定与 Rust 相反：

> **默认绑定可变更（mutable）**。只有显式使用 `let` 才是不可变绑定。

| 绑定形式 | 可变性 | 说明 |
|----------|:------:|------|
| `let x = 42` | 不可变绑定 | 不可重新赋值 |
| `x = 42` | 默认可变绑定 | 默认可重新赋值 |
| `ref x = 42` | 不可变引用 | 不可重新赋值 |
| `mut ref x = 42` | 可变引用 | 可重新赋值 |
---

## 二、默认可变绑定

### 2.1 基本语法

```lz
x = 42            // 默认可变
x = 100           // 重新赋值，合法
print(x)          // 100

y = "hello"
y = "world"       // 合法
```

### 2.2 带类型注解

```lz
x: int = 42       // 默认可变 + 类型注解
x = 100           // 合法
```

### 2.3 mut 修饰符（no-op）

```lz
mut x = 42        // 等价于 x = 42
mut y: int = 42   // 等价于 y: int = 42
```

`mut` 关键字仅作为装饰性标记存在，不改变语义。

> `mut` 在变量绑定中是 no-op（默认已可变），但在 struct 方法参数中 `mut self` 表示 `&mut Self`（可变引用）。详见 [06a-struct.md](06a-struct.md)。

## 三、let 不可变绑定

### 3.1 基本语法

```lz
let x = 42        // 不可变
// x = 100        // ❌ 编译错误
```

### 3.2 带类型注解

```lz
let x: int = 42
let name: str = "world"
let pi: f64 = 3.14159
```

### 3.3 解构绑定

```lz
let (a, b) = (1, 2)     // 元组解构
let Some(v) = opt        // Option 解构（需在 match/guard let/if let 中使用）

// `..` rest 模式：忽略其余元素
let (first, ..,) = (1, 2, 3, 4)    // first=1，其余忽略
let (head, .., tail) = xs          // 解构 head 和 tail，中间忽略
```

## 四、const 编译期常量

### 4.1 语法

```lz
const MAX_SIZE: int = 1000
const PI: f64 = 3.14159
const GREETING: str = "hello"
```

- 必须在声明时初始化
- 值必须在编译期可确定
- 不支持运行时表达式

### 4.2 错误示例

```lz
// ❌ 常量值需编译期可求值
const LEN: int = some_list.len()
const NOW: str = get_time()
```

## 五、ref 引用绑定

### 5.1 可变引用

```lz
x = 42
ref r = x         // r 是 x 的可变引用
r = 100           // 通过引用修改 x
print(x)          // 100
```

### 5.2 不可变引用

```lz
x = 42
let ref r = x     // r 是 x 的不可变引用
// r = 100        // ❌ 编译错误
```

## 六、owned 所有权转移

```lz
//owned s: str = "hello"    // 错误，owned 只 修饰形参
def greet(owned name: str) = print(f"Hello, {name}!") // owned 只 修饰形参

s: str = "Alice" // 这个就是自带 owned
t = s^                    // 所有权转移给 t（后缀 ^ 标记移动）

//greet(s)                //ERROR, ❌ s 已被移动

greet(t)                // 编译通过,自动转移所有权，等同于 greet(t^)   



// print(t)               // ❌ t 已被移动
```

## 七、海象运算符 `:=`

在表达式中赋值并返回值：

```lz
if (n := compute()) > 0:
    print(n)
    print("positive")

// 等价于：
n = compute()
if n > 0:
    print(n)
    print("positive")

count = 0

def count_up() -> int = 
    count += 1
    count

while (n := count_up()) < 10:
    print(n)

```

## 八、错误语法边界

```lz
// ❌ let 绑定不可重新赋值
let x = 1
x = 2                       // 错误

// ❌ const 运行时赋值
const X: int = rand()       // 错误：运行时表达式，需用 comptime 包裹

// ❌ let owned 语义矛盾（解析器忽略 owned）
let owned s: str = "hi"     //错误： owned 只能修饰 形参

// ❌ 变量名与关键字冲突
let if = 1                  // 错误：if 是关键字
let match = 2               // 错误：match 是关键字
let test = 3                // 错误：test 是关键字
```
