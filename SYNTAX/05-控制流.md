# LZ 控制流

> 规范版本: 3.3 · 基于编译器源码 · 最后校订: 2026-08-05

本文档定义 Lang-Zone 的完整控制流语法：条件分支、模式匹配、循环、守卫、提前退出。

---

## 一、if / elif / else

### 1.1 基本语法

```lz
if condition:
    body
elif other_condition:
    body
else:
    body
```

- `if` / `elif` / `else` 后面冒号必须**换行 + 缩进**
- 每个分支体至少一个语句/表达式

### 1.2 作为表达式

```lz
let sign = if n > 0:
        "positive"
    elif n < 0:
        "negative"
    else:
        "zero"
```

每个分支的**尾表达式**作为该分支的值。全部分支必须返回相同类型。

### 1.3 单条件

```lz
if x > 0:
    print("positive")
```

### 1.4 三元条件表达式 `a if cond else b`

单行三元表达式，直接用于赋值或返回值：

```lz
status = "pass" if score >= 60 else "fail"

def sign(n: int) -> str =
    "positive" if n > 0 else "negative" if n < 0 else "zero"

let r = double(x) if x > 0 else 0
```

三元表达式中每个分支都是表达式，不需要 `return`。`elif` 不可用于三元，用嵌套 `else if`。

## 二、match / case

### 2.1 冒号形式

```lz
match expr:
    case pattern1:
        body1
    case pattern2:
        body2
    case _:
        default_body
```

### 2.2 胖箭头形式（内联）

```lz
match expr:
    case pattern1 => value1
    case pattern2 => value2
    case _ => default_value
```

### 2.3 模式类型

| 模式 | 语法 | 匹配 |
|------|------|------|
| 整数 | `case 0:` | 精确匹配 |
| 字符串 | `case "hello":` | 精确匹配 |
| 布尔 | `case True:` | 精确匹配 |
| 浮点 | `case 3.14:` | 精确匹配（按位比较） |
| 标识符 | `case x:` | 绑定到变量 |
| 变体 | `case Some(v):` | 解构匹配 |
| 元组 | `case (a, b):` | 解构匹配 |
| 列表 | `case [a, b, c]:` | 定长列表解构（`..` 表示其余，见下） |
| 字典 | `case {"k": v}:` | 键匹配 + 值绑定（未列出的键忽略） |
| 范围 | `case 1..=5:` | 闭区间匹配（`1..5` 为半开区间） |
| 类型守卫 | `case x if x is int:` | 匹配 + `if` 条件过滤（守卫） |
| 通配符 | `case _:` | 匹配一切 |
| 或模式 | `case 0 \| 1:` | 多模式合并（任一匹配，`\|`） |
| 引用绑定 | `case ref x:` | **不可变引用绑定**：匹配成功时 `x` 绑定为值的引用（`&T`），不转移所有权 |
| 可变引用绑定 | `case ref mut x:` | **可变引用绑定**：匹配成功时 `x` 绑定为值的可变引用（`&mut T`），不转移所有权 |

引用绑定模式细节：

- `ref x` / `ref mut x` 可出现在**任意模式位置**（变体字段、元组元素、嵌套模式），用于「匹配但不 move」的场景——迭代器/容器消费时借用元素。
- 与普通绑定 `case x`（move 绑定）相对：`case ref x` 不移动值，`x` 是 `&T`；`case ref mut x` 给出 `&mut T` 供原地修改。
- 例：`case Some(ref mut inner):` 匹配 `Option<J>` 内层迭代器并取得可变引用，供后续 `inner.__next__()` 推进。
- `ref mut` 对应 Rust 模式 `ref mut`；`ref` 对应 Rust `ref`。

列表模式细节：

- `case [a, b, c]` 匹配**恰好 3 个元素**的列表并依次绑定。
- `case [first, ..rest]` 匹配 1+ 元素：`first` 绑定首元素，`..rest` 绑定剩余列表；`..` 可省略绑定名（`case [_, ..]`）。
- `..` 在模式中只能出现一次。

守卫（`case x if cond:`）：`cond` 可用 `x` 及其后绑定，`False` 时落入下一分支，不尝试回溯（与整体 `guard` 语句正交，见 §7）。

**穷尽性规则**：

- match 要求**穷尽**：编译器检查所有可能的输入是否被覆盖。若可能无分支匹配且无 `case _`（或通配变量 `case x`）兜底 → **编译警告**（非错误），运行时无匹配时：表达式形式返回 `()`，语句形式直接跳过。
- 对 `enum` 类型（封闭变体集合），编译器可证明穷尽时不要求 `case _`；对开放类型（`int`/`str`/`List` 等）必须有兜底分支。

### 2.4 嵌套模式

```lz
match result:
    case Ok(Some(v)):
        print(f"got: {v}")
    case Ok(None):
        print("empty")
    case Err(e):
        print(f"error: {e}")
```

### 2.5 作为表达式

```lz
let desc = match color:
    case Red => "warm"
    case Blue => "cool"
    case _ => "unknown"
```

## 三、for 循环

### 3.1 基本语法

```lz
for variable in iterable:
    body
```

- 冒号后必须**换行 + 缩进**
- 循环变量默认可变

**迭代协议**：`for x in expr:` 要求 `expr` 满足 `IntoIterator`（映射 Rust `std::iter::IntoIterator`，见 [06d-内置魔法trait和全局函数.md](06d-内置魔法trait和全局函数.md) §一 / [99-内置预导入库.md](99-内置预导入库.md) §2.4）。内部流程：`let mut __it = expr.into_iter()`；每次迭代调用 `__it.next()`，返回 `Option<T>`——`Some(x)` 进入体，`None` 结束循环。`StopIteration` 由编译器自动处理（`Option` 语义，不抛异常）。

- 可迭代的内建类型：`List<T>`、`Range`（`0..n` / `0..=n`）、`Dict`（产出键值对元组）、`Set`、`str`（产出单字符）、生成器/迭代器本身（自身即 `IntoIterator`）。
- 循环变量**可解构**：`for (k, v) in dict:` 将每个迭代元素按元组解构绑定（元素是 `(K, V)` 时）。
- **循环变量作用域**：循环变量是循环体的局部变量，循环结束后**不再可见**（与 Rust 一致）；如需循环后使用结果，用 `sum`/`prod` 声明式（§3.4）、累积捕获变量或 `loop` 表达式带值（§6）。

### 3.2 遍历范围

```lz
for i in 0..10:
    print(i)           // 0 1 2 ... 9

for i in 0..=10:
    print(i)           // 0 1 2 ... 10
```

### 3.3 遍历集合

```lz
for x in [1, 2, 3]:
    print(x)

for (k, v) in dict:
    print(f"{k}: {v}")
```

### 3.4 声明式 for：sum / prod

```lz
let total = sum x in arr: x * x
let fact = prod i in 1..n: i
```

### 3.5 for / while 守卫（循环内过滤）

`for` 与 `while` 可在迭代/条件表达式之后附加一个 `if <cond>` 守卫，仅对满足条件的迭代执行循环体，等价于在体首插入 `if cond:` 但书写更扁平、意图更清晰：

```lz
def has(x: int) -> bool = True

// for 守卫：仅对满足 has(i) 的元素执行体
for i in [1, 2, 3, 4] if has(i):
    process(i)

// while 守卫：条件与守卫可叠加
while running if queue_size() > 0:
    step()
```

- 守卫 `if <cond>` 紧跟在迭代表达式（或 while 条件）之后、冒号之前。
- 语义等价于 `for i in items: if has(i): process(i)`，但更紧凑。
- 可与 `else:` 子句共存（循环正常结束且从未 `break` 时执行 else）。

```lz
for i in [1, 2, 3] if i > 1:
    print(i)
else:
    print("all filtered")
```

## 四、while 循环

### 4.1 基本语法

```lz
while condition:
    body
```

- 冒号后必须**换行 + 缩进**

```lz
i = 0
while i < 10:
    print(i)
    i += 1
```

### 4.2 for/while 的 else 子句

for 和 while 循环支持 `else` 子句：循环正常结束（非 break）时执行 else 体。

```lz
for variable in iterable:
    body
else:
    else_body     // 循环正常结束（非break）时执行

while condition:
    body
else:
    else_body     // 循环正常结束（非break）时执行
```

示例：

```lz
def find_index(arr: List<int>, target: int) -> () =
    for (i, val) in enumerate(arr):
        if val == target:
            print(f"found at {i}")
            break
    else:
        print("not found")
```

## 六、break / continue

> `break` 和 `continue` 无标签时仅作用于**最内层**循环/块；跨层跳出通过 **`block` 命名作用域** 的 `break NAME` / `continue NAME` 实现（详见 [05b-block命名块.md](05b-block命名块.md)）。

### 6.1 break

`break` 立即退出**当前最内层的可跳出构造**（`loop` / `for` / `while` / `block`）。支持留白、带标签、带值：

```lz
// 留白：退最内层循环/块
for x in xs:
    if x > 100:
        break
    print(x)

block A:
    break            // 退最内层 block A

// 带标签：跨层跳出（标签由 block 给出，详见 05b-block命名块.md）
block outer:
    for i in 0..10:
        if i == 7:
            break outer

// 带值（循环有效；block 不能带值，见 §6.3 与 05b §4.3）
let result = loop:
    if found:
        break with value        // 等价 break value：给最内层循环带值
let r = for i in xs:
    if i > 5:
        break with i            // r == i；循环正常结束则 r == ()
// 注意：带值跳出必须写 break with v 或 break NAME v（NAME 为循环标签）；
// break v（无 with、无 NAME）会被解析为 break NAME，v 被当作标签名 → 编译错误（见 05b §4.3.1）
```

**循环表达式的类型规则**（`loop` / `for` / `while` 均为表达式，值由 `break [NAME] [value]` 决定）：

- **所有 `break` 均不带值** → 循环类型 `()`
- **所有 `break value` 的值类型相同** → 循环类型为该统一类型
- **`break value` 的值类型不同** → 存在公共父类型则用父类型，否则编译期报错
- **既有无值 `break` 又有有值 `break`** → 循环类型 `Option<T>`，无值 `break` 等价于 `break None`

```lz
// 示例: loop 作为表达式
let answer = loop:
    for i in 0..10:
        if i == 7:
            break with i      // loop 类型 -> int
// answer == 7
```

### 6.2 continue

`continue` 立即跳到当前循环的下一轮迭代：

```lz
for x in xs:
    if x < 0:
        continue
    print(x)
```

支持 `continue expr` 带值形式（仅 loop 体中有效）：
- `continue expr` 的 `expr` 值传递给 `loop` 的**下一轮迭代起始**，作为该轮 `loop` 表达式的初始值代入。
- 若 loop 体未以 `break` 终止而靠 `loop` 自然结束，`continue expr` 的值不参与最终结果类型推断。

支持 `continue NAME` 带标签形式：`NAME` 为 `block` / `for` / `while` / `loop` 标签时，续跑该标签所指的**循环**下一轮；`NAME` 指向 block 时编译错误（block 非迭代器）。标签由 `block NAME:` 给出（详见 [05b-block命名块.md](05b-block命名块.md) §4.4）。

### 6.3 break / continue 带标签

跨层跳出由 **`block` 命名作用域**提供。标签由 `block NAME:` 给出，`break NAME` / `continue NAME` 指定层级：

```lz
block outer:                 // 标签 outer 由 block 给出
    for i in 0..10:
        for j in 0..10:
            if i * j > 50:
                break outer  // 跳出 outer（含两层 for）
            print(i, j)
```

- `break NAME` 跳出标签 `NAME` 所指的 block/循环；`NAME` 须为 break 点的词法祖先（跳兄弟块非法）。
- **block 的 `break NAME` 不带值**；带值跳出（`break NAME v`，无 `with`）仅当 `NAME` 指向循环（loop/for/while）时合法，此时 `v` 成为该循环表达式的值。block 的「带参复用」用 `break NAME with v`（`v` 为 `__Params`，重入该块一次，不跳出循环，见 [05b-block命名块.md](05b-block命名块.md) §4.3）。
- `continue NAME` 续跑标签所指的循环下一轮（block 不能作为 continue 目标）。
- 标签命名空间与变量独立；同作用域内标签名唯一。完整细则见 [05b-block命名块.md](05b-block命名块.md)。

```lz
def skip_negatives(xs: List<int>) =
    total = 0
    for x in xs:
        if x < 0:
            continue
        total += x
    total
```

## 七、guard 守卫

### 7.1 guard 条件守卫

```lz
guard cond else ACTION   // ACTION 是失败路径要执行的「早退/吞吐」动作
guard cond else:
    handler_body          // 块形式：当 cond 为 False 时执行，体末尾隐式 return（默认失败动作）

continuation_body        // 当 cond 为 True 时继续
```

**默认失败动作 = `return`**。`guard` 语义是「前置断言」：条件 `cond` 为 **True 则放行**继续后续；为 **False 则走失败路径**。失败路径的默认动作，以及它**能出现在哪里**，按下面规则：

- **默认 `return`**：`guard cond else ...` 中的 `...` 若未显式写动作，则**默认是 `return`**（函数提前退出；在块/顶层无 `return` 语义处则隐式「中止当前体并向上返回」）。
- **`guard cond else return ...` / `guard cond else ...`（省略 return）**：等价「条件不满足就 return」。
- **循环体内须用 `guard ... else break/continue`**：在 `for`/`while`/`loop` 体内，默认 `return` 语义不适合（或本意就是跳出循环），必须**显式覆盖**为 `break`/`continue`——`guard cond else break ...` 表示「不满足就跳出循环」，覆盖掉默认 return；`guard cond else continue ...` 表示「不满足就跳到下一轮」。
- **`guard cond else yield ...`**：**仅生成器（`iterator` / 生成器构建块 `*:`）中**可用，`else` 后可跟 `yield`，表示「不满足就产出」（普通 `def` 中 `yield` 非法，见 [14-生成器.md](14-生成器.md) §2.2）。
- **使用范围**：`guard` 可在**任意作用域**使用——函数体、循环体、命名块 `block` 体、**顶层**均可。在「非函数」作用域（循环体、块体、顶层），默认失败动作 `return` 无意义，因此**必须显式给出动作**（`break` / `continue` / `yield` / 对块用 `break NAME` / 对顶层用 `raise` 或 `panic` 中止脚本等）。**顶层直接 `return` 非法**（见 [附录B](附录B-关键字保留字符号语法边界.md) §四），顶层 guard 的失败动作不能用 `return`。

| 写法 | 失败动作 | 适用作用域 | 说明 |
|------|----------|------------|------|
| `guard cond else` / `guard cond else return v` | `return`（默认） | 函数体为主 | 不满足 → 函数提前退出 |
| `guard cond else break` / `break label` | `break`（覆盖默认） | 循环体 | 不满足 → 跳出循环（覆盖 return） |
| `guard cond else continue` | `continue`（覆盖默认） | 循环体 | 不满足 → 跳下一轮 |
| `guard cond else yield v` | `yield`（覆盖默认） | 生成器内（`iterator`/`*:`） | 不满足 → 产出 |
| `guard cond else:`（块） | 块末尾隐式 `return` | 函数体为主 | 块形式失败路径 |

- `guard cond else:`（块形式）冒号后必须**换行 + 缩进**；块体是失败路径，可用 `return` 退出函数、可用尾表达式求值，也可用 `break`/`continue`/`yield` 覆盖默认 `return`。
- 单行形式 `guard cond else ACTION` 中 `else` 后不换行，直接跟动作/表达式（动作即 `return`/`break`/`continue`/`yield` 之一，或纯表达式默认按 `return` 处理）。
- 单行形式中，`else` 后若是**纯表达式**（如 `else 0`），默认按 `return 0` 处理；若要跳出循环则必须写 `else break`，要产出则 `else yield x`。
- guard 通过后继续执行后续代码。

```lz
// ① 函数内：失败路径默认 return
def safe_div(a: int, b: int) -> int =
    guard b != 0 else:        // 块形式失败路径
        return 0             // 显式 return（块内也可用尾表达式求值）
    a / b

def safe_div2(a: int, b: int) -> int =
    guard b != 0 else 0       // 单行：else 后纯表达式 → 等价于 if b == 0: return 0
    a / b

// ② 循环体内：必须覆盖默认 return，用 break / continue
for x in xs:
    guard x > 0 else continue   // 不满足 → 跳下一轮（覆盖默认 return）
    guard x < 100 else break    // 不满足 → 跳出循环（覆盖默认 return）
    process(x)

// ③ 生成器内：else 后跟 yield（生成器用 iterator 关键字声明，见 14-生成器.md）
iterator evens(xs: List<int>) -> int =
    for x in xs:
        guard x % 2 == 0 else yield -1   // 不满足 → 产出 -1（覆盖默认 return）
        yield x

// ④ 放宽到块体 / 顶层：非函数作用域必须显式给动作
block Check[ps: __Params]:
    guard ps.args[0] > 0 else break Check   // 块内：失败 → break 该块（无 return 语义，须显式）
out = []
guard len(out) < 10 else raise ValueError("too many")   // 顶层：失败 → raise 中止脚本（顶层不可 return）
```

> `cond` 支持 truthiness 判定链（`__bool__` → `__len__` → 默认 true`），详见 [06g-魔法综合.md §九](06g-魔法综合.md)。

### 7.2 guard let 模式守卫

```lz
guard let PATTERN = expr else:
    handler_body

// pattern 匹配失败 → 执行 else 体
// pattern 匹配成功 → 变量绑定，继续执行
```

```lz
def greet_user(name: Option<str>) =
    guard let Some(n) = name else:
        print("no name")
        // return  // 可省略，函数尾表达式隐式返回
    print(f"hello {n}")
```

> `guard let` 同样适用 §7.1 的规则：失败路径默认 `return`，在循环体/块体/顶层须显式覆盖（`break`/`continue`/`yield`/`break NAME`），可在任意作用域使用。

### 7.3 while let 模式循环

```lz
while let PATTERN = expr:
    body
```

- **语义**：反复求值 `expr` 并尝试模式匹配——`PATTERN` 匹配成功则绑定变量、执行 `body`、进入下一轮；匹配失败（`PATTERN` 不匹配）则**结束循环**（等价 `guard let` 失败路径 `break`）。
- **用途**：迭代器消费循环（每次 `next()` 产出 `Option`/`Result`，成功则继续），等价 Rust `while let`。
- 模式种类与 `match`/`guard let` 一致（变体解构、元组、绑定、通配 `_`）。

```lz
def sum_all(it: Iterator<int>) -> int =
    total = 0
    while let Some(item) = it.next():
        total += item
    total

// Result 版本：遇到 Err 结束循环
while let Ok(v) = parse_each():
    use(v)
```

- **与 `for` 分工**：`for x in it:` 遍历 `IntoIterator` 容器；`while let` 显式控制迭代（手写 `next()` 与模式），适合需要中途 break、或基于 `Result` 迭代的场景。
- `while let` 的 `PATTERN` 匹配失败时无 else 分支（静默结束）；需要失败处理用 `guard let` + `else`。

## 八、return

```lz
return expr            // 带值返回
return                 // 仅 () 函数中合法
```

- 块体**尾表达式**自动作为返回值，不需要显式 `return`
- 显式 `return` 用于提前退出

## 九、pass 空操作

```lz
if cond:
    pass               // 占位，什么都不做
else:
    action()
```

`pass` 求值为 `()`（单元值），可在任何需要语句的位置使用：

```lz
def todo() -> () = pass          // 占位函数体
match x:
    case Some(v) => process(v)
    case None => pass            // 什么都不做，表达式返回 ()
```

## 十、with 上下文管理器

```lz
with expr:
    body               // expr 的资源在 body 中可用，结束时自动清理
```

```lz
with open("file.txt") as f:
    content = f.read()
    print(content)
// f 在这里自动关闭
```

`with` 依赖魔法方法 `__enter__`（进入块时调用）和 `__exit__`（退出块时调用）。实现这两个方法的 struct 即可用于 `with` 语句。

> 详见 **[06d-内置魔法trait](06d-内置魔法trait和全局函数.md)** §十七 上下文管理器。

```lz
struct MyFile =
    path: str
    def __enter__(self) -> File =
        open(self.path)
    def __exit__(mut self, file: File) =
        file.close()

with MyFile(path: "data.txt") as f:
    process(f)
```

## 十一、defer 延迟执行

```lz
defer:
    cleanup()          // 当前作用域结束时执行（LIFO）

defer file.close()     // 单行形式，直接跟表达式
```

```lz
def process() =
    file = open("data.txt")
    defer:
        file.close()
    // ... 处理文件 ...
    // 函数返回前自动执行 file.close()
```

多个 defer 按**后进先出**（LIFO）顺序执行。

## 十二、错误语法边界

```lz
// ❌ while 冒号后不换行
while True: print("...")     // 错误

// ❌ for 冒号后不换行
for x in xs: print(x)        // 错误

// ❌ guard let else 不换行
guard let Some(v) = opt else: return     // 错误：guard let 不支持单行

// ✅ 但 guard 条件守卫支持单行（见 §7.1）
// guard b != 0 else 0              // 合法：else 纯表达式 → 默认 return 0
// guard x > 0 else continue       // 合法：循环体内覆盖默认 return → continue
// guard x < 100 else break        // 合法：循环体内覆盖默认 return → break
// guard x % 2 == 0 else yield -1  // 合法：生成器内 → yield

// ❌ match case 缺少模式
match x:
    case:                     // 错误：缺少 pattern

// ❌ break / continue 在循环外
break                        // 错误：不在循环中
continue                     // 错误：不在循环中

// ❌ return 在等式体中多余
def f() = return 42           // 错误：等式体不需要 return

// ❌ guard 条件表达式缺少比较
guard x:                      // 错误：guard 条件必须是 bool 表达式
    ...
```

## 十三、`else` 关键字用法汇总

`else` 在 LZ 中可用于四种控制流结构。`loop` 不支持 `else`。

### 13.1 if/else

```lz
if score >= 60:
    print("pass")
else:
    print("fail")
```

> §一 详述。

### 13.2 for/else

`for` 循环**正常结束**（非 `break` 退出）时执行 `else` 体：

```lz
def find(arr: List<int>, target: int) =
    for (i, val) in enumerate(arr):
        if val == target:
            print(f"found at {i}")
            break
    else:
        print("not found")
```

### 13.3 while/else

`while` 循环条件变为假时执行 `else` 体（`break` 退出则跳过）：

```lz
n = 5
while n > 0:
    print(n)
    n -= 1
else:
    print("done")
```

### 13.4 try/else

`try` 块成功执行（未触发异常）后执行 `else` 体：

```lz
try:
    let data = read_file("config.json")
catch IOError:
    print("file not found")
else:
    print(f"loaded {data.len()} bytes")
```

> 详见 **[09-错误处理](09-错误处理.md)** §3.4。

### 13.5 对照表

| 结构 | else 触发条件 | else 跳过条件 |
|------|------|------|
| `if/else` | 条件为假 | 条件为真 |
| `for/else` | 循环正常结束 | `break` 退出 |
| `while/else` | 条件变为假 | `break` 退出 |
| `try/else` | try 成功 | 异常抛出 |
| `loop` | ❌ 不支持 | — |
