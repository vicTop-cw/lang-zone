# LZ 控制流

> 版本: 3.1 · 基于编译器源码 · 2026-07-27

本文档定义 Lang-Zong 的完整控制流语法：条件分支、模式匹配、循环、守卫、提前退出。

---

## 一、if / elif / else

### 1.1 基本语法

```lz
if condition:
    body
elif other_condition:
    body
else:
    body
```

- `if` / `elif` / `else` 后面冒号必须**换行 + 缩进**
- 每个分支体至少一个语句/表达式

### 1.2 作为表达式

```lz
let sign = if n > 0:
        "positive"
    elif n < 0:
        "negative"
    else:
        "zero"
```

每个分支的**尾表达式**作为该分支的值。全部分支必须返回相同类型。

### 1.3 单条件

```lz
if x > 0:
    print("positive")
```

## 二、match / case

### 2.1 冒号形式

```lz
match expr:
    case pattern1:
        body1
    case pattern2:
        body2
    case _:
        default_body
```

### 2.2 胖箭头形式（内联）

```lz
match expr:
    case pattern1 => value1
    case pattern2 => value2
    case _ => default_value
```

### 2.3 模式类型

| 模式 | 语法 | 匹配 |
|------|------|------|
| 整数 | `case 0:` | 精确匹配 |
| 字符串 | `case "hello":` | 精确匹配 |
| 布尔 | `case True:` | 精确匹配 |
| 标识符 | `case x:` | 绑定到变量 |
| 变体 | `case Some(v):` | 解构匹配 |
| 元组 | `case (a, b):` | 解构匹配 |
| 通配符 | `case _:` | 匹配一切 |

### 2.4 嵌套模式

```lz
match result:
    case Ok(Some(v)):
        print(f"got: {v}")
    case Ok(None):
        print("empty")
    case Err(e):
        print(f"error: {e}")
```

### 2.5 作为表达式

```lz
let desc = match color:
    case Red => "warm"
    case Blue => "cool"
    case _ => "unknown"
```

## 三、for 循环

### 3.1 基本语法

```lz
for variable in iterable:
    body
```

- 冒号后必须**换行 + 缩进**
- 循环变量默认可变

### 3.2 遍历范围

```lz
for i in 0..10:
    print(i)           // 0 1 2 ... 9

for i in 0..=10:
    print(i)           // 0 1 2 ... 10
```

### 3.3 遍历集合

```lz
for x in [1, 2, 3]:
    print(x)

for (k, v) in dict:
    print(f"{k}: {v}")
```

### 3.4 声明式 for：sum / prod

```lz
let total = sum x in arr: x * x
let fact = prod i in 1..n: i
```

## 四、while 循环

### 4.1 基本语法

```lz
while condition:
    body
```

- 冒号后必须**换行 + 缩进**

```lz
i = 0
while i < 10:
    print(i)
    i += 1
```

### 4.2 for/while 的 else 子句

for 和 while 循环支持 `else` 子句：循环正常结束（非 break）时执行 else 体。

```lz
for variable in iterable:
    body
else:
    else_body     // 循环正常结束（非break）时执行

while condition:
    body
else:
    else_body     // 循环正常结束（非break）时执行
```

示例：

```lz
def find_index(arr: List<int>, target: int) -> () =
    for (i, val) in enumerate(arr):
        if val == target:
            print(f"found at {i}")
            break
    else:
        print("not found")
```

## 五、loop 无限循环

```lz
loop:
    body         // 持续执行直到 break
```

```lz
i = 0
loop:
    if i >= 10:
        break
    print(i)
    i += 1
```

## 六、break / continue

### 6.1 break

```lz
for x in xs:
    if x > 100:
        break
    print(x)
```

`break` 可以带值（从循环返回）：

```lz
let result = loop:
    if found:
        break value
```

### 6.2 continue

```lz
for x in xs:
    if x < 0:
        continue
    print(x)
```

### 6.3 continue 带值

```lz
def skip_negatives(xs: List<int>) =
    total = 0
    for x in xs:
        if x < 0:
            continue             // 跳过，继续下一轮
        total += x
    total
```

`continue` 立即跳到循环的下一轮迭代，不执行后续语句。支持 `continue expr` 带值形式（仅 loop 体中有效）。

## 七、guard 守卫

### 7.1 guard 条件守卫

```lz
guard cond else:
    handler_body          // 当 cond 为 False 时执行

continuation_body        // 当 cond 为 True 时继续
```

- `guard cond else:` 冒号后必须**换行 + 缩进**
- else 体是失败路径，其中是否用 `return` 取决于你的意图：需提前退出函数时使用 `return`，否则 else 体末尾表达式即为 guard 整体的值（如 guard 是表达式上下文）
- guard 通过后继续执行后续代码

```lz
def safe_div(a: int, b: int) -> int =
    guard b != 0 else:
        return 0          // 提前退出函数
    a / b
```

### 7.2 guard let 模式守卫

```lz
guard let PATTERN = expr else:
    handler_body

// pattern 匹配失败 → 执行 else 体
// pattern 匹配成功 → 变量绑定，继续执行
```

```lz
def greet_user(name: Option<str>) =
    guard let Some(n) = name else:
        print("no name")
        // return  // 可省略，函数尾表达式隐式返回
    print(f"hello {n}")
```

## 八、return

```lz
return expr            // 带值返回
return                 // 仅 () 函数中合法
```

- 块体**尾表达式**自动作为返回值，不需要显式 `return`
- 显式 `return` 用于提前退出

## 九、pass 空操作

```lz
if cond:
    pass               // 占位，什么都不做
else:
    action()
```

`pass` 求值为 `()`（单元值），可在任何需要语句的位置使用：

```lz
def todo() -> () = pass          // 占位函数体
match x:
    case Some(v) => process(v)
    case None => pass            // 什么都不做，表达式返回 ()
```

## 十、with 上下文管理器

```lz
with expr:
    body               // expr 的资源在 body 中可用，结束时自动清理
```

```lz
with open("file.txt") as f:
    content = f.read()
    print(content)
// f 在这里自动关闭
```

`with` 依赖魔法方法 `__enter__`（进入块时调用）和 `__exit__`（退出块时调用）。实现这两个方法的 struct 即可用于 `with` 语句。

> 详见 **[06d-内置魔法trait](06d-内置魔法trait和全局函数.md)** §十六 上下文管理器。

```lz
struct MyFile = path: str
    def __enter__(self) -> File =
        open(self.path)
    def __exit__(self, file: File) =
        file.close()

with MyFile(path: "data.txt") as f:
    process(f)
```

## 十一、defer 延迟执行

```lz
defer:
    cleanup()          // 当前作用域结束时执行（LIFO）
```

```lz
def process() =
    file = open("data.txt")
    defer:
        file.close()
    // ... 处理文件 ...
    // 函数返回前自动执行 file.close()
```

多个 defer 按**后进先出**（LIFO）顺序执行。

## 十二、错误语法边界

```lz
// ❌ if / elif / else 冒号后不换行
if x > 0: print(x)           // 错误

// ❌ while 冒号后不换行
while True: print("...")     // 错误

// ❌ for 冒号后不换行
for x in xs: print(x)        // 错误

// ❌ guard else 冒号后不换行
guard x > 0 else: return     // 错误

// ❌ match case 缺少模式
match x:
    case:                     // 错误：缺少 pattern

// ❌ break / continue 在循环外
break                        // 错误：不在循环中
continue                     // 错误：不在循环中

// ❌ return 在等式体中多余
def f() = return 42           // 错误：等式体不需要 return

// ❌ guard 条件表达式缺少比较
guard x:                      // 错误：guard 条件必须是 bool 表达式
    ...
```

## 十二、`else` 关键字用法汇总

`else` 在 LZ 中可用于四种控制流结构。`loop` 不支持 `else`。

### 12.1 if/else

```lz
if score >= 60:
    print("pass")
else:
    print("fail")
```

> §一 详述。

### 12.2 for/else

`for` 循环**正常结束**（非 `break` 退出）时执行 `else` 体：

```lz
def find(arr: List<int>, target: int) =
    for (i, val) in enumerate(arr):
        if val == target:
            print(f"found at {i}")
            break
    else:
        print("not found")
```

### 12.3 while/else

`while` 循环条件变为假时执行 `else` 体（`break` 退出则跳过）：

```lz
n = 5
while n > 0:
    print(n)
    n -= 1
else:
    print("done")
```

### 12.4 try/else

`try` 块成功执行（未触发异常）后执行 `else` 体：

```lz
try:
    let data = read_file("config.json")
catch IOError:
    print("file not found")
else:
    print(f"loaded {data.len()} bytes")
```

> 详见 **[09-错误处理](09-错误处理.md)** §3.4。

### 12.5 对照表

| 结构 | else 触发条件 | else 跳过条件 |
|------|------|------|
| `if/else` | 条件为假 | 条件为真 |
| `for/else` | 循环正常结束 | `break` 退出 |
| `while/else` | 条件变为假 | `break` 退出 |
| `try/else` | try 成功 | 异常抛出 |
| `loop` | ❌ 不支持 | — |
