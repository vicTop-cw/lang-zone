# LZ 函数泛型

> 规范版本: 3.3 · 基于编译器源码 · 最后校订: 2026-09-14

本文档定义 Lang-Zone 的泛型函数语法：基本泛型参数、带约束的泛型（通过 `where` 子句）、where 子句、泛型默认参数类型，以及编译期形参 `comptime`。

---

## 一、基本泛型

```lz
def identity<T>(x: T) -> T = x
def first<T>(a: T, b: T) -> T = a
```

## 二、带约束的泛型

约束不写在尖括号内，统一通过 `where` 子句表达：

```lz
def larger<T>(a: T, b: T) -> T
    where T: Ordered =
    if a > b:
        a
    else:
        b
```

## 三、where 子句

```lz
def clone_all<T>(items: List<T>) -> List<T>
    where T: Clone =
    result = []
    for item in items:
        result.push(item.clone())
    result
```

## 四、泛型默认参数类型

```lz
def make_pair<T = int>(x: T, y: T) -> (T, T) =
    (x, y)
```

## 五、编译期形参 `comptime`

在形参名前加 `comptime`，要求该形参的**实参在编译期已知**（字面量、`const` 常量、其他 comptime 结果）。

```lz
def repeat(comptime n: int, s: str) -> str = ...
```

- **约束**：调用时，`comptime` 形参对应的实参必须是编译期已知值，否则在**调用点**报编译错误。
- **函数体**：该形参在函数体内视为编译期已知符号，可在 `comptime:` 块 / `const` 初始化上下文中使用。
- **特化**：调用点按实参真值特化函数，该值被内联"焊死"进函数体（不同实参 → 不同特化实例）。
- **不传染**：约束不沿调用链自动传播；调用方若把自身参数转发给它，需自行加 `comptime`（逐层显式，Rust const 泛型式）。
- **与 `comptime def` 的区别**：`comptime def` 是**整函数编译期**、运行时不可调用（见 [08b](08b-comptime编译期.md) §4.3）；形参 `comptime` 只约束**个别形参**，函数本身仍是普通运行时函数。

```lz
const N = 8

def f(comptime size: int) = ...

f(N)               // ✅ 实参为 const，编译期已知
f(3 + 2)           // ✅ 字面量表达式，编译期可求
f(comptime 5 * 5)  // ✅ 其他 comptime 结果

def caller(x: int) =
    f(x)           // ❌ x 运行时已知 → 调用点编译错误
```

## 六、错误语法边界

```lz
// ❌ 泛型尖括号与函数名/参数间有空格
def foo <T> (x: T) = x     // 错误：`<T>` 必须紧贴函数名且其后无空格（正确：def foo<T>(x: T) = ...）

// ✅ 泛型参数标注（无注解参数默认 int，见 03-函数基础 §3.2）
def bar<T>(x: T) = x         // x 以泛型参数 T 注解

// ❌ 约束使用未定义的 trait
def baz<T>(x: T) where T: NonExistent = x  // 错误：NonExistent trait 未定义
```
