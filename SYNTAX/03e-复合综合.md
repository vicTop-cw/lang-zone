## 一、函数嵌套

### 1.1 内嵌函数定义

```lz
def outer(x: int) -> int =
    def inner(y: int) -> int =
        x + y
    inner(x + 1)

outer(1)   // 3
```

内嵌函数可以捕获外层函数的变量（闭包语义）。

### 1.2 内嵌类型别名

```lz
def process() =
    type Id = int
    let x: Id = 42
    x
```

## 二、装饰器

### 2.1 语法

```lz
@decorator_name
def f() = ...

@decorator_with_args(arg1, arg2)
def g() = ...

// 多个装饰器叠加（从上到下应用）
@bench
@log
def h() = ...
```

### 2.2 内置装饰器

| 装饰器 | 用途 | 状态 |
|--------|------|:---:|
| `@export(Rust)` | 导出为 Rust `pub fn`，可生成 cdylib | ✅ 已实现 |
| `@export(Python)` | 导出为 PyO3 `#[pyfunction]` | ✅ 已实现 |
| `@memoize` | 自动缓存（`OnceLock<HashMap>`） | ✅ 已实现 |
| `@math` | Number trait 多态标记 | ✅ 已实现 |
| `@simd` | `#[inline(always)]` | 🔧 设计阶段 |
| `@parallel` | rayon 候选标记 | 🔧 设计阶段 |
| `@tail_call` | TCO 保证标记 | 🔧 设计阶段 |
| `@unsafe` | strict 模式豁免 | 🔧 设计阶段 |
| `@overload` | 预留多分派 | 🔧 设计阶段 |

```lz
@export(Rust)
def add(a: int, b: int) -> int = a + b

@memoize
def fib(n: int) -> int =
    if n <= 1:
        n
    else:
        fib(n - 1) + fib(n - 2)

@math
def sq(x, y) = x * x + y * y
```

### 2.3 装饰器使用示例

**@overload — 多分派**（预留）：
```lz
@overload(int)
def process(x: int) -> str = f"int: {x}"

@overload(str)
def process(x: str) -> str = f"str: {x}"
```

**@tail_call — 尾调用优化**：
```lz
@tail_call
def factorial(n: int, acc: int = 1) -> int =
    if n <= 1:
        acc
    else:
        factorial(n - 1, acc * n)
```

**@simd — SIMD 内联优化**：
```lz
@simd
def vector_add(a: List<f64>, b: List<f64>) -> List<f64> =
    [a[i] + b[i] for i in 0..a.length()]
```

**@parallel — 并行执行**：
```lz
@parallel
def heavy_computation(data: List<int>) -> int =
    sum x for x in data
```

**@unsafe — strict 模式豁免**：
```lz
@unsafe
def raw_pointer_op(ptr: int) -> int =
    // 绕过 borrow checker 的原生指针操作
    ptr
```

## 三、闭包

### 3.1 管道闭包

```lz
|x| x + 1                    // 单参数
|x, y| x + y                 // 多参数
|a, b| a > b                 // 返回 bool
```

### 3.2 赋值给变量

```lz
let double = |x| x * 2
print(double(5))             // 10
```

### 3.3 作为参数传递

```lz
def apply(f: fn(int) -> int, x: int) -> int =
    f(x)

apply(|x| x + 1, 5)          // 6
```

### 3.4 多行闭包体

```lz
let compute = |a, b|
    c = a + b
    c * c

print(compute(3, 4))         // 49
```

## 四、错误语法边界

```lz
// ❌ 装饰器缺少参数
@export
def f() = 42                    // 错误：@export 必须指定目标，如 @export(Rust)

// ❌ 闭包捕获运行时变量用于 comptime
comptime:
    let cap = outer_var          // 错误：outer_var 运行时不存在

// ❌ 闭包使用 yield（yield 必须在函数体顶层）
def f() =
    let g = || yield 1           // 错误：yield 嵌套在闭包内
```
