# LZ 并发与异步

> 版本: 3.1 · 基于编译器源码 · 2026-07-27

本文档定义 Lang-Zong 的并发与异步语法：`async`/`await`、`spawn`、`go` 并行进程。

---

## 一、async / await

### 1.1 async 函数定义

```lz
async def fetch_data(id: int) -> str =
    "data_" + id.to_str()
```

- `async def` 定义异步函数，返回 future
- 异步函数可以调用其他异步函数

### 1.2 await 等待

```lz
async def fetch_all() -> str =
    let a = await fetch_data(1)
    let b = await fetch_data(2)
    a + " + " + b
```

- `await` 只能在 `async` 函数中使用
- `await` 暂停当前异步函数执行直到结果就绪

### 1.3 从同步函数调用

```lz
def main() =
    // spawn 启动异步任务
    let f1 = spawn fetch_data(10)
    let f2 = spawn fetch_data(20)

    // await 等待结果
    let r1 = await f1
    let r2 = await f2
    print(r1)               // "data_10"
    print(r2)               // "data_20"
```

## 二、spawn 并发

`spawn` 启动异步任务，返回 `Future<T>`。

### 2.1 内联语法

```lz
spawn function_call(args)           // 启动异步任务，返回 Future<T>
```

### 2.2 赋值给变量

```lz
let task: Future<str> = spawn fetch_data(10)
// ... 其他工作 ...
let result = await task              // 等待并获取结果
```

### 2.3 块语法（冒号 + 换行缩进）

```lz
let task = spawn:
    let data = prepare()
    fetch_data(data)
// 块末尾表达式作为 spawn 的返回，task: Future<T>
```

块语法支持多语句，末尾表达式为异步执行的结果。

### 2.4 多任务并发

```lz
let t1 = spawn download("url1")
let t2 = spawn download("url2")
let t3: Future<str> = spawn:
    let u = build_url()
    download(u)

let results = [await t1, await t2, await t3]
```

### 2.5 Futures 聚合

```lz
// 并发等待多个 Future
let tasks: Futures<str, str, int> = [
    spawn fetch_data(1),
    spawn fetch_data(2),
    spawn compute_all()
]
let results = await tasks            // 并发等待所有完成
```

| 类型 | 说明 |
|------|------|
| `Future<T>` | 单个异步任务的句柄 |
| `Futures<T1, T2, ...>` | 多个 Future 聚合，`await` 并发等待 |

## 三、go 并行进程

`go` 启动独立进程（非线程），适合 CPU 密集型任务。返回 `Future<T>`，与 `spawn` 用法一致。

### 3.1 内联语法

```lz
go function_call(args)              // 启动进程，返回 Future<T>
```

### 3.2 赋值给变量

```lz
let worker: Future<int> = go heavy_computation(data)
// ... 其他工作 ...
let result = await worker            // 等待进程完成
```

### 3.3 块语法

```lz
let worker = go:
    let config = load_config()
    let data = prepare(config)
    heavy_computation(data)
// worker: Future<int>
```

### 3.4 spawn vs go

| | spawn | go |
|------|-------|----|
| 启动 | 异步任务（线程） | 独立进程 |
| 适合 | I/O 密集型 | CPU 密集型 |
| 返回值 | `Future<T>` | `Future<T>` |
| 用法 | `spawn fn()` / `spawn: ...` | `go fn()` / `go: ...` |

## 四、错误语法边界

```lz
// ❌ await 在非 async 函数中使用（无 spawn 包装）
def sync_fn() =
    await async_fn()          // 错误：需用 spawn 启动

// ❌ spawn 非函数调用
spawn 42                     // 错误：spawn 后必须是调用

// ❌ async 函数作为 spawn 参数
spawn async def f(): ...      // 错误：spawn 接受调用而非定义
```
