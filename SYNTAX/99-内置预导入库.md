# LZ 内置预导入库（Prelude 设计）

> 规范版本: 3.3 · 基于编译器源码 · 最后校订: 2026-08-04

本文档定义 LZ 编译后项目**默认自动导入**的内置 API。这些 API 无需任何 `import` 即可直接使用，编译器在生成的 `.rs` 文件头部自动注入对应的 `use` 语句。

---

## 一、设计原则

| 原则 | 说明 |
|------|------|
| **最小化** | prelude 只包含"几乎所有程序都会用到"的符号，避免命名空间污染 |
| **透明映射** | 每一个 prelude 项都对应一个 Rust 标准库路径，零运行时开销 |
| **增量可用** | Rust crate 未实现的功能可以"先声明后实现"，prelude 条目不受限制 |
| **可覆盖** | 用户可以显式 `import` 同名模块，覆盖 prelude 默认符号 |

## 三、LZ 自有内置类型（编译器注入，非 Rust std）

以下类型不属于 Rust 标准库，由 LZ 编译器在 codegen 阶段**自动注入**到生成的 `.rs` 文件中。它们对 LZ 代码透明可用，无需显式 import。

### 3.1 构建块运行时

| 类型 | 说明 | 注入条件 |
|------|------|:---:|
| `__Pack` | 构建块参数包枚举（`Tuple` / `Dict` / `Single`） | 含构建块时注入 |
| `IterStopException` | 生成器构建块终止信号 | 含 `*:` 构建块时注入 |
| `BuildParams` trait | 构建块参数协议：`fn into_args(self) -> __Pack` | 魔法方法 `__buildparams__` 触发 |

```rust
// 编译器自动生成（含构建块的模块）：
pub enum __Pack {
    Tuple(Vec<Box<dyn std::any::Any>>),
    Dict(std::collections::HashMap<String, Box<dyn std::any::Any>>),
    Single(Box<dyn std::any::Any>),
}
pub struct IterStopException;

pub trait BuildParams {
    fn into_args(self) -> __Pack;
}
```

### 3.2 策略系统

| 类型 | 说明 | 注入条件 |
|------|------|:---:|
| `Strategy` trait | 统一策略抽象基 trait（关联类型 `Host`） | 含策略符号时注入 |
| `CloneStrategy` trait | 克隆策略：`fn clone_of(&self, src: &Host) -> Host` | 含 `__clone__` 等 |
| `DestroyStrategy` trait | 析构策略：`fn destroy(&self, target: Host)` | 含 `__drop__` 等 |
| `SerializeStrategy` trait | 序列化策略：`fn encode/decode` | 含序列化魔法 |
| `IterStrategy` trait | 迭代策略：`fn iterate(&self, src: &Host) -> Box<dyn Iterator<Item=Item>>` | 含 `__iter_strategy__` |
| `IterStrategyKind` | 内置迭代策略枚举 | 含迭代策略符号 |
| `StrategyKind` | 策略解析枚举（`Clone`/`Destroy`/`Serialize`/`Iter`/...） | 含策略符号 |
| `__iter_resolve()` | 策略解析器：按优先级取首个适用策略包裹 base 迭代器 | 含迭代策略符号 |
| `history_strategy` | 历史策略：保留并重放迭代历史 | 含 `History` 策略 |

**`IterStrategyKind` 枚举变体**：

| 变体 | 说明 |
|------|------|
| `Forward` | 正向迭代（保持惰性） |
| `Reverse` | 反向迭代（collect 后 .rev()） |
| `Strided(i64)` | 步进迭代（collect 后 .step_by()） |
| `Controlled` | 可控迭代（包裹 `Itor`，支持暂停/跳转） |
| `Collected` | 收集迭代（非惰性，collect 为 Vec 再迭代） |
| `Historized` | 历史迭代（记录已迭代元素） |
| `Indexed` | 索引迭代（按索引访问） |
| `Chunked(usize)` | 分块迭代 |
| `Infinite` | 无限迭代 |

### 3.3 可控迭代器

| 类型 | 函数 | 说明 |
|------|------|------|
| `Itor<T>` | `itor(iter)` / `__itor_from(iter)` | 线程安全可控迭代器 |
| `ItorState` | — | 迭代器状态 |
| `Node` | — | 迭代器节点 |

```lz
// Itor 支持：暂停/恢复/停止/重启/跳转
let it = itor(xs)
it.pause()     // 暂停迭代
it.resume()    // 恢复迭代
it.stop()      // 停止（不可恢复）
it.restart()   // 重新开始

```

### 3.4 延迟执行

| 类型 | 函数 | 说明 |
|------|------|------|
| `Stuff<R>` | `stuff(f)` | 延迟执行原语：一个策略就是一个"被延后的决策"，`stuff` 是该决策的载体 |

```lz

```

### 3.5 可调用对象

| 类型 | 函数 | 说明 |
|------|------|------|
| `Callable<Args>` trait | `__call_magic(obj, args)` | 使 struct（含 `__call__` 方法）和闭包可通过 `obj(args)` 语法调用 |

### 可调用性规则

| 类型 | 可调用？ | 说明 |
|------|:--:|------|
| **struct**（作为构造器） | ✅ 始终 | `Point(x, y)` = 构造新实例 |
| **struct 实例**（含 `__call__` 时） | ✅ | `obj(args)` → `__call__(self, args)` |
| **struct 实例**（不含 `__call__`） | ❌ | 报 `not callable` |
| **闭包 / 函数** | ✅ 始终 | `|x| x+1` / `def f()` |
| **enum** | ❌ | enum 变体通过路径构造（`Option.Some(v)`），不通过 `()` 直接调用 |
| **trait** | ❌ | trait 不是值，��可调用 |
| **duck** | ❌ | duck 是约束描述，不可实例化/调用 |

> **struct 构造器**：LZ 中 struct 名本身是一个构造器函数，`Point(1, 2)` 等价于构建 `Point { x: 1, y: 2 }`。这与 `__call__` 无关——struct 构造是编译器内置的，不需要实现 `Callable`。
>
> **struct 实例的 `__call__`**：如果 struct 定义了 `__call__` 魔法方法，其实例变成可调用对象。编译器为该 struct 生成 `impl Callable<Args> for StructName`，`obj(args)` 脱糖为 `__call_magic(obj, args)`。

```rust
// 编译器始终注入：
pub trait Callable<Args> { type Output; fn call(self, args: Args) -> Self::Output; }
pub fn __call_magic<T, Args>(f: T, args: Args) -> <T as Callable<Args>>::Output
    where T: Callable<Args> { f.call(args) }

// 闭包的 Callable 实现（含 __call__ 魔法时注入）
impl<FnT, Args, Out> Callable<Args> for FnT
    where FnT: Fn(Args) -> Out
{ type Output = Out; fn call(self, args: Args) -> Out { (self)(args) } }
```

### 3.6 生成器偏函数

| 类型 | 说明 | 状态 |
|------|------|:---:|
| `PartialFunc` | 生成器偏函数，三阶段管道（pre_filter → map → post_filter） | 设计阶段 |

| 字段 | 签名 | 默认 | 说明 |
|------|------|------|------|
| `pre_filter` | `fn(T) -> bool` | `\|x\| True` | 前过滤 |
| `map` | `fn(T) -> R` | `\|x\| x` | 映射变换 |
| `post_filter` | `fn(R) -> bool` | `\|x\| True` | 后过滤 |

```lz
let transform = PartialFunc(
    pre_filter  = |x| x != 0,
    map         = |x| x * 2,
    post_filter = |x| x < 100,
)

for x in source with transform:
    print(x)    // 仅产出非零、翻倍后小于 100 的元素
```

### 3.7 守卫策略

| 类型 | 说明 |
|------|------|
| `GuardedStrategy` trait | 兜底守卫模式：`__guarded_pred__` 判定 + `__guarded_action__` 执行 |

```lz
// struct 实现守卫策略后，guard 语句的失败路径可显式调用守卫魔法（guard 是语句，不可赋值，见 05-控制流 §7.1）
struct SafeDiv = a: int, b: int
    def __guarded_pred__(self, input: int) -> bool = self.b != 0
    def __guarded_action__(self, input: int) -> int = 0

let div = SafeDiv(a: 10, b: 0)
guard div.__guarded_pred__(42) else:      // guard 条件是 bool 表达式（谓词调用）
    return div.__guarded_action__(42)     // 失败路径显式调用兜底动作
```

### 3.10 测试框架运行时

`test` 和 `suite` 声明由编译器自动生成 struct 实例，并提供组合 API。以下类型和函数属于 prelude，无需显式 import。

**Test struct**

```rust
pub struct Test {
    pub name: String,
    pub body: fn(),
    pub suite_name: Option<String>,   // None = 顶层测试
}
```

**Suite struct**

```rust
pub struct Suite {
    pub name: String,
    pub tests: Vec<Test>,
    pub setup: Option<fn()>,
    pub teardown: Option<fn()>,
}
```

**suite 操作符（编译器自动实现 trait）**

| LZ 表达式 | 语义 | Rust 等价 |
|-----------|------|-----------|
| `A + B` | 合并两个套件（并集） | `SuiteOps::add(A, B)` |
| `A - ["slow"]` | 排除指定测试 | `SuiteOps::sub(A, vec!["slow"])` |
| `A["a", "b"]` | 筛选指定测试 | `SuiteOps::index(A, vec!["a", "b"])` |

**全局函数**

| LZ 函数 | 签名 | 说明 |

| `test_by_name(n)` | `(str) -> Test` | 按名查找顶层 test |

| `std.marker` | `std::marker` | P1 | PhantomData、Unpin、Sized |
| `std.os` | `std::os` | P1 | c_char、OsStr、FFI 类型 |
| `std.reflect` | `std::reflect` | P1 | 运行时反射（自定义库） |
| `std.itor` | `std::itor` | P1 | 可控迭代器（vools 库） |
| `std.iter` | `std::iter` | P1 | 迭代器完整适配器方法别名 |

## 五、代码生成注入策略

编译器在生成 `.rs` 文件时，在文件头部**自动注入** prelude use 块：

```rust
// === LZ Prelude (auto-generated) ===
use std::println as __lz_println;
use std::format as __lz_format;
use std::clone::Clone;
use std::fmt::{Debug, Display};
use std::default::Default;
use std::cmp::{Eq, PartialEq, Ord, PartialOrd};
use std::hash::Hash;
use std::convert::{From, Into, TryFrom, TryInto};
use std::marker::{Copy, Send, Sync};
use std::ops::{Add, Sub, Mul, Div, Rem, Neg, Not};
use std::boxed::Box;
use std::rc::Rc;
use std::sync::Arc;
use std::cell::{Cell, RefCell};
use std::iter::{Iterator, IntoIterator};
use std::io::Error as IOError;
// === End Prelude ===

// 后续：模块代码...
```

### 5.1 冗余消除

- 每个 `use` 声明**只注入一次**（通过 `HashSet<&str>` 追踪已注入项）
- 如果用户代码已经显式 `import` 了同名符号，prelude 中的对项自动跳过
- 未使用的 `use` 声明由 `rustc` 的 `unused_imports` lint 警告（但不会报错）

### 5.2 增量实现路径

| 阶段 | Rust 状态 | LZ 状态 |
|------|-----------|---------|
| **Phase 1**（当前） | Rust std 直接映射 | prelude API 声明可用，展开为 `use std::*` |
| **Phase 2**（自举后） | LZ 自定义实现替代部分 std | prelude 指向 `lz::builtins::*` |
| **Phase 3**（成熟期） | 完全自举，零依赖 | prelude 全部指向自实现库 |
