# LZ 魔法方法 — 模块级魔法属性

> 规范版本: 3.3 · 基于编译器源码 · 最后校订: 2026-08-05

模块级魔法属性是写在模块顶层、以 `__xxx__` 命名的声明，由编译器自动识别并填充元数据。

---

## 一、Identity（模块身份）

| 属性 | 类型 | 说明 | 自动填充？ |
|------|------|------|:---:|
| `__name__` | `str` | 模块全限定名，如 `"myapp.utils.math"` | ✅ |
| `__file__` | `str` | `.lz` 源文件绝对路径 | ✅ |
| `__is_macro__` | `bool` | 是否宏模块（`#!bin macro`） | ✅ |
| `__package__` | `str` | 包路径（父目录组件） | ✅ |
| `__path__` | `str` | 模块文件所在目录 | ✅ |

```lz
// 编译期可用
comptime:
    const MOD_NAME = __name__      // "myapp.utils.math"
```

---

## 二、Meta（元信息）

| 属性 | 类型 | 说明 |
|------|------|------|
| `__doc__` | `str` | 模块文档注释（首个多行注释或连续单行注释） |

```lz
// 模块文档注释
// 这是 my_module 的说明
// 会被自动收集到 __doc__

def main() =
    print(__doc__)   // "模块文档注释..."
```

---

## 三、Visibility（可见性控制）

| 属性 | 类型 | 说明 |
|------|------|------|
| `__all__` | `List<str>` | 公开导出列表（`from module import *` 时的白名单） |
| `__public__` | `List<str>` | 显式声明为公开的符号 |
| `__private__` | `List<str>` | 显式声明为私有的符号 |
| `__deps__` | `List<str>` | 模块依赖列表 |

```lz
__all__ = ["add", "multiply"]      // 只有 add 和 multiply 对外可见

def add(a: int, b: int) -> int = a + b
def multiply(a: int, b: int) -> int = a * b
def internal_helper() = ...        // 不在 __all__ 中，外部不可见
```

---

## 四、Bridge（桥接）

| 属性 | 类型 | 说明 |
|------|------|------|
| `__bridge__` | `str` | 桥接目标语言（`"Rust"` / `"Python"` / `"C"`） |
| `__bridge_tier__` | `str` | 桥接层级（`"source"` / `"ffi"` / `"cli"` / `"shared"`） |

```lz
__bridge__ = "Rust"
__bridge_tier__ = "ffi"
```

---

## 五、Compile-env（编译环境）

| 属性 | 类型 | 说明 |
|------|------|------|
| `__backend__` | `str` | 编译后端（`"rustc"`） |
| `__target__` | `str` | 目标平台（`"x86_64-pc-windows"` 等） |
| `__version__` | `str` | 编译器版本号 |

---

## 六、Layout（内存布局）

| 属性 | 类型 | 说明 | 对应 Rust |
|------|------|------|-----------|
| `__slots__` | `str` | struct 内存布局控制 | `#[repr(...)]` |

`__slots__` 映射为 Rust 的 `#[repr(...)]` 属性，控制结构体的内存布局：

```lz
struct MyStruct =
    __slots__ = "C"               // #[repr(C)] — C 兼容布局
    x: int
    y: int

struct Packed =
    __slots__ = "packed"          // #[repr(packed)] — 紧凑布局
    a: u8
    b: u32

struct Aligned =
    __slots__ = "align(16)"       // #[repr(align(16))] — 16 字节对齐
    data: List<f64>
```

有效值：`"C"` / `"packed"` / `"transparent"` / `"align(N)"`

> **注意**：`__slots__` 是 **struct 级属性**（非模块级），用于 struct 内部控制内存布局。详见 [06a-struct.md](06a-struct.md)。
>
> LZ 的 `__slots__` 与 Python 的 `__slots__` 语义不同。Python 的 `__slots__` 用于限制实例属性、优化内存，而 LZ 的 `__slots__` 直接控制 Rust 编译器的内存布局。这是静态类型语言的自然选择。

---

## 七、语法边界

```lz
// ❌ 在函数体内使用模块级魔法属性
def f() =
    __all__ = ["x"]              // 错误：__all__ 只能在模块顶层

// ❌ __all__ 包含不存在的符号
__all__ = ["nonexistent"]        // 编译警告
```
