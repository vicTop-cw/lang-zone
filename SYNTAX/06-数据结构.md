## 公共规则

所有 struct、enum、trait 均**支持泛型参数**：

```lz
struct Pair<T, U> = first: T, second: U       // struct + 泛型
enum Option<T>: Some(T), None                   // enum + 泛型
trait Container<T> = def get(self, i: int) -> T // trait + 泛型
impl<T: Display> ToStr for Pair<T,T> = ...      // impl + 泛型
```

- struct → `=`
- enum → `:`
- trait → `=`
