# LZ 构建块

> 规范版本: 3.3 · 基于编译器源码 · 最后校订: 2026-08-04

本文档定义 Lang-Zone 的构建块表达式家族：变量构建块 `=:`、索引构建块 `^:`、调用构建块 `~:`；生成器构建块 `*: ` 见 **[14-生成器](14-生成器.md)**。

> 生成器已独立为专题文档，详见 **[14-生成器](14-生成器.md)**。

---

## 空白规则

构建块操作符 `=:` `^:` `~:` `*:` 是**整体 token**（符号内无空格）：`=:`/`~:`/`*:`/`^:` 均**冒号后换行缩进**（`^:` 块体为**单个表达式（单值 key）**，不接多语句块体、不要求元组/字典）；操作符前后需留白。

```
x =:
    body             // ✅ 操作符前后留白 + 换行缩进

x=:body              // ❌ 操作符前后必须留白 + 换行缩进
x = : body           // ❌ = 和 : 之间不能有空格，=: 是整体
```

## 一、变量构建块 `=:`

`=:` 创建一个**无参不安全闭包**，块体末尾表达式作为返回值。

```lz
// 简单变量构建块
x =:
    y = 1
    y + 2
print(x)   // 3

// 多语句构建块
result =:
    a = 10
    b = 20
    a + b
print(result)  // 30
```

### 条件构建块

```lz
grade = "B"
score =:
    if grade == "A":
        90
    elif grade == "B":
        80
    else:
        60
print(score)   // 80
```

### 嵌套构建块

构建块可以任意嵌套，每层都产生一个独立的 unsafe 作用域。嵌套构建块内的语句遵循标准 LZ 作用域规则。

```lz
outer =:
    inner =:
        5 * 5       // inner → 25
    inner + 10      // outer → 35
print(outer)        // 35
```

**构建块类型组合规则**：

| 嵌套组合 | 说明 |
|----------|------|
| `=:` 内含 `^:` | 合法 — 运算块内暂存所有权用于后续消费 |
| `^:` 内含 `=:` | 合法 — 消费块内计算中间值 |
| `~:` 内含 `*:` | 合法 — 引用块内声明指针 |
| `=:` 内含 `=:` | 合法 — 嵌套运算 |

任何构建块组合均为合法，只要每层各自展开为合法的 LZ 表达式。

### 构建块内循环

```lz
total =:
    sum = 0
    for i in 1..5:
        sum = sum + i
    sum
print(total)   // 10
```

## 二、索引构建块 `^:`

`^:` 是**索引构建块**：对容器做索引访问，脱糖为 `__getitem__` 调用。形态与 `=:`/`~:`/`*:` 一致——**冒号后换行缩进**；区别在于块体是**单个表达式（单值 key）**，直接作为 `__getitem__` 的唯一参数。

- 形态：`container ^:\n    key_expr` —— 块体为单个表达式（单值），换行缩进书写。
- 脱糖：`container ^:\n    key` → `container.__getitem__(key)`。
- 与调用构建块 `~:` 的区别：`~:` 要求块尾为**元组/字典**并拆包传参；`^:` 块体是**单值 key**，不继承 `~:` 的元组/字典约束——这是索引构建块的特殊之处。
- `^:` 不接多语句块体（与 `=:` 不同），块体只写单个表达式。

> `[]` 仍是规范索引写法（`xs[i]` → `__getitem__`）。`^:` 是构建块风格的等价写法，二者可互换；推荐优先使用 `[]`。

```lz
let nums = [10, 20, 30]
let a = nums ^:
    0                   // → nums.__getitem__(0) → 10
let i = 2
let b = nums ^:
    i                   // → nums.__getitem__(i) → 30
```

### 2.1 `^:` 作为 block 入口构建块（重载）

在 [05b-block命名块.md](05b-block命名块.md) 中，命名块 `block NAME[...]` 的入口复用 `^:`——因为 block 用中括号 `[...]`，与索引同属括号族，故取 `^:` 而非函数入口的 `~:`（对应 `()`）。此处 `^:` 是**专用重载**，与「索引」语义正交：

- **目标不是容器**：block 非容器，无 `__getitem__` 冲突；`^:` 在此读作「进入 block 并以其单值块体作入口参数」。
- **脱糖**：`^:` 的单值块体（元组 / 字典 / 裸值 / record，各为一个值）按 [03c-检查站.md](03c-检查站.md) §4.3 脱糖为 `__Params` 注入 `ps`。
- **与 `~:` 对称**：`f ~:` = 函数调用入口（`()` 族）；`block A ^:` = block 入口（`[]` 族）。两者都要求「`^:`/`~:` 冒号后换行缩进写参数」（参数写于下一行缩进）。
- **单值约束一致**：`^:` 块体本就是单值表达式，`(a, b)` 整体是一个元组值，故完全满足 `^:`「单值 key」约束，不冲突。

```lz
block A[ps: __Params]:        // 定义（惰性登记）
    print(ps.args[0])
block A ^:                    // 触发：^: 单值块体 = 入口参数
    (10, 20)                  // → __Params{ args: (10, 20) } 注入 ps
block A ^:                    // 再触发（块已定义，无体）
    (30, 40)
```

## 三、调用构建块 `~:`

`~:` 创建一个**带参闭包**，块体末尾返回元组或字典，自动拆包传递给左侧 callee。

```lz
// 元组拆包：按位置传参
def add[chk](a: int, b: int) -> int = a + b

r1 = add ~:
    (10, 20)
print(r1)   // 30

def chker(ps: __Params) -> __Params raises str =   // checker 须声明 raises（03c §4.1）；raises 后接具体类型
    let N = len(ps.args)
    if N == 0:
        raise ValueError("expected 2 arguments, got " + str(N))
    elif N == 1:
        p1 = ps.args[0] as int
        p2 = p1
    else:
        p1 = ps.args[0] as int
        p2 = ps.args[1] as int
        if p1 < 0 or p2 < 0:
            raise ValueError("p1 and p2 must be non-negative")
    (p1, p2)

// 注：args 为 List<dyn>，ps.args[0] / ps.kwargs["k"] 均为标准索引访问（见 03c §4.1/4.3）
r2 = add[chker] ~:
    (10,)

print(r2) // 20
// 字典拆包：按名称传参
def greet(greeting: str, name: str) -> str =
    greeting + ", " + name + "!"

r2 = greet ~:
    {"greeting": "Hello", "name": "Lang-Zone"}
print(r2)   // Hello, Lang-Zone!
```

### 多参数函数

```lz
def volume(width: f64, height: f64, depth: f64) -> f64 =
    width * height * depth

r4 = volume ~:
    (2.0, 3.0, 4.0)
print(r4)   // 24.0
```

### 计算型构建块

块体中可执行任意计算，末尾返回元组拆包给 callee：

```lz
r5 = add ~:
    a = 100
    b = 200
    (a, b)
print(r5)   // 300
```

## 四、构建块中的 return

所有构建块都支持 `return` 提前退出。**重要**：构建块内的 `return` 退出的是**构建块自身**，不是外层函数。

### 4.1 变量构建块 `=:` 中的 return

```lz
def demo() =
    x =:
        if True:
            return 42        // 退出 =: 构建块，x = 42
        99                   // 不会执行
    print(x)                 // 42
    print("still here")      // ← 外层函数继续执行

demo()
// 输出：42   "still here"
```

`return` 不带值时，构建块返回单元值：

```lz
x =:
    if skip:
        return               // 退出构建块，x = ()
    compute()
```

### 4.2 调用构建块 `~:` 中的 return

```lz
def add(a: int, b: int) -> int = a + b

r = add ~:
    if use_default:
        return (0, 0)        // 退出 ~: 构建块，拆包传给 add(0, 0)
    a = complex_calc1()
    b = complex_calc2()
    (a, b)

// r == add(0, 0) 当 use_default 为真时
```

### 4.3 构建块在函数体内：作用域规则

```lz
def outer(x: int) -> int =
    if x > 10:
        return 0             // ← 退出 outer 函数

    val =:
        if x < 0:
            return -1        // ← 退出 =: 构建块，不是退出 outer
        x * 2                // x >= 0 时 val = x * 2

    val + 1                  // outer 函数继续执行
```

> `return` 的作用域是它所在的**最内层可 return 边界**：函数体中的 `return` 退出函数，构建块中的 `return` 退出构建块。
