# LZ 构建块

> 版本: 3.1 · 基于编译器源码 · 2026-07-27

本文档定义 Lang-Zong 的两种构建块表达式：变量构建块 `=:`、调用构建块 `~:`。

> 生成器已独立为专题文档，详见 **[14-生成器](14-生成器.md)**。

---

## 空白规则

构建块操作符 `=:` `~:` 是**整体 token**（符号间无空格），操作符**前后留白 + 后换行缩进**：

```
x =:
    body             // ✅ 操作符前后留白 + 换行缩进

x=:body              // ❌ 操作符前后必须留白 + 换行缩进
x = : body           // ❌ = 和 : 之间不能有空格，=: 是整体
```

---

## 一、变量构建块 `=:`

`=:` 创建一个**无参不安全闭包**，块体末尾表达式作为返回值。

```lz
// 简单变量构建块
x =:
    y = 1
    y + 2
print(x)   // 3

// 多语句构建块
result =:
    a = 10
    b = 20
    a + b
print(result)  // 30
```

### 条件构建块

```lz
grade = "B"
score =:
    if grade == "A":
        90
    elif grade == "B":
        80
    else:
        60
print(score)   // 80
```

### 嵌套构建块

```lz
outer =:
    inner =:
        5 * 5
    inner + 10
print(outer)   // 35
```

### 构建块内循环

```lz
total =:
    sum = 0
    for i in 1..5:
        sum = sum + i
    sum
print(total)   // 10
```

## 二、调用构建块 `~:`

`~:` 创建一个**带参闭包**，块体末尾返回元组或字典，自动拆包传递给左侧 callee。

```lz
// 元组拆包：按位置传参
def add(a: int, b: int) -> int = a + b

r1 = add ~:
    (10, 20)
print(r1)   // 30

// 字典拆包：按名称传参
def greet(greeting: str, name: str) -> str =
    greeting + ", " + name + "!"

r2 = greet ~:
    {"greeting": "Hello", "name": "Lang-Zong"}
print(r2)   // Hello, Lang-Zong!
```

### 多参数函数

```lz
def volume(width: f64, height: f64, depth: f64) -> f64 =
    width * height * depth

r4 = volume ~:
    (2.0, 3.0, 4.0)
print(r4)   // 24.0
```

### 计算型构建块

块体中可执行任意计算，末尾返回元组拆包给 callee：

```lz
r5 = add ~:
    a = 100
    b = 200
    (a, b)
print(r5)   // 300
```

## 三、构建块中的 return

所有构建块都支持 `return` 提前退出。**重要**：构建块内的 `return` 退出的是**构建块自身**，不是外层函数。

### 3.1 变量构建块 `=:` 中的 return

```lz
def demo() =
    x =:
        if True:
            return 42        // 退出 =: 构建块，x = 42
        99                   // 不会执行
    print(x)                 // 42
    print("still here")      // ← 外层函数继续执行

demo()
// 输出：42   "still here"
```

`return` 不带值时，构建块返回单元值：

```lz
x =:
    if skip:
        return               // 退出构建块，x = ()
    compute()
```

### 3.2 调用构建块 `~:` 中的 return

```lz
def add(a: int, b: int) -> int = a + b

r = add ~:
    if use_default:
        return (0, 0)        // 退出 ~: 构建块，拆包传给 add(0, 0)
    a = complex_calc1()
    b = complex_calc2()
    (a, b)

// r == add(0, 0) 当 use_default 为真时
```

### 3.3 构建块在函数体内：作用域规则

```lz
def outer(x: int) -> int =
    if x > 10:
        return 0             // ← 退出 outer 函数

    val =:
        if x < 0:
            return -1        // ← 退出 =: 构建块，不是退出 outer
        x * 2                // x >= 0 时 val = x * 2

    val + 1                  // outer 函数继续执行
```

> `return` 的作用域是它所在的**最内层可 return 边界**：函数体中的 `return` 退出函数，构建块中的 `return` 退出构建块。

## 四、语法边界

```lz
// ❌ 冒号后必须换行缩进
// x =: 42            // 错误：=: 后必须换行缩进

// ❌ 调用构建块末尾必须是元组或字典
// r = f ~: 42        // 错误：~: 块体末尾必须是元组或字典

// ❌ 操作符前后必须留白
// x=:                // 错误：= 和 : 之间及前后必须留白
```
