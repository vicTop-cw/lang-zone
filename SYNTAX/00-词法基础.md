# LZ 词法基础

> 版本: 3.1 · 基于编译器源码 · 2026-07-27

本文档定义 Lang-Zone 语言的完整词法规则：关键字、字面量、标识符、运算符、注释、缩进与空白。

---

## 一、关键字

### 1.1 声明关键字

| 关键字 | 用途 |
|--------|------|
| `def` | 函数定义 |
| `struct` | 结构体定义 |
| `enum` | 枚举定义 |
| `trait` | Trait 定义 |
| `Number` | 数值 trait（`@math` 装饰器将无注解参数默认为 `Number`） |
| `impl` | Trait 实现 |
| `type` | 类型别名（模块级/局部/trait关联类型/泛型别名+where约束），详见 [01-类型系统.md](01-类型系统.md) §五 |
| `const` | 编译期常量 |
| `mut` | 可变修饰（默认已是可变，`mut` 为 no-op） |
| `ref` | 引用绑定 |
| `let` | 不可变绑定 |
| `owned` | 仅形参修饰，表示该参数需要所有权，所有权将被转移给调用者，原变量会失效 |
| `magic` | 魔法方法声明块 |
| `...` | 抽象方法标记（trait 中 `= ...` 表示无默认实现） |

### 1.2 控制流关键字

| 关键字 | 用途 |
|--------|------|
| `if` | 条件分支 |
| `elif` | 条件继续（else if） |
| `else` | 条件否则（`if`）、循环正常结束（`for`/`while`）、try 成功（`try`）。`loop` 不支持 else |
| `match` | 模式匹配 |
| `case` | 匹配臂 |
| `guard` | 条件守卫 / 模式守卫 |
| `for` | 迭代循环 |
| `while` | 条件循环 |
| `loop` | 无限循环 |
| `pass` | 占位符，无实际作用,也可用于函数体内 |
| `break` | 退出循环，支持留白或带值，仅支持跳出单层 |
| `continue` | 继续下一轮迭代，支持留白或带值，仅支持当前循环 |
| `return` | 函数返回，显式返回，一般是提前返回用。默认最后一行表达式的值就是返回值。仅用于函数体内和构建块语句 |
| `with` | 上下文管理器 |
| `defer` | 延迟执行（LIFO） |

### 1.3 异常关键字

| 关键字 | 用途 |

| `raise` | 抛出异常 |
| `raises` | 异常类型标注，函数体内有raise语句的 或 调用的函数有异常的， 必须标注 |
| `try` | 异常捕获块 |
| `catch` | 捕获分支 |
| `finally` | 最终执行块 |

### 1.4 异步与并发

| `await` | 等待异步结果 |

### 1.5 迭代与生成器

| 关键字 | 用途 |
|--------|------|
| `yield` | 生成器产出值，支持 yield 留白、yield expr、yield from expr、yield from expr with PartialFunc |


### 1.6 模块与导入

| `teardown` | 测试套件语句内使用（设计阶段，编译器未实现） |

### 1.10 运算符关键字

| 关键字 | 语义 |
|--------|------|
| `and` | 逻辑与（短路），等价 `&&` |
| `or` | 逻辑或（短路），等价 `\|\|` |
| `not` | 逻辑非，等价 `!` |
| `is` | 同一性 / 类型判断 |

### 1.11 字面量关键字

| 关键字 | 对应 Rust | 说明 |
|--------|-----------|------|
| `True` | `true` | 布尔真 |
| `False` | `false` | 布尔假 |
| `None` | `None::<T>` | Option 空值 |
| `Some` | `Some(...)` | Option 包装 |
| `Ok` | `Ok(...)` | Result 成功 |
| `Err` | `Err(...)` | Result 失败 |
| `Never` | `!` | 永远不会返回 |
| `Unit` | `()` | 空值类型 |
| `Nil` | `()` | 空列表字面量（设计阶段，当前使用 `[]` 直接表示） |

> `Nil` 是空列表 `[]` 的类型别名，主要用于类型注解场景如 `def f() -> Nil`。使用 `[]` 作为值，`Nil` 作为类型。两者在运行时等价。

### 1.12 禁止使用的写法

| 错误写法 | 原因 | 正确写法 |
|----------|------|---------|
| `void` | 不是关键字 | `()` |
| `string` | 不是关键字 | `str` |
| `null` | 不是关键字 | `None` |
| `::` | 词法分析器识别但语法层已废弃 | `.` |
| `;` | 不支持分号 | 省略 |
| `#` 作为注释 | `#` 是属性宏标记 | `//` |

> 词法层识别 `::` 为 PathSep token（向后兼容），但语法解析器不接受 `::` 作为路径分隔符。

## 二、字面量

| 类型 | 语法 | 示例 | 生成 Rust |
|------|------|------|-----------|
| 整数 | 十进制 `42` | `42` | `42i64` |
| 整数 | 十六进制 `0x` | `0xFF` | `255i64` |
| 整数 | 八进制 `0o` | `0o77` | `63i64` |
| 整数 | 二进制 `0b` | `0b1010` | `10i64` |
| 浮点 | 小数 / 科学计数 | `3.14` `1e10` | `3.14f64` |
| 字符串 | 双引号 | `"hello"` | `"hello".to_string()` |
| f-string | `f"..."` 含 `{expr}` | `f"x={x}"` | `format!("x={}", x)` |
| 原始字符串 | `r"..."` | `r"\d+"` | `r"\d+".to_string()` |
| 多行字符串 | `"""..."""` | `"""line1\nline2"""` | `"line1\nline2".to_string()` |
| 布尔 | `True` `False` | `True` | `true` |
| 列表 | 方括号逗号分隔 | `[1, 2, 3]` | `vec![1i64, 2i64, 3i64]` |
| 元组 | 圆括号逗号分隔 | `(1, "hi")` | `(1i64, "hi".to_string())` |
| 字典 | 花括号键值对 | `{"a": 1, "b": 2}` | `HashMap::from([...])` |
| 集合 | 花括号逗号分隔 | `{1, 2, 3}` | `HashSet::from([...])` |

> `{}` 为空 dict；`{1, 2, 3}` 为 set；`{a: 1}` 为 dict。消歧规则：包含 `:` 即 dict，否则为 set。

| 区间 | `start..end` | `0..10` | `0..10` |
| 闭区间 | `start..=end` | `0..=9` | `0..=9` |

## 三、注释

LZ 支持两种注释：
- `//` 单行注释（至行尾）
- `/* */` 块注释（可跨行）

```lz
// 单行注释
let x = 42

/*
  多行注释
  可以跨行
*/
let y = 10
```

## 四、标识符

### 4.1 普通标识符

```lz
my_var       // 小写字母开头
MyType       // 大写字母开头（用于类型名）
_private     // 下划线开头
x1           // 字母 + 数字
café         // 支持 Unicode 字母
```

标识符规则：`[a-zA-Z_][a-zA-Z0-9_]*` 或任何 Unicode 字母序列。

### 4.2 魔法方法名

```lz
__init__     // 以双下划线开头和结尾
__add__
__str__
__iter__
```

用于 `magic` 块和 trait 定义中的特殊方法。

### 4.3 下划线 `_`

`_` 是一个特殊标识符，不能作为变量名使用，但在多个上下文中有特定语义：

| 上下文 | 语法 | 语义 |
|--------|------|------|
| match 通配 | `case _ => ...` | 匹配任意值，忽略绑定 |
| 解构忽略 | `let (a, _, c) = t` | 忽略元组中不需要的元素 |
| guard let 忽略 | `guard let Some(_) = opt` | 只检查变体，不绑定值 |
| 丢弃返回值 | `let _ = expr` | 求值但不绑定结果 |
| 函数参数占位 | `f(1, _, 3)` | 调用时省略参数，编译器自动命名 |
| 私有约定 | `_private_var` | 模块内部约定（非强制） |
| 未用参数 | `def f(_: int) = ...` | 声明参数但不在函数体内使用 |

```lz
// match 通配
match x:
    case 0 => "zero"
    case _ => "other"

// 解构忽略
let (a, _) = (1, 2)        // 只取 a=1
let (first, ..,) = xs      // 取第一个，其余忽略

// 丢弃返回值
let _ = heavy_side_effect() // 忽略返回值，仅要副作用

// 函数参数占位
let result = map(values, _, 0)  // _ → 自动命名 __1

// 未用参数
def handler(_: int) =
    print("called")         // 参数声明了但不使用
```

> `_` 本身不能作为普通变量名：`let _ = 42` 是丢弃绑定，后续不能使用 `_`。

## 六、缩进与空白

### 6.1 缩进规则

Lang-Zong 使用**缩进敏感**语法。缩进用 **4 个空格**（不使用 Tab）。

```
缩进增加 → 新块开始
缩进减少 → 块结束
```

### 6.2 冒号规则

```lz
// 冒号后必须换行 + 缩进 的场景：
if x > 0:        // 正确：冒号后换行缩进
    print(x)

for x in xs:     // 正确：冒号后换行缩进
    print(x)

while cond:      // 正确：冒号后换行缩进
    body()

guard cond else: // 正确：guard else 必须换行缩进
    handle()

// case 分支支持两种写法：
case 0:          // 形式一：冒号换行缩进
    "zero"
case 1 => "one"  // 形式二：胖箭头内联（前后留白）

// 类型注解中的冒号（不换行）：
let x: int = 42
def f(a: int) -> str = ...
```

### 6.3 `=` 函数体规则

```lz
// `=` 后若跟表达式在同一行 → 等式风格（单行体）
def double(x: int) -> int = x * 2

// `=` 后若换行 → 块体风格（缩进体）
def abs(x: int) -> int =
    x if x >= 0 else -x 
```

### 6.4 空行与缩进

- 空行不改变缩进级别
- 块内语句必须严格对齐
- 块结束由缩进减少（Dedent）标记

## 七、错误语法边界

以下是**明确非法**的写法：

```lz
// ❌ 冒号后不换行（while / for / guard / if 块体）
if x > 0: print(x)        // 错误：单行 if 块体不支持
while cond: do_something() // 错误：单行 while 块体不支持
for x in xs: print(x)     // 错误：单行 for 块体不支持
guard x > 0 else: return   // 错误：guard else 必须换行缩进

// ❌ 混用缩进风格
def f() =
  2空格缩进                  // 错误：必须 4 空格

// ❌ 路径分隔符
import std::io               // 错误：:: 产生词法错误，应用 .
Option::Some(42)             // 错误：应用 Option.Some(42)

// ❌ 错误类型名
let x: void = ...            // 错误：void 不是类型
let s: string = "hi"         // 错误：应为 str
let n: null = ...            // 错误：应为 None

// ❌ 分号
let x = 1;                   // 错误：不支持分号

// ❌ # 作为注释
# 这不是注释                  // 错误：# 是属性宏标记
```
