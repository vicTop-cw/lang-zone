# LZ 词法基础

> 规范版本: 3.3 · 基于编译器源码 · 最后校订: 2026-08-04

本文档定义 Lang-Zone 语言的完整词法规则：关键字、字面量、标识符、运算符、注释、缩进与空白。

---

> **语句分隔约定（必读）**：LZ **不使用 `;` 终结语句**。语句靠**换行 + 缩进**分隔（与 Python 一致）；在 LZ 源码里写 `;` 会编译报错。
>
> | | LZ 源码 | Rust 生成物 |
> |---|---|---|
> | 语句分隔 | 换行（无需符号） | `;` 终结 |
> | 示例 | `let x = 1` | `let x = 1;` |
>
> `;` 只应出现在 ```` ```rust ```` 代码块（编译器产物）中，不要抄进你写的 LZ。反例与边界见 [附录B-关键字保留字符号语法边界.md](附录B-关键字保留字符号语法边界.md)。

## 一、关键字

> **关键字 vs 内建（builtin）**：关键字是参与语言*语法结构*的保留词（如 `def`/`if`/`for`/`match`），不可用作标识符。内建值 / 类型 / 构造器 / 函数 / trait 属于 prelude 提供的库内容，**不是关键字**。`Unit`/`Never`/`Nil`/`Number` 当前以普通标识符经 prelude 解析；`panic`/`None`/`Some`/`Ok`/`Err` 当前在词法层保留专用 token（仅为解析稳定），但其**语义定位是内建函数 / 构造器，不是关键字**。判断标准：该词是否在语法产生式中具有结构性含义。完整内建清单见 [LZSTD/builtins.md](../LZSTD/builtins.md)。

### 1.1 声明关键字

| 关键字 | 用途 |
|--------|------|
| `def` | 函数定义 |
| `struct` | 结构体定义 |
| `enum` | 枚举定义 |
| `trait` | Trait 定义 |
| `impl` | Trait 实现 |
| `type` | 类型别名（模块级/局部/trait关联类型/泛型别名+where约束），详见 [01-类型系统.md](01-类型系统.md) §五 |
| `const` | 编译期常量（支持 `const X: Type = expr`，可用于 comptime） |
| `mut` | 可变修饰（变量绑定中为 no-op；struct 方法中 `mut self` = `&mut Self`） |
| `ref` | 引用绑定/参数修饰（语义随语境：变量绑定 `ref r = x` = 可变引用 `&mut`、`let ref r = x` = 不可变引用 `&`；参数 `ref x: T` = 不可变引用 `&T`、`mut ref x: T` = 可变引用 `&mut T`）。详见 [02-变量与绑定.md](02-变量与绑定.md) §五、[13-指针与引用.md](13-指针与引用.md) §2.1/2.2 |
| `let` | 不可变绑定 |
| `owned` | 仅形参修饰，表示该参数需要所有权，所有权将被转移给调用者，原变量会失效 |
| `magic` | 魔法方法声明块（支持模块级 `magic __name__:` 和 struct 内联 `magic __new__` / `magic __implicit_from__`） |
| `...` | 抽象方法标记（trait 中 `= ...` 表示无默认实现） |

| 关键字 | 用途 |
|--------|------|
| `if` | 条件分支 |

| `while` | 条件循环 |
| `loop` | 无限循环 |
| `block` | 命名作用域/标签跳出；两种形态：plain 块 `block NAME:` 定义即执行一次，checker 块 `block NAME[ps]/[chk]` 惰性登记、可经 `^:`/`[(expr)]`/`[chk]`/`break NAME with` 四种途径触发。详见 [05b-block命名块.md](05b-block命名块.md) |

| `continue` | 继续下一轮迭代，支持留白、带值 `continue expr`（仅 loop 体内）、带标签 `continue NAME`（仅续跑循环，block 不可作 continue 目标） |
| `return` | 函数返回，显式返回，一般是提前返回用。默认最后一行表达式的值就是返回值。可用于函数体内、构建块语句和 checker 块体内（checker 块内终止本次运行，见 05b §4.6）；plain 块内编译错误 |
| `with` | 上下文管理器（依赖 `__enter__`/`__exit__` 魔法，支持 `with expr as name:` 绑定） |
| `defer` | 延迟执行（LIFO） |

|--------|-----------|------|

| `False` | `false` | 布尔假 |

### 1.12 内建值 / 类型 / 构造器（**非关键字**）

以下均为 prelude 提供的内建内容，**不是关键字**，不可与 `def`/`if` 等保留字混为一谈：

| 名称 | 类别 | 对应 Rust | 说明 |
|------|------|-----------|------|
| `None` | 构造器 | `None::<T>` | `Option<T>` 空值变体 |
| `Some` | 构造器 | `Some(...)` | `Option<T>` 包装变体 |
| `Ok` | 构造器 | `Ok(...)` | `Result<T,E>` 成功变体 |
| `Err` | 构造器 | `Err(...)` | `Result<T,E>` 失败变体 |
| `Never` | 内建类型 | `!` | 发散类型（永不返回） |
| `Unit` | 内建类型 | `()` | 单元类型（无返回值） |
| `Nil` | 内建类型别名 | `()` | 单元类型 `()` 的别名（无返回值场景，如 `def f() -> Nil`）。与空列表 `[]` 无关——`[]` 是空列表字面量，类型由上下文推断为 `List<T>`（见 01-类型系统 §7.7） |

> 这些名称当前由 prelude / 类型系统解析为内建值或类型。`Unit`/`Never`/`Nil` 以普通标识符解析；`None`/`Some`/`Ok`/`Err` 当前在词法层保留为专用 token（仅解析便利），未来可统一降级为 prelude 标识符。完整签名与规范见 [LZSTD/builtins.md](../LZSTD/builtins.md)。

### 1.13 禁止使用的写法

| 错误写法 | 原因 | 正确写法 |
|----------|------|---------|

| `#` 作为注释 | `#` 是属性宏标记 | `//` |

## 二、字面量

| 类型 | 语法 | 示例 | 生成 Rust |
|------|------|------|-----------|
| 整数 | 十进制 `42` | `42` | `42i64` |
| 整数 | 十六进制 `0x` | `0xFF` | `255i64` |
| 整数 | 八进制 `0o` | `0o77` | `63i64` |
| 整数 | 二进制 `0b` | `0b1010` | `10i64` |
| 浮点 | 小数 / 科学计数 | `3.14` `1e10` | `3.14f64` |
| 字符串 | 双引号 | `"hello"` | `"hello".to_string()` |
| f-string | `f"..."` 含 `{expr}` | `f"x={x}"` | `format!("x={}", x)` |
| 原始字符串 | `r"..."` | `r"\d+"` | `r"\d+".to_string()` |
| 多行字符串 | `"""..."""` | `"""line1\nline2"""` | `"line1\nline2".to_string()` |
| f-多行字符串 | `f"""..."""` | `f"""x={x}"""` | `format!("x={}", x)` |
| r-多行字符串 | `r"""..."""` | `r"""\d+"""` | `r"\d+".to_string()` |
| 布尔 | `True` `False` | `True` | `true` |
| 列表 | 方括号逗号分隔 | `[1, 2, 3]` | `vec![1i64, 2i64, 3i64]` |
| 元组 | 圆括号逗号分隔 | `(1, "hi")` | `(1i64, "hi".to_string())` |
| 字典 | 花括号键值对 | `{"a": 1, "b": 2}` | `HashMap::from([...])` |
| 集合 | 花括号逗号分隔 | `{1, 2, 3}` | `HashSet::from([...])` |

> `{}` 为空 dict；`{1, 2, 3}` 为 set；`{a: 1}` 为 dict。消歧规则：包含 `:` 即 dict，否则为 set。

### 2.1 字符串转义序列

双引号 / 多行 / f-string 字符串内的反斜杠转义（原始字符串 `r"..."` / `r"""..."""` 不处理转义，所有字符原样保留）：

| 转义 | 含义 |
|------|------|
| `\n` | 换行 |
| `\t` | 制表符 |
| `\\` | 反斜杠 |
| `\"` | 双引号 |
| `\'` | 单引号 |
| `\r` | 回车 |
| `\0` | 空字符 |
| `\u{XXXX}` | Unicode 码点（十六进制，1~6 位，如 `\u{1F600}`） |
| `\{` `\}` | f-string 中的字面花括号（转义插值） |
| 其他 `\x` | **编译错误**（非法转义序列，如 `\q`） |

- 转义在词法层处理，生成 Rust 时转义为对应字面量。
- f-string 的 `{}` 是插值边界；字面花括号用 `\{` `\}` 转义（见 [04-表达式.md](04-表达式.md) f-string 一节）。

### 2.2 数值字面量边界

| 规则 | 行为 |
|------|------|
| 整数类型 | 十进制/十六进制/八进制/二进制整数统一为 `i64`；负号 `-` 是一元运算符，不属于字面量 |
| 整数下划线 | `1_000_000` 合法（数字间任意下划线分隔，仅作可读性，不改变值） |
| 整数溢出 | 超出 `i64` 范围（`-9223372036854775808`~`9223372036854775807`）→ **编译错误**（非回绕） |
| 浮点类型 | 小数与科学计数统一为 `f64`；`1e10`/`1.5e-3`/`3.14` 合法；`1.`（省略小数部分）与 `.5`（省略整数部分）**不合法**，须写 `1.0` / `0.5` |
| 浮点后缀 | 无 `f32` 后缀字面量；需要 `f32` 时用 `1.5 as f32` |
| 浮点下划线 | 不支持（如 `3.14_15` 非法） |

| 区间 | `start..end` | `0..10` | `0..10` |
| 闭区间 | `start..=end` | `0..=9` | `0..=9` |

## 三、注释

LZ 支持两种注释：
- `//` 单行注释（至行尾）
- `/* */` 块注释（可跨行）

```lz
// 单行注释
let x = 42

/*
  多行注释
  可以跨行
*/
let y = 10
```

## 四、标识符

### 4.1 普通标识符

```lz
my_var       // 小写字母开头
MyType       // 大写字母开头（用于类型名）
_private     // 下划线开头
x1           // 字母 + 数字
café         // 支持 Unicode 字母
```

标识符规则：`[a-zA-Z_][a-zA-Z0-9_]*` 或任何 Unicode 字母序列。

### 4.2 魔法方法名

**规则**：所有魔法方法**必须以双下划线开头和结尾**（`__name__`），即 Python Dunder 风格。

```
模式: __<方法名>__
```

该规则适用于：
- `magic` 声明块中的方法
- struct 内的 `magic` 内联方法
- trait 定义中的抽象方法
- 任何需要编译器特殊处理的标记方法

```lz
// ✅ 正确：双下划线开头和结尾
__init__        __add__         __str__         __iter__
__new__         __from__        __into__        __default__
__implicit_from__  __implicit_to__   __implicit_copy__
__eq__          __lt__          __hash__        __clone__
__getitem__     __next__        __repr__        __drop__

// ❌ 错误：不符合双下划线规范
_init_          __init         init            // 下划线不完整
implicit_from                                // 无下划线（不是魔法方法）
```

**交叉引用**：
- 完整魔法方法列表 → [06d 内置魔法trait和全局函数](06d-内置魔法trait和全局函数.md)
- magic 块语法 → [06f magic用法](06f-magic用法.md)
- 魔法方法工作流 → [06g 魔法综合](06g-魔法综合.md)

### 4.3 下划线 `_`

`_` 是一个特殊标识符，不能作为变量名使用，但在多个上下文中有特定语义：

| 上下文 | 语法 | 语义 |
|--------|------|------|
| match 通配 | `case _ => ...` | 匹配任意值，忽略绑定 |
| 解构忽略 | `let (a, _, c) = t` | 忽略元组中不需要的元素 |
| guard let 忽略 | `guard let Some(_) = opt` | 只检查变体，不绑定值 |
| 丢弃返回值 | `let _ = expr` | 求值但不绑定结果 |
| 丢弃语句 | `_ = expr` | 仅执行副作用、丢弃结果（见 §4.3.2） |
| 函数参数占位 | `f(1, _, 3)` | 调用中含 `_` 时脱糖为闭包 `fn(__1) = f(1, __1, 3)`；其余实参照常内联（与 §4.3.1 占位偏应用同义） |
| 占位偏应用 | `add(_, 10)` | 洞脱糖为闭包 `fn(__1) = add(__1, 10)`（见 §4.3.1） |
| 私有约定 | `_private_var` | 模块内部约定（非强制） |
| 未用参数 | `def f(_: int) = ...` | 声明参数但不在函数体内使用 |

```lz
// match 通配
match x:
    case 0 => "zero"
    case _ => "other"

// 解构忽略
let (a, _) = (1, 2)        // 只取 a=1
let (first, ..,) = xs      // 取第一个，其余忽略

// 丢弃返回值
let _ = heavy_side_effect() // 忽略返回值，仅要副作用

// 函数参数占位
let result = map(values, _, 0)  // 脱糖为 fn(__1) = map(values, __1, 0)

// 未用参数
def handler(_: int) =
    print("called")         // 参数声明了但不使用
```

> `_` 本身不能作为普通变量名：`let _ = 42` 是丢弃绑定，后续不能使用 `_`。

#### 4.3.1 占位偏应用（hole / partial application）

当 `_` 出现在**调用参数位置**时，它表示「洞（hole）」。编译器会将该调用脱糖为一个**闭包**，洞按出现顺序成为闭包参数 `__1, __2, …`：

```lz
// 单洞 → 单参数闭包
let add10 = add(_, 10)        // 等价于 fn(__1) = add(__1, 10)
add10(5)                      // 15

// 多洞 → 多参数闭包（洞的顺序即参数顺序）
let f = sum3(_, 2, 3, _)      // 等价于 fn(__1, __2) = sum3(__1, 2, 3, __2)
f(1, 4)                      // sum3(1, 2, 3, 4) = 10

// 简化闭包创建：用 _ 替代显式 lambda
let g = list.map(_ * 2)       // 等价于 list.map(|x| x * 2)
```

- 仅当调用中**至少含一个洞**且处于「被当作值使用」（赋值、传参、返回等）的语境时，才脱糖为闭包；所有参数齐备则仍是普通调用。
- 洞只捕获「未被提供的参数」，已提供的字面量/变量照常内联。
- 脱糖结果就是闭包：`apply(_ + 1, 5)` → `apply(|__1| __1 + 1, 5)`。

#### 4.3.2 丢弃语句 `_ = expr`

可单独以 `_` 作为左值接收表达式结果，仅执行其副作用、丢弃返回值，**无需**先绑定到具名变量：

```lz
_ = heavy_side_effect()       // 等价于 let _ = heavy_side_effect()，但更简短
_ = println("done")           // 仅要打印副作用
```

> 与 `let _ = expr` 语义相同；`_ = expr` 是其在语句位置的简写形式，lz 不强制要求有具名接收者。

## 六、缩进与空白

### 6.1 缩进规则

Lang-Zone 使用**缩进敏感**语法。缩进用 **4 个空格**（不使用 Tab）。

```
缩进增加 → 新块开始
缩进减少 → 块结束
```

### 6.2 冒号规则

```lz
// 冒号后必须换行 + 缩进 的场景：
if x > 0:        // 正确：冒号后换行缩进
    print(x)

for x in xs:     // 正确：冒号后换行缩进
    print(x)

while cond:      // 正确：冒号后换行缩进
    body()

guard cond else: // 正确：guard else 必须换行缩进
    handle()

// case 分支支持两种写法：
case 0:          // 形式一：冒号换行缩进
    "zero"
case 1 => "one"  // 形式二：胖箭头内联（前后留白）

> **例外**：`test` 关键字支持单行写法 `test "name": expr`（详见 [15-测试框架.md](15-测试框架.md)）。

// 类型注解中的冒号（不换行）：
let x: int = 42
def f(a: int) -> str = ...
```

### 6.3 `=` 函数体规则

```lz
// `=` 后若跟表达式在同一行 → 等式风格（单行体）
def double(x: int) -> int = x * 2

// `=` 后若换行 → 块体风格（缩进体）
def abs(x: int) -> int =
    x if x >= 0 else -x
```

### 6.4 空行与缩进

- 空行不改变缩进级别
- 块内语句必须严格对齐
- 块结束由缩进减少（Dedent）标记

## 七、错误语法边界

以下是**明确非法**的写法：

```lz
// ❌ 冒号后不换行（if/while/for/guard let 块体）
// 单行仅限：三元 a if cond else b（见 05-控制流.md §1.4）、guard cond else expr（见 05 §7.1）
while cond: do_something() // 错误：单行 while 块体不支持
for x in xs: print(x)     // 错误：单行 for 块体不支持
if x > 0: print(x)        // 错误：if 块体单行不支持（单行仅限三元）
guard let Some(v) = opt else: return   // 错误：guard let else 必须换行缩进

// ❌ 混用缩进风格
def f() =
  2空格缩进                  // 错误：必须 4 空格

// ❌ 路径分隔符
import std::io               // 错误：:: 产生词法错误，应用 .
Option::Some(42)             // 错误：应用 Option.Some(42)

// ❌ 错误类型名
let x: void = ...            // 错误：void 不是类型
let s: string = "hi"         // 错误：应为 str
let n: null = ...            // 错误：应为 None

// ❌ 分号
let x = 1;                   // 错误：不支持分号

// ❌ # 作为注释
# 这不是注释                  // 错误：# 是属性宏标记
```
