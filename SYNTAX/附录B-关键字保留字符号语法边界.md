## 一、关键字全集

> **关键字 vs 内建（builtin）**：关键字是参与语言*语法结构*的保留词（如 `def`/`if`/`for`/`match`），不可作标识符；内建值 / 类型 / 构造器 / 函数 / trait 属于 prelude 提供的库内容，**不是关键字**。`Unit`/`Never`/`Nil`/`Number` 当前以普通标识符经 prelude 解析；`panic`/`None`/`Some`/`Ok`/`Err` 当前在词法层保留专用 token（仅为解析稳定），语义上仍是内建，不是关键字。

### 1.1 声明关键字

| 关键字 | 用途 | 可嵌套位置 |
|--------|------|-----------|
| `def` | 函数定义 | 顶层, struct/trait/impl 内, 函数内 |
| `struct` | 结构体定义 | 仅顶层 |
| `enum` | 枚举定义 | 仅顶层 |
| `trait` | Trait 定义 | 仅顶层 |
| `duck` | 结构性约束定义（鸭子类型）。可用作类型注解但不可实例化，地位与 trait 等同。详⻅ [01-类型系统.md](01-类型系统.md) §九 | 仅顶层 |
| `impl` | Trait 实现 | 仅顶层 |
| `type` | 类型别名 | 顶层, 函数内, trait 内(关联类型) |
| `const` | 编译期常量 | 顶层, comptime 块内 |
| `mut` | 可变修饰 | 变量/参数声明(no-op于变量) |
| `ref` | 引用绑定 | 变量/参数声明 |
| `let` | 不可变绑定 | 任何块内 |
| `owned` | 所有权转移(仅形参) | 仅函数参数 |
| `magic` | 魔法方法声明 | 顶层, struct 内 |
| `test` | 测试用例 | 顶层, suite 内 |
| `suite` | 测试套件 | 仅顶层 |
| `setup` | 套件初始化 | 仅 suite 内 |
| `teardown` | 套件清理 | 仅 suite 内 |
| `import` | 模块导入 | 仅顶层 |
| `from` | 选择性导入 | 仅顶层 |
| `as` | 导入别名/类型转换 | 导入/表达式中 |

### 1.10 内建值/类型/构造器（**非关键字**）

| 名称 | 类别 | 对应 Rust | 说明 |
|------|------|-----------|------|
| `None` | 构造器 | `None::<T>` | Option 空值 |
| `Some` | 构造器 | `Some(...)` | Option 包装 |
| `Ok` | 构造器 | `Ok(...)` | Result 成功 |
| `Err` | 构造器 | `Err(...)` | Result 失败 |
| `Never` | 内建类型 | `!` | 发散类型 |
| `Unit` | 内建类型 | `()` | 单元类型 |
| `Nil` | 内建类型别名 | `()` | 空列表类型别名(设计阶段) |
| `Number` | 内建数值 trait | — | 泛型约束 trait（如 `T: Number`），**非关键字** |

> 以上均为 prelude 内建内容，**不是关键字**。`Unit`/`Never`/`Nil` 以普通标识符解析；`None`/`Some`/`Ok`/`Err` 当前词法层保留专用 token（仅解析便利）。

## 二、禁止使用的写法

| 错误写法 | 原因 | 正确写法 |
|----------|------|---------|
| `void` | 不是关键字 | `()` |
| `string` | 不是类型名 | `str` |
| `null` | 不是关键字 | `None` |
| `::` | 废弃路径分隔符（路径用 `.`）。duck 约束中另作运算符（`T :: Iterable`，见 [01b-duck关系约束.md](01b-duck关系约束.md) §3.2），两者上下文互不重叠 | `.`（路径）|
| `;` | LZ 不支持分号，语句以换行分隔 | 省略 |
| `#` 作为注释 | `#` 是属性宏标记 | `//` |
| `float` | 不是类型名 | `f64` |
| `lazy` | 不是 LZ 关键字 | (无对应——Rust 后端不需要) |

## 四、语法边界 — 嵌套限制

| 语法 | 允许位置 | 不允许位置 |
|------|---------|-----------|
| `def` | 顶层, struct/trait/impl 内, 函数内 | — |
| `struct` | 仅顶层 | 函数内, 其他 struct 内 |
| `enum` | 仅顶层 | 函数内 |
| `duck` | 仅顶层 | 函数内, struct 内, impl 内 |
| `trait` | 仅顶层 | 函数内 |
| `impl` | 仅顶层 | 函数内 |
| `suite` | 仅顶层 | 函数内, 其他 suite 内 |
| `test` | 顶层, suite 内 | 函数内, 其他 test 内 |
| `setup` | 仅 suite 内 | 顶层, 函数内 |
| `teardown` | 仅 suite 内 | 顶层, 函数内 |
| `import` | 仅顶层(文件头部) | 函数内 |
| `type` | 顶层, 函数内, trait 内 | — |
| `comptime` | 函数/块内, 顶层 | — |
| `const` | 顶层, comptime 块内 | 函数体内(直接写 `const` 报错) |
| `break` | `for`/`while`/`loop` 内 | 循环外 |
| `continue` | `for`/`while`/`loop` 内 | 循环外 |
| `return` | 函数/构建块内 | 顶层 |
| `yield` | 生成器函数内 | 普通函数内 |
| `async` | 仅修饰 `def` | — |
| `await` | 仅 `async` 函数内 | 普通函数内 |

## 五、特殊限制

| 限制 | 说明 |
|------|------|
| 缩进 | 4 空格，不允许 Tab |
| 分号 | LZ 不支持分号，语句以换行分隔 |
| `::` | 词法层识别。作为路径分隔符已废弃（改为 `.`）；在 duck 约束中作约束满足运算符（`T :: Iterable`，见 [01b-duck关系约束.md](01b-duck关系约束.md)），上下文互不重叠 |
| `[]` | 在函数签名中 `[name]` 表示**运行时检查站**（见 [03c-检查站.md](03c-检查站.md)）。泛型约束使用 `<>` + `where`，不使用方括号。表达式中的 `[]` 仍为索引操作符 |
| 单行 if | `if cond: expr` 仅支持三元 `a if cond else b`。`if cond: stmt` 块体必须换行缩进 |
| 单行 guard | `guard cond else expr` 支持；`guard let Pattern = expr else:` 块体必须换行缩进 |
| 单行 for/while | 不支持，冒号后必须换行缩进 |
| `for`/`while` 不可赋值 | `let x = for ...` 编译错误 |
| `loop` 可赋值 | `let x = loop: ... break value` |
| 所有权 `^` | 后缀操作符，仅用于变量/字段移动 |
| `mut` 在变量中 | no-op，默认已可变；`mut self` 在方法中表示 `&mut Self` |
| struct 字段 | 必须带类型注解 |
| 闭包参数 | 必须带类型注解 |
