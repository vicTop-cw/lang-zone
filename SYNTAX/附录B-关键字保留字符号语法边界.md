## 一、关键字全集

> **关键字 vs 内建（builtin）**：关键字是参与语言*语法结构*的保留词（如 `def`/`if`/`for`/`match`），不可作标识符；内建值 / 类型 / 构造器 / 函数 / trait 属于 prelude 提供的库内容，**不是关键字**。`Unit`/`Never`/`Nil`/`Number` 以普通标识符经 prelude 解析；`panic`/`None`/`Some`/`Ok`/`Err` 在词法层保留专用 token（仅为解析稳定），语义上仍是内建，不是关键字。

### 1.1 声明关键字

| 关键字 | 用途 | 可嵌套位置 |
|--------|------|-----------|
| `def` | 函数定义 | 顶层, struct/trait/impl 内, 函数内 |
| `struct` | 结构体定义 | 仅顶层 |
| `enum` | 枚举定义 | 仅顶层 |
| `trait` | Trait 定义 | 仅顶层 |
| `duck` | 结构性约束定义（鸭子类型）。可用作类型注解但不可实例化，地位与 trait 等同。详⻅ [01-类型系统.md](01-类型系统.md) §九 | 仅顶层 |
| `impl` | Trait 实现 | 仅顶层 |
| `type` | 类型别名 | 顶层, 函数内, trait 内(关联类型) |
| `const` | 编译期常量 | 顶层, comptime 块内 |
| `mut` | 可变修饰 | 变量/参数声明(no-op于变量) |
| `ref` | 引用绑定 | 变量/参数声明 |
| `let` | 不可变绑定 | 任何块内 |
| `owned` | 所有权转移(仅形参) | 仅函数参数 |
| `magic` | 魔法方法声明 | 顶层, struct 内 |
| `test` | 测试用例 | 顶层, suite 内 |
| `suite` | 测试套件 | 仅顶层 |
| `setup` | 套件初始化 | 仅 suite 内 |
| `teardown` | 套件清理 | 仅 suite 内 |
| `import` | 模块导入 | 仅顶层 |
| `from` | 选择性导入 | 仅顶层 |

### 1.10 逻辑运算符关键字

| 关键字 | 符号等价 | 用途 |
|--------|:-------:|------|
| `and` | `&&` | 短路逻辑与 |
| `or` | `\|\|` | 短路逻辑或 |
| `not` | `!` | 逻辑非 |

> `and`/`or`/`not` 与符号形式（`&&`/`||`/`!`）功能等价。关键字形式适合自然语言风格，符号形式适合链式条件。位非（按位取反）用 `~`，与逻辑非 `!`/`not` 是不同运算符（见 [12-操作符.md](12-操作符.md) §二）。

### 1.12 内建值/类型/构造器（**非关键字**）

| 名称 | 类别 | 对应 Rust | 说明 |
|------|------|-----------|------|
| `None` | 构造器 | `None::<T>` | Option 空值 |
| `Some` | 构造器 | `Some(...)` | Option 包装 |
| `Ok` | 构造器 | `Ok(...)` | Result 成功 |
| `Err` | 构造器 | `Err(...)` | Result 失败 |
| `Never` | 内建类型 | `!` | 发散类型 |
| `Unit` | 内建类型 | `()` | 单元类型 |
| `Nil` | 内建类型别名 | `()` | 单元类型 `()` 别名（与空列表 `[]` 无关，见 00/01） |
| `Number` | 内建数值 trait | — | 泛型约束 trait（如 `T: Number`），**非关键字** |

> 以上均为 prelude 内建内容，**不是关键字**。`Unit`/`Never`/`Nil` 以普通标识符解析；`None`/`Some`/`Ok`/`Err` 在词法层保留专用 token（仅解析便利）。

### 1.13 duck 专用软关键字（soft keywords，仅在 `duck` 体内生效）

`duck` 体内有一批**软关键字（soft keyword）**：它们在 `duck` 约束块内具有专用语法含义（约束行引导词 / 签名内嵌约束 / 伪类型），**在 duck 体外仍是普通标识符**——可作变量名、字段名、方法名、函数名，不占用全局保留字空间，与 Rust 的 `union`、Swift 的 `some` 同属软关键字机制。

**分类总表**（详见 [01b-duck关系约束.md](01b-duck关系约束.md) §十一）：

| 软关键字 | 类别 | duck 体内含义 | 使用位置 |
|----------|------|---------------|----------|
| `require(...)` | 约束行 | 目标方法调用时必须提供列出的命名参数 | 方法签名之后的独立行 |
| `optional(...)` | 约束行 | 目标方法的命名参数可选（有默认值） | 方法签名之后的独立行 |
| `exact(N)` | 签名内嵌 | 位置参数恰好 N 个 / 正则匹配恰好 N 个 | 方法参数位 / `match` 行 |
| `min(N)` | 签名内嵌 | 位置参数至少 N 个 | 方法参数位 |
| `max(N)` | 签名内嵌 | 位置参数不超过 N 个 | 方法参数位 |
| `range(L, R)` | 签名内嵌 | 位置参数在 L~R 个 | 方法参数位 |
| `at_least(N)` | match 行 | 至少有 N 个方法匹配正则模式 | `match` 行 |
| `at_most(N)` | match 行 | 最多 N 个方法匹配正则模式 | `match` 行 |
| `match` | 约束行 | 引入正则模式匹配约束（`match /pat/ at_least(N)`） | duck 体内独立行 |
| `StackType` | 伪类型 | 参数必须为栈类型（Copy 语义，零堆分配） | 方法参数类型位 |
| `RefType` | 伪类型 | 参数必须为引用类型（Move 语义，含堆分配） | 方法参数类型位 |
| `Any` | 伪类型 | 位置通配（`_: Any` / `def _(self) -> Any`） | 字段/方法占位 |
| `satisfies` | 约束行 | 要求目标类型同时满足另一 duck（`satisfies Base`） | duck 体内独立行 |
| `sealed` | 约束行 | 闭合约束：目标类型不得有额外成员（与 `..` 相反） | duck 体内独立行 |
| `default` | 签名修饰 | 该成员可选：目标类型可不实现（缺省跳过，非强制） | 方法签名行 |

> **软关键字解析规则**：编译器在 `duck` 块体内按上下文识别以上 token；一旦离开 `duck` 块（函数体/表达式/字段声明等），这些词恢复普通标识符身份，`let require = 1` / `struct X = x: StackType` 等**完全合法**。
>
> **duck 体内使用**：全部软关键字按 [01b-duck关系约束.md](01b-duck关系约束.md) §十一 的定义在 duck 体内识别；`require`/`optional`/`exact`/`min`/`max`/`range`/`at_least`/`at_most`/`match`/`StackType`/`RefType`/`Any` 见 §八，`satisfies`/`sealed`/`default` 见 §11.4。

## 二、禁止使用的写法

| 错误写法 | 原因 | 正确写法 |
|----------|------|---------|
| `void` | 不是关键字 | `()` |
| `string` | 不是类型名 | `str` |
| `null` | 不是关键字 | `None` |
| `::` | 非路径分隔符（路径用 `.`）。**无其他运算符用法**（duck 约束用 `:` / `==`，见 [01b-duck关系约束.md](01b-duck关系约束.md) §3.2） | `.`（路径）|
| `;` | LZ 不支持分号，语句以换行分隔 | 省略 |
| `#` 作为注释 | `#` 是属性宏标记 | `//` |
| `float` | 不是类型名 | `f64` |
| `lazy` | 不是 LZ 关键字 | (无对应——Rust 后端不需要) |

## 三、运算符全集

> **单一权威来源**：完整的运算符优先级表（含 `..` 范围、`if/else` 三元、`:=` 海象、复合赋值 `+=` 等全部符号，并逐行对照解析器源码核对）见 **[12-操作符.md §二](12-操作符.md)**。本文件不维护独立的优先级副本。
>
> 本 §三 仅保留「符号边界」层面的补充说明，优先级数值以 12-操作符.md 为准：

| 类别 | 符号 | 边界说明 |
|------|------|----------|
| 范围 | `..` `..=` | 表达式级运算符，优先级仅高于赋值 `=`、海象 `:=`、三元（见 12-操作符.md §二 1 级区） |
| 三元 | `if`/`else` | 仅作 `a if c else b` 三元表达式；与 `if` 语句不共享优先级 |
| 复合赋值 | `+=` `-=` `*=` `/=` `%=` `**=` `&=` `|=` `^=` `<<=` `>>=` | 与 `=` 同级（最低），语句级 |
| 构建块 | `=:` `^:` `~:` `*:` | 非表达式运算符，不进入优先级体系 |
| 所有权移动 | `^`（后缀） | 后缀操作符，不进入中缀优先级体系 |

## 四、语法边界 — 嵌套限制与顶层内容

> 本节约化自《模块顶层内容与嵌套位置方案细则》（2026-08-05）。**总原则**：模块顶层是「item 容器 + 顺序执行入口」——声明类语法（def/struct/enum/…）在顶层登记，语句类语法（let / 裸绑定 / 顶层表达式 / plain block）在**首次 import 时按书写顺序执行一次**（07 §2.5.2）。判定口诀：**有 Rust 对应物 → 按 Rust 分层；无 Rust 对应物（LZ 特有）→ 按本节约化矩阵**。

### 4.1 模块顶层可写内容总表

#### 4.1.1 声明类（item，顶层登记，对齐 Rust）

| 语法 | 顶层 | Rust 对应 | 说明 |
|------|:---:|-----------|------|
| `def` | ✅ | `fn` | 函数定义 |
| `struct` | ✅ | `struct` | 结构体定义（仅顶层） |
| `enum` | ✅ | `enum` | 枚举定义（仅顶层） |
| `trait` | ✅ | `trait` | trait 定义（仅顶层） |
| `impl` | ✅ | `impl` | 实现块（仅顶层） |
| `type` | ✅ | `type` 别名 | 类型别名（另可在函数内/trait 内） |
| `const` | ✅ | `const` | 编译期常量（另可在 comptime 块内） |
| `import` / `from` | ✅ | `use` | 模块导入（仅顶层） |
| `import macro` | ✅ | — | 宏导入（仅顶层） |
| `duck` | ✅ | 无（≈ trait bound） | LZ 特有：结构性约束（仅顶层） |
| `magic` | ✅ | 无（≈ trait+impl） | LZ 特有：魔法声明块（另可在 struct 内） |
| `iterator` | ✅ | 无（≈ generator fn） | LZ 特有：生成器函数（仅顶层） |
| `suite` | ✅ | 无 | LZ 特有：测试套件（仅顶层） |
| `test` | ✅ | 无 | LZ 特有：测试用例（顶层或 suite 内） |
| `block NAME[ps]/[chk]:`（checker 块） | ✅ | 无（≈ fn） | LZ 特有：惰性登记、默认公开、可跨模块（07 §2.5.1 / 05b §7.7） |

#### 4.1.2 语句类（顶层顺序执行，LZ 特有扩展）

| 语法 | 顶层 | 说明 |
|------|:---:|------|
| `let x = expr`（顶层初始化） | ✅ | 首次 import 时执行一次；可被模块内函数引用 |
| `x = expr`（裸绑定，默认可变） | ✅ | 模块级共享可变状态；可被函数闭包捕获修改（`walrus.lz` 模式） |
| 顶层表达式（如 `print(...)`） | ✅ | 首次 import 时执行（`services.lz` 的初始化打印） |
| `block NAME:`（plain 块） | ✅ | 定义即执行一次 |
| `x =:`（顶层变量构建块） | ✅ | 缺失报告 P1-1：已实现（`top_level_build.lz`） |
| `xs = f *:`（顶层生成器构建块） | ✅ | 已实现（`gen_block_star.lz`、`combo-iterator-generator.lz`） |

> ⚠️ **顶层禁止**：`return`（本附录 §四 4.3：顶层脚本直接写 `return` 报错）；`yield`（仅生成器内）；`await`（仅 async 函数内）；`break`/`continue`（仅循环/块内）。

> ✅=允许；❌=禁止。行 = 语法，列 = 宿主位置。

| 语法 | 模块顶层 | 函数内 | struct 内 | trait 内 | impl 内 | suite 内 | comptime 块内 | 原则 |
|------|:---:|:---:|:---:|:---:|:---:|:---:|:---:|------|
| `def` | ✅ | ✅ | ✅（方法） | ✅（抽象/默认方法） | ✅（实现方法） | ❌ | ❌（用 `comptime def`） | 对齐 Rust：fn 可嵌套 |
| `struct` | ✅ | ❌ | ❌ | ❌ | ❌ | ❌ | ❌ | 对齐 Rust：类型定义仅顶层 |
| `enum` | ✅ | ❌ | ❌ | ❌ | ❌ | ❌ | ❌ | 同上 |
| `trait` | ✅ | ❌ | ❌ | ❌ | ❌ | ❌ | ❌ | 同上 |
| `impl` | ✅ | ❌ | ❌ | ❌ | ❌ | ❌ | ❌ | 同上（Rust 中 impl 也可局部，LZ 收紧为仅顶层） |
| `duck` | ✅ | ❌ | ❌ | ❌ | ❌ | ❌ | ❌ | LZ 特有：对齐 trait |
| `iterator` | ✅ | ❌ | ❌ | ❌ | ❌ | ❌ | ❌ | LZ 特有：对齐 def 但收紧为仅顶层（14 §7） |
| `magic` | ✅ | ❌ | ✅ | ❌ | ❌ | ❌ | ❌ | LZ 特有：顶层声明块 / struct 内联 |
| `type` | ✅ | ✅ | ❌ | ✅（关联类型） | ❌ | ❌ | ❌ | 对齐 Rust：type 可局部 |
| `const` | ✅ | ❌ | ❌ | ❌ | ❌ | ❌ | ✅ | LZ：const 顶层 / comptime 内（本附录 §四） |
| `suite` | ✅ | ❌ | ❌ | ❌ | ❌ | ❌ | ❌ | LZ 特有：仅顶层 |
| `test` | ✅ | ❌ | ❌ | ❌ | ❌ | ✅ | ❌ | LZ 特有：顶层或 suite 内 |
| `setup` / `teardown` | ❌ | ❌ | ❌ | ❌ | ❌ | ✅ | ❌ | LZ 特有：仅 suite 内 |
| `import` / `from` | ✅ | ❌ | ❌ | ❌ | ❌ | ❌ | ❌ | 对齐 Rust：use 仅模块级（LZ 收紧，Rust 允许局部 use） |

| `yield` | ❌ | ❌ | ✅ | ❌ | ✅ | ❌ | 仅生成器直接作用域 / `*:` 构建块（14 §2.2） |
| `await` | ❌ | ❌ | ❌ | ❌ | ❌ | ✅ | 仅 async 函数内（00 §1.4） |
| `return` | ❌ | ✅ | ✅ | ✅（checker 块）/ ❌（plain 块） | ✅（=raise） | ✅ | 函数/构建块/checker 块内（本附录 §四） |
| `break`/`continue` | ❌ | ✅（循环内） | ✅ | ✅ | ✅ | ✅ | 循环/块内 |

\* `comptime:` 块内可有循环（08b §4.1 支持 for/while）。

> 注：`async` 仅作 `def` 修饰符（见 §1.4）；`await` 仅 async 函数内（见上表）。

### 4.4 与 Rust 的对齐/差异对照

| 维度 | Rust | LZ | 判定 |
|------|------|-----|:---:|
| 模块顶层允许 `let` | ❌（仅 const/static） | ✅（let + 裸绑定，import 时执行） | **LZ 特有差异** |
| 模块顶层允许裸表达式语句 | ❌ | ✅ | **LZ 特有差异** |
| `struct`/`enum`/`trait` 仅顶层 | ✅（模块/函数均可定义，LZ 收紧） | ✅ 仅顶层 | 对齐（LZ 更严） |
| `fn` 可嵌套（函数内定义函数） | ✅ | ✅ | 对齐 |
| `type` 别名可局部 | ✅ | ✅ | 对齐 |
| `use` 仅模块级 | ✅（Rust 允许局部 use，LZ 收紧） | ✅ 仅顶层 | 对齐（LZ 更严） |
| 模块级共享可变状态 | ❌（static mut 需 unsafe） | ✅（顶层裸绑定 + 闭包捕获） | **LZ 特有差异** |
| 模块初始化时机 | 懒加载（首次触碰） | 首次 import 顺序执行一次 | LZ 明确（07 §2.5.2） |
| 生成器 / 测试 / 魔法声明 | 无对应 | iterator / suite / magic | **LZ 特有**（无 Rust 对照） |

> **结论**：声明类语法严格对齐 Rust 的「类型/特征定义仅顶层、函数与别名可嵌套」分层；LZ 的差异集中在**语句类**——模块顶层可作为「带副作用的初始化入口」（let/裸绑定/表达式/plain block），这是 LZ 为模块级共享状态与顺序初始化有意保留的能力，不随 Rust 收紧。

## 五、特殊限制

| 限制 | 说明 |
|------|------|
| 缩进 | 4 空格，不允许 Tab |
| 分号 | LZ 不支持分号，语句以换行分隔 |
| `::` | 不是路径分隔符（路径用 `.`），无其他运算符用法（duck 约束用 `:` / `==`，见 [01b-duck关系约束.md](01b-duck关系约束.md) §3.2） |
| `[]` | 在函数签名中 `[name]` 表示**运行时检查站**（见 [03c-检查站.md](03c-检查站.md)）。泛型约束使用 `<>` + `where`，不使用方括号。表达式中的 `[]` 仍为索引操作符 |
| 单行 if | `if cond: expr` 仅支持三元 `a if cond else b`。`if cond: stmt` 块体必须换行缩进 |
| 单行 guard | `guard cond else expr` 支持；`guard let Pattern = expr else:` 块体必须换行缩进 |
| 单行 for/while | 不支持，冒号后必须换行缩进 |
| `for`/`while`/`loop` 可赋值 | 均为表达式，值由 `break [NAME] [v]` 决定；正常完成 → `()`（`let r = for i in xs: if c: break with i`） |
| 所有权 `^` | 后缀操作符，仅用于变量/字段移动 |
| `mut` 在变量中 | no-op，默认已可变；`mut self` 在方法中表示 `&mut Self` |
| struct 字段 | 必须带类型注解 |
| 闭包参数 | 必须带类型注解 |
