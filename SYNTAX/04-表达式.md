# LZ 表达式

> 版本: 3.1 · 基于编译器源码 · 2026-07-27

本文档定义 Lang-Zong 的完整表达式语法：运算符优先级、字面量、调用、方法访问、管道、推导式等。

---

## 一、概述

表达式是产生值的语法单元。LZ 的表达式涵盖字面量、运算符、调用、管道、推导式等。

> 完整运算符优先级表详见 **[12-操作符.md](12-操作符.md)** §二。

### 4.3 is 类型判断

`is` 除了引用同一性比较，还支持运行时类型判断：

```lz
def describe(x) -> str =
    if x is int:
        f"integer: {x}"
    elif x is str:
        f"string: {x}"
    elif x is bool:
        f"boolean: {x}"
    else:
        "unknown type"
```

`x is T` 在编译期展开为 `TypeId::of::<T>() == x.type_id()`，与 `__cast__` 魔法方法配合实现类型安全的向下转型。

## 五、逻辑运算

```lz
a and b             // 逻辑与（短路）
a or b              // 逻辑或（短路）
not a               // 逻辑非
!a                  // 逻辑非（与 not 等价）
```

符号形式（与关键字完全等价）：

```lz
a && b              // 逻辑与，等价 a and b
a || b              // 逻辑或，等价 a or b
!a                  // 逻辑非，等价 not a
```

> `and`/`or`/`not` 是关键字形式，`&&`/`||`/`!` 是符号形式，两者完全等价。

## 八、调用表达式

### 8.1 函数调用

```lz
f(1, 2)             // 位置参数
f(1, 2, 3)          // 多参数
```

### 8.2 方法调用

```lz
xs.len()            // 无参方法
xs.push(42)         // 带参方法
s.to_upper()        // 链式方法
```

### 8.3 字段访问

```lz
point.x             // struct 字段
obj.field           // 对象字段
```

### 8.4 路径访问（模块）

```lz
std.io.print        // 模块路径
std.collections.List // 类型路径
```

### 8.5 泛型调用 Turbofish `.<T>`

当函数调用的泛型参数无法从上下文推断时，使用 `.<T>` 显式指定：

```lz
let x = parse.<int>("42")          // 显式指定泛型为 int
let y = collect.<str>(items)       // 收集为 List<str>
let z = foo.<int, str>(bar)        // 多泛型参数
```

编译后等价于 Rust 的 turbofish `::<T>` 语法。在 LZ 中 `.` 是统一路径/泛型分隔符。

## 十、管道 `|>`

```lz
data |> f            // 等价于 f(data)
data |> f |> g       // 等价于 g(f(data))

[1, 2, 3]
    |> map(|x| x * 2)
    |> filter(|x| x > 3)
    |> collect()
```

管道将前一个表达式的结果作为下一个函数的第一个参数。

## 十七、if 表达式

`if` / `elif` / `else` 后的冒号**必须换行 + 缩进**（非注解冒号规则）：

```lz
let result = if x > 0:
        "positive"
    else:
        "negative"

let grade = if score >= 90:
        "A"
    elif score >= 80:
        "B"
    else:
        "C"
```

单行 `if` 表达式**不合法**（冒号必须换行缩进）。

---

## 十八、match 表达式

`case` 的**冒号形式**必须换行 + 缩进；**胖箭头** `=>` 支持内联：

```lz
// 冒号形式：换行缩进（非注解冒号规则）
let msg = match n:
    case 0:
        "zero"
    case 1:
        "one"
    case _:
        "other"

// => 内联形式（前后留白）
let msg = match n:
    case 0 => "zero"
    case 1 => "one"
    case _ => "other"
```

## 二十、错误语法边界

```lz
// ❌ 冒号内联 — 非注解冒号必须换行+缩进
if x > 0: "positive"        // 错误：if 冒号后必须换行缩进
case 0: "zero"              // 错误：case 冒号后必须换行缩进，内联用 =>

// ❌ 优先级歧义（需加括号）
a + b * c          // 正确：* 优先级高
(a + b) * c        // 显式分组

// ❌ 索引越界（运行时错误）
xs.[0]             // 错误：. 和 [] 不要连用，用 xs[0]

// ❌ 管道右值不是函数
data |> 42         // 错误：管道右值必须是可调用

// ❌ 安全导航用于非 Option 类型
let x: int = 42
x?.method()        // 错误：int 不是 Option

// ❌ f-string 中非法表达式
f"{if x: 1}"       // 错误：f-string 不支持控制流表达式
f"{|x| x + 1}"     // 错误：f-string 不支持闭包
```
