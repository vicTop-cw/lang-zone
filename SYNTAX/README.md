## 设计原则

每份文档遵循以下原则：

- **只描述语法规范** — 不讨论实现状态或历史变更
- **正反示例并重** — 每个章节包含正确语法和错误语法边界
- **精确性优先** — 所有示例基于编译器实际行为
- **自包含** — 每篇独立可读，通过链接组织
