# LZ 测试框架

> 版本: 3.2 · 2026-07-28

LZ 测试框架将测试用例和套件视为**一等数据**——通过 `Test` / `Suite` struct 和 trait API 实现声明式 + 编程式组合。

---

## 一、`test` 测试用例

### 1.1 静态名称

```lz
test "addition":
    assert 1 + 1 == 2
```

### 1.2 动态名称

测试名可以是**任意求值为 `str` 的表达式**：

```lz
name = "generated_test"
test name:
    assert True

for i in 1..5:
    test f"dynamic_{i}":
        assert i > 0
```

`setup` 中定义的变量可直接用作测试名。

---

## 二、`suite` 测试套件

```lz
suite MathTests:
    test "add":
        assert 1 + 1 == 2
    test "mul":
        assert 2 * 3 == 6

suite StringTests:
    test "len":
        assert "abc".len() == 3
```

---

## 三、`setup` / `teardown`

```lz
suite DatabaseTests:
    setup:
        db = connect(":memory:")
        db.migrate()
        prefix = "db"

    teardown:
        db.close()

    test f"{prefix}_insert":
        db.insert("users", name="Alice")
        assert db.count("users") == 1
```

`setup` 中的变量在套件内所有 test 中可见。

---

## 四、Suite / Test 作为一等数据

编译器将 `suite` 和 `test` 映射为 struct，提供 trait API 实现组合操作。

### 4.1 Suite struct

```lz
struct Suite =
    name: str
    tests: List<Test>
    setup: Option<fn()>
    teardown: Option<fn()>
```

### 4.2 Test struct

```lz
struct Test =
    name: str
    body: fn()
    suite_name: Option<str>        // None = 顶层测试
```

### 4.3 内置操作 trait（编译器自动实现）

```lz
trait SuiteOps =
    // 并集 — 合并两个套件的测试
    def __add__(self, other: Suite) -> Suite

    // 筛选 — 保留匹配的测试
    def __getitem__(self, names: List<str>) -> Suite

    // 排除 — 移除匹配的测试
    def __sub__(self, names: List<str>) -> Suite
```

### 4.4 全局函数（编译器自动生成）

```lz
// 取所有顶层定义的测试（不含 suite 内的）
def all_tests() -> List<Test>

// 取指定名称的 suite
def suite_by_name(name: str) -> Suite

// 取指定名称的顶层 test
def test_by_name(name: str) -> Test

// 动态构建 suite
def new_suite(name: str, tests: List<Test>) -> Suite
```

## 五、组合示例

### 5.1 合并套件

```lz
// 顶层：基础测试
test "add": assert 1 + 1 == 2
test "mul": assert 2 * 3 == 6

suite CoreTests:
    setup:
        print("core init")
    test "core_add": 
        assert 5 + 5 == 10

// 编程组合：两个套件合并
suite AllTests =
    new_suite("all", all_tests()) + CoreTests
```

### 5.2 筛选 & 排除

```lz
// 从 CoreTests 中只取指定测试
suite QuickCheck = CoreTests["core_add"]

// 排除慢速测试
suite CI = AllTests - ["slow_network", "bench_io"]

// 链式：合并后筛选再排除
suite DailyRun = (CoreTests + suite_by_name("StringTests")) - ["flaky_test"]
```

### 5.3 条件组合

```lz
def build_tests(is_ci: bool) -> Suite =
    base = new_suite("base", all_tests()) + CoreTests
    if is_ci:
        base - ["slow_network"]
    else:
        base
```

### 5.4 遍历测试名

```lz
for t in all_tests():
    print(f"found test: {t.name}")
```

## 六、`assert` 硬断言

```lz
assert expr                 // 失败立即中止
assert expr, "错误消息"      // 带自定义消息
```

## 七、`check` 软断言

```lz
check expr                  // 失败记录但继续
check expr, "警告"           // 带消息
```

---

## 八、运行方式

```bash
lang-zone test              # 执行所有测试
lang-zone test --suite CI   # 只执行指定套件
```

---

## 九、语法边界

| 规则 | 说明 |
|------|------|
| test 名称 | 任意 `str` 表达式 |
| suite 不可嵌套 | `suite` 必须在顶层 |
| setup/teardown 作用域 | setup 变量在套件内所有 test 可见 |
| Suite/Trait | 编译器自动为每个 `suite`/`test` 生成 struct 实例和 trait 实现 |
| 运行 | `lang-zone test` |
