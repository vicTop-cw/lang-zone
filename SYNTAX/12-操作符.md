# LZ 操作符

> 规范版本: 3.2 · 基于编译器源码 · 最后校订: 2026-07-31

本文档定义 Lang-Zone 的完整操作符体系：分类列表、优先级表、操作符与魔法方法的映射关系，以及错误语法边界。

## 一、完整运算符列表（按类别）

| `-` | 一元取负 | `__neg__` | `std::ops::Neg` | 符号反转 |

### 1.3 比较运算符

| 符号 | 名称 | 魔法方法 | Rust Trait | 说明 |
|------|------|----------|------------|------|
| `==` | 等于 | `__eq__` | `std::cmp::PartialEq` | 值相等 |
| `!=` | 不等 | `__ne__` | `std::cmp::PartialEq` | 值不相等 |
| `<` | 小于 | `__lt__` | `std::cmp::PartialOrd` | 偏序比较 |
| `>` | 大于 | `__gt__` | `std::cmp::PartialOrd` | 偏序比较 |
| `<=` | 小于等于 | `__le__` | `std::cmp::PartialOrd` | 偏序比较 |
| `>=` | 大于等于 | `__ge__` | `std::cmp::PartialOrd` | 偏序比较 |
| `is` | 同一性 | — | — | 编译器内置（指针/引用比较） |
| `in` | 成员判断 | `__contains__` | `Contains` | 关键字 |


>
> `<` / `>` / `<=` / `>=` 由 `PartialOrd` trait 生成，定义 `__lt__` 后其余比较自动派生。
>
> 需要全序比较时，实现 `__cmp__` → `std::cmp::Ord`，编译器自动同步 `PartialOrd` 的各种方法。

### 1.5 短路逻辑运算符

| 符号 | 名称 | 魔法方法 | 说明 |
|------|------|----------|------|
| `&&` | 短路与 | — | 编译器内建，等价 `and` |

`and` / `or` 是关键字形式，`&&` / `||` 是符号形式。两者功能等价（均为短路），关键字形式适合自然语言风格，符号形式适合链式条件。

| 符号 | 名称 | 魔法方法 | Rust Trait | 说明 |

| 符号 | 名称 | 魔法方法 | 说明 |

### 1.18 空白规则

| 类别 | 空白要求 | 示例 |
|------|:---:|------|
| 二元操作符 | 前**必须**留白 · 后**必须**留白 | `a + b` ✅ · `a+b` ❌ |
| 一元操作符 | **必须**紧贴操作数 | `-x` ✅ · `- x` ❌ |
| 后缀操作符 (`?` `?.` `^`) | **必须**紧贴前值 | `x?` ✅ · `x ?` ❌ |
| 括号 `()` `[]` | **必须**紧贴函数名/值 | `f(x)` ✅ · `f (x)` ❌ |
| 复合赋值 `*=` `+=` `<<=` 等 | **符号内无空格**，前后留白 | `x *= 2` ✅ · `x * = 2` ❌ |
| 构建块 `=:` `^:` `~:` `*:` | **符号内无空格**；均**前后留白 + 冒号后换行缩进**（`^:` 块体为单值表达式，其余为块体） | `x =:\n    body` ✅ · `lst ^:\n    k` ✅ |

```lz
// ✅ 二元操作符前后留白
a + b
x * y
n >= 0
a and b

// ❌ 二元操作符不留白
a+b                // 错误：二元操作符前后必须留白
a==b               // 错误：二元操作符前后必须留白

// ✅ 一元操作符紧贴操作数
-x
~a
not x              // not 是关键字，自然留白

// ❌ 一元操作符有空白
- x                // 错误：一元操作符必须紧贴操作数
~ a                // 错误：一元操作符必须紧贴操作数

// ✅ 后缀操作符紧贴
x?
obj?.field
x^

// ❌ 后缀操作符有空白
x ?                // 错误：后缀操作符必须紧贴
```

### 1.19 `~` 后缀命名参数糖（call-site 简写）

`~` 在**函数调用参数位置作为后缀**时，表示「把该标识符以其同名命名参数传入」，用于精简具名调用。函数**签名不变**，仅在调用处生效。

| 形式 | 含义 |
|------|------|
| `f(x~)` | 等价于 `f(x = x)` —— 将变量 `x` 作为命名参数 `x` 传入 |
| `f(a, b~)` | 第一个位置参数 `a`（位置传参），第二个以命名 `b = b` 传入 |
| `f(b~, a~)` | 两个都以命名参数传入，顺序按函数形参名匹配，不依赖书写顺序 |

```lz
def name(a: int, b: int) -> int = a + b
a = 1
b = 2
name(b, b~)        // 位置：a 收到 b(=2)；命名：b 收到 b(=2) → a=2, b=2 → 结果 4
name(b~, a~)       // 等价 name(b = b, a = a) → a=1, b=2 → 结果 3
name(1, b~)        // 位置 a=1，命名 b=b(=2) → 3
```

规则：

- `ident~` 中的 `~` **必须紧贴**标识符（同其他后缀操作符 `?` `?.` `^` 的留白规则），`x ~` 非法。
- 与**前缀** `~x`（位非 / `HasInvert`，见 §3.1、§5.1）按位置区分：`~x` 前缀 = 位非；`x~` 后缀 = 命名参数糖。二者不冲突。
- 仅作用于「调用实参」语境；非调用位置使用 `x~` 视为语法错误。
- 仅改变参数传递方式，**不改变函数类型签名**；重载解析仍按原签名进行。

> **当前实现状态**：解析器尚未识别后缀 `~`（`grep Tilde` 在 `src/parser` 无任何调用实参处理），属未实现特性；本文档为规范目标。

### 1.20 海象运算符 `:=`（表达式内赋值）

`:=` 在**表达式内部**完成赋值并返回被赋的值，因此可嵌入 `if` / `while` 条件、`|>` 管道等位置，顺带把结果绑定到变量：

```lz
if (n := compute()) > 0:
    print(n)          // n 在条件成立分支中可用

// 等价于：
n = compute()
if n > 0:
    print(n)

count = 0
def next() -> int =
    count += 1
    count
while (n := next()) < 10:
    print(n)          // n 在循环体中可用
```

规则：
- 右结合；在 §二 优先级表中为 **1 级**（表达式级，仅高于赋值 `=`(0)，低于管道 `|>`(2) 与逻辑/比较/算术运算符）。
- 目标必须是可绑定的标识符（或解构模式），值可以是任意表达式。
- 在 `if` / `while` 条件中声明的变量，作用域覆盖整个 `if` / `while` 体（codegen 会自动把 walrus 提升到条件外侧）。
- 与 `=` 的区别：`=` 是语句级绑定（`let x = …`）；`:=` 是**表达式**，有返回值、可嵌套在更大表达式里。
- 该运算符**已实现**（AST / 解析 / codegen / 类型推导均已支持），区别于本文件其余"规范目标"小节。

> 更完整的讲解与边界示例见 [`02-变量与绑定.md` §7](02-变量与绑定.md)。

## 二、运算符优先级表

> **权威表**：本表逐行对照解析器源码（`src/parser/expr.rs` 的 `parse_expr` 递归下降调用层级）核对，是 LZ 运算符优先级的**唯一权威来源**。`附录B-关键字保留字符号语法边界.md` §三 改为引用本表，不再维护独立副本。

优先级从最低 (0) 到最高 (17)，数值越大优先级越高（越先结合）。

| 优先级 | 运算符 | 结合性 | 说明 |
|:-----:|--------|:-----:|------|
| 0 | `=` `+=` `-=` `*=` `/=` `%=` `&=` `|=` `^=` `<<=` `>>=` | 右 | 赋值与复合赋值（语句级，最低） |
| 1 | `:=` | 右 | 海象赋值（表达式内）。同级的还有三元 `a if c else b`、范围 `..` `..=` |
| 2 | `or` `||` | 左 | 逻辑或（短路） |
| 3 | `and` `&&` | 左 | 逻辑与（短路） |
| 4 | `not` | 右 | 逻辑非（**仅关键字 `not`**） |
| 5 | `==` `!=` `<` `>` `<=` `>=` | — | 比较 |
| 6 | `is` `in` `as` | — | 同一性 / 成员 / 类型转换（`as` 为 cast，绑定到其左侧表达式） |
| 7 | `|>` | 左 | 管道 |
| 8 | `??` | 左 | 空值合并（比 `|>` 更紧） |
| 9 | `|` | 左 | 位或 |
| 10 | `^` | 左 | 位异或 |
| 11 | `&` | 左 | 位与 |
| 12 | `<<` `>>` | 左 | 移位 |
| 13 | `+` `-` | 左 | 加减 |
| 14 | `*` `/` `%` | 左 | 乘除模 |
| 15 | `**` | 右 | 幂 |
| 16 | `+` `-` `~` `!`（一元） | 右 | 一元运算符（含位非 `!`、位反 `~`） |
| 17 | `?` `?.` `^`（后缀） `[]` `()` `.` | 左 | 错误传播 / 安全导航 / 所有权移动 / 索引 / 调用 / 成员访问 |

> **语法约定**：同优先级运算符严格左结合或右结合，不允许不加括号混用。
>
> **`not` 与 `!` 是不同运算符**：`not`（关键字，逻辑非）在 **4 级**（较松，低于比较）；`!`（前缀，位非 `BitNot`）在 **16 级**（最紧的一元运算符）。例如 `not a == b` 解析为 `not (a == b)`，而 `!a + b` 解析为 `(!a) + b`。
>
> **`:=` 比 `|>` 松**：`x := 1 |> f` 解析为 `x := (1 |> f)`（海象赋值包住整个管道），而非 `(x := 1) |> f`。
>
> **`??` 比 `|>` 紧、比 `or`/`and` 松**：`1 or 2 ?? 3` 解析为 `1 or (2 ?? 3)`，`1 ?? 2 |> f` 解析为 `(1 ?? 2) |> f`。
>
> **比较链**：`a < b < c` 展开为 `a < b and b < c`（语法糖，与 Python 行为一致）。

## 三、操作符→魔法方法完整映射表

下表列出**每个有对应魔法方法的操作符**。实现对应的魔法方法后，编译器自动生成 Rust trait 实现，使该类型可用于相应操作符。

### 3.1 二元运算符映射

| 操作符 | 魔法方法 | Rust Trait | trait 方法 | 魔法签名 |
|--------|----------|------------|------------|----------|
| `+` | `__add__` | `std::ops::Add` | `add` | `__add__(self, other: Rhs) → Ret` |
| `-` | `__sub__` | `std::ops::Sub` | `sub` | `__sub__(self, other: Rhs) → Ret` |
| `*` | `__mul__` | `std::ops::Mul` | `mul` | `__mul__(self, other: Rhs) → Ret` |
| `/` | `__div__` | `std::ops::Div` | `div` | `__div__(self, other: Rhs) → Ret` |
| `%` | `__rem__` | `std::ops::Rem` | `rem` | `__rem__(self, other: Rhs) → Ret` |
| `**` | `__pow__` | `Pow` | `pow` | `__pow__(self, other: Rhs) → Ret` |
| `&` | `__bitand__` | `std::ops::BitAnd` | `bitand` | `__bitand__(self, other: Rhs) → Ret` |
| `\|` | `__bitor__` | `std::ops::BitOr` | `bitor` | `__bitor__(self, other: Rhs) → Ret` |
| `^` | `__bitxor__` | `std::ops::BitXor` | `bitxor` | `__bitxor__(self, other: Rhs) → Ret` |
| `<<` | `__shl__` | `std::ops::Shl` | `shl` | `__shl__(self, other: Rhs) → Ret` |
| `>>` | `__shr__` | `std::ops::Shr` | `shr` | `__shr__(self, other: Rhs) → Ret` |
| `\|>` | `__pipe__` | `Pipe` | `pipe` | `__pipe__(self, other: Rhs) → Ret` |

> 二元运算符魔法方法支持多分派：`self` 和 `rhs` 均消费所有权，`Output` 类型由返回类型推断。

### 3.2 一元运算符映射

| 操作符 | 魔法方法 | Rust Trait | trait 方法 | 魔法签名 |
|--------|----------|------------|------------|----------|
| `+x` (正号) | `__pos__` | `Pos` | `pos` | `__pos__(self) → T` |
| `-x` (取负) | `__neg__` | `std::ops::Neg` | `neg` | `__neg__(self) → T` |
| `~x` (位非) | `__invert__` | `HasInvert` | `invert` | `__invert__(self) → Self` |
| `not x` / `!x` (逻辑非) | `__not__` | `std::ops::Not` | `not` | `__not__(self) → bool` |

### 3.3 比较运算符映射

| 操作符 | 魔法方法 | Rust Trait | trait 方法 | 魔法签名 |
|--------|----------|------------|------------|----------|
| `==` | `__eq__` | `std::cmp::PartialEq` | `eq` | `__eq__(self, other: &Rhs) → bool` |
| `!=` | `__ne__` | `std::cmp::PartialEq` | `ne` | `__ne__(self, other: &Rhs) → bool` |
| `<` | `__lt__` | `std::cmp::PartialOrd` | `partial_cmp` | `__lt__(self, other: &Rhs) → bool` |
| `>` | `__gt__` | `std::cmp::PartialOrd` | `partial_cmp` | `__gt__(self, other: &Rhs) → bool` |
| `<=` | `__le__` | `std::cmp::PartialOrd` | `partial_cmp` | `__le__(self, other: &Rhs) → bool` |
| `>=` | `__ge__` | `std::cmp::PartialOrd` | `partial_cmp` | `__ge__(self, other: &Rhs) → bool` |

> **派生关系**：
> - 实现 `__eq__` 后，`__ne__` 自动派生为 `!__eq__`。
> - 实现 `__lt__` 后，其余比较 (`__le__` / `__gt__` / `__ge__`) 由编译器根据偏序关系自动派生。
> - 如需全序比较，实现 `__cmp__` → `std::cmp::Ord`。

### 3.4 复合赋值映射

| 操作符 | 魔法方法 | Rust Trait | trait 方法 | 魔法签名 |
|--------|----------|------------|------------|----------|
| `+=` | `__iadd__` | `std::ops::AddAssign` | `add_assign` | `__iadd__(&mut self, other: Rhs)` |
| `-=` | `__isub__` | `std::ops::SubAssign` | `sub_assign` | `__isub__(&mut self, other: Rhs)` |
| `*=` | `__imul__` | `std::ops::MulAssign` | `mul_assign` | `__imul__(&mut self, other: Rhs)` |
| `/=` | `__idiv__` | `std::ops::DivAssign` | `div_assign` | `__idiv__(&mut self, other: Rhs)` |

> 其余复合赋值 (`%=` / `**=` / `&=` / `\|=` / `^=` / `<<=` / `>>=`) 由编译器脱糖为 `x = x <op> rhs`，不需要魔法方法。

### 3.5 索引与调用映射

| 操作符 | 魔法方法 | Rust Trait | trait 方法 | 魔法签名 |
|--------|----------|------------|------------|----------|
| `[]` (读) | `__getitem__` | `std::ops::Index` | `index` | `__getitem__(self, index: Idx) → &Output` |
| `[]=` (写) | `__setitem__` | `std::ops::IndexMut` | `index_mut` | `__setitem__(&mut self, index: Idx, value: Val)` |
| `()` (调用) | `__call__` | `Callable` | `call` | `__call__(self, args: (A, B, ..)) → Output` |

### 3.6 间接映射（关键字运算符）

| 操作符/关键字 | 魔法方法 | Rust Trait | 说明 |
|--------------|----------|------------|------|
| `in` | `__contains__` | `Contains` | `a in b` → `b.__contains__(&a)` |
| `len()` | `__len__` | `HasLen` | 内置函数 `len(x)` → `x.__len__()` |
| `bool()` | `__bool__` | `HasBool` | 隐式布尔测试 → `x.__bool__()` |
| `abs()` | `__abs__` | `HasAbs` | `abs(x)` → `x.__abs__()` |

### 3.7 无魔法方法的操作符

以下操作符由编译器直接处理，**没有对应的魔法方法**，不可自定义：

| 操作符 | 原因 |
|--------|------|
| `=` | 编译器内置变量绑定与重绑定 |
| `and` / `or` | 编译器内建短路逻辑关键字 |
| `&&` / `\|\|` | 编译器内建短路逻辑符号 |
| `is` | 编译器内置引用/指针同一性检查。支持类型判断 `x is int` 和引用同一性 `a is b` 两种语义 |
| `.` (字段) | 编译器内置字段查找与模块路径解析 |
| `..` / `..=` | 编译器内置区间语法糖 |
| `?` | 编译器内置错误传播（`try!` 宏替换） |
| `?.` | 编译器内置安全导航 |
| `??` | 编译器内置空值合并 |
| `:=` | 编译器内置海象解构赋值 |
| `@` / `!` / `#` | 宏/装饰器处理 |
| `=:` / `~:` / `*:` | 构建块协议 |
| `^` (move后缀) | 编译器内置所有权转移 |
| `:` / `,` / `->` / `=>` | 标点，语法结构 |

## 四、错误语法边界

```lz
// ❌ 优先级歧义（需加括号消除歧义）
a + b * c          // 正确：* 优先级高
(a + b) * c        // 显式分组

// ❌ 索引与成员访问连用
xs.[0]             // 错误：. 和 [] 不要连用，用 xs[0]

// ❌ 管道右值不是可调用
data |> 42         // 错误：管道右值必须是可调用对象

// ❌ 安全导航用于非 Option 类型
let x: int = 42
x?.method()        // 错误：int 不是 Option<T>

// ❌ 二元运算符缺少括号导致歧义
a + b - c * d / e ** f   // 依赖优先级（合法但建议分组）

// ❌ 逻辑运算符与位运算符混用含混
a & b == 0         // 可能混淆（位与 and 比较），建议加括号

// ❌ 赋值在不可赋值的上下文中
1 + (x = 2)        // 错误：= 最低优先级，不能在表达式中间赋值
// 合法写法：x = 1 + 2  或  使用 := 海象

// ❌ 幂运算符右结合陷阱
-2 ** 2            // -(2**2) = -4，而非 (-2)**2 = 4
(-2) ** 2          // 正确：4
```
