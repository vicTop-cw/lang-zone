# LZ 类型系统

> 版本: 3.1 · 基于编译器源码 · 2026-07-27

本文档定义 Lang-Zong 的完整类型系统：内置类型、容器泛型、类型注解、类型别名、Option/Result 及类型推断规则。

---

## 一、内置类型

### 1.1 标量类型

| LZ 类型 | Rust 映射 | 说明 |
|---------|-----------|------|
| `int` | `i64` | 64 位有符号整数 |
| `f64` | `f64` | 64 位浮点数 |
| `str` | `String` | UTF-8 字符串（堆分配） |
| `bool` | `bool` | 布尔值 |

```lz
let a: int = 42
let b: f64 = 3.14
let c: str = "hello"
let d: bool = True
```

> `string`、`void`、`null`、`float` 不是有效的 LZ 类型名。分别使用 `str`、`()`、`None`、`f64`。

### 1.2 单元类型与发散类型

| LZ 类型 | Rust 映射 | 说明 |
|---------|-----------|------|
| `Unit` | `()` | 单元类型（无返回值） |
| `Never` | `!` | 发散类型（永不返回，如 `panic` 内置函数调用） |


```lz
def log1(msg: str) =    // 无返回值 省略了 `-> Unit`
    print(msg)

def log(msg: str) -> Unit =    // 无返回值
    print(msg)

def abort(msg: str) -> Never = // 永不返回
    panic(msg)
```

### 1.3 Self 类型

```lz
trait Clone =
    def clone(self) -> Self = ...    // self 类型自动推导为 Self，可省略注解

// 显式写出 self: Self 也是合法的，等价于省略：
impl Clone for Point =
    def clone(self: Self) -> Self =
        Point(x: self.x, y: self.y)

// 但推荐省略，更简洁：
impl Clone for Point =
    def clone(self) -> Self =
        Point(x: self.x, y: self.y)
```

`Self` 在 trait 定义中代表实现该 trait 的具体类型，在 impl 中代表目标类型。

## 二、容器泛型

### 2.1 内置容器

| LZ 类型 | Rust 映射 | 说明 |
|---------|-----------|------|
| `List<T>` | `Vec<T>` | 动态数组 |
| `Dict<K, V>` | `HashMap<K, V>` | 哈希字典 |
| `Set<T>` | `HashSet<T>` | 哈希集合 |

```lz
let nums: List<int> = [1, 2, 3]
let ages: Dict<str, int> = {"alice": 30, "bob": 25}
let tags: Set<str> = {"rust", "compiler", "lz"}
```

> `Dict<K,V>` 要求 `K: Hash + Eq`，`Set<T>` 要求 `T: Hash + Eq`。使用自定义类型作为键时必须实现 `Hash` 和 `Eq` trait。

### 2.2 Option

`Type?` 是 `Option<Type>` 的语法糖，两者等价：

| 完整形式 | 简写形式 |
|----------|---------|
| `Option<int>` | `int?` |
| `Option<str>` | `str?` |
| `Option<List<int>>` | `List<int>?` |

```lz
// 完整形式与简写形式等价
let x: Option<int> = Some(42)
let y: int? = None                    // int? 等价于 Option<int>

// 模式匹配 Option
match x:
    case Some(v):  // 冒号后必须换行后缩进
        print(f"value: {v}")
    case None:
        print("empty")

match x:
    case Some(v) =>  // 换行后缩进,前后必须留白， 推荐使用
        print(f"value: {v}")
    case None => print("empty") // 也可不换行写，`=>`,前后必须留白

```

`Option<T>` 映射到 Rust `Option<T>`。`T?` 简写形式在编译时展开为 `Option<T>`，两者在运行时完全等价。

### 2.3 Result

```lz
// Result<int, str> 是可能失败的结果
def divide(a: int, b: int) -> Result<int, str> =
    if b == 0: // 换行后缩进
        Err("division by zero")
    else:
        Ok(a / b)

match divide(10, 2):
    case Ok(v):
        print(f"result: {v}")
    case Err(e):
        print(f"error: {e}")
```

`Result<T, E>` 映射到 Rust `Result<T, E>`。

## 三、类型注解

### 3.1 变量注解

```lz
let x: int = 42              // 完整注解
let name: str = "world"      // 完整注解
let xs: List<int> = [1,2,3]  // 容器注解
```

### 3.2 函数参数与返回注解

```lz
// 完整注解
def add(a: int, b: int) -> int =
    a + b

// 部分注解
def log(msg: str) -> () =
    print(msg)

// 无注解（参数默认 int，返回默认 int）
def double(x) = x * 2

// main 特殊：无注解返回 ()
def main() =
    print("hello")
```

### 3.3 struct 字段注解

struct 字段**必须**带有类型注解：

```lz
struct Point =
    x: f64       // 必须
    y: f64       // 必须
```

## 四、类型推断

### 4.1 推断规则

| 场景 | 行为 |
|------|------|
| 无注解参数 | 默认 `int` |
| 无注解返回 | 默认 `-> int`（main 除外，默认 `-> ()`） |
| `let` 无注解 | 由初始化表达式推断 |
| struct 字段 | **必须**显式注解 |
| 闭包参数 | 由调用上下文推断 |
| `@math` 宏参数 | 每个无注解参数自动获得独立泛型参数 `<T: Number>`，`sq(x, y)` → `sq<T: Number, U: Number>(x: T, y: U)`，返回类型由表达式推断 |

### 4.2 推断示例

```lz
def foo(a, b) = a + b          // a: int, b: int, -> int
let x = 42                     // x: int（字面量推断）
let y = "hello"                // y: str（字面量推断）
let z = [1, 2, 3]              // z: List<int>
let f = |x| x + 1              // 闭包类型由调用处推断
```

## 五、类型别名

### 5.1 模块级别名

```lz
type UserId = int
type NameList = List<str>
type JsonValue = Dict<str, str>

def get_user(id: UserId) -> str = ... // 抽象函数，若未实现，使用会报错，不使用没事

def get_user2(id: UserId) -> str = pass // 占位待实现，若未实现，使用会报错，不使用报警告
```

### 5.2 局部别名（函数内）

```lz
def process() =
    type Id = int
    let x: Id = 42
    x + 1
```

### 5.3 泛型别名

```lz
type Pair<T> = (T, T)
type StringMap<V> = Dict<str, V>

let p: Pair<int> = (1, 2)
let m: StringMap<f64> = {"pi": 3.14}
```

### 5.4 泛型别名 + where 约束

```lz
type MapLike<K, V> = Dict<K, V> where K: Hash + Eq
type Sortable<T> = List<T> where T: Ord
```

编译后等价于 Rust 的 `pub type MapLike<K, V> = HashMap<K, V> where K: Hash + Eq;`。

### 5.5 trait/impl 关联类型

在 trait 中声明关联类型，在 impl 中实现。> 详见 **[06c-trait和impl](06c-trait和impl.md)** §五。

```lz
trait Container =
    type Item                             // 抽象关联类型
    def get(self, index: int) -> Option<Self.Item> = ...

impl Container for List<T> =
    type Item = T                         // 关联类型实现
    def get(self, index: int) -> Option<T> =
        if index < self.length():
            Some(self[index])
        else:
            None
```

关联类型可以是抽象的（仅有 `type Item`），也可以有默认值（`type Item = T`）。

### 5.6 Codegen：透明别名

`type` 是**零开销透明别名** — 不创建新类型，编译后直接替换为基础类型：

```lz
type UserId = int                       // LZ

// → Rust 生成：
pub type UserId = i64;                  // 透明，UserId 就是 i64
```

| | `type` | `struct` |
|------|:---:|:---:|
| 创建新类型 | ❌ 透明 | ✅ 新类型 |
| 零开销 | ✅ 编译期替换 | ❌ 需构造/解构 |
| 适用场景 | 语义别名、缩短长类型名 | 封装、类型安全区分 |

### 5.7 桥接类型别名

`import std.xxx` 时编译器自动注入类型别名：

```lz
import std.io
// 编译器自动生成：pub type IOError = std::io::Error;
```

用户可直接使用 `IOError` 而不需了解 Rust 类型路径。

### 5.8 作用域：Module vs Local

| 作用域 | 语法 | 可见性 | Rust 生成 |
|------|------|:---:|------|
| Module（模块级） | 顶层 `type Name = T` | 整个模块 | `pub type` |
| Local（局部） | 函数内 `type Name = T` | 函数体内 | 内联替换 |

```lz
// 模块级
type UserId = int

def get_user(id: UserId) -> str = ...

// 局部（函数内）
def process() =
    type Id = int
    let x: Id = 42
    x + 1
```

局部别名仅在定义行之后可见，编译时展开为内联替换，不生成 Rust `type` 声明。

### 5.9 完整错误边界

```lz
// ❌ 循环引用
type A = B
type B = A                            // 错误：循环引用

// ❌ 别名不能带函数体 / 装饰器 / raises
type Fn = (int) -> str = ...          // 错误：类型别名不能有函数体
@export
type T = int                          // 错误：类型别名不支持装饰器

// ❌ 别名不能出现在 match 分支
match x:
    case MyAlias => ...               // 错误：类型别名不是模式

// ❌ 局部别名的作用域
def f() =
    let x: Id = 1                     // 错误：Id 尚未定义
    type Id = int
    let y: Id = 2                     // ✅ Id 已定义
```

## 六、类型转换 `as`

`as` 用于显式类型转换：

```lz

let s: str = 42 as str      // int → str
```

- `x as T` → 调用 `x.__cast__() -> T` 或 `x.__try_cast__() -> Result<T, E>`

## 七、复合类型

### 7.1 元组

```lz
let t: (int, str, bool) = (42, "hi", True)
let (a, b, c) = t             // 解构
let (a, _) = t                // 解构：忽略后续元素，要求元组长度 ≥ 解构变量数
let (first, ..) = t           // 解构取出第一个元素
```

### 7.2 引用类型

```lz
let x = 42
ref r: int = x                 // &int（可变引用）
let ref s: int = x             // &int（不可变引用）
```

### 7.3 函数类型

```lz
let f: fn(int, int) -> int = |a, b| a + b  // fn 是个函数类型 trait
```

### 7.4 指针类型

> 详见 [13-指针与引用.md](13-指针与引用.md)。

| LZ 类型 | Rust 映射 | 说明 |
|---------|-----------|------|
| `Box<T>` | `Box<dyn T>` (T=trait) / `Box<T>` (T=具体类型) | 独占所有权堆分配 |
| `Rc<T>` | `Rc<dyn T>` | 引用计数（单线程） |
| `Arc<T>` | `Arc<dyn T>` | 原子引用计数（多线程） |
| `Cell<T>` | `Cell<T>` | 内部可变性（Copy 类型） |
| `RefCell<T>` | `RefCell<T>` | 内部可变性（运行时借用检查） |

### 7.5 辅助类型

| LZ 类型 | Rust 映射 | 说明 |
|---------|-----------|------|
| `Ordering` | `std::cmp::Ordering` | 全序比较结果（Less/Equal/Greater），`__cmp__` 返回值 |
| `Formatter` | `std::fmt::Formatter` | 格式化输出器，`__fmt__`/`__str__` 的参数类型 |

### 7.6 并发类型

| LZ 类型 | Rust 映射 | 说明 |
|---------|-----------|------|
| `Future<T>` | `impl Future<Output = T>` | 异步任务句柄，`spawn`/`go` 返回值 |
| `Futures<T1, T2, ...>` | `(F1, F2, ...)` | 1~12 个并发任务句柄元组 |

### 7.7 Nil 类型

`Nil` 是空列表 `[]` 的类型别名，映射到 Rust `()`。主要用于类型注解场景如 `def f() -> Nil`。`[]` 作为值，`Nil` 作为类型。设计阶段，当前使用 `[]` 直接表示。

## 九、Duck 类型约束

### 9.1 概述

`duck` 定义**结构性类型约束**（鸭子类型），与 `trait`（名义类型）互补：

| | `trait` | `duck` |
|---|---|---|
| 匹配方式 | **名义匹配** — 需显式 `impl Trait for Type` | **结构匹配** — 类型满足方法签名即自动满足约束 |
| 第三方类型 | 无法 impl 不拥有的 trait | ✅ 自动匹配，只要结构符合 |
| 类型检查 | 编译期查 impl 注册表 | 编译期查方法签名一致 |
| 性能 | 零开销（静态分发） | 零开销（编译期展开） |

`duck` 编译期检查：当类型 `T` 被用作 `duck` 约束的实参时，编译器检查 `T` 是否拥有 `duck` 块中声明的所有方法（名称、self 形态、参数类型、返回类型）。**不生成运行时开销**。

### 9.2 语法

```lz
duck ConstraintName =
    def method1(self, ...) -> RetType
    def method2(mut self, ...) -> RetType
    .field_name: FieldType            // 可选字段约束
    type AssociatedType               // 可选关联类型
```

| 部分 | 说明 |
|------|------|
| `duck` | 关键字声明 |
| `ConstraintName` | 约束名称（首字母大写，与类型名相同规范） |
| `def` | 方法签名——声明要求目标类型包含该方法 |
| `self` / `ref self` / `mut self` | self 形态，与 trait 方法一致 |
| `.field_name: Type` | 可选字段约束——要求目标类型有该字段 |
| `type X` | 可选关联类型声明 |

### 9.3 基本用法

**定义 duck 约束**：

```lz
// 鸭子类型：任何有 quack() 和 walk() 方法的类型都满足
duck Quackable =
    def quack(self) -> ()
    def walk(self) -> ()

// 包含字段约束
duck HasName =
    .name: str
    def greet(self) -> str

// 包含关联类型
duck Iterable =
    type Item
    def __iter__(self) -> Iterator<Self.Item>
```

**作为泛型约束使用**：

```lz
// 在泛型参数中使用 duck（与 trait 约束语法一致）
def make_quack[T: Quackable](x: T) =
    x.quack()
    x.walk()

// 在 where 子句中使用
def process[T](x: T) where T: Quackable + HasName =
    print(x.greet())
    x.quack()
```

### 9.4 结构匹配规则

编译器在编译期执行以下检查：

| 检查项 | 规则 | 示例 |
|--------|------|------|
| 方法名 | 必须精确匹配 | `quack` ≠ `quak` |
| self 形态 | `self` vs `ref self` vs `mut self` 必须一致 | `def quack(self)` ≠ `def quack(ref self)` |
| 参数类型 | 参数顺序、类型、数量必须一致 | `def walk(self, n: int)` ≠ `def walk(self)` |
| 返回类型 | 必须一致 | `def quack(self) -> str` ≠ `def quack(self) -> ()` |
| 字段名 | `.name` 要求目标类型有同名字段 | `Point` 有 `.x: f64` 即满足 `duck` 的 `.x: f64` |
| 关联类型 | 名称和约束必须一致 | `type Item` 要求目标有关联类型 `Item` |

**何时触发检查**：

```lz
// 1. 泛型函数调用处
make_quack(my_duck)         // 检查 Duck 类型是否满足 Quackable 约束

// 2. 变量绑定（带 duck 类型注解）
let x: Quackable = some_val   // 编译期检查 some_val 的类型是否满足
```

> **注意**：`duck` 的约束检查在**泛型实例化时**发生（Rust 中 monomorphization 阶段）。不是 `duck` 定义时。这意味着 `duck Quackable = ...` 本身不报错——报错发生在 `make_quack(my_duck)` 而 `MyDuck` 不满足约束时。

### 9.5 与 trait 共存

`duck` 和 `trait` 可以混合使用在同一约束中：

```lz
// 既是 Duckable（结构匹配）又是 Display（名义 trait）
def show_and_quack[T: Quackable + Display](x: T) =
    print(x.to_string())
    x.quack()
```

`duck` 约束也可以引用 `trait` 方法：

```lz
// duck 约束中包含一个 trait 方法要求
duck Printable =
    def to_string(ref self) -> str    // 对应 Display trait 的 to_string
```

### 9.6 与 type 别名的区别

```lz
// type 别名 —— 给已有类型起新名字
type UserId = int                     // UserId 就是 int，等价

// duck 约束 —— 定义结构性约束，不是类型
duck CanGreet =
    .name: str
    def greet(self) -> str

// 用法区别
def process1(id: UserId) = ...        // UserId 是 int 的同义词
def process2[T: CanGreet](x: T) = ... // T 必须是"有 name 字段且能 greet"的类型
```

### 9.7 完整示例

```lz
// type 别名 —— 给已有类型起新名字
type UserId = int                     // UserId 就是 int，等价

// duck 约束 —— 定义结构性约束，不是类型
duck CanGreet =
    .name: str
    def greet(self) -> str

// 用法区别
def process1(id: UserId) = ...        // UserId 是 int 的同义词
def process2[T: CanGreet](x: T) = ... // T 必须是"有 name 字段且能 greet"的类型
```

### 9.7 完整示例

```lz
// 定义 duck 约束
duck HasArea =
    def area(self) -> f64

// 两个不相关的 struct，但都有 area 方法
struct Circle =
    radius: f64
    def area(self) -> f64 = 3.14159 * self.radius * self.radius

struct Rectangle =
    width: f64
    height: f64
    def area(self) -> f64 = self.width * self.height

// 泛型函数使用 duck 约束
def print_area[T: HasArea](shape: T) =
    print(f"area: {shape.area()}")

// 使用 —— 不需 impl，结构匹配自动生效
let c = Circle(radius: 2.0)
let r = Rectangle(width: 3.0, height: 4.0)
print_area(c)          // OK: Circle 有 area() ✅
print_area(r)          // OK: Rectangle 有 area() ✅
print_area(42)         // ❌ 编译错误: int 没有 area()
```

> **扩展**：`duck` 还支持**多类型间的关系约束**（如 `T.map 的返回类型等于 R`），见 [01b-duck关系约束.md](01b-duck关系约束.md)。
