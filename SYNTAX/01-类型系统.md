# LZ 类型系统

> 版本: 3.1 · 基于编译器源码 · 2026-07-27

本文档定义 Lang-Zong 的完整类型系统：内置类型、容器泛型、类型注解、类型别名、Option/Result 及类型推断规则。

---

## 一、内置类型

### 1.1 标量类型

| LZ 类型 | Rust 映射 | 说明 |
|---------|-----------|------|
| `int` | `i64` | 64 位有符号整数 |
| `f64` | `f64` | 64 位浮点数 |
| `str` | `String` | UTF-8 字符串（堆分配） |
| `bool` | `bool` | 布尔值 |

```lz
let a: int = 42
let b: f64 = 3.14
let c: str = "hello"
let d: bool = True
```

> `string`、`void`、`null`、`float` 不是有效的 LZ 类型名。分别使用 `str`、`()`、`None`、`f64`。

### 1.2 单元类型与发散类型

| LZ 类型 | Rust 映射 | 说明 |
|---------|-----------|------|
| `Unit` | `()` | 单元类型（无返回值） |
| `Never` | `!` | 发散类型（永不返回，如 `panic` 内置函数调用） |


```lz
def log1(msg: str) =    // 无返回值 省略了 `-> Unit`
    print(msg)

def log(msg: str) -> Unit =    // 无返回值
    print(msg)

def abort(msg: str) -> Never = // 永不返回
    panic(msg)
```

### 1.3 Self 类型

```lz
trait Clone =
    def clone(self: Self) -> Self = ...

struct Point =
    x: int
    y: int

impl Clone for Point =
    def clone(self: Self) -> Self =
        Point(x: self.x, y: self.y)
```

`Self` 在 trait 定义中代表实现该 trait 的具体类型，在 impl 中代表目标类型。

## 二、容器泛型

### 2.1 内置容器

| LZ 类型 | Rust 映射 | 说明 |
|---------|-----------|------|
| `List<T>` | `Vec<T>` | 动态数组 |
| `Dict<K, V>` | `HashMap<K, V>` | 哈希字典 |
| `Set<T>` | `HashSet<T>` | 哈希集合 |

```lz
let nums: List<int> = [1, 2, 3]
let ages: Dict<str, int> = {"alice": 30, "bob": 25}
let tags: Set<str> = {"rust", "compiler", "lz"}
```

### 2.2 Option

```lz
// Option<int> 是可空整数
let x: Option<int> = Some(42)
let y: Option<int> = None

// 模式匹配 Option
match x:
    case Some(v):  // 冒号后必须换行后缩进
        print(f"value: {v}")
    case None:
        print("empty")

match x:
    case Some(v) =>  // 换行后缩进,前后必须留白， 推荐使用 
        print(f"value: {v}")
    case None => print("empty") // 也可不换行写，`=>`,前后必须留白 

```

`Option<T>` 映射到 Rust `Option<T>`。

### 2.3 Result

```lz
// Result<int, str> 是可能失败的结果
def divide(a: int, b: int) -> Result<int, str> =
    if b == 0: // 换行后缩进
        Err("division by zero")
    else:
        Ok(a / b)

match divide(10, 2):
    case Ok(v): 
        print(f"result: {v}")
    case Err(e):
        print(f"error: {e}")
```

`Result<T, E>` 映射到 Rust `Result<T, E>`。

## 三、类型注解

### 3.1 变量注解

```lz
let x: int = 42              // 完整注解
let name: str = "world"      // 完整注解
let xs: List<int> = [1,2,3]  // 容器注解
```

### 3.2 函数参数与返回注解

```lz
// 完整注解
def add(a: int, b: int) -> int =
    a + b

// 部分注解
def log(msg: str) -> () =
    print(msg)

// 无注解（参数默认 int，返回默认 int）
def double(x) = x * 2

// main 特殊：无注解返回 ()
def main() =
    print("hello")
```

### 3.3 struct 字段注解

struct 字段**必须**带有类型注解：

```lz
struct Point =
    x: f64       // 必须
    y: f64       // 必须
```

## 四、类型推断

### 4.1 推断规则

| 场景 | 行为 |
|------|------|
| 无注解参数 | 默认 `int` |
| 无注解返回 | 默认 `-> int`（main 除外，默认 `-> ()`） |
| `let` 无注解 | 由初始化表达式推断 |
| struct 字段 | **必须**显式注解 |
| 闭包参数 | 由调用上下文推断 |
| `@math` 宏参数 | 默认 `int` + Number trait 标记 |

### 4.2 推断示例

```lz
def foo(a, b) = a + b          // a: int, b: int, -> int
let x = 42                     // x: int（字面量推断）
let y = "hello"                // y: str（字面量推断）
let z = [1, 2, 3]              // z: List<int>
let f = |x| x + 1              // 闭包类型由调用处推断
```

## 五、类型别名

### 5.1 模块级别名

```lz
type UserId = int
type NameList = List<str>
type JsonValue = Dict<str, str>

def get_user(id: UserId) -> str = ... // 抽象函数 ，若未实现 ，使用会报错,不使用没事

def get_user2(id: UserId) -> str = pass // 占位待实现 ，若未实现 ，使用会报错，不使用报警告
```

### 5.2 局部别名（函数内）

```lz
def process() =
    type Id = int
    let x: Id = 42
    x + 1
```

### 5.3 泛型别名

```lz
type Pair<T> = (T, T)
type StringMap<V> = Dict<str, V>

let p: Pair<int> = (1, 2)
let m: StringMap<f64> = {"pi": 3.14}
```

## 六、类型转换 `as`

`as` 用于显式类型转换：

```lz
let x: int = 42
let y: f64 = x as f64       // int → f64
let s: str = 42 as str      // int → str
```

与魔法方法的对应：
- `x as T` → 调用 `x.__cast__() -> T` 或 `x.__try_cast__() -> Result<T, E>`
- 详见 [06d-内置魔法trait](06d-内置魔法trait和全局函数.md) §三 类型转换

## 七、复合类型

### 6.1 元组

```lz
let t: (int, str, bool) = (42, "hi", True)
let (a, b, c) = t             // 解构
let (a, _) = t                // 解构：忽略后续元素，要求元组长度 ≥ 解构变量数
let (first, ..) = t           // 解构取出第一个元素
```

### 6.2 引用类型

```lz
let x = 42
ref r: int = x                 // &int（可变引用）
let ref s: int = x             // &int（不可变引用）
```

### 6.3 函数类型

```lz
let f: fn(int, int) -> int = |a, b| a + b  // fn 是个函数类型 trait
```

## 八、错误类型边界

```lz
// ❌ 非法类型名
let x: void = ()               // 错误：void 不是类型
let s: string = "hi"           // 错误：应为 str
let f: float = 3.14            // 错误：应为 f64
let n: null = None             // 错误：None 不是类型名

// ❌ struct 字段无注解
struct Bad =
    x                          // 错误：字段必须带类型注解
    y: int

// ❌ 类型别名循环引用
type A = B
type B = A                     // 错误：循环引用

// ❌ 类型与值混淆
let x: None = ...              // 错误：None 是值不是类型，应为 Option<T>
let y: Some = ...              // 错误：Some 是构造器不是类型
```
