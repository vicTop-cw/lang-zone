# LZ 函数 — 可变参数

> 版本: 3.1 · 基于编译器源码 · 2026-07-27

LZ 提供两种可变参数模式：**安全收集**（类型安全，无 `..`）和 **`..` 分隔符模式**（动态类型，unsafe 边界）。

---

## 一、安全收集：`lst: List<T>`（无 `..`）

**不需要 `..`**。直接将 `List<T>` 作为参数，编译器自动将所有位置实参收集到该 List 中：

```lz
def sum_all(values: List<int>) -> int =
    total = 0
    for v in values:
        total += v
    total

sum_all(1, 2, 3, 4, 5)           // 15 — 自动收集为 List<int>
sum_all()                          // 0  — 空参，values = []
sum_all([1, 2, 3])                // 15 — 显式传 List 也可以
```

- 编译期类型安全，所有参数必须能转为 `T`
- 空参合法，`values = []`
- `name..: Type` 是 `name: List<Type>` 的语法糖，两者等价

---

## 二、`..` 分隔符模式

`..` 是参数列表中控制**传递方式**的分隔符，最多出现 **2 次**。

### 2.1 核心规则：`..` 影响参数传递方式

```
[仅位置参数]  ..  [仅关键字参数]  ..  [多余命名实参 → kwargs]
```

- **`..` 之前**：参数仅接受**位置传递**
- **`..` 之后**：参数仅接受**关键字传递**（`name=val`）
- **无 `..` 约束**：参数同时支持位置和关键字传递
- **`args` / `kwargs` 收集**：仅在**两个 `..`** 时生成

### 2.2 List 参数的位置语义

| 签名 | `lst` 传递方式 | 说明 |
|------|:---:|------|
| `f(lst: List<T>)` | 位置或关键字 | 无 `..` 参与。自动收集所有位置实参，或接收一个显式 List |
| `f(lst: List<T>, ..)` | 位置或关键字 | `..` 在末尾，不影响 `lst`。剩余命名实参 → `kwargs` |
| `f(.., lst: List<T>)` | **仅关键字** | `..` 在 `lst` 之前，`lst` 必须用关键字传递 |
| `f(a: int, lst: List<T>, ..)` | 位置或关键字 | `a` 必须位置。`lst` 在后面不受 `..` 约束 |
| `f(.., a: int, lst: List<T>)` | a、lst 均仅关键字 | `..` 在最前，后面所有参数都必须关键字传递 |

### 2.3 完整模式表

| 签名 | 传递约束 | args | kwargs | 说明 |
|------|------|:---:|:---:|------|
| `f(lst: List<T>)` | lst: 位置或关键字 | — | — | 安全收集 |
| `f(lst: List<T>, ..)` | lst: 位置或关键字 | — | — | `..` 单独无作用 |
| `f(.., lst: List<T>)` | lst: 仅关键字 | — | — | 必须 `lst=[...]` |
| `f(a: int, ..)` | a: 仅位置 | — | — | 去掉尾巴关键字能力 |
| `f(.., ..)` | — | ✅ | ✅ | 双 `..`，args + kwargs 激活 |
| `f(..: Tuple<str, ..>, ..: Dict<str, int>)` | 2 | ✅ | ✅ | args 元素=str；kwargs 值=int |
| `f(a: int, .., b: str, ..)` | a: 仅位置；b: 仅关键字 | ✅ | ✅ | 双 `..`，双收集 |
| `f(a: int, ..: Tuple<int>, b: str, ..: Dict<str, f64>)` | a: 仅位置；b: 仅关键字 | ✅ | ✅ | args=int；kwargs=f64 |

### 2.4 `..` 类型标注

`..` 支持附带类型注解，约束 `args` / `kwargs` 的动态类型：

```lz
// ..: Tuple(T1, T2, ...) — 约束 args 的元素类型
def log(..: Tuple<str, int>, ..) =
    for v in args:
        print(v)              // v: str | int

// ..: Dict<K, V> — 约束 kwargs 的值类型
def config(.., ..: Dict<str, str | int>) =
    for (k, v) in kwargs:
        print(f"{k}: {v}")    // v: str | int

// 两端都标注
def handler(..: Tuple<str, ..>, ..: Dict<str, str>) =
    // args 元素类型: str（可变长元组）
    // kwargs 值类型: str
    ...
```

| 标注 | 含义 |
|------|------|
| `..: Tuple<T>` | args 中每个元素类型为 T |
| `..: Tuple<T1, T2, ...>` | args 按位置约束不同类型 |
| `..: Dict<K, V>` | kwargs 的值类型为 V |
| 无标注 | 默认 `Box<dyn Any>` 擦除 |

### 2.5 内置变量

仅在**两个 `..`** 模式中，编译器自动注入：

| 变量 | 类型 | 出现条件 |
|------|------|---------|
| `args` | `Vec<Box<dyn Any>>` | 两个 `..` |
| `kwargs` | `HashMap<String, Box<dyn Any>>` | 两个 `..` |

## 三、示例

```lz
// === 安全收集 — 推荐 ===
def log(level: str, messages: List<str>) =
    for msg in messages:
        print(f"[{level}] {msg}")

log("INFO", "started", "ready")          // 自动收集
log("INFO", ["started", "ready"])        // 显式 List

// === .. 分隔符 ===

// lst: 位置或关键字 — 单个 .. 无特殊效果
def proc<T>(lst: List<T>, ..) =
    for x in lst:
        print(x)

proc([1, 2, 3])                          // lst 位置传入
proc(lst=[1, 2, 3])                      // lst 关键字传入

// lst: 仅关键字（.. 在 lst 之前）
def kw_proc<T>(.., lst: List<T>) =
    for x in lst:
        print(x)

kw_proc(lst=[1, 2, 3])                   // ✅ 必须关键字
// kw_proc([1, 2, 3])                    // ❌ 错误：lst 是仅关键字参数
```

## 四、语法边界

```lz
// ❌ `..` 最多出现 2 次
def f(.., .., ..) = ...

// ❌ 连续逗号
def f(..,,..) = ...

// ❌ List 参数在 .. 之后不能自动收集位置参数
def f(.., lst: List<int>) = ...
// f(1, 2, 3)  // 错误：lst 仅关键字，不接受位置参数
```

---

## 五、两种模式对比

| | 安全 `lst: List<T>` | `..` 分隔符 |
|------|:---:|:---:|
| 类型安全 | ✅ 编译期 | ❌ `Any` 擦除 |
| 空参调用 | ✅ `lst = []` | 视签名而定 |
| 关键字传递 | ✅ 支持 | 受 `..` 位置控制 |
| 内置变量 | 无 | `args` / `kwargs` |
| 推荐场景 | 同类型变长 | 异构参数、DSL |
