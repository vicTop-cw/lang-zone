## 🔴 一、严重问题（逻辑矛盾）

### 1.1 `ref` 语义自相矛盾 — 02-变量与绑定.md

**§一 表格**说 `ref x = 42` 是**不可变引用**：

```
| `let x = 42`   | 不可变绑定     |
| `x = 42`       | 默认可变绑定   |
| `ref x = 42`   | 不可变引用     |  ← 这里说不可变
| `mut ref x = 42` | 可变引用     |
```

**§5.1 示例**却说 `ref r = x` 是**可变引用**：

```lz
x = 42
ref r = x         // r 是 x 的可变引用    ← 这里说可变
r = 100           // 通过引用修改 x
```

**§5.2 示例**说 `let ref r = x` 是**不可变引用**：

```lz
let ref r = x     // r 是 x 的不可变引用
```

**推论矛盾**：按照 LZ "默认可变"原则，`ref r = x`（无 `let`）应该是可变的，这与 §一 表格冲突。需统一语义：要么表格改成"可变引用"，要么 §5.1 的注释改成"不可变引用"并说明为何能修改 x。

**涉及文件**：02-变量与绑定.md（§一 表格 vs §五 示例）

## 🔵 四、遗漏

全体 enum 文档没有提到**枚举变体是否能定义方法**。06a-struct.md 明确讲了 struct 方法（§三），而 06b-enum.md 完全没有对应内容。
