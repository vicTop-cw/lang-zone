# 代码生成审计

## 一、函数生成 (gen_function)

| LZ 语法 | Rust 生成 | 验证 |
|---------|----------|:---:|
| `def f(x) = x + 1` | `pub fn f(x: i64) -> i64 { x + 1 }` | ✅ |
| `def f(x: int) -> int = x * x` | `pub fn f(x: i64) -> i64 { x * x }` | ✅ |
| `def main() = print("hello")` | `pub fn main() -> i64 { println!("hello") }` | ✅ |
| `def f<T>(x: T) -> T = x` | `pub fn f<T>(x: T) -> T { x }` | ❌ |
| `def f<T>(x: T) where T <: fmt::Debug` | `pub fn f<T>(x: T) -> T\nwhere T: Debug { x }` | ❌ |
| `def f<T = i64>(x: T) = x` | `pub fn f<T = i64>(x: T) -> T { x }` | ❌ |
| `def async foo() = await x` | `pub async fn foo() -> i64 { { x }.await }` | ❌ |
| `def f(x) raises Error` | `pub fn f(x: T) -> Result<T, Error> { Ok(...) }` | ❌ |
| `def f(x: int, y: int) raises MathError` | `pub fn f(x: i64, y: i64) -> Result<T, MathError>` | ❌ |
| `@export(Rust) def f() = 1` | `pub fn f() -> i64 { 1 }` | ✅ |
| `@export(Python) def f() = 1` | `#[cfg(feature="pyo3")] pub mod __pyo3 { #[pyfunction] fn f() -> PyResult<i64> { ... } }` | ❌ |
| `@memoize def fib(n) = ...` | 自动生成 `OnceLock<Mutex<HashMap<K,V>>>` 缓存包装器 + `_fib_impl` 内部函数 | ✅ |
| `@simd def f() = ...` | `#[inline(always)] pub fn f() ...` | ✅ |
| `@parallel def f() = ...` | `// @parallel: rayon candidate` 注释 + `pub fn f()` | ✅ |
| `@tail_call def f() = ...` | `// @tail_call: ensure tail-call` 注释 + `pub fn f()` | ✅ |
| `@math def f() = ...` | `// @math: Number-trait polymorphic` 注释 + `pub fn f()` | ✅ |
| `@inline(always) def f() = 1` | `#[inline(always)] pub fn f() -> i64 { 1 }` (passthrough) | ❌ |
| `def f(*..args: int, **..kwargs: str)` | 注入 `args: Vec<Box<dyn Any>>, kwargs: HashMap<String, Box<dyn Any>>` | ❌ |
| `def f(...) [checker]` | `unsafe fn f(ps: Option<fn(__Params)->__Params>, ...)` + checker 包装 | ❌ |
| `def _private() = 1` | `fn _private() -> i64 { 1 }` (无 pub) | ❌ |
| `def __init__() = 0` | `pub fn __init__() -> i64 { 0 }` (dunder 仍 pub) | ❌ |

## 已知风险点

1. **variadic 未测试** — `..` / `..*` / `..**` 可变参数函数调用侧打包/解包无 E2E 测试
2. **raises 未测试** — 错误枚举的 Display + Error 自动 impl 无对应测试用例
3. **defer 未测试** — DeferGuard LIFO Drop 语义无测试
4. **生成器 `*:` 构建块未测试** — yield/yield from、IterStopException 路径无测试
5. **异步代码未测试** — `async fn`、`await` 无测试
6. **try/catch 未测试** — `try: ... catch Err(e): ...` 模式无测试
7. **@export(Python) 未测试** — PyO3 绑定生成无编译验证
8. **结构体方法中的 self 自动 clone 未测试** — `self.string_field.clone()` 行为无覆盖
9. **列表推导未测试** — `[x for x in range if cond]` 无测试
10. **SafeNav / NullCoalesce 未测试** — `?.` / `??` 操作符无测试
11. **内置类型转换函数未测试** — `int()`, `str()`, `float()`, `bool()`, `hash()`, `list()`, `set()`, `dict()` 无测试
12. **复合运算符除 +/*/= 外未测试** — `<<=` / `>>=` / `|=` / `^=` / `&=` 无测试
