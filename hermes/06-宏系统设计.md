# Lang-Zong 宏系统设计 v2

> 参考仓颉语言宏系统，适配 lz 缩进语法。
> 设计原则：签名固定、展开后检测、内部仅做 Token 分组分类、支持嵌套。

## 一、设计哲学

### 核心原则

| 原则 | 说明 |
|------|------|
| **`@name!` 是宏，`@name` 是装饰器** | `!` 后缀是宏调用的唯一标识 |
| **展开后检测** | lz 语法检测只作用于宏展开后的代码 |
| **内部轻量解析** | 宏体内部仅做 Token 分组分类，不进行完整类型检查 |
| **签名固定** | `(Tokens) -> Tokens` 或 `(Tokens, Tokens) -> Tokens` |
| **支持嵌套** | 内层优先展开，反引号块内的宏延迟展开 |
| **仓颉为参考** | Token 模型、API 设计对齐仓颉 |

### 与仓颉的关键差异

| 特性 | 仓颉 | lz (Lang-Zong) |
|------|------|----------------|
| 块语法 | `{ }` 大括号 | 缩进 |
| 宏定义关键字 | `public macro` | `macro` |
| 类型注解 | `: Tokens` | `: Tokens` |
| 返回类型 | `: Tokens` | `-> Tokens` |
| 宏调用 | `@name()` / `@name` | `@name!()` / `@name!` ← **注意 `!`** |
| 装饰器 | 无单独概念 | `@name` ← **无 `!`** |
| 代码捕获 | `quote(...)` | ` ```...``` ` 反引号块 |
| 插值 | `$x` / `$(expr)` | `$x` / `$(expr)` 在 `f ``` ` 内 |
| 字符串 | `"..."` | `"..."` / `f"..."` / `r"..."` / `"""..."""` |

## 二、三种 @ 语法区分

### 2.1 @name! — 宏调用

```lz
@twice!(1 + 2)              // 带括号：表达式宏调用
@twice!(                    // 多行也可以
    1 + 2
)
@log_expr!                  // 无括号：作用于下一个声明
def foo() = 42

@derive_debug![Debug]       // 有属性宏：[] 中是属性
struct Point = ...
```

**词法特征**：`@` + 标识符 + `!`

### 2.2 @name — 装饰器

```lz
@simd                       // 装饰器（已有语法，保持不变）
def vec_add() = ...

@parallel
def process() = ...
```

**词法特征**：`@` + 标识符（**无 `!`**），现有代码无需修改。

### 2.3 @name! 与 @name 在 Token 流的区分

```
Token: [At, Ident("foo"), Exclamation, LParen, ...]  → 宏调用 @foo!(
Token: [At, Ident("foo"), Exclamation, Newline, ...]  → 宏调用 @foo!（无括号）
Token: [At, Ident("foo"), Newline/Ident/Def/...]      → 装饰器 @foo
```

### 2.4 在反引号块内部

反引号块内部，`@name!` 和 `@name` 都**不会被立即展开**：

```lz
let t: Tokens = ```
    @twice!(x)      // ← 保留原样，不展开
    @simd           // ← 保留原样，不展开
    def f() = 42
```
```

## 三、核心类型：Tokens

### 3.1 Tokens 定义

```rust
pub struct Tokens {
    pub tokens: Vec<Token>,
    pub span: Span,
    pub kind: TokenGroupKind,    // 运行时分类
}
```

### 3.2 TokenGroupKind 分组类型

```rust
pub enum TokenGroupKind {
    Expr,      // 表达式 tokens：1 + 2, foo(), x.y
    Decl,      // 声明 tokens：def/struct/enum/trait/impl/const
    Stmt,      // 语句 tokens：return x, if ..., for ...
    Pattern,   // 模式 tokens：Some(x), (a, b), _
    Type,      // 类型标注 tokens：int, List<str>, Option<int>
    Any,       // 未分类（默认）
}
```

### 3.3 ToTokens 接口

```rust
trait ToTokens {
    fn to_tokens(&self) -> Tokens;
}

// 内置实现
impl ToTokens for i64  { /* → IntLit Token */ }
impl ToTokens for f64  { /* → FloatLit Token */ }
impl ToTokens for str  { /* → StrLit Token */ }
impl ToTokens for bool { /* → True/False Token */ }
impl ToTokens for Tokens { /* 返回自身 */ }
```

## 四、宏定义语法

### 4.1 无属性宏

固定 1 个 `Tokens` 参数：

```lz
macro foo(input: Tokens) -> Tokens =
    ```

        $input
    ```

macro twice(input: Tokens) -> Tokens =
    ```

        $input + $input
    ```

macro log_expr(input: Tokens) -> Tokens =
    let label = ```
        $input
    ```
    f```
        let __val = $input
        print(f"[DEBUG] $(label.to_string()) = {__val}")
        __val
    ```
```

**语法规则**：
```
macro_def ::= 'macro' IDENT '(' IDENT ':' 'Tokens' ')' '->' 'Tokens' '=' NEWLINE INDENT stmt* DEDENT
```

**约束**：
- 宏名不能与已有函数/类型/变量同名
- 宏定义必须在模块顶层
- 参数类型必须为 `Tokens`，返回值类型必须为 `Tokens`
- 宏体是受限 lz 代码（仅 Token 操作 + 控制流）

### 4.2 有属性宏

固定 2 个 `Tokens` 参数（属性 + 输入）：

```lz
macro derive_debug(attr: Tokens, input: Tokens) -> Tokens =
    f```

        $input

        impl Debug for $(input.name) =
            def __str__(self: Self) -> str =
                f"$(input.name)(...)"
    ```
```

**语法规则**：
```
macro_def ::= 'macro' IDENT '(' IDENT ':' 'Tokens' ',' IDENT ':' 'Tokens' ')' '->' 'Tokens' '=' NEWLINE INDENT stmt* DEDENT
```

### 4.3 宏注册

```rust
pub struct MacroRegistry {
    macros: HashMap<String, MacroDef>,
}

pub struct MacroDef {
    pub name: String,
    pub is_attr: bool,          // 是否为有属性宏
    pub param_names: Vec<String>,
    pub body_ast: Vec<Stmt>,    // 宏体 AST（受限 lz 语法）
    pub span: Span,
}
```

## 五、宏调用语法

### 5.1 无属性宏调用

```lz
// 带括号
@foo!(1 + 2)
@twice!(print("hello"))

// 多行括号（缩进自由）
@twice!(
    1 + 2
)

// 作用于声明（无括号）
@log_expr!
def add(a: int, b: int) -> int =
    a + b

@log_expr!
struct Point =
    x: f64
    y: f64
```

**语法规则**：
```
macro_call ::= '@' IDENT '!' '(' token_seq ')'     // 带括号
             | '@' IDENT '!' NEWLINE/SPACE decl    // 作用于声明
```

### 5.2 有属性宏调用

```lz
// 属性在 [] 中，输入在 () 中
@attr_demo![debug](def foo() = 42)

// 作用于声明
@derive_debug![Clone, Debug]
struct Point =
    x: f64
    y: f64
```

**语法规则**：
```
attr_macro_call ::= '@' IDENT '!' '[' token_seq ']' '(' token_seq ')'
                  | '@' IDENT '!' '[' token_seq ']' NEWLINE/SPACE decl
```

### 5.3 转义

```lz
\@foo!       // 不是宏调用，是普通 token 序列 @foo!
\$var        // 不是插值，是普通 token 序列 $var
```

## 六、反引号代码块（取代 quote 关键字）

### 6.1 基本用法

` ``` ` 三反引号将代码片段捕获为 `Tokens`，不进行求值。与 Markdown 代码块风格一致。

```lz
let a: Tokens = ```
    1 + 2
```
// a.tokens = [IntLit(1), Plus, IntLit(2)]

let b: Tokens = ```
    def foo() = 42
```
// b.tokens = [Def, Ident("foo"), LParen, RParen, Eq, IntLit(42)]

let c: Tokens = ```
    if x > 0:
        return x
```
// c.tokens = [If, Ident("x"), Gt, IntLit(0), Colon, Newline, Indent, Return, Ident("x"), Dedent]
```

**语法规则**：
```
backtick_block ::= '```' NEWLINE token_seq NEWLINE '```'
```

**约束**：
- 开始和结束的 ` ``` ` 必须各自占一行
- 内部的缩进会被规范化为相对缩进（类似 Python `textwrap.dedent`）
- 内部 token 直接按 lz 词法规则扫描
- `$` 在普通 ` ``` ` 中为普通 token（不插值）
- `@name!` 在普通 ` ``` ` 中为普通 token（不展开）

### 6.2 f 前缀：插值模式

`f ``` ` 启用代码插值，行为类似 `f"..."` 字符串：

```lz
let op: Tokens = ```
    +
```
let result: Tokens = f```
    1 $(op) 2
```
// result.tokens = [IntLit(1), Plus, IntLit(2)]

let name = "world"
let greeting: Tokens = f```
    print("Hello, $(name)")
```
// greeting.tokens = [Ident("print"), LParen, StrLit("Hello, world"), RParen]
```

**插值范围规则**：

```lz
let x: int = 5

f```
    $x + 2
```                         // → 5 + 2

f```
    $(x + 1) + 2
```                         // → 6 + 2

f```
    1 + ($x + 1) * 2
```                         // → 1 + (5 + 1) * 2
```

### 6.3 r 前缀：原始模式

`r ``` ` 禁用所有插值和宏展开，类似 `r"..."` 原始字符串：

```lz
let t: Tokens = r```
    @some_macro!(x + y)     // ← 不展开
    $var                    // ← 不插值
    $(expr)                 // ← 不插值
```
// t 中的所有 token 保持原样，$ 和 @ 都是普通 token
```

### 6.4 三种模式对比

| 模式 | `$()` 插值 | `@name!` 展开 | 用途 |
|------|-----------|--------------|------|
| ` ``` ` (普通) | ❌ 不插值 | ❌ 不展开 | 简单 token 捕获 |
| `f ``` ` (插值) | ✅ 插值求值 | ❌ 不展开 | 构建含变量的代码 |
| `r ``` ` (原始) | ❌ 不插值 | ❌ 不展开 | 原样保留所有 token |

**关键规则**：反引号块内的 `@name!` 宏调用**永远不会立即展开**。展开只发生在：
1. 反引号块的结果被返回给调用者之后
2. 宏展开引擎处理展开后的 token 流时

### 6.5 Tokens 拼接

```lz
let a: Tokens = ```
    def
```
let b: Tokens = ```
     f() = 42
```
let c: Tokens = a + b
// c.to_string() == "def f() = 42"
```

## 七、Token 上游流水线

### 7.1 流水线架构

```
┌──────────┐     ┌─────────────┐     ┌──────────────┐     ┌──────────┐     ┌──────────┐
│ .lz 源文件 │ ──→ │   Lexer     │ ──→ │ MacroExpander │ ──→ │  Parser  │ ──→ │ CodeGen  │
│           │     │ (token.rs)  │     │  (新增模块)    │     │(parser.rs)│     │(codegen) │
└──────────┘     └─────────────┘     └──────────────┘     └──────────┘     └──────────┘
                                            │
                                     ┌──────┴──────┐
                                     │  展开后的    │
                                     │  Token 流    │
                                     │ (无 @name! ) │
                                     └─────────────┘
```

**新增模块 `src/macro_expand.rs`** 负责：
1. 扫描 Token 流，识别 `@name!(` / `@name!` / `@name![attr](` 模式
2. 区分宏调用（有 `!`）和装饰器（无 `!`）
3. 查找宏定义（从 `MacroRegistry`）
4. 将输入 tokens 按分组分类
5. 执行宏体 → 返回 `Tokens`
6. 将结果 tokens 拼接到原位置
7. 递归处理嵌套宏（内层优先）

### 7.2 展开算法

```
function expand_macros(tokens: Vec<Token>, registry: &MacroRegistry) -> Vec<Token>:
    result = []
    i = 0
    while i < tokens.len():
        if tokens[i] == At AND i+1 < len AND tokens[i+1] is Ident AND i+2 < len AND tokens[i+2] == Exclamation:
            // 匹配到 @name! 模式
            (macro_call, next_i) = parse_macro_call(tokens, i)
            if macro_call found in registry:
                input_tokens = macro_call.collect_input_tokens()
                input_group = classify_token_group(input_tokens)
                expanded = execute_macro(registry[macro_call.name], input_group)
                expanded = expand_macros(expanded, registry)  // 递归展开嵌套宏
                result.extend(expanded)
                i = next_i
            else:
                result.push(tokens[i]); i += 1
        else:
            result.push(tokens[i]); i += 1
    return result
```

### 7.3 展开时机

| 位置 | 展开行为 |
|------|---------|
| 模块顶层 `@name!(...)` | 立即展开 |
| ` ``` ` / `f ``` ` / `r ``` ` 内部 | **不展开**，保留原样 |
| 宏展开结果中 | **递归展开**，直到无更多 `@name!` |
| 嵌套 `@outer!(@inner!(x))` | **内层先展开** |

### 7.4 装饰器保留

`@name`（无 `!`）不在宏展开阶段处理，保留给 Parser 作为装饰器：

```
@simd                    ← 留给 Parser 处理
@parallel                ← 留给 Parser 处理  
def foo() = ...
```

## 八、Token 分组分类

### 8.1 分类算法

宏调用处的输入 tokens 分类为五种 TokenGroupKind：

```rust
pub fn classify_token_group(tokens: &[Token]) -> TokenGroupKind {
    let trimmed = trim_whitespace(tokens);
    
    if matches_decl(trimmed)    { return TokenGroupKind::Decl; }
    if matches_stmt(trimmed)    { return TokenGroupKind::Stmt; }
    if matches_pattern(trimmed) { return TokenGroupKind::Pattern; }
    if matches_type(trimmed)    { return TokenGroupKind::Type; }
    
    TokenGroupKind::Expr   // 默认
}
```

### 8.2 各类别的首 Token 判定

| TokenGroupKind | 特征首 Token | 示例 |
|---------------|-------------|------|
| `Decl` | `Def`, `Struct`, `Enum`, `Trait`, `Impl`, `Const` | `def foo() = 42` |
| `Stmt` | `Return`, `If`, `For`, `While`, `Loop`, `Match`, `Let`, `Guard`, `Try`, `Raise`, `Yield`, `Defer` | `return x` |
| `Pattern` | `Ident`+`(` 或 `_`（match 上下文） | `Some(x)` |
| `Type` | `Int`, `F64`, `Str`, `Bool`, `List`, `Dict`, `Set`, `Option`, `Result` 或 `Ident`+`<` | `List<int>` |
| `Expr` | 其他所有情况（默认） | `1 + 2` |

### 8.3 边界判定

```
输入 tokens: (1 + 2) * 3
分类结果: Expr（括号匹配，完整表达式）

输入 tokens: def foo() =
分类结果: Decl

输入 tokens: Some(x) =>
分类结果: Pattern（到 => 停止）
```

## 九、宏嵌套规则

### 9.1 嵌套展开顺序

**规则：内层宏先展开。**

```
@outer!(@inner!(1 + 2), x + 3)
```

展开过程：
1. 检测 `@outer!(...)` 调用
2. 收集参数 tokens: `@inner!(1 + 2), x + 3`
3. 先展开参数中的 `@inner!(1 + 2)` → `(1 + 2) * 2`
4. 替换后参数: `(1 + 2) * 2, x + 3`
5. 展开 `@outer!((1 + 2) * 2, x + 3)` → 最终结果

### 9.2 反引号块内的延迟展开

```lz
macro outer(input: Tokens) -> Tokens =
    let code: Tokens = ```
        @inner!($(input))
    ```
    f```
        process($(code))
    ```

// 展开过程：
// 1. @outer!(1+2) → 执行 outer 体
// 2. outer 体返回: process(``` @inner!(1+2) ```)
// 3. 反引号块展开为 Tokens，内部 @inner! 不展开
// 4. 生成代码中 @inner! 在后续轮次被展开
```

### 9.3 递归宏

**仅允许在反引号块内部的递归自调用：**

```lz
macro repeat(input: Tokens) -> Tokens =
    if is_empty(input):
        ```
        
        ```
    else
        let first = take_first(input)
        let rest = take_rest(input)
        f```
            $first
            @repeat!($rest)
        ```

// ✅ 反引号块内递归 — OK
// ❌ 直接 @repeat!(...) — 编译期死循环
```

**递归终止条件**：宏体必须包含终止条件，递归深度限制默认 128 层。

## 十、语法检测策略

### 10.1 分层检测模型

```
┌─────────────────────────────────────────┐
│  Layer 3: 完整 lz 语法检测               │ ← 仅对展开后代码
│  (类型检查、所有权、借用)                  │
├─────────────────────────────────────────┤
│  Layer 2: Token 分组分类                 │ ← 宏输入 / 反引号块内部
│  (Expr | Decl | Stmt | Pattern | Type)   │
├─────────────────────────────────────────┤
│  Layer 1: 词法正确性                     │ ← 所有代码
│  (括号匹配、缩进、关键字)                  │
└─────────────────────────────────────────┘
```

### 10.2 展开前的检测

- Layer 1: token 扫描无错误，括号匹配，缩进正确
- Layer 2: 分类输入为 Expr/Decl/Stmt/Pattern/Type
- 宏签名匹配（参数数量正确）

**不执行**：类型推导、变量解析、所有权分析、借用检查。

### 10.3 展开后的检测

展开后的 Token 流走正常流水线：`Parser → AST → CodeGen`，完整语法和语义分析。

## 十二、代码生成

### 12.1 展开后代码生成

宏展开后的代码是纯 lz Token 流，走正常的 `Parser → AST → CodeGen` 路径。

### 12.2 编译期解释器

```rust
pub struct MacroInterpreter {
    registry: Rc<MacroRegistry>,
    variables: HashMap<String, Tokens>,
}

impl MacroInterpreter {
    pub fn execute(&mut self, macro_def: &MacroDef, input: Tokens, attr: Option<Tokens>) -> Tokens {
        self.variables.insert(macro_def.params[0].name.clone(), input);
        if let (true, Some(attr)) = (macro_def.is_attr, attr) {
            self.variables.insert(macro_def.params[1].name.clone(), attr);
        }
        
        let mut last_value: Tokens = Tokens::empty();
        for stmt in &macro_def.body {
            last_value = self.execute_stmt(stmt);
        }
        last_value
    }
}
```

### 12.3 编译期内置函数

| 函数 | 签名 | 说明 |
|------|------|------|
| `is_empty(t: Tokens)` | `bool` | Tokens 是否为空 |
| `len(t: Tokens)` | `int` | Token 数量 |

### 示例 4：嵌套宏

```lz
macro inner(input: Tokens) -> Tokens =
    f```
        $input * 2
    ```

macro outer(input: Tokens) -> Tokens =
    f```
        $input + @inner!($input)
    ```

let x = @outer!(5)

// 展开过程：
// 1. @outer!(5) → 收集 tokens: [IntLit(5)]
// 2. 执行 outer: f``` $input + @inner!($input) ```
// 3. 替换参数: f``` 5 + @inner!(5) ```

```

## 十五、关键技术决策记录

| 决策 | 选择 | 理由 |
|------|------|------|
| 宏调用标识 | `@name!` 带 `!` | 与装饰器 `@name` 无歧义区分 |
| 代码捕获 | ` ``` ` 反引号块 | 无新关键字，与 lz 的 Python 风格一致 |
| 插值模式 | `f ``` ` 前缀 | 与 `f"..."` 字符串语法一致 |
| 原始模式 | `r ``` ` 前缀 | 与 `r"..."` 字符串语法一致 |
| 展开时机 | Lexer → Parser 之间 | 展开结果需完整语法分析 |
| 嵌套顺序 | 内层优先 | 符合直觉 |
| 反引号块内宏 | 延迟展开 | 外层宏可控制展开时机 |
| 装饰器 | 保持 `@name` | 不改动现有系统 |
