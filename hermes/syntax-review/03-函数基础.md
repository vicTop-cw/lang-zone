# LZ 函数基础

> 版本: 3.1 · 基于编译器源码 · 2026-07-27

本文档定义 Lang-Zong 函数的核心语法：`def` 声明、参数、返回类型、return 语句、异常函数及常见语法错误边界。

---

## 一、基本定义

### 1.1 `def` 声明

```lz
def function_name(param1: Type1, param2: Type2) -> ReturnType =
    body
```

### 1.2 等式体（单行）

`=` 后跟表达式在同一行：

```lz
def add(a: int, b: int) -> int = a + b
def double(x) = x * 2
def greet(name: str) -> str = f"Hello, {name}"
```

### 1.3 块体（多行）

`=` 后换行 + 缩进：

```lz
def max(a: int, b: int) -> int =
    if a > b:
        a
    else:
        b
```

## 二、参数

### 2.1 基本参数

```lz
def add(a: int, b: int) -> int = a + b
```

### 2.2 无注解参数，需要数学表达（默认 Number）

```lz
@math // 数学表达，强制加这行 自动加注解用，后期使用宏也可以自定义
def double(x) = x * 2      // x: Number, -> Number
```

### 2.3 参数修饰符

| 修饰符 | 示例 | 说明 |
|--------|------|------|
| 无 | `x: int` | 默认按值传递 |
| `ref` | `ref x: str` | 不可变引用传递 |
| `mut ref` | `mut ref x: int` | 可变引用传递 |

```lz
def read_data(ref data: List<int>) -> int =
    data.len()

def modify(mut ref data: List<int>) =
    data.push(42)
```

### 2.4 默认参数值

```lz
def greet(name: str = "world") -> str =
    f"Hello, {name}"

greet()              // "Hello, world"
greet("Lang-Zong")   // "Hello, Lang-Zong"
```

## 三、返回类型

### 3.1 显式返回类型

```lz
def add(a: int, b: int) -> int = a + b
def is_positive(x: int) -> bool = x > 0
```

### 3.2 无返回类型（默认 int）

```lz
def double(x) = x * 2     // -> int（推断）
```

### 3.3 main 函数（默认 ()）

```lz
def main() =
    print("hello")        // -> ()  不需要显式标注
```

### 3.4 无返回值 `()`

```lz
def log(msg: str) -> () =
    print(msg)
```

### 3.5 发散函数 `Never`

```lz
def abort(msg: str) -> Never =
    raise Exception(msg)
```

## 四、return 语句

```lz
def early_exit(x: int) -> int =
    if x < 0:
        return 0          // 提前返回
    x + 1                 // 尾表达式作为返回值
```

- 块体**尾表达式**自动作为返回值（无需 `return`）
- 也支持显式 `return expr` 提前退出
- `return` 不带值仅在 `-> ()` 函数中合法

---

## 五、异常函数

### 5.1 raises 声明

```lz
def divide(a: int, b: int) -> int raises str =
    if b == 0:
        raise "division by zero"
    a / b
```

### 5.2 raise 语义检查

如果函数体内有 `raise`，则**必须**声明 `raises` 类型。

```lz
// ❌ 错误：有 raise 但无 raises 声明
def bad() -> int =
    raise "oops"
    // 错误：缺少 raises 子句
```

## 六、错误语法边界

```lz
// ❌ 冒号不匹配
def bad(x:): ...             // 错误：: 后缺类型
def bad(-> int): ...         // 错误：-> 必须在参数列表后

// ❌ 等式体换行不缩进
def bad() =
x + 1                        // 错误：必须缩进

// ❌ 函数名与关键字冲突
def test(): ...              // 错误：test 是关键字
def check(): ...             // 错误：check 是关键字

// ❌ 匿名函数语法错误
|x, y| -> x + y              // 错误：闭包不用 ->
```
