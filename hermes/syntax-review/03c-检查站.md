# LZ 函数 — 检查站 [checker]

> 版本: 3.1 · 基于编译器源码 · 2026-07-27

`[checker]` 是参数**运行时检查与转换**机制。可以定义在**任意函数**（含普通函数、`..` 可变参数函数、魔法方法）的签名中。

---

## 一、语法位置

```lz
def function_name[checker_name]<generics>(params) -> Ret = body
                  ↑                ↑
              中括号检查站        尖括号泛型
```

- `[checker]` 必须放在函数名**之后**、`<generics>` **之前**
- 内容是单个标识符（检查函数名），不能为空
- **可用于任意函数**：普通函数、可变参数函数、魔法方法

---

## 二、定义

```lz
// 普通函数 + 检查站
def add[validate](a: int, b: int) -> int =
    a + b                          // body 中参数已通过 validate 检查站处理

// 可变参数函数 + 检查站
def send[validate]<R>(.., ..) -> R =
    for v in args:
        print(v)
    for (k, v) in kwargs:
        print(f"{k}: {v}")

// 魔法方法 + 检查站
magic map<T, R> =
    def __map__[validate](self, f: fn(T) -> R) -> Iterable<R>
        where Self <: Iterable<T>
        = ...
```

---

## 三、调用

定义时声明了 `[checker]` 的函数，调用时可以**选择传入或不传入**检查站函数：

```lz
// ✅ 带检查站：传入具体检查函数
add[my_check](1, 2)                // 参数先经过 my_check 校验
send[check_params]<int>(a, v, k=1)

// ✅ 不带检查站：直接调用，参数原样通过（默认行为）
add(1, 2)                          // 跳过检查站
send<int>(a, v, k=1)

// ❌ 非法：检查站函数不能引用自身
// add[add](1, 2)                   // 自引用 → 编译错误
```

> 定义了 `[checker]` 的函数**不是必须**在调用时传入检查站。不传则 `ps = None`，参数原样通过。

---

## 四、检查函数契约

检查函数接受 `__Params` 并返回 `__Params`：

```lz
// 编译器为每个含 [checker] 的函数自动生成：
// struct __Params:
//     args:    Vec<Box<dyn Any>>         // 位置参数
//     kwargs:  HashMap<String, Box<dyn Any>>  // 关键字参数
```

```lz
// 校验 age 参数的检查函数
def validate_age(ps: __Params) -> __Params =
    if ps.kwargs.contains("age"):
        let age = ps.kwargs["age"].downcast.<int>()
        if age < 0 or age > 150:
            raise "invalid age"
    ps                               // 返回处理后的参数
```

注：泛型方法消歧使用 `.` 而非 `::`（与 LZ 统一路径规则一致）。

## 五、代码生成

函数签名自动注入 `ps` 伪参数，调用时 `Some(chk)` 或 `None`：

```rust
// add[my_check](1, 2) 生成：
pub unsafe fn add(
    ps: Option<fn(__Params) -> __Params>,  // 检查站函数指针
    a: i64,
    b: i64,
) -> i64 {
    let __params = match ps {
        Some(chk) => chk(__Params { args: vec![Box::new(a), Box::new(b)], kwargs: HashMap::new() }),
        None => __Params { args: vec![Box::new(a), Box::new(b)], kwargs: HashMap::new() },
    };
    // 从 __params 提取参数...
    // body...
}

// add(1, 2) 生成：
add(None, 1, 2)                      // 不传检查站 → ps = None
```

## 六、编译期验证

| 检查项 | 行为 |
|--------|------|
| `[checker]` 中的标识符是否已定义 | 未定义 → 编译错误 |
| checker 函数的签名是否为 `(__Params) -> __Params` | 不匹配 → 编译错误 |
| `[checker]` 是否只含一个标识符 | 多内容 → 解析错误 |
| checker 是否为自身递归引用 | 自引用 → 编译错误 |

---

## 七、语法边界

```lz
// ❌ [checker] 位置错误（必须在泛型 <T> 之前，函数名之后）
def bad<T>[check](..) = ...        // 错误：[checker] 不能在 <T> 之后

// ❌ [checker] 内容为空
def bad[](..) = ...                // 错误：检查站名称不能为空

// ✅ 正确位置
def good[check]<T>(..) = ...       // [checker] 在泛型之前，函数名之后

// ✅ 任意函数皆可用
def simple[check](x: int) -> int = x * 2    // 普通函数
magic map<T> =
    def __map__[check](self, f) -> T = ...  // 魔法方法
```
