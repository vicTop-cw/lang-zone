# LZ 函数泛型

> 版本: 3.1 · 基于编译器源码 · 2026-07-27

本文档定义 Lang-Zong 的泛型函数语法：基本泛型参数、带约束的泛型、where 子句及泛型默认参数类型。

---

## 一、基本泛型

```lz
def identity<T>(x: T) -> T = x
def first<T>(a: T, b: T) -> T = a
```

## 二、带约束的泛型

```lz
def larger<T: Ordered>(a: T, b: T) -> T =
    if a > b:
        a
    else:
        b
```

## 三、where 子句

```lz
def clone_all<T>(items: List<T>) -> List<T>
    where T: Clone =
    result = []
    for item in items:
        result.push(item.clone())
    result
```

## 四、泛型默认参数类型

```lz
def make_pair<T = int>(x: T, y: T) -> (T, T) =
    (x, y)
```

---

## 五、错误语法边界

```lz
// ❌ 泛型尖括号后有空格
def foo <T> (x: T) = x     // 错误：<T> 紧贴函数名

// ❌ 缺少类型参数
def bar<T>(x) = x           // 错误：x 缺少类型注解（泛型不做推断时需标注）

// ❌ 约束使用未定义的 trait
def baz<T: NonExistent>(x: T) = x  // 错误：NonExistent trait 未定义
```
