# LZ 测试框架

> 版本: 3.1 · 基于编译器源码 · 2026-07-27

LZ 内置轻量级测试框架，支持测试套件组织、硬断言与软断言。

---

## 一、`test` 测试用例

`test "description":` 定义一个独立测试用例，冒号后使用 `=` + 缩进的块体形式。

```lz
test "addition":
    assert 1 + 1 == 2
    assert 2 + 3 == 5
```

测试用例直接写在顶层模块中（无需包在 `def main()` 中）。运行时框架自动发现并执行所有 `test`。

---

## 二、`suite` 测试套件

`suite "name":` 将一组相关测试组织在一起，便于分组管理和批量执行。

```lz
suite MathTests:
    test "addition":
        assert 1 + 1 == 2

    test "subtraction":
        assert 5 - 3 == 2
```

套件内可包含任意数量的 `test`、`setup` 和 `teardown`。

---

## 三、`setup` / `teardown`

> **注意**：setup / teardown 为设计阶段功能，编译器未完整实现。

`setup:` 在每个测试运行之前执行，通常用于创建共享的局部变量；`teardown:` 在每个测试运行之后执行，用于清理或输出报告。

```lz
suite DatabaseTests:
    setup:
        db = connect(":memory:")
        db.migrate()

    teardown:
        db.close()
        print("测试完成")

    test "insert":
        db.insert("users", name="Alice")
        assert db.count("users") == 1

    test "delete":
        db.insert("users", name="Bob")
        db.delete("users", name="Bob")
        assert db.count("users") == 0
```

`setup` 中创建的局部变量，套件内所有测试体均可直接使用。

---

## 四、`assert` 硬断言

`assert expr` 或 `assert expr, "消息"` — 硬断言，失败时立即中止当前测试。

```lz
test "hard assertion":
    assert 1 + 1 == 2
    assert 10 / 2 == 5
    assert "hello".len() == 5, "字符串长度应为 5"
```

一旦 `assert` 失败，当前 `test` 块剩余代码不再执行。

---

## 五、`check` 软断言

`check expr` 或 `check expr, "消息"` — 软断言，失败时记录错误但继续执行后续语句。

```lz
test "soft assertion":
    check 1 + 1 == 3     // 失败，记录但继续
    check 2 + 2 == 4     // 仍然会执行
    assert 3 + 3 == 6    // 最终硬断言
```

适用场景：需要收集多条失败信息后再报告，而非遇到第一个失败就停止。

## 六、完整工作示例

```lz
suite MathTests:
    test "addition":
        assert 1 + 1 == 2
        assert 2 + 3 == 5
        assert 0 + 0 == 0

    test "subtraction":
        assert 5 - 3 == 2
        assert 0 - 5 == -5

    test "multiplication":
        assert 2 * 3 == 6
        assert 10 * 0 == 0
        assert (-2) * 3 == -6

    test "division":
        assert 10 / 2 == 5
        assert 7 / 2 == 3          // 整数除法

suite StringTests:
    test "concat":
        assert "hello" + " " + "world" == "hello world"

    test "length":
        assert "abc".len() == 3
        assert "".len() == 0

    test "substring":
        s = "hello world"
        assert s.starts_with("hello")
        assert s.ends_with("world")

suite CheckDemo:
    test "soft assertions":
        check 1 + 1 == 3           // 失败但继续
        check 2 + 2 == 4           // 仍会执行
        assert 3 + 3 == 6          // 最终断言

suite WithSetupTeardown:
    setup:
        values = [1, 2, 3]

    teardown:
        print("清理完成")

    test "sum":
        sum = 0
        for v in values:
            sum = sum + v
        assert sum == 6

    test "count":
        assert values.len() == 3

def main() =
    print("运行测试: lang-zone test")
```

## 七、语法边界

1. **`test` / `suite` 命名**：描述字符串使用双引号，名称需在同一模块内唯一。
2. **`setup` / `teardown` 作用域**：`setup` 中创建的变量在套件内所有 `test` 可见，但在 `teardown` 中不可写（仅可读取）。
3. **`assert` vs `check`**：`assert` 失败抛出错误并中止当前 `test`；`check` 失败仅记录到报告中，测试继续。
4. **错误消息**：`assert expr, "msg"` 和 `check expr, "msg"` 的第二个参数是可选的错误描述字符串。
5. **嵌套限制**：`suite` 不可嵌套；`test` 必须定义在顶层或 `suite` 内部。
6. **运行方式**：通过 `lang-zone test` 命令执行所有测试。
