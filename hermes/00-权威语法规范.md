| `bool` | `bool` | 布尔 |
| `f64` | `f64` | 浮点 |
| `List<T>` | `Vec<T>` | 列表 |
| `Dict<K,V>` | `HashMap<K,V>` | 字典 |
| `()` | `()` | 单元类型（**不是** `void`） |

> ⚠️ **被禁止的写法**  
> `#` — 不是注释符（是属性宏标记），注释用 `//`  
> `::` — 已废弃（产生 LexError），统一用 `.`  
> `;` — 不支持分号  
> `void` — 应为 `()`  
> `string` — 应为 `str`  
> `null` — 应为 `None`

## 八、语句

### 8.1 循环

```lz
for x in xs: print(x)                               // ✅ test_for.lz
while cond: body                                    // ✅ test_while.lz
loop: break                                         // ❌
sum x in arr: x * x                                 // ✅ test_sum_prod.lz
prod i in 1..n: i                                   // ✅
```

### 8.2 守卫

```lz
guard b != 0 else:                                  // ✅ test_guard.lz
    0                                               // else 体必须缩进，禁止 return
a / b                                               // 通过路径
```

> 规则：`guard cond else:` 后**必须**换行缩进，else 体内不需 `return`

### 8.3 返回

```lz

return                                              // ❌
```
