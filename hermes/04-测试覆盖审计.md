## 关键发现与建议

### 代码生成质量

1. **@memoize 装饰器**实现完整，生成线程安全的 `OnceLock<Mutex<HashMap>>` 缓存——这是最复杂的一条代码生成路径，通过编译验证
2. **guard/else** 正确转换为 `if !(cond) { return val; }` 守卫模式
3. **match/case/_** 直接映射为 Rust match，无需额外处理
4. **closure** 闭包完全映射为 Rust `|params| expr` lamdba
5. **struct/enum** 自动派生 `Clone`（及 enum 的 `Debug`）

### 警告与改进点

1. **test_if.rs** 的 `(-1)`, `(-x)`, `(-5)`, `(-3)` 产生 5 处 `unnecessary parentheses` 警告——代码生成器在 `else if` 和一元负号处理时引入了多余括号
2. **test_for.rs** 的 `mut xs` 和 `for mut x in xs` 产生 2 处 `unused_mut` 警告——生成的 `mut` 修饰在只读遍历场景下是多余的
3. 装饰器 `@parallel`, `@tail_call`, `@math` 目前仅生成 Rust 注释标记，未产生实际的代码转换

### 测试覆盖不足

1. `test_import.lz` 仅是占位测试，未实际测试 import 语法
2. `test_option.lz` / `test_result.lz` 名不副实——未使用 Option/Result 类型
3. `test_unsafe.lz` / `test_borrow.lz` / `test_owned.lz` 语义层测试过于简单，实际仅测试基础函数定义
4. 宏系统、comptime、async、pipe、trait/impl 等核心特性完全无测试覆盖
