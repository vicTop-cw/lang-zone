## 1. 顶层声明 (`parse_module`)

### 1.1 属性 / 装饰器

| 语法 | AST 输出 | 示例 | 测试 |
|------|---------|------|:---:|
| `#[...]` Rust 风格属性 | `attributes: Vec<String>` | `#[repr(C)]` | ❌ |
| `@name` 无参装饰器 | `Decorator { name, args: [] }` | `@math` | ✅ |
| `@name(args)` 带参装饰器 | `Decorator { name, args: [..] }` | `@derive(Clone)` | ❌ |

**特殊情况**：
- 属性宏和装饰器可以共存，先解析 `#[...]` 再解析 `@...`
- 属性宏支持嵌套 `[]`，以 depth 计数匹配
- 装饰器参数为任意表达式

### 2.3 条件 / 匹配 / 闭包

| 语法 | AST 输出 | 示例 | 测试 |
|------|---------|------|:---:|
| `if cond: then_body` | `Expr::If` | `if x > 0: 1` | ✅ |

| `for _ in iter:` 占位符 | `Stmt::For { var: "_" }` | `for _ in range(10): ...` | ❌ |
| `loop: \n\tbody` | `Stmt::Loop` | `loop: \n\ttick()` | ❌ |
| `sum x in iter: expr` 求和 | 脱糖为 `Stmt::Loop` | `sum x in xs: x` | ❌ |
| `prod x in iter: expr` 连乘 | 脱糖为 `Stmt::Loop` | `prod x in xs: x` | ❌ |

**特殊情况**：
- `sum`/`prod` 在解析时完全脱糖为 `let __sum/x + expr (::Mul/Add 累积) + break __sum/x` 的 while-for 组合
- `for` 变量支持 `_` 作为占位符

### 3.6 绑定 / 赋值

| 语法 | AST 输出 | 示例 | 测试 |
|------|---------|------|:---:|
| `let x = expr` (不可变) | `Stmt::Let { mutable: false }` | `let x = 42` | ✅ |
| `let ref x = expr` | `Stmt::Let { is_ref: true }` | `let ref r = &x` | ❌ |
| `let const x = expr` | `Stmt::Const` | `let const N = 100` | ❌ |
| `mut x = expr` | `Stmt::Let { mutable: true }` | `mut x = 0` | ✅ |
| `mut x: T = expr` | `Stmt::Let { ty }` | `mut x: int = 0` | ❌ |
| `ref x = expr` | `Stmt::Let { is_ref: true }` | `ref r = &x` | ❌ |
| `const x = expr` | `Stmt::Const` | `const N = 100` | ❌ |
| `owned x = expr` | `Stmt::Let`（owned 忽略） | `owned x = expr` | ❌ |
| `name: T = value` (类型化本地绑定) | `Stmt::Let { mutable: true, ty }` | `x: int = 42` | ✅ |
| `x = expr` (赋值) | `Stmt::Let` (Ident) 或 `Stmt::Assign` (复杂左值) | `x = 1` | ✅ |
| `x += expr` 等复合赋值 | `Stmt::Assign { AddEq/SubEq/MulEq/DivEq/ModEq/PowEq/AmpEq/PipeEq/CaretEq/ShlEq/ShrEq }` | `x += 1` | ❌ |
| `x = comptime expr` | `Stmt::Const { comptime: true }` | `x = comptime 1 + 2` | ❌ |

**特殊情况**：
- Lang-Zong 默认绑定可变更，`mut` 为 no-op 兼容
- `let mut` 允许但忽略 mut 修饰
- `let owned` 语义矛盾，忽略
- 普通 `let` 前缀 → 不可变绑定；`mut`/`ref`/`const`/`owned` 前缀 → `parse_binding_stmt`
- `const` 绑定: 若值为 `Expr::Comptime` 则 `comptime: true`
- `let const` 最终转为 `Stmt::Const` 而非 `Stmt::Let`

### 注意事项

1. **`::` 路径分隔符已废弃**（expr.rs:326）：在词法层报废弃警告，解析层仍兼容处理
2. **`let mut` 为 no-op**（stmt.rs:486）：默认绑定已可变更，`mut` 仅起兼容作用
3. **`let owned` 语义矛盾**（stmt.rs:534）：允许语法但忽略修饰符
4. **浮点数 pattern 转为字符串**（expr.rs:847-848）：`FloatLit` 在 pattern 中被转为 `Pattern::Str`
5. **BUG-7 修复**（parser.rs:1249-1256）：`impl Box<T>` 中类型名后的泛型后缀自动合并到 impl 泛型列表
6. **BUG-16 修复**（expr.rs:878-898）：限定枚举变体 pattern `Enum.Variant(args)`
7. **BUG-17 修复**（expr.rs:767-779）：catch 块支持类型注解（虽然后续丢弃）
8. **嵌套泛型 `>>` 分裂**（parser.rs:47,74-78）：使用 `pending_gt` 计数实现 `>>` → `>` `>` 分裂
9. **match 臂复制处理**（expr.rs:694-714）：多 pattern 时每个 pattern 复制整份 arm（含 guard 和 body）
10. **构建块顶层禁用**（parser.rs:303-310）：顶层直接出现 BuildBlock 会报明确的错误消息
