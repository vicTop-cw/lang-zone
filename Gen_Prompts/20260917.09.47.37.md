## 具体修复任务

### 1. 修复 if/else 分支类型不匹配

**错误代码**：
```rust
if self.peek() == "-".to_string() { self.advance() } else { () };
```

**问题**：`self.advance()` 返回 `String`，但 `else` 分支返回 `()`

**修复方向**：
- 检查 `Stmt::If` 处理中的类型一致性逻辑
- 确保 if 和 else 分支返回类型兼容

### 2. 修复字符串索引类型不匹配

**错误代码**：
```rust
... + &{let __cs: Vec<char> = (self.s).chars().collect(); let __i = (((self.pos.clone()) as usize) as usize); if __i >= __cs.len() { '\0' as i64 } else { __cs[__i] as i64 }};
```

**问题**：期望 `&str`，但生成了 `&i64`

**修复方向**：
- 检查 `IndexGet` 代码生成中的 `idx_wants_string` 逻辑
- 确保在字符串拼接上下文中正确处理类型转换

### 3. 修复 Result::Ok(self.skip_ws()) 类型不匹配

**错误代码**：
```rust
Result::Ok(self.skip_ws())
```

**问题**：期望 `()`，但 `skip_ws()` 返回 `Result<(), _>`

**修复方向**：
- 检查 `wrap_ok` 逻辑，当返回类型为 `()` 时不生成 `Result::Ok()` 包裹
- 相关文件：`src/ir/codegen/mod.rs` 中的 `wrap_ok` 函数

### 4. 修复 str 不能按 usize 索引

**错误代码**：
```rust
self.s.clone()[(self.pos.clone() as usize)].clone()
```

**问题**：Rust 中 `str` 不能直接用 `usize` 索引

**修复方向**：
- 检查字符串索引的代码生成逻辑
- 对于 char 索引，应使用 `chars().nth()` 方式

### 5. 修复 String 参数类型不匹配

**错误代码**：
```rust
let mut parser = Parser { s: (s).clone(), pos: 0i64 };
```

**问题**：期望 `String`，但 `s` 是 `&str`

**修复方向**：
- 检查参数传递时的类型转换逻辑
- 确保 `&str` 到 `String` 的转换正确生成

### 6. 修复 replace 方法 Pattern trait 不满足

**错误代码**：
```rust
s.replace("\\", "\\\\").replace("\"".to_string(), "\\\"".to_string())...
```

**问题**：`String` 不能作为 `Pattern`，需要改为 `&str`

**修复方向**：
- 检查 `MethodCall` 处理中 `String` 参数的引用添加逻辑
- 确保 `replace` 方法的第一个参数生成 `&str` 而非 `String`
- 参考之前修复的 `contains` 方法处理方式

### 7. 修复 DictExt::keys 泛型缺失

**错误代码**：
```rust
for key in (<dyn DictExt>::keys(&(obj), )).into_iter() {
```

**问题**：`DictExt` 需要泛型参数 `K, V`

**修复方向**：
- 检查 trait 方法调用的泛型参数生成逻辑
- 添加必要的泛型参数 `<K, V>`
