## 三、修复了啥

| 版本 | 缺陷 | 根因 |
|---|---|---|
| v162 | List+List 拼接 → Vec+Vec（E0369） | binop Add 对 List 操作数无特判 |
| v162 | 索引元素按值传参未 clone（E0507） | 实参 clone 注入仅覆盖 Var |
| v162 | BlockExpr 块内调用不 clone（E0507） | 子 CodeGen 未继承 fn_param_types |
| v162 | vec![ts[i]] 元素移动（E0507） | ListLit 元素未 clone |
| v163 | for 变量未遮蔽 → static mut idx（E0530） | collect_stmt_var_refs 的 For 分支缺 shadow |
| v164 | match 臂模式绑定未遮蔽（E0530） | Stmt::Match 分支缺 collect_pattern_bindings |
| v165 | Lambda 参数裸写变量名 → static mut x（E0530） | 生成的构造代码误引用参数名 |
| v165 | 深层嵌套构造 → lang-zone 栈溢出 | 生成器需扁平化中间变量 |
