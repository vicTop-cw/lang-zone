# Lang-Zone 自举计划（Bootstrap Plan）

> 本目录收录 Lang-Zone 编译器项目的自举（self-hosting）规划文档。
> 自举 = 项目自身的工具链能够用于构建和迭代自身，不再依赖外部预构建的版本。

## 目录结构

```
bootstrap/
├── README.md                        # 本文档：导航与总览
├── 01-自举总纲.md                    # 定义、动机、分级标准（L0–L4）、核心原则
├── 02-自举前置条件清单.md            # 启动自举的功能 / 质量 / 基础设施门槛
├── 03-自举执行计划.md                # 阶段划分、启动时机、成功判定标准
├── 04-当前项目自举具体方案.md        # 结合 Lang-Zone 现状的具体落地方案（已填充）
├── 05-自举里程碑台账.md              # 100% 链路权重表 + 40% 里程碑组成与证据（2026-08-16 冻结）
├── 06-自举交接续推文档.md            # 40%→100% 续推路径、恢复点、风险与覆盖映射表
├── build.sh / build.ps1              # 自举构建闭环双入口（all / closed / clean）
└── rollback.sh / rollback.ps1        # 回滚到上一个可用构建（backup/good 基线）
```

## 阅读顺序

1. **01-自举总纲** —— 先建立自举的共识与分级（L0–L4）。
2. **02-自举前置条件清单** —— 对照检查项目是否具备启动资格。
3. **03-自举执行计划** —— 看清阶段、时机与判定标准。
4. **04-当前项目自举具体方案** —— 落到 Lang-Zone 当前真实状态（类型、依赖、覆盖率、差距）与可执行路径。

## 本项目关键事实（速览）

- **类型**：转译型编译器（`.lz` → Rust → 原生二进制），后端即 Rust。
- **开发语言**：Rust（Edition 2024）；编译器 `src/*.rs` 当前**非自托管**。
- **自举对象**：近期以全部 `.lz` 生态源码为主（路线 A）；长期规划编译器自托管（路线 B）。
- **测试现状**：黑盒功能/边界/构建块/异常 39/39 通过；语法边界 127/133 通过（95%）；
  端到端测试与 Rust 模块级单测仍缺口。

> 详情见 `04-当前项目自举具体方案.md` 的「一、项目现状评估」。
