## 0. 口径声明（2026-08-16 冻结）

1. **40% 的度量口径 = 里程碑权重口径**：按本文 §2 的环节权重表，完成项权重合计 ≥ 40% 即达成 40% 里程碑。

## 5. 构建闭环与退出码/日志约定

- 标准化命令：
  - PowerShell（本机默认）：`.\bootstrap\build.ps1 -Mode Closed|All|Clean`
  - git-bash（等价）：`bash bootstrap/build.sh closed|all|clean|<file.lz>`
- 产物位置：生成物 `bootstrap/work/`（.rs/.exe）；清单 `bootstrap/work/manifest/run1.sha256`、`run2.sha256`；日志 `bootstrap/work/log/<时间戳>.log` + `latest.log`；回滚基线 `bootstrap/work/backup/good/`。
- 日志阶段前缀：`[LZC]` 转译 / `[RUSTC]` / `[RUN]` / `[VERIFY]` 一致性校验 / `[PROMOTE]` 基线提升。
- 退出码：0 闭环全通过；1 lzc 失败；2 rustc 失败；3 运行失败；4 两轮 manifest 不一致；5 环境缺失。
- 一致性校验：第 1 轮构建+运行 → `run1.sha256`（对 work 下全部 .rs 与 .exe 算 SHA256，**排除 .pdb**）；清理 .rs/.exe 后第 2 轮 → `run2.sha256`；diff 为空 → exit 0 并 PROMOTE 到 backup/good。
- 降级口径预案：若 .exe 二进制哈希实测不稳定（rustc 非确定性），降级为"全部 .rs 哈希一致 + 全部 .exe 运行输出比对一致"，实测结论写入 §7 修订记录。

## 6. 回滚方案、覆盖率口径与失败演练

### 6.1 回滚
- 存储：`bootstrap/work/backup/good/`（每次闭环全绿后 PROMOTE 更新：产物快照 + manifest.sha256）。
- 命令：`bash bootstrap/rollback.sh` 或 `.\bootstrap\rollback.ps1`：
  1. 校验 backup/good/manifest.sha256 存在，否则 exit 2；
  2. 当前 work 下 .rs/.exe **移动**到 `backup/bad-<时间戳>/`（保留现场，非删除）；
  3. 从 backup/good 复制 .rs/.exe 回 work；
  4. 重算哈希与 manifest 比对：一致 `[OK] 回滚成功` exit 0，否则 exit 3。
- 禁止项：不用 `rm -rf`、不碰 .lz 源与源码树、不做破坏性 git 操作。

### 6.2 失败演练（`bootstrap/work/fail_drill.sh`，幂等）
1. 跑一轮 closed 建立绿基线；2. 注入非法 `fail_probe/bad.lz`；3. 重跑 closed 断言退出码 1 且 [LZC] 段含 bad.lz 错误行；4. 执行回滚断言 exit 0、哈希与基线一致、bad.lz 无生成物；5. 清理 fail_probe 后重跑 closed 断言 exit 0；6. 输出 `fail_drill.log`。

### 6.3 覆盖率口径（≥70%，冻结）
- 定义：**关键路径覆盖映射表口径**——把自举组件的关键路径（台账中每个完成项的验证命令所走通的代码路径）逐条列出，要求每条至少 1 个自动化用例命中；命中率 ≥ 70% 即达标。
- 工具现状：本机无 `cargo llvm-cov`/grcov（2026-08-16 实测）；行覆盖率工具就绪后按 `02-自举前置条件清单` 长期门槛（全仓 ≥85%）另行升级，不阻塞本里程碑。
- 映射表落点：`bootstrap/06-自举交接续推文档.md` §6 关键路径覆盖映射表。
