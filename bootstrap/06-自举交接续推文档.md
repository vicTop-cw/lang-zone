## 3. 启动命令 / 停止与恢复点

- **一次完整自举构建**：`powershell -File bootstrap\build.ps1 -Mode Closed`（或 `bash bootstrap/build.sh closed`）。退出码含义与日志定位见 `05` §5。
- **回滚**：`bash bootstrap/rollback.sh`（或 `.\bootstrap\rollback.ps1`）。恢复上一个可用构建（backup/good）。
- **停止/恢复总则**：每环节完成即更新台账状态列 + 提交引用 + 产物哈希；恢复时先重放一轮 `closed` 确认产物与 manifest 一致再继续；不要删除历史构建产物与 work 快照。
- **前端 .lz → .rs 同步**：`lang-zone.exe src\frontend\lz_parser.lz --std-dir std` 会在 .lz 旁生成 .rs（须与 .lz 一起提交）；改完 .lz 必跑 `cargo test` + `bash bootstrap/build.sh all`。
