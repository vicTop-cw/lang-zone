# `11-构建块.md` 插入新章节后编号断链（两个"三"）

- **Status**: Fixed
- **Severity**: 规范一致性（中）
- **Category**: doc-standard
- **Discovered**: 2026-07-29
- **Reporter**: 用户复核指出

## Summary

我插入"二、索引构建块 `^:`"后，只把旧"二、调用构建块 `~:`"改成"三"，漏改后续两项，导致出现**两个"三"**、且"语法边界"仍停在"四"。

## Fix

- 顺延编号：
  - 一、变量构建块 `=:`
  - 二、索引构建块 `^:`
  - 三、调用构建块 `~:`
  - 四、构建块中的 return（含 4.1 / 4.2 / 4.3）
  - 五、语法边界
- 改动文件：`SYNTAX/11-构建块.md`（章节标题 + 子节 3.1/3.2/3.3 → 4.1/4.2/4.3）。

## Lesson

插入新章节后必须顺延后续**所有**编号（含子节）。
