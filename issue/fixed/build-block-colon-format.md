# `^:` 被写成中缀/同行，违反构建块冒号换行缩进标准

- **Status**: Fixed
- **Severity**: 规范一致性（中）
- **Category**: doc-standard
- **Discovered**: 2026-07-29
- **Reporter**: 用户复核指出（"你的展示有问题"）
- **Fixed by**: 文通通

## Summary

构建块（`=:` / `^:` / `~:` / `*:`) 的冒号都必须**换行后缩进**。我此前把 `^:` 错写成中缀/同行形式：`nums ^: 0`、`lst ^: key`，并描述为"表达式型/中缀写法、不接块体"。
`^:` 虽块体为**单值 key**（区别于 `~:` 的元组），但**仍是构建块**，冒号必须换行缩进。

## Fix

- 改为：`container ^:\n    key` 形态（冒号后换行缩进，块体为单值表达式）。
- 改动文件：
  - `SYNTAX/11-构建块.md`：L13 空白规则、`## 二、索引构建块 ^:` 整节措辞与示例（去掉"中缀/表达式型/不接块体"表述）。
  - `SYNTAX/12-操作符.md`：§1.17 `^:` 表行、§1.18 构建块白空格表。
  - `DEMO/99_spec/index_build.lz`：注释 + 两处 `^:` 改换行缩进。
  - `DEMO/99_spec/README.md`：`index_build.lz` 行描述。
- grep 全仓确认 `^:` 已无"同行/中缀"残留。

## Lesson

凡是构建块一律 `lhs X:\n    块体`；别因"单值"退化成中缀。
