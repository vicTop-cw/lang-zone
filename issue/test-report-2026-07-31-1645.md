## 🔴 新发现 P1 Bug（IR→rustc 编译失败）

### #1 — 元组枚举变体构造语法错误（回归）
- **文件**: `issue/ir-codegen-tuple-enum-ctor.md`（Open → 回归未修复）
- **现象**: `Shape::Circle(0.0, 0.0, 5.0)` → 生成 `Shape::Circle { x: 0.0, y: 0.0, radius: 5.0 }`
- **错误**: `E0559: variant has no field named x/y/radius`
- **影响**: match.lz, enum.lz, enum_more.lz, trait_impl.lz（~4 文件）
- **严重**: 🔴 P1 — match/enum 核心功能受阻

### #2 — 模式匹配变量绑定丢失（回归）
- **新文件**: `issue/ir-codegen-pattern-var-binding.md`
- **现象**: `enum Color::Red | enum Color::Green` 模式变量未绑定到 Rust 变量
- **错误**: `E0425: cannot find value 'r'`（enum.lz: `Circle(r) → return 3.14 * r * r`）
- **影响**: enum.lz, enum_more.lz, combo_enum_match_guardlet.lz（~3 文件）
- **严重**: 🔴 P1 — match 臂内无法使用解构变量

### #3 — 泛型类型参数未正确生成
- **新文件**: `issue/ir-codegen-generic-type-params.md`
- **现象**: `<T>` 泛型函数生成的 Rust 代码中 `T` 未解析
  - `let cloned: Vec<T>` — `T` 不是有效 Rust 类型
  - `make_pair < str && str > (...)` — 缺少 turbofish `::`
  - `convert < int, str > (...)` — 括号而非尖括号
- **错误**: `E0425: cannot find type T` + 多个语法错误
- **影响**: generics.lz, combo_generic_struct_method.lz（~2 文件）
- **严重**: 🔴 P1 — 泛型功能不可用

### #4 — 类型关键字错误用作值
- **新文件**: `issue/ir-codegen-type-keyword-as-value.md`
- **现象**: `int`、`f64`、`str` 作为值表达式出现在生成代码中
  - `42 == int` (operators.lz) — `int` 不是值
  - `float(x)` → `x as f64` 但 `f64` 出现在值位置 (type_conversion.lz)
- **错误**: `E0423: expected value, found builtin type`
- **影响**: operators.lz, type_aliases_more.lz, type_conversion.lz（~3 文件）
- **严重**: 🔴 P1 — 类型转换功能受阻

### #5 — 关键字 await 错用
- **新文件**: `issue/ir-codegen-keyword-await.md`
- **现象**: 生成代码中使用 `await` 作为标识符
- **错误**: `incorrect use of await`（keywords.lz, async_spawn.lz, async_more.lz）
- **严重**: 🟡 P1.5（P1 但影响范围有限）
- **影响**: ~3 文件

### #6 — Rc/Box 类型未导入
- **新文件**: `issue/ir-codegen-missing-rc-box-import.md`
- **现象**: `Rc<T>` 无 `use std::rc::Rc;`，`Box<i64>` 错误索引
- **错误**: `E0425: cannot find type Rc`，`E0608: cannot index Box<i64>`
- **严重**: 🔴 P1
- **影响**: primitives.lz, box_rc_arc.lz, rc_arc_more.lz（~3 文件）
