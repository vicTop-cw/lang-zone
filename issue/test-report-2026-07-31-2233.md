## 四、新发现的 Bug

### 🔴 B3 — P0: 括号分组信息在 IR 代码生成中被丢弃
- **文件**: `issue/ir-codegen-paren-grouping-dropped.md`
- **症状**: `(a + b) * c` 和 `a + b * c` 生成完全相同的 Rust 代码 `a + b * c`
- **影响**: 算术表达式的语义可能完全错误，静默产生错误结果
- **严重性**: P0 — 核心语义正确性问题

### 🔴 B4 — P1: 字符串 `+` 拼接右侧未自动借用
- **文件**: `issue/ir-codegen-str-concat-borrow.md`
- **症状**: `"Hello, " + "World!"` → `"Hello, ".to_string() + "World!".to_string()` → E0308
- **影响**: 字符串拼接场景 rustc 编译失败
- **严重性**: P1 — 生成无法编译的代码

### 🟡 B5 — P1: 模块级变量生成 `const` 而非可变
- **文件**: `issue/ir-codegen-module-level-mut-const.md`
- **症状**: `count = 0` 模块级 → `const count: i64 = 0` → 函数中 `count += 1` → E0070
- **影响**: walrus.lz 模块级变量修改失败
- **严重性**: P1 — walrus fix 后暴露的残留问题
