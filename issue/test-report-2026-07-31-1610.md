## 四、新发现 Bug

### 🆕 N1 🔴 P0 — IR codegen: match 臂枚举变体生成表达式而非模式

**复现**: `DEMO/06_control_flow/match.lz`
```lz
match c:
    Color.Red: "warm"
```
**生成**: `match c { Color.Red => { ... } }` — Rust 要求模式，`Color.Red` 是表达式
**rustc**: `error: expected a pattern, found an expression`
**影响**: match.lz, match_more.lz, enum.lz, enum_more.lz, mutable_let.lz 等 ~10+ 文件

---

### 🆕 N2 🔴 P1 — IR codegen: match 臂模式解构变量丢失

**复现**: `DEMO/07_data_structures/enum.lz`
```lz
match shape:
    Circle(_, _, r): 3.14 * r * r
```
**生成**: `return 3.14 * r * r;` — `r` 从未被绑定
**rustc**: `error[E0425]: cannot find value 'r' in this scope`
**影响**: enum.lz, match.lz 等

---

### 🆕 N3 🔴 P1 — IR codegen: Result/Error 模式名混淆

**复现**: `DEMO/03_variables/mutable_let.lz`
```lz
match result:
    Ok(Some(v)): ...
```
**生成**: `Error::Ok(Error::Some(v)) => { ... }` — `Error::` 前缀是非法的
**rustc**: `error[E0433]: cannot find type 'Error' in this scope`
**影响**: mutable_let.lz, extractor_unapply.lz

---

### 🆕 N4 🔴 P1 — IR codegen: `mut` 参数生成错误

**复现**: `DEMO/04_functions/basic.lz`
```lz
def modify(data: mut List<int>) -> int = ...
```
**生成**: `pub fn modify(data: mut Vec<i64>) -> i64`
**rustc**: `error: expected type, found keyword 'mut'`
**影响**: basic.lz

---

### 🆕 N5 🔴 P1 — IR codegen: 推导式宏缺失

**复现**: `DEMO/05_expressions/comprehension.lz`
**生成**: `comp!(...)` — 宏未定义
**rustc**: `error: cannot find macro 'comp' in this scope`
**影响**: comprehension.lz, dict_comprehension.lz, set_comprehension.lz, comprehension_more.lz

---

### 🆕 N6 🟡 P2 — IR codegen: Vec 缺泛型参数

**复现**: `DEMO/05_expressions/operators.lz`
**生成**: `const items: Vec = vec![...]` — 缺少 `<_>`
**rustc**: `error[E0107]: missing generics for struct 'Vec'`
**影响**: operators.lz

---

### 🆕 N7 🟡 P2 — IR codegen: 递归类型无限大小

**复现**: `DEMO/07_data_structures/enum_more.lz`
```lz
enum Expr: Add(Expr, Expr) | ...
```
**生成**: 直接递归，未 `Box`
**rustc**: `error[E0072]: recursive type 'Expr' has infinite size`
**影响**: enum_more.lz

---

### 🆕 N8 🟡 P2 — IR codegen: Null coalesce if/else 类型不兼容

**复现**: `DEMO/05_expressions/null_coalesce.lz`
**生成**: `if ... { None } else { "value".to_string() }` — 类型不一致
**rustc**: `error[E0308]: 'if' and 'else' have incompatible types`
**影响**: null_coalesce.lz
