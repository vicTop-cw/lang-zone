# 函数

## 1. 函数定义

`def` 后跟函数签名，函数体用 **`=`** 开启（替代 v2 的 `:`）。

### 1.1 基本形式

```
def hello() =
    print("hi")

// 单行简写
def add1(x: int) -> int = x + 1

// 多语句函数体
def add(a: int, b: int) -> int =
    a + b                       // 最后一行是返回值
```

### 1.2 完整签名

```
def 函数名<泛型>(参数) -> 返回类型 raises 异常 where 约束 = 函数体
```

```
def demo<T, F>(x: T, f: F) -> str raises MyError where T: Intable, F: Callable<int, bool> =
    i = int(x)??
    if f(i):
        str(i + 1)
    else:
        str(i - 1)
```

### 1.3 匿名函数

```
double = |x: int| -> int: x * 2
add    = |a: int, b: int| -> int: a + b

// 类型推断
sq = |x| x * x
```

### 1.4 `_` 占位符

在函数调用参数位置，`_` 自动生成闭包参数：

```
[1, 2, 3].map(_ * 2)          // 等价于 .map(|x| x * 2)
[1, 2, 3].filter(_ > 1)       // 等价于 .filter(|x| x > 1)
[1, 2, 3].reduce(_ + _)       // 等价于 .reduce(|a, b| a + b)
```

**限制**：`_` 只能在函数调用参数位置使用，不能独立创建匿名函数。

## 2. 参数传递

| 修饰 | 含义 | 调用方要求 |
|------|------|-----------|
| （默认） | 借用（只读） | 无限制 |
| `owned` | 所有权转移 | 调用后不可用 |
| `mut` | 可变借用 | 必须是 `mut` 变量 |

```
def inspect(data: Data) =              // 默认借用
    print(data.payload)

def consume(data: owned Data) =        // 拿走所有权
    print(data.payload)

def modify(data: mut Data) =           // 可变借用
    data.payload = "changed"
```

## 3. 可变参数 `*args`

`*args: T` 收集同类型可变参数：

```
def sum_all(*args: int) -> int =
    args.fold(0, |acc, x| acc + x)

sum_all(1, 2, 3, 4)       // 10
sum_all()                  // 0
```

### 3.1 参数解包 `*`

```
nums = [1, 2, 3]
sum_all(*nums)             // 等价于 sum_all(1, 2, 3)
```

### 3.2 不支持 `**kwargs`

`**kwargs` 已移除。替代方案是下面的 `KwArgs` 参数包构建块。

## 4. Callable 调用块（`name :`）

`name :` 后换行缩进，为 `name` 这个可调用对象**构建一个参数包并应用**。这是 Lang-Zong 的核心创新语法。

### 4.1 无参函数

```
def hello() = print("Hi!")

hello :                   // 调用 hello
    print("what can I do for you?")
// 先打印 "what can I do for you?"，再调用 hello() 打印 "Hi!"
```

块体作为前置副作用执行，然后调用无参的 `hello()`。

### 4.2 关键字参数包 `KwArgs:`

`KwArgs:` 开启关键字参数包构建块，`out` 关键字输出绑定到参数包：

```
def hello2(age: int, name: str) = print(f"Hi! my name is {name}, i'm {age} years old,")

hello2 :
    print("what can I do for you?")
    KwArgs:
        age_helper = 17
        out age : mut = age_helper + 1     // out 输出到参数包
        out name = "Alice"
    t = 3                                  // 其它代码
    age += 5                               // 更新 age
// 最终 hello2(age=22, name="Alice")
```

### 4.3 位置参数包 `Args`

`Args` 是关键字，开启位置参数包构建块：

```
hello2 :
    Args:
        out 14
        out "Alice"
```

### 4.4 直接返回元组/字典

块尾的表达式如果是元组或字典，可直接作为参数包：

```
hello2 :
    print("prepare")
    (22, "Alice")          // ✅ 元组参数包（位置参数）

hello2 :
    {: "age": 22, "name": "Alice"}   // ✅ 字典参数包（关键字参数）
```

> 若既构建了 `KwArgs`，块尾又返回了一个元组/字典参数包，编译器会**忽略已构建的 KwArgs** 并给出 warning。

### 4.5 接收返回值

```
result = hello2 :          // 接收 hello2 的返回值
    KwArgs:
        out age : mut = 17
        out name = "Alice"
```

### 4.6 方法调用

任何 callable（包括对象的方法）都支持此语法：

```
result2 = result.replace :
    "old"
    "new"
```

### 4.7 用构建块创建实例

```
trait demo2 =
    def mymethod(Self)

struct demo = ()                // 空 struct

result3 = demo :
    impl demo2 for demo =
        def mymethod(Self) =
            print("hi")
    break                       // break 留白，构建拥有实现的实例
```

`break`（留白）表示"结束构建块，值为已构建的实例"。

## 5. 函数返回值

- 最后一行表达式是返回值
- `return <expr>` 提前返回
- `return` 等价于 `return None`
- 元组返回：`return 1, "hi"` 自动打包为 `(1, "hi")`

### 5.1 单行多语句

单行函数中可用 `;` 分隔语句，**最后一个表达式**是返回值：

```
def hello2(age: int, name: str) = print(f"Hi! my name is {name}, i'm {age} years old,"); "done"
// 先执行 print，返回值是 "done"
```

```
def bar() -> (int, str) =
    return 1, "hello"
```

## 6. 异常声明

函数体内有 `raise` 就必须写 `raises`：

```
def divide(a: int, b: int) -> int raises DivError =
    if b == 0:
        raise DivError("zero")
    a / b
```

详见 [18-错误处理.md](18-错误处理.md)。

## 7. 高阶函数与管道

```
// 高阶函数
doubled = [1, 2, 3].map(|x| x * 2)
evens   = [1, 2, 3, 4].filter(|x| x % 2 == 0)
sum     = [1, 2, 3, 4].fold(0, |acc, x| acc + x)

// 管道
result = [1, 2, 3, 4, 5]
    |> filter(|x| x % 2 == 0)
    |> map(|x| x * x)
    |> sum()
```

## 8. 生成器

```
def fibs() =
    yield 0
    yield 1
    yield from _fib_step(0, 1)

def _fib_step(a: int, b: int) =
    yield a + b
    yield from _fib_step(b, a + b)
```

## 9. 宏函数（`!` 标记）

带 `!` 后缀的函数是**转译期辅助函数**，必须定义在宏模块中：

```
// 仅在 #!bin macro 模块中合法
def derive!(ts: Tokens) -> Tokens =
    ...
```

详见 [14-宏与转译期.md](14-宏与转译期.md)。
