# 泛型

## 1. 泛型参数

使用 `<T>` 声明泛型参数，可用于函数、struct、enum、trait、class：

```
def identity<T>(x: T) -> T = x

struct Pair<T> =
    x : T
    y : T

enum Option<T> =
    Some(T)
    None

trait Iterator<T> =
    def next(mut Self) -> T?
```

## 2. 泛型约束

`where` 关键字用于泛型约束：

```
def max<T>(a: T, b: T) -> T where T: Comparable =
    a if a > b else b
```

### 2.1 多约束

```
def sort<T>(xs: [T]) -> [T] where T: Comparable + Hashable =
    ...
```

### 2.2 约束位置

`where` 子句写在函数签名末尾，`=` 之前：

```
def demo<T, F>(x: T, f: F) -> T where T: Intable, F: Callable<T, bool> =
    f(x)
```

## 3. 泛型实例化

调用处可显式指定泛型参数，也可由编译器推断：

```
def identity<T>(x: T) -> T = x

a = identity(42)            // T 推断为 int
b = identity<int>(42)       // 显式指定
```

## 4. 类型别名

`type` 关键字定义类型别名：

```
type IntList = [int]
type Callback<T> = |T| -> bool
type IntPair = (int, int)
```

> 注意：`define` 关键字已移除。如需函数参数的结构化约束，使用 `trait` + `where`。

## 5. 泛型可见性

泛型参数在函数/类型体内可见，出体后不可用。泛型参数名遮蔽外层同名标识符：

```
type T = int

def foo<T>(x: T) -> T =     // 此处 T 是泛型参数，遮蔽外层 type T
    x
```

## 6. 泛型与容器

```
list : [int] = [1, 2, 3]
dict : {:str: int} = {: "a": 1}
opt : int? = None
```

容器类型本身是泛型实例化的语法糖：`[int]` 即 `List<int>`，`int?` 即 `Option<int>`。

## 7. trait 作为约束

trait 是唯一的显式约束来源（替代了被移除的 `define`）：

```
trait Display =
    def display(Self) -> str

def print_all<T>(xs: [T]) where T: Display =
    for x in xs:
        print(x.display())
```
