# 注释

Lang-Zong 只支持两种注释形式，移除了 `#|` / `$|` / `&|` 多行字符串前缀。

## 1. 单行注释

以 `//` 开始，直到行尾。

```
// 这是单行注释
x = 1  // 行尾注释
```

## 2. 多行注释

以 `/*` 开始、`*/` 结束，**支持嵌套**：

```
/*
   这是多行注释
   可以跨越多行
*/

/*
   外层注释
   /*
      内层注释，允许嵌套
   */
   外层继续
*/
```

## 3. 文档注释（约定）

文档注释是**约定**而非语法强制：在 `def` / `struct` / `class` / `enum` / `trait` 定义前一行以 `///` 开头的注释，会被工具识别为文档：

```
/// 计算阶乘。
/// n 必须 >= 0。
def factorial(n: int) -> int =
    if n <= 0:
        1
    else:
        n * factorial(n - 1)
```

## 4. 禁用的形式

以下注释形式**不再支持**，如在源码中出现视为语法错误：

| 形式 | 状态 |
|------|------|
| `# ...` 行注释 | ❌ 移除（`#` 仅用于文件指令 `#!bin` 和标签 `#label`） |
| `#| ...` | ❌ 移除 |
| `$| ...` | ❌ 移除 |
| `&| ...` | ❌ 移除 |

## 5. 注释与缩进

注释不参与缩进语义，但**多行注释必须与所在缩进层级对齐**或更深，以避免歧义：

```
def f() =
    // 正确：注释与代码同级缩进
    x = 1
    /* 正确：
       多行注释缩进对齐 */
    y = 2
```
