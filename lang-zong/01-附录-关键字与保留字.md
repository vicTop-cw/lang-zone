# 附录 — 关键字与保留字

## 1. 关键字汇总

### 1.1 按类别分组

| 类别 | 关键字 |
|------|--------|
| 声明 | `def` `struct` `enum` `trait` `class` `type` `const` `owned` `mut` |
| 导入 | `import` `from` `as` |
| 控制流 | `if` `elif` `else` `match` `case` `loop` `while` `for` `block` `break` `continue` `return` `where` |
| 异常 | `try` `catch` `finally` `raise` `raises` |
| 并发 | `go` `async` `await` `spawn` |
| 迭代 | `yield` `in` |
| 模块 | `impl` `Self` `Type` |
| 宏 | `macro` `comptime` |
| 参数包 | `KwArgs` `Args` `out` |
| 其他 | `defer` `guard` `let` `assert` `test` `suite` `with` `is` |
| 字面量 | `True` `False` `None` |
| 逻辑 | `and` `or` `not` |
| 文件指令 | `#!bin` |

### 1.2 完整关键字列表（字母序）

```
and         as          assert      async       await
Args        block       break       case        catch       class
comptime    const       continue    defer       def
do          elif        else        enum
finally     for         from        go          guard       if
impl        import      in          is
let         loop        macro       match       mut
not         None        owned
out         KwArgs
raise       raises     return
Self        spawn      struct      suite
test        trait      True        try
Type        until      where       while       with
yield
```

> 注意：`val` / `var` / `define` / `extend` / `omit` / `when` / `then` / `end` / `of` / `event` / `toml` / `transtime` **不再是关键字**。

### 1.3 关键字语义说明

| 关键字 | 用途 | 所在文档 |
|--------|------|---------|
| `mut` | 变量可变标注，写在类型注解中 | [06-变量与绑定.md](06-变量与绑定.md) |
| `owned` | 所有权"只借不转移"标注 | [06-变量与绑定.md](06-变量与绑定.md) |
| `const` | 编译期常量标注 | [06-变量与绑定.md](06-变量与绑定.md) |
| `break` | 跳出循环 / 在构建块中提前返回构建值 | [03-缩进规则.md](03-缩进规则.md) |
| `out` | 在 `KwArgs:` / `Args` 块中输出一个绑定到参数包 | [09-函数.md](09-函数.md) |
| `KwArgs` | 开启关键字参数包构建块 | [09-函数.md](09-函数.md) |
| `Args` | 开启位置参数包构建块 | [09-函数.md](09-函数.md) |
| `macro` | 声明宏 | [14-宏与转译期.md](14-宏与转译期.md) |
| `comptime` | 编译期求值 | [14-宏与转译期.md](14-宏与转译期.md) |

## 2. 保留字

保留字暂不为当前版本赋予语义，但禁止作为标识符使用，为未来扩展预留：

```
abstract    base        extern      internal    override
pass        protected   pub         sealed      unsafe
```

## 3. 魔法方法前缀

以双下划线包围的方法为魔法方法，始终公开：

```
__init__    __new__     __del__     __copy__    __move__
__eq__      __ne__      __hash__    __str__     __repr__
__bool__    __int__     __float__   __call__
__add__     __sub__     __mul__     __div__     __mod__     __pow__
__neg__     __pos__     __abs__     __invert__
__iadd__    __isub__    __imul__    __idiv__
__getitem__ __setitem__ __delitem__ __len__     __contains__
__iter__    __next__
__enter__   __exit__
__getattr__ __setattr__ __delattr__
```

## 4. 软关键字

以下标识符在特定上下文中作为关键字，其他位置可作为普通标识符：

| 标识符 | 触发上下文 |
|--------|----------|
| `match` | 出现在表达式起始 |
| `case` | `match` 块内的分支 |
| `Args` / `KwArgs` | 出现在 `:` 构建块内 |
| `out` | 出现在 `Args` / `KwArgs` 块内 |
| `Self` / `Type` | 方法首参数位置 |
