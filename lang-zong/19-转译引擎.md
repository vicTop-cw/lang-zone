# 转译引擎

## 1. 转译流程

```
source.lz  →  [Lang-Zong 编译器]  →  目标语言源码  →  [目标编译器]  →  二进制
```

Lang-Zong 是**转译型**语言，只负责将 `.lz` 源码转译为目标语言源码，不直接生成机器码。

## 2. 默认目标语言

**默认目标语言为 Cython**，可通过以下方式覆盖：

| 方式 | 作用域 | 语法 |
|------|--------|------|
| `#!bin lang_name` | 单文件 | 文件首部 |
| `#!bin macro lang_name` | 单文件（宏模块） | 文件首部 |
| `__toml__.lz` 的 `[bin].default` | 整个项目 | 项目根目录 |

优先级：`#!bin` > `__toml__.lz` > 全局默认（Cython）。

## 3. 支持的目标语言

| 目标语言 | 后缀 | 说明 |
|---------|------|------|
| `cython` | `.pyx` | 默认，数据科学友好 |
| `python` | `.py` | 纯 Python |
| `rust` | `.rs` | 系统级、零开销 |
| `nim` | `.nim` | 系统级 |

## 4. `#!bin` 指令

详见 [02-文件与模块结构.md](02-文件与模块结构.md)。

```
#!bin rust                    // 本文件转译为 Rust

#!bin macro default            // 本文件是宏模块，默认目标语言

#!bin macro python             // 本文件是宏模块，目标 Python
```

## 5. `__toml__.lz` 配置

```
[bin]
default = "cython"            // 项目默认目标语言
edition = "2024"

[dependencies]
numpy = "1.24"
requests = ">=2.28, <3.0"
```

| 节 | 说明 |
|----|------|
| `[bin]` | 项目级转译配置 |
| `[bin].default` | 默认目标语言 |
| `[dependencies]` | 外部依赖（传递给目标语言的包管理器） |

## 6. 编译器架构

```
lang-zong/
├── src/
│   ├── lexer.lz        // 缩进敏感词法分析
│   ├── parser.lz       // 生成 AST
│   ├── ast.lz          // AST 定义
│   ├── codegen/        // 代码生成
│   │   ├── cython.lz   // → Cython
│   │   ├── rust.lz     // → Rust
│   │   ├── python.lz   // → Python
│   │   └── nim.lz      // → Nim
│   └── main.lz         // CLI 入口
└── __toml__.lz
```

## 7. 转译示例

### 7.1 变量声明

```
// Lang-Zong
x : mut int = 5
y = 3
z : owned str = "hi"

// Cython（默认）
cdef int x = 5
y = 3
z = "hi"

// Rust
let mut x: i32 = 5;
let y = 3;
let z: String = "hi".to_string();
```

### 7.2 函数

```
// Lang-Zong
def add(a: int, b: int) -> int =
    a + b

// Cython
cpdef int add(int a, int b):
    return a + b

// Rust
fn add(a: i32, b: i32) -> i32 {
    a + b
}
```

### 7.3 match case

```
// Lang-Zong
match x:
    case 0:
        "zero"
    case _:
        "many"

// Cython
if x == 0:
    "zero"
else:
    "many"

// Rust
match x {
    0 => "zero",
    _ => "many",
}
```

### 7.4 Callable 调用块

```
// Lang-Zong
hello2 :
    KwArgs:
        out age : mut = 17
        out name = "Alice"

// Cython（等价）
hello2(age=17, name="Alice")

// Rust
hello2(17, "Alice");     // 或具名参数
```

### 7.5 所有权转移

```
// Lang-Zong
y : mut int = 5
t = y^

// Cython（引用计数）
y = 5
t = y
del y                      // 删除变量名，引用计数减一

// Rust
let mut y = 5;
let t = y;                  // move 语义，y 不再可用
```

## 8. 转译期与编译期

| 阶段 | 职责 | 标记 |
|------|------|------|
| 转译期 | Lang-Zong 编译器解析 `.lz`，生成目标源码 | `!` 标记、`macro`、`#!bin` |
| 编译期 | 目标语言编译器编译生成的源码 | `comptime`、`const` |

`!` 标记的宏变量/宏函数在**转译期**执行，生成目标语言源码；`comptime` 在**编译期**执行，产生编译期常量。

## 9. 已移除的转译期特性

| 特性 | 状态 | 替代 |
|------|------|------|
| `transtime` | ❌ 移除 | `#!bin macro` 宏模块 |
| `template` | ❌ 移除 | `macro` |
| `toml` 关键字 | ❌ 移除 | `__toml__.lz` 配置文件 |
| `external` 外部语言互操作 | ❌ 移除 | FFI 或宏模块 |

## 10. 设计原则

1. **语法糖优先** — 不碰底层，只做语法层转译
2. **目标语言生态复用** — 所有库、性能、安全都保留
3. **`!` 即转译期** — 任何带 `!` 后缀的标识符都是转译期辅助
4. **默认 Cython** — 数据科学友好，无缝对接 Python 生态
5. **多目标支持** — 可转译为 Rust/Nim 等系统级语言
