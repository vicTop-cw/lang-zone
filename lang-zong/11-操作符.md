# 操作符

Lang-Zong **不开放自定义操作符符号**（移除了 `*fix` 全家族），仅保留内置操作符。

## 1. 保留的操作符

### 1.1 管道与组合

| 操作符 | 名称 | 说明 |
|:---:|------|------|
| `\|>` | 管道 | 数据从左到右流动，`a \|> f` 等价于 `f(a)` |
| `<\|` | 反向管道 | `f <\| a` 等价于 `f(a)` |
| `~>` | 函数组合（左结合） | `f ~> g` 等价于 `|x| g(f(x))` |
| `<~` | 函数组合（右结合） | `f <~ g` 等价于 `|x| f(g(x))` |

```
// 管道
result = [1, 2, 3, 4, 5]
    |> filter(|x| x % 2 == 0)
    |> map(|x| x * x)
    |> sum()

// 函数组合
def add1(x: int) -> int = x + 1
def mul2(x: int) -> int = x * 2

pipeline = add1 <~ mul2        // pipeline(x) = add1(mul2(x))
g = mul2 ~> add1               // 等价
```

> 其它 `|*>` `|?>` `|>>` `|&>` `|@>` 等管道变体已移除。

### 1.2 所有权

| 操作符 | 说明 |
|:---:|------|
| `^` | 后缀操作符，显式转移所有权（见 [06-变量与绑定.md](06-变量与绑定.md)） |

### 1.3 Option 相关

| 操作符 | 说明 |
|:---:|------|
| `?`（类型后缀） | `T?` 等价于 `Option<T>` |
| `?.` | 安全导航 |
| `??` | 强制解包 / null 合并 |

```
name = user?.profile?.name ?? "Anonymous"
ensured = risky_call()??
```

### 1.4 算术

```
+  -  *  /  %  **
```

### 1.5 比较

```
==  !=  <  <=  >  >=
```

### 1.6 逻辑

```
and  or  not        // 关键字形式
```

### 1.7 位运算

```
&  |  ^  ~  <<  >>
```

### 1.8 赋值与复合赋值

```
=  +=  -=  *=  /=  %=  **=  &=  |=  ^=  <<=  >>=
```

### 1.9 海象运算符

```
while (n := read()) != 0:
    process(n)
```

### 1.10 成员访问与调用

```
.      // 成员访问
::     // 模块路径 / 命名空间访问
()     // 函数调用
[]     // 索引
```

## 2. 已移除的操作符

| 操作符 | 状态 | 替代 |
|:---:|------|------|
| `++` / `--` | ❌ 移除 | `+= 1` / `-= 1` |
| `\|*>` `\|?>` `\|>>` `\|&>` `\|@>` | ❌ 移除 | 用 `go` / `async` + channel |
| `\|\|>` `\|\|>>` 等（并行操作符） | ❌ 移除 | 用 `go` / `spawn` |
| `<:` `^:` `@:`（参数包构建符号） | ❌ 移除 | 用 `name :` Callable 调用块 |
| `?` `->` `!` `=?` 条件链表达式 | ❌ 移除 | 用 `if`/`elif`/`else` |
| `*fix` 自定义操作符声明 | ❌ 移除 | 不支持自定义符号 |

## 3. 优先级

从高到低：

| 优先级 | 操作符 | 说明 |
|:---:|:---:|------|
| 10.0 | `.` `::` | 成员访问、路径 |
| 9.0 | `?.` `??` | 安全导航、null 合并 |
| 8.0 | `!`（宏标记后缀） | 转译期标记 |
| 7.0 | `-`（前缀） `not` `~`（前缀） | 一元 |
| 6.0 | `*` `/` `%` | 乘除模 |
| 5.0 | `+` `-` | 加减 |
| 4.0 | `<<` `>>` | 位移 |
| 3.5 | `&` | 位与 |
| 3.0 | `^`（位异或）/ `^`（所有权后缀，看上下文） | 位异或 / 所有权 |
| 2.6 | `\|` | 位或 |
| 2.55 | `\|>` `<\|` | 管道 |
| 2.05 | `~>` `<~` | 函数组合 |
| 2.0 | `==` `!=` `<` `<=` `>` `>=` | 比较 |
| 1.5 | `and` | 逻辑与 |
| 1.0 | `or` | 逻辑或 |
| 0.5 | `:=` `=` `+=` 等 | 赋值 |

> `^` 在表达式后缀位置是所有权转移，在双操作数中缀位置是位异或，由上下文区分。

## 4. 空白规则

### 4.1 infix 操作符必须两侧有空格

```
a + b              // ✅
a+b                // ❌ 错误

val s = 1          // ✅
val s=1            // ❌ 错误
```

### 4.2 prefix / suffix 操作符必须紧贴

```
^x                 // ✅ 所有权转移
x^                 // ✅ 后缀所有权转移

-not x             // ❌ 前缀不能有空格
```

### 4.3 类型注解 `:` 前紧后松

```
x : int = 1        // ✅
x :int = 1         // ❌ `:` 后必须有空格
```

### 4.4 语句块 `:` 可松可紧

```
if x > 0:          // ✅
    print("ok")
if x > 0 :        // ✅ 也允许
    print("ok")
```

### 4.5 分号

分号紧贴前一个 token，与后一个 token 之间需要空格，**不能作为行尾**：

```
a = 1; b = 2       // ✅
a = 1 ;b = 2       // ❌
a = 1;             // ❌ 不能作为行尾
```

## 5. 魔法方法映射

操作符通过魔法方法实现，自定义类型可实现对应魔法方法：

| 操作符 | 魔法方法 |
|:---:|------|
| `+` `-` `*` `/` `%` `**` | `__add__` `__sub__` `__mul__` `__div__` `__mod__` `__pow__` |
| `+=` `-=` 等 | `__iadd__` `__isub__` 等 |
| `-x` `+x` `~x` | `__neg__` `__pos__` `__invert__` |
| `==` `!=` `<` `<=` `>` `>=` | `__eq__` `__ne__` `__lt__` `__le__` `__gt__` `__ge__` |
| `[]` 索引 | `__getitem__` / `__setitem__` |
| `()` 调用 | `__call__` |
| `len()` | `__len__` |
| `in` | `__contains__` |
| `iter()` | `__iter__` / `__next__` |

详见 [13-数据类型.md](13-数据类型.md)。
