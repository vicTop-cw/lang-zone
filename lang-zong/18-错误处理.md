# 错误处理

## 1. 异常定义

异常用 `enum` 定义：

```
enum MyError =
    NotFound(str)
    PermissionDenied(str)
    InvalidInput(str)
```

## 2. 抛出 `raise`

```
def might_fail(x: int) -> int raises MyError =
    if x < 0:
        raise MyError.NotFound("x < 0")
    100 / x
```

- 函数体内有 `raise` 就必须写 `raises`
- `raises` 后跟异常类型（必须是 enum）

## 3. 捕获 `try`/`catch`

```
def safe_call(x: int) -> Result<int, MyError> =
    try:
        result = might_fail(x)
    catch MyError.NotFound(msg):
        print(f"Not found: {msg}")
        Err(MyError.NotFound(msg))
    catch e:
        panic(f"Unexpected: {e}")
    else:
        // 没有异常时才执行
        print(f"Success: {result}")
        Ok(result)
    finally:
        cleanup()
```

## 4. 块语义

与 Python 一致：

| 块 | 执行时机 |
|------|------|
| `try` | 始终先执行 |
| `catch` | 匹配到异常时执行 |
| `else` | `try` 无异常时执行（在 `finally` 之前） |
| `finally` | 始终最后执行（无论是否异常） |

## 5. Result 与 `?` 错误传播

除了 `try/catch`，Lang-Zong 也支持 `Result` 类型的错误传播：

```
def read_config(path: str) -> Result<Config, IOError> =
    content = open(path)?           // 出错则提前返回 Err
    parse(content)?

def parse(s: str) -> Result<Config, ParseError> =
    ...
```

`?` 后缀表示：若左侧是 `Err`，则提前返回该 `Err`；若是 `Ok`，则解包继续。

## 6. Option 与错误

`Option` 用于可能缺失的值，`Result` 用于可能失败的操作：

```
// Option — 可能没有值
def find_user(id: int) -> User? =
    if id == 0:
        return None
    User(id)

// Result — 可能失败
def read_file(path: str) -> Result<str, IOError> =
    ...
```

## 7. panic

`panic` 用于不可恢复的错误，直接终止程序：

```
def get(arr: [int], i: int) -> int =
    if i >= arr.len():
        panic("index out of bounds")
    arr[i]
```

## 8. 与目标语言的衔接

| 目标语言 | `raise` | `try/catch` | `Result` |
|---------|--------|-------------|----------|
| Cython/Python | `raise` | `try/except/else/finally` | 自定义类 |
| Rust | `panic!` 或返回 `Result` | 无（用 `match`） | `Result<T, E>` |

```
// Lang-Zong
def safe_call(x: int) -> int raises MyError =
    try:
        might_fail(x)
    catch MyError.NotFound(msg):
        0

// Cython（默认）
def safe_call(x):
    try:
        return might_fail(x)
    except NotFoundError as msg:
        return 0
```

## 9. 已移除的特性

| 特性 | 状态 | 说明 |
