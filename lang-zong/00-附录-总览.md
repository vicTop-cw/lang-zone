# Lang-Zong 核心语法文档 v0 — 总览

> *"写如 Python，跑如 Cython。"*

## 1. 语言定位

Lang-Zong 是一门**转译型**语言：

- 源码 `.lz` 文件由编译器转译为**目标语言源码**
- 默认目标语言为 **Cython**，也可在文件首部用 `#!bin` 指令指定其它目标（Rust / Python / Nim ...）
- 不直接生成机器码，只做语法层转译，复用目标语言的生态、类型系统与优化器

核心原则：

1. **函数式与命令式并存** —— 高阶函数、推导式与 `for`/`while`/`loop` 循环同时支持
2. **缩进即语法** —— 4 空格缩进决定作用域，省去 `{}`
3. **目标语言扛底层** —— 内存管理、所有权、性能全部由目标语言编译器负责
4. **`!` 即转译期** —— 任何带 `!` 后缀的标识符（变量、函数名、装饰器）都表示**转译期辅助生成语法树**，必须定义在宏模块中
5. **`=` 构建块** —— `def`/`struct`/`class`/`enum`/`trait` 定义体以及变量构建块都使用 `=` 开启缩进体

## 2. 与 Vox v2 的差异

本版相对 Vox v2 做了大量删减与重构：

### 2.1 被移除的特性

| 类别 | 移除项 | 原因 |
|------|--------|------|
| 关键字 | `define` / `extend` / `omit` / `val` / `var` / `when` / `then` / `end` / `of` / `event` / `toml` / `transtime` | 用更轻量的语法替代 |
| 操作符声明 | `prefix` / `infix` / `suffix` / `nthfix` / `pairfix` / `buildfix`（即 `*fix` 全家族） | 不开放自定义操作符符号，仅保留内置 |
| 自增自减 | `++` / `--` | 用 `+= 1` / `-= 1` 替代 |
| 并行操作符 | `||>` `||>>` `||?>` `||*>` `||&>` `||@>` `|||` | 改用 `go` / `async` / `spawn` + channel |
| 多行字符串 | `#|` / `$|` / `&|` | 改用三引号 + `f"""..."""` |
| 日期字面量 | `#2024-01-15#` | 改用标准库函数 |
| 管道流 | 仅保留 `|>` 与 `<|`，移除其它 `|*>` `|?>` `|>>` 等 | 简化操作符面 |
| 函数组合 | 仅保留 `~>` 与 `<~`，移除其它组合符号 | 简化操作符面 |
| `match` 管道 | `match x: | A => ...` 改为 `match x: case A: ...`（与 Python 对齐） | 降低学习成本 |
| `case of` | 移除 `case ... of ...` 语法 | 与 `match case` 统一 |

### 2.2 新增的特性

| 类别 | 新增项 | 说明 |
|------|--------|------|
| 文件指令 | `#!bin lang_name` | 文件首部指定目标转译语言 |
| 文件指令 | `#!bin macro lang_name` | 声明本文件为宏模块 |
| 宏标记 | `def name!(...)` / `x! : T = ...` / `@name!` | 末尾 `!` 表示转译期辅助生成，必须导入宏包 |
| 变量语法 | `x = 1` / `x : mut = 1` / `x : int = 1` / `x : mut int = 1` | 替代 `val` / `var` |
| 变量语法 | `x : owned T = ...` | 所有权"只能借不能转移"语义 |
| 变量语法 | `PI : const f64 = 3.14` | 编译期常量 |
| 变量语法 | `t = y^` | 显式转移所有权 |
| 定义语法 | `def hello() = ...` | `=` 替代 `:` 开启函数体 |
| 构建块 | `x =` 后留白并缩进 | 缩进块构建变量值，支持 `break <expr>` 提前返回 |
| 参数包 | `hello :` 缩进体 | Callable 对象构建参数包并解包应用 |
| 参数包 | `KwArgs:` / `Args` | 关键字/位置参数包关键字 |
| 参数包 | `out` | 在参数包构建块中输出一个绑定到参数包 |
| 接收返回 | `result = hello :` | 在 `:` 块尾部接收 callable 的返回值 |
| match 语法 | `match x: case ... :` | 与 Python `match case` 对齐 |

## 4. 术语约定

| 术语 | 含义 |
|------|------|
| 转译期 | Lang-Zong 编译器解析源码、生成目标语言源码的阶段 |
| 编译期 | 目标语言编译器（如 `cython`/`rustc`）编译生成的阶段 |
| 宏模块 | 用 `#!bin macro` 声明的文件，提供 `!` 标记的转译期辅助 |
| 构建块 | `=` 或 `:` 后留白缩进的代码块，用于构建一个值或参数包 |
| 参数包 | `hello :` 块内为可调用对象准备的参数集合 |
| 目标语言 | Lang-Zong 源码转译后生成的语言，默认 Cython |
