# 控制流

## 1. 条件

### 1.1 if-elif-else

```
x = 10

category = if x < 0:
    "negative"
elif x == 0:
    "zero"
else:
    "positive"

// 单行
result = "positive" if x > 0 else "non-positive"
```

### 1.2 `if let` 模式守卫

```
if let Some(v) = opt:
    print(v)
```

## 2. match case（与 Python 对齐）

`match` 使用 `case` 关键字开启分支，**移除了 `| A => ...` 管道式语法**：

```
def describe(x: int) -> str =
    match x:
        case 0:
            "zero"
        case 1:
            "one"
        case 2:
            "two"
        case _:
            "many"
```

### 2.1 带守卫

```
def classify(x: int) -> str =
    match x:
        case n if n < 0:
            "negative"
        case 0:
            "zero"
        case n if n < 10:
            "small"
        case _:
            "large"
```

### 2.2 解构匹配

```
struct Point =
    x : f64
    y : f64

def quadrant(p: Point) -> str =
    match p:
        case Point(0, 0):
            "origin"
        case Point(x, y) if x > 0 and y > 0:
            "Q1"
        case Point(x, y) if x < 0 and y > 0:
            "Q2"
        case _:
            "axis"

// 枚举匹配
def unwrap_or<T>(opt: Option<T>, default: T) -> T =
    match opt:
        case Some(v):
            v
        case None:
            default

// 列表匹配
def sum_list(xs: [int]) -> int =
    match xs:
        case []:
            0
        case [x, ...rest]:
            x + sum_list(rest)
```

### 2.3 Atom 匹配

```
match msg:
    case :inc:
        counter += 1
    case :dec:
        counter -= 1
    case :reset:
        counter = 0
```

> 注意：`case ... of` 语法已移除，统一使用 `match case`。

## 3. guard 语句

`guard` 只能用在函数内部（含匿名函数）。`let` 不能单独使用，必须与 `if`/`while`/`guard`/`until` 配合。

### 3.1 基本形式

```
def add(a: int?, b: int?) -> int =
    guard let Some(v) = a else 0
    v
```

### 3.2 连级 guard

```
def add(a: int?, b: int?) -> int =
    guard let Some(v) = a else:
        guard let Some(t) = b else 0
    v + t
```

转译为目标语言的 `let ... else` 语义。

## 4. 循环

### 4.1 loop — 无限循环

```
loop:
    msg = recv()
    if msg == :quit:
        break
    process(msg)
```

### 4.2 while — 条件循环

```
i : mut = 0
while i < 10:
    print(i)
    i += 1
```

### 4.3 for — 迭代器循环

```
for x in [1, 2, 3]:
    print(x)

for (k, v) in map:
    print(f"{k}: {v}")
```

### 4.4 守卫过滤

```
for x in 0..100 if x % 2 == 0:
    print(x)
```

### 4.5 while let

```
while let Some(x) = iter.next():
    process(x)
```

### 4.6 标签跳转

`#label` 给循环或块命名，`break #label` / `continue #label` 跳转：

```
#outer: for row in 0..matrix.rows:
    for col in 0..matrix.cols:
        if matrix.get(row, col) == target:
            break #outer
        if matrix.get(row, col) == 0:
            continue #outer
```

## 5. 标签块（Labeled Block）

`block #name:` 创建带标签的作用域，`break #name with expr` 跳出并返回值：

```
result = block #compute:
    if cache_hit:
        break #compute with cached_value
    fresh = expensive()
    if fresh == 0:
        break #compute with default_value
    fresh
```

### 5.1 `break` 在构建块中

`break` 可用于任何 `=` 或 `:` 构建块中提前返回构建值（见 [03-缩进规则.md](03-缩进规则.md)）：

```
x =
    y : mut = 1
    if y > 3:
        break y + 7          // 提前构建变量
    y
```

`break`（留白）表示结束构建块，值为已构建的实例：

```
result3 = demo :
    impl demo2 for demo =
        def mymethod(Self) =
            print("hi")
    break                    // 结束构建，返回实例
```

## 6. break 带返回值

`loop` 和 `for` 可作为表达式，`break with expr` 跳出并返回值：

```
found = loop:
    msg = recv()
    if msg.kind == :data:
        break with msg.payload

first_even = for x in 0..100:
    if x % 2 == 0 and x > 10:
        break with x
```

## 7. for/while 的 else 子句

循环正常结束（非 `break`）时执行 `else`：

```
def find_index(items: [int], target: int) -> int? =
    for (i, v) in items.enumerate():
        if v == target:
            break
    else:
        return None
    i
```

## 8. defer

```
def file_operation() =
    file = open("data.txt")
    defer: file.close()
    process(file.read())
```

## 9. with 上下文管理器

```
with open(path) as f:
    process(f.read())
```

详见 [13-数据类型.md](13-数据类型.md) 的 `__enter__` / `__exit__`。

## 10. return

```
def foo() -> int =
    return 42

def bar() -> (int, str) =
    return 1, "hello"        // 隐式打包为元组

def maybe(x: bool) -> int? =
    if x:
        return 42
    return                   // 等价于 return None
```

## 11. 已移除的控制流语法

| 语法 | 状态 | 替代 |
|------|------|------|
| `match x: \| A => ...` | ❌ 移除 | `match x: case A:` |
| `case x of ...` | ❌ 移除 | `match x: case ...` |
| `when` / `then` | ❌ 移除 | `case` 分支 |
| `end` | ❌ 移除 | 缩进回退闭合 |
