# 并发

Lang-Zong 移除了所有并行操作符（`||>` `||>>` 等），改用 `go` / `spawn` / `async` / `await` + channel。

## 1. goroutine (`go`)

```
def worker(id: int, ch: Chan[str]) =
    go:
        ch.send(f"Worker {id} started")
        ch.send(f"Worker {id} done")

def main() =
    ch = Chan::new()
    go: worker(1, ch.clone())
    go: worker(2, ch.clone())
    go: worker(3, ch.clone())

    print(ch.recv())
    print(ch.recv())
    print(ch.recv())
```

## 2. Channel

```
def pipeline() =
    ch1 = Chan::new()
    ch2 = Chan::buffered(10)

    go:
        ch1.send(1)
        ch1.send(2)
        ch1.close()

    go:
        for msg in ch1:
            ch2.send(msg * 2)
        ch2.close()

    results = ch2.collect()      // [2, 4]
```

| API | 说明 |
|-----|------|
| `Chan::new()` | 创建无缓冲 channel |
| `Chan::buffered(n)` | 创建容量为 n 的缓冲 channel |
| `ch.send(v)` | 发送 |
| `ch.recv()` | 接收 |
| `ch.close()` | 关闭 |
| `ch.collect()` | 收集所有剩余消息 |

## 3. Actor 模型 (`spawn`)

```
spawn Counter:
    state : mut int = 0

    def handle(msg) =
        match msg:
            case :inc:
                state += 1
                state
            case :dec:
                state -= 1
                state
            case :get:
                state
            case :reset:
                state = 0
                0

def main() =
    counter = spawn Counter
    print(counter.send(:inc))     // 1
    print(counter.send(:inc))     // 2
    print(counter.send(:get))     // 2
    print(counter.send(:reset))  // 0
```

## 4. async / await

```
async def fetch_data(url: str) -> Result<str, NetError> =
    response = await http.get(url)
    if response.status != 200:
        return Err(NetError(f"HTTP {response.status}"))
    Ok(response.body)

async def fetch_all(urls: [str]) -> [str] =
    tasks = urls.map(|url| fetch_data(url))
    results = await gather(tasks)
    results.filter_map(|r| r.ok())
```

| 关键字 | 说明 |
|--------|------|
| `async` | 声明异步函数 |
| `await` | 等待异步结果 |
| `gather(tasks)` | 并发等待多个任务 |

## 5. 并行策略

不再使用 `||>>` 等操作符。需要并行时：

- **数据并行**：用 `go` + channel 分片处理
- **任务并行**：用 `async` + `gather`
- **Actor**：用 `spawn`

```
// 数据分片并行
def parallel_map(data: [int], f) =
    ch = Chan::buffered(data.len())
    for chunk in data.chunks(4):
        go:
            for x in chunk:
                ch.send(f(x))
    ch.collect()
```

## 6. 已移除的特性

| 特性 | 状态 | 替代 |
|------|------|------|
| `\|\|>` `\|\|>>` 并行管道 | ❌ 移除 | `go` + channel |
| `\|\|?>` 并行 filter | ❌ 移除 | `go` + channel |
| `\|\|&>` 并行 reduce | ❌ 移除 | `go` + channel |
| `\|\|\|` join | ❌ 移除 | `await gather` |
| `event` 事件系统 | ❌ 移除 | 用 `Chan` + `spawn` 替代 |

## 7. 线程安全

线程安全由目标语言保证：

- Cython/Python：受 GIL 限制，IO 密集型用 `async`/`await`
- Rust：`Send`/`Sync` trait 自动检查
- 跨 channel 传递的数据必须满足目标语言的线程安全要求
