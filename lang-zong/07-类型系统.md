# 类型系统

## 1. 基本类型

```
name : str = "Lang-Zong"
age  : int = 42
pi   : f64 = 3.14159
flag : bool = True
data : bytes = b"hello"
nothing : None = None
```

| 类型 | 示例 | 说明 |
|------|------|------|
| `str` | `"hi"` | 字符串 |
| `int` | `42` | 整数（目标语言决定宽度） |
| `f64` | `3.14` | 浮点 |
| `bool` | `True` | 布尔 |
| `bytes` | `b"hi"` | 字节串 |
| `None` | `None` | 空类型 |

## 2. Option 类型 (`?`)

`T?` 等价于 `Option<T>`：

```
def find_user(id: int) -> str? =
    if id == 0:
        return None
    "User {id}"

// 安全访问
name = user?.profile?.name

// 强制解包
ensured = risky_call()??
name = user?.profile?.name ?? "Anonymous"
```

| 形式 | 含义 |
|------|------|
| `T?` | Option 类型 |
| `obj?.field` | 安全导航 |
| `expr ??` | 强制解包，None 时 panic |
| `a ?? b` | null 合并 |

## 3. 容器类型

```
list   : [int]            = [1, 2, 3]
tuple  : (int, str, bool) = (42, "hi", True)
dict   : {:str: int}      = {: "a": 1}
set    : {int}            = {1, 2, 3}
```

### 3.1 字典与集合的区分

- `{:` 开头 = 字典
- `{` 开头无 `:` = 集合
- `{}` = 空集合
- `{:}` = 空字典

详见 [05-字面量.md](05-字面量.md)。

## 4. 类型注解位置

类型注解出现在变量声明、函数参数、函数返回值位置：

```
x : int = 1
def add(a: int, b: int) -> int = a + b
data : [int] = [1, 2, 3]
```

## 5. Atom 类型

`:name` 是 Atom 字面量，本质是 `u64` 哈希常量：

```
a = :inc
```

Atom 不是字符串，比较是 O(1) 整数比较。详见 [05-字面量.md](05-字面量.md)。

## 6. 类型作为一等值

类型本身可以作为运行时值使用：

```
t = Enum3                  // t 是类型引用
types = [Struct1, Enum2]  // 类型列表
cat = type(t)              // 返回 TypeCategory::Enum
name = t.name()
```

### 6.1 限制

- 类型引用不可变（编译期确定）
- 不能动态创建新类型
- 泛型类型必须完全实例化：`List<int>` 可用，`List` 不可用

## 7. 自动类型转换

```
a : f64 = 1               // ✅ int → f64
b : int = "a"             // ❌ 编译错误
```

仅支持安全的宽化转换，具体规则由目标语言决定。

## 8. 不再支持的特性

| 特性 | 状态 | 说明 |
|------|------|------|
| `define` 结构类型约束 | ❌ 移除 | 用 `trait` 替代 |
| 自定义操作符符号 | ❌ 移除 | 不开放 `*fix` 声明 |
| `*args` 异类型 | ❌ 不支持 | 同类型可变参数用 `[T]` |
| `**kwargs` | ❌ 不支持 | 用 `KwArgs` 参数包构建块替代 |
