# 变量与绑定

Lang-Zong 移除了 `val` / `var` 关键字，改为通过**类型注解形式**表达可变性与所有权语义。

## 1. 变量声明形式

### 1.1 不可变绑定（替代 `val`）

```
x = 3                    // 自推断，不可变
x : int = 1              // 显式类型，不可变
```

### 1.2 可变绑定（替代 `var`）

```
x : mut = 1              // 可变，自推断类型
x : mut int = 5          // 可变，显式类型

x += 1                   // ✅ 允许重新赋值
```

### 1.3 编译期常量

```
PI : const f64 = 3.1415926     // 编译期常量
MAX : const int = 1024
```

`const` 标注的绑定在编译期求值，不可重新赋值，**可用于类型位置**。

### 1.4 owned 绑定

`owned` 表示**所有权"只借不转移"**：变量持有资源，但**不能被显式转移**给其它变量。作用域结束时自动清理。

```
z : owned int = 1
// z 可读、可改（若同时标注 mut）
z : mut owned int = 1
z += 1                    // ✅
```

### 1.5 语法汇总

| 形式 | 含义 | 可重新赋值 | 可转移所有权 |
|------|------|:---:|:---:|
| `x = e` | 自推断不可变 | ❌ | ❌ |
| `x : T = e` | 显式类型不可变 | ❌ | ❌ |
| `x : mut = e` | 自推断可变 | ✅ | ❌ |
| `x : mut T = e` | 显式类型可变 | ✅ | ❌ |
| `x : owned T = e` | owned 不可变 | ❌ | ❌（从不转移） |
| `x : mut owned T = e` | owned 可变 | ✅ | ❌（从不转移） |
| `x : const T = e` | 编译期常量 | ❌ | ❌ |
| `x! : T = e` | 宏变量（转译期） | — | — |

## 2. 所有权转移 `^`

`^` 是**后缀操作符**，显式转移所有权。

```
y : mut int = 5
t = y^                  // y 的所有权转移给 t，之后 y 不可用
// print(y)             // ❌ 编译错误：y 已被转移
```

对于**引用计数类**的目标语言（如 Cython/Python），`y^` 表示**删除变量名 `y`**，引用计数减一。

### 2.1 owned 不可转移

```
z : owned int = 1
k = z^                  // ❌ 编译错误：z 是 owned，从不转移
```

### 2.2 可变自更新

```
c : mut int = 10
c = c^ + 1              // ✅ 先移出旧值再赋新值
```

## 3. 解构绑定

```
// 元组解构
(x, y) = (1, 2)

// 枚举解构
Some(v) = maybe_value

// 列表解构
[first, ...rest] = [1, 2, 3]
```

## 4. 宏变量（`!` 后缀）

带 `!` 后缀的变量是**转译期辅助变量**，必须定义在宏模块中，由宏包提供：

```
// 仅在 #!bin macro 模块中合法
x! : int = 9
```

详见 [14-宏与转译期.md](14-宏与转译期.md)。

## 5. 变量构建块

`= ` 后留白并缩进，可以用一个缩进块来构建变量值（见 [03-缩进规则.md](03-缩进规则.md)）：

```
x =                     // = 后留白，下一行缩进
    y : mut = 1
    if y > 3 :
        break y + 7     // 提前构建变量，后续同级不执行
    y                   // 块尾表达式作为构建值
// 等价于  x : mut int = y
```

## 6. 类型注解的空白规则

类型注解的 `:` 必须**前紧后松**：

```
x : int = 1             // ✅
x :int = 1              // ❌ `:` 后必须有空格
x : int= 1              // ❌ infix `=` 两侧必须有空格
```

详见 [11-操作符.md](11-操作符.md)。
