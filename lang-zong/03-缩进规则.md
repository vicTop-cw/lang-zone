# 缩进规则

## 1. 基本规则

- **4 空格** 为一个缩进层级，不允许 Tab
- 同一文件内缩进必须一致
- 缩进决定作用域，回退缩进即闭合块

## 2. 块开启符

以下符号/关键字后跟换行 + 缩进，开启一个缩进块：

| 块开启符 | 示例 | 说明 |
|---------|------|------|
| `:` | `if x > 0:` | 条件/循环/异常等控制流块 |
| `=` | `def hello() =` | 函数体、类型定义体 |
| `match x:` | — | match 块 |
| `case ...:` | — | match 分支 |
| `KwArgs:` | — | 关键字参数包块 |
| `Args:` | — | 位置参数包块 |
| `name :` | `hello :` | Callable 调用块（构建参数包并应用） |
| `guard let ... else:` | — | guard 块 |

## 3. `=` 构建块（变量构建块）

`=` 后**留白并换行缩进**，表示用一个缩进块来构建一个值。

### 3.1 基本形式

```
x =                     // = 后留白，下一行必须缩进
    y : mut = 1
    if y > 3 :
        break y + 7     // 提前构建变量，后续同级作用域不再执行
    y                   // 块尾表达式作为构建值
// 等价于  x : mut int = y
```

- 块内最后一行表达式作为构建结果
- `break <expr>` 用于**提前返回构建值**，后续同级语句不再执行
- `break`（留白）用于在需要时显式结束构建块，不返回值（用于副作用构建块）
- 若未显式 `break`，以块尾最后一个表达式为值

### 3.2 单行形式

```
x = 3
```

不换行时 `=` 后直接跟表达式，等价于普通赋值。

### 3.3 与类型注解的组合

```
x : int =               // 显式类型 + 构建块
    val a = read_int()
    a * 2
```

## 4. `name :` Callable 调用块

`name :` 后换行缩进，表示为 `name` 这个可调用对象构建一个参数包并应用：

```
def hello() = print("Hi!")

hello :                  // 调用 hello
    print("what can I do for you?")
// 先打印 "what can I do for you?"，再调用 hello() 打印 "Hi!"
```

- 若函数无参，块内不需要参数包，块体作为前置副作用执行
- 若函数有参，块内通过 `KwArgs:` / `Args:` 或返回元组/字典构造参数包
- 详见 [09-函数.md](09-函数.md)

### 4.1 接收返回值

```
result = hello2 :        // 接收 hello2 的返回值
    KwArgs:
        out age : mut = 17
        out name = "Alice"
```

### 4.2 方法调用

```
result2 = result.replace :
    "old"
    "new"
```

只要是 callable 都可使用此语法。

## 5. 缩进回退闭合

缩进块由**缩进回到块开启符同级或更浅**时闭合，无需 `end`：

```
def compute(x: int) =
    if x > 0:
        print("positive")
    else:
        print("non-positive")
// ↑ 缩进回到 def 同级，函数体结束
```

## 6. 续行

表达式需要跨行时，满足以下任一条件即可续行：

- 在括号 `()` `[]` `{}` 内部
- 在中缀操作符之后
- 在 `=` / `->` / `:` 之后换行并缩进

```
val total = 1 +
            2 +
            3

val result = [
    1, 2, 3,
    4, 5, 6,
]
```

## 7. 空行与空块

- 空行不影响语义
- 空块用 `pass` 关键字显式表示（保留字，见 [01-附录-关键字与保留字.md](01-附录-关键字与保留字.md)）：

```
def noop() =
    pass
```
