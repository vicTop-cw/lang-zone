# 包与导入

## 1. 可见性规则

**无 `pub` 关键字**（`pub` 是保留字）。可见性通过命名约定控制：

| 标识符开头 | 可见性 |
|-----------|--------|
| 非下划线 | 公开 |
| `_` 前缀 | 私有（模块内可见） |
| `__xxx__` 双下划线包围 | 魔法方法，始终公开 |

```
// 公开
def factorial(n: int) -> int =
    ...

// 私有
def _internal(n: int) -> int =
    ...

// 公开（魔法方法）
def __add__(Self, other: Point) -> Point =
    ...
```

### 1.1 公开 API 签名约束

公开函数的签名中**不能出现私有 trait**，否则编译报错：

```
trait _Sortable<T> =
    def cmp(Self, other: T) -> int

// ❌ 编译错误 — 公开函数暴露了私有 trait
def sort(xs: [_Sortable]) = ...

// ✅ 私有函数无此限制
def _sort(xs: [_Sortable]) = ...
```

## 2. 包结构

与 Python 一致：包含 `__init__.lz` 的目录即为一个包。

```
myapp/
  __init__.lz              // 标记 myapp 为包（可为空）
  main.lz
  utils/
    __init__.lz
    math.lz
    strings.lz
  models/
    __init__.lz
    user.lz
```

## 3. 导入语法

```
// 导入整个模块
import utils.math

// 导入指定符号
import utils.math::{add, sub}

// 导入并别名
import utils.strings as strutil

// 从模块导入单个符号
from utils.math import add

// 从模块导入多个符号
from utils.math import add, sub, mul

// 惰性导入
lazy import std::heavy_module
```

## 4. 命名空间访问

使用 `::` 分隔路径：

```
result = utils.math::add(1, 2)
s = strutil::trim("  hello  ")
```

## 5. 标准库

标准库以 `std::` 开头：

```
import std::net::{TcpListener, TcpStream}
import std::io::{read_to_string, write}
import std::ml::{Tensor, Model}
```

## 6. 宏模块的导入

宏模块通过 `#!bin macro` 声明，导入后可使用其中的 `!` 标记：

```
import mymacros

@mymacros.derive!
struct Point =
    x : f64
    y : f64
```

详见 [14-宏与转译期.md](14-宏与转译期.md)。

## 7. 与目标语言的衔接

Lang-Zong 编译器扫描 `__init__.lz` 确定包结构，转译时生成目标语言的模块层级：

| 目标语言 | `__init__.lz` | `import utils.math` | 命名空间访问 |
|---------|---------------|---------------------|-------------|
| Cython | `__init__.pyx` | `from .utils import math` | `utils.math::add` |
| Rust | `mod.rs` | `use crate::utils::math;` | `utils::math::add` |
| Python | `__init__.py` | `from .utils import math` | `utils.math::add` |

## 8. 已移除的特性

| 特性 | 状态 | 说明 |
|------|------|------|
| `toml` 关键字 | ❌ 移除 | 用 `__toml__.lz` 配置文件替代 |
| `package` 关键字 | ❌ 不支持 | 目录即包 |
| `external` 外部语言互操作 | ❌ 移除 | 用 FFI 或宏模块替代 |
