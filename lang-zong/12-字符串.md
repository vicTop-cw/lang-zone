# 字符串

## 1. 单行字符串

| 前缀 | 转义 `\n` | 插值 `{...}` | 说明 |
|------|:---:|:---:|------|
| `"..."` | 是 | 否 | 普通双引号 |
| `'...'` | 是 | 否 | 普通单引号 |
| `f"..."` | 是 | 是 | 插值双引号 |
| `f'...'` | 是 | 是 | 插值单引号 |
| `r"..."` | 否 | 否 | 原始双引号 |
| `r'...'` | 否 | 否 | 原始单引号 |

```
name = "Lang-Zong"
version = 0

s1 = "Hello, World!"
s2 = f"Hello, {name} v{version}"
s3 = r"C:\Users\{name}\data"      // {name} 原样输出
```

## 2. 三引号字符串

| 前缀 | 转义 `\n` | 插值 `{...}` | 说明 |
|------|:---:|:---:|------|
| `"""..."""` | 是 | 否 | 普通三双引号 |
| `'''...'''` | 是 | 否 | 普通三单引号 |
| `f"""..."""` | 是 | 是 | 插值三双引号 |
| `f'''...'''` | 是 | 是 | 插值三单引号 |
| `r"""..."""` | 否 | 否 | 原始三双引号 |
| `r'''...'''` | 否 | 否 | 原始三单引号 |

```
doc1 = """多行
字符串
示例"""

doc2 = f"""Hello, {name}!
Version: {version}"""

doc3 = r'''C:\Users\
{name}\data'''              // {name} 原样输出
```

## 3. 与 Python 的关键区别

不加 `f` 前缀的字符串 `{name}` **原样输出**，不会插值：

```
s = "Hello, {name}"           // 字符串内容就是字面 "Hello, {name}"
s = f"Hello, {name}"          // 插值，值为 "Hello, Lang-Zong"
```

## 4. 字符串操作

```
s = "Hello, Lang-Zong!"

first = s[0]                  // 'H'
slice = s[0..5]               // "Hello"
upper = s.to_upper()          // "HELLO, LANG-ZONG!"
len = s.len()                 // 17
has = s.contains("Lang")      // True
```

## 5. 已移除的形式

| 形式 | 状态 | 替代 |
|------|------|------|
| `#| ...` | ❌ 移除 | `"""..."""` |
| `$| ...` | ❌ 移除 | `f"""..."""` |
| `&| ...` | ❌ 移除 | `r"""..."""` |

## 6. 转义字符

在非 `r` 前缀的字符串中，以下转义生效：

| 转义 | 含义 |
|------|------|
| `\n` | 换行 |
| `\t` | 制表符 |
| `\r` | 回车 |
| `\\` | 反斜杠 |
| `\"` `\'` | 引号 |
| `\0` | 空字符 |
| `\x41` | 十六进制字节 |
| `\u0041` | Unicode 码点 |
