# 字面量

## 1. 数字字面量

```
42              // int
0xFF            // 十六进制
0o17            // 八进制
0b1010          // 二进制
1_000_000       // 下划线分组

3.14            // f64
1.0e-3          // 科学计数法
6.022e23
```

## 2. 布尔与空值

```
True
False
None
```

`True` / `False` / `None` 是关键字，首字母大写。

## 3. 列表字面量

```
[1, 2, 3]
[1, 2, 3,]          // 尾部逗号允许
[]                  // 空列表
[[1, 2], [3, 4]]    // 嵌套

// 列表推导式
[x * x for x in 0..10]
[x for x in 0..10 if x % 2 == 0]
```

## 4. 元组字面量

```
(1, "hi", True)     // 多元素元组
(1,)                // 单元素元组（必须有逗号）
()                  // 空元组
```

## 5. 字典字面量

`{:` 是字典字面量的起始标记（双字符 token），与集合区分：

```
{:}                     // 空字典
{: "a": 1}              // 单键值对
{: "a": 1, "b": 2}      // 多键值对

// 字典推导式
{: x: x * x for x in 0..5}
```

类型标注：

```
d : {:str: int} = {: "a": 1, "b": 2}
```

## 6. 集合字面量

`{` 开头且紧跟非 `:` 字符为集合：

```
{}                      // 空集合
{1, 2, 3}               // 非空集合

// 集合推导式
{x % 3 for x in 0..10}
```

## 7. 区分规则

| 开头 | 内容 | 结果 |
|------|------|------|
| `{:` | `}` 直接闭合 | 空字典 |
| `{:` | `key: val, ...` | 字典 |
| `{` | `}` 直接闭合 | 空集合 |
| `{` | `elem, elem, ...` | 集合 |
| `{` | `expr for ...` | 集合推导式 |
| `{` | `key: val for ...` | 字典推导式 |

## 8. Atom 字面量

以 `:` 前缀表示，是编译期确定的唯一标识符，本质是 `u64` 哈希。

```
:inc
:dec
:ok
:error
```

用途：

```
match msg:
    case :inc:
        counter += 1
    case :dec:
        counter -= 1

// 作为字典 key
config = {: :host: "localhost", :port: 8080}
```

> 字典 key 场景下 `:` 前需空格以避免与 `{:` token 冲突：`config[: :host]`。

## 9. 不再支持的字面量

| 形式 | 状态 | 替代方案 |
|------|------|---------|
| `#2024-01-15#` 日期字面量 | ❌ 移除 | 用标准库 `Date.from("2024-01-15")` |
| `#| ...` 多行字符串 | ❌ 移除 | 用三引号 `"""..."""` |
| `$| ...` | ❌ 移除 | 用 `f"""..."""` |
| `&| ...` | ❌ 移除 | 用 `r"""..."""` |
