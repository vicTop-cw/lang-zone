# 文件与模块结构

## 1. 文件后缀

Lang-Zong 源码文件后缀为 `.lz`。

## 2. `#!bin` 文件指令

`#!bin` 必须出现在文件**第一行**（允许前面有空白/注释），一份文件**只能有一条** `#!bin`，否则编译错误。

### 2.1 指定目标转译语言

```
#!bin rust
```

含义：本文件转译为 Rust 源码。

### 2.2 声明宏模块

```
#!bin macro default
```

含义：本文件是宏模块，目标语言使用默认（即 `__toml__.lz` 或全局默认）。

```
#!bin macro python
```

含义：本文件是宏模块，目标语言为 Python。

### 2.3 省略 `#!bin`

不写 `#!bin` 表示：

- 本文件是普通源码模块（非宏模块）
- 目标语言由 `__toml__.lz` 指定，若也未指定则使用全局默认 **Cython**

## 3. `__toml__.lz` 配置文件

每个项目根目录可以放置一个 `__toml__.lz`，作为项目级配置。语法为 TOML 子集。

```
[bin]
default = "cython"      // 项目默认目标语言
edition = "2024"        // 目标语言 edition

[dependencies]
numpy = "1.24"
requests = ">=2.28, <3.0"
```

| 节 | 说明 |
|----|------|
| `[bin]` | 项目级转译配置 |
| `[bin].default` | 默认目标语言，可选值：`cython` / `rust` / `python` / `nim` |
| `[dependencies]` | 外部依赖（传递给目标语言的包管理器） |

## 4. 包目录结构

与 Python 一致：包含 `__init__.lz` 的目录即为一个包。

```
myapp/
  __init__.lz              // 标记 myapp 为包
  main.lz
  utils/
    __init__.lz
    math.lz
    strings.lz
  models/
    __init__.lz
    user.lz
```

## 5. 模块与目标语言的衔接

Lang-Zong 编译器扫描 `__init__.lz` 确定包结构，转译时生成目标语言的模块层级：

```
Lang-Zong                          Cython（默认）
───────                            ───────────
myapp/                             myapp/
  __init__.lz           →           __init__.pyx
  main.lz               →           main.pyx
  utils/
    __init__.lz         →           utils/__init__.pyx
    math.lz             →           utils/math.pyx
```

若目标语言为 Rust：

```
Lang-Zong                          Rust
───────                            ────
myapp/                             myapp/
  __init__.lz           →           mod.rs
  main.lz               →           main.rs
  utils/math.lz         →           utils/math.rs
```

## 6. 宏模块的引用

宏模块以 `#!bin macro` 声明，其它文件通过 `import` 引入后即可使用其中的 `!` 标记：

```
import mymacros                   // mymacros 是宏模块

@mymacros.derive!                  // 使用宏模块中的宏
struct Point =
    x : f64
    y : f64
```
