# 并发

Lang-Zong 移除了所有并行操作符（`||>` `||>>` 等），改用 `go` / `spawn` / `async` / `await` + channel。

> ✅ 已实现：`spawn <expr>` 转译为 `std::thread::spawn(move || { ... })`，可用表达式形式编写并发。
> ✅ 已实现：`async def` 声明生成 `async fn`，函数体内 `await expr` 生成 `{expr}.await`。
> ⚠️ 未实现（规划中）：下文 `go:` / `Chan` / channel API / `spawn Name:`（actor 形式）/ `gather` / `select` 等当前编译器不解析或不生成，示例暂无法通过 lzc 编译。

## 1. goroutine (`go`)

> ⚠️ 未实现（规划中）：`go:` 不存在对应 token，编译器无法解析；`Chan`/channel API 亦未实现。并发请用已实现的 `spawn <expr>` 表达式形式。

```
def worker(id: int, ch: Chan[str]) =
    go:
        ch.send(f"Worker {id} started")
        ch.send(f"Worker {id} done")

def main() =
    ch = Chan::new()
    go: worker(1, ch.clone())
    go: worker(2, ch.clone())
    go: worker(3, ch.clone())

    print(ch.recv())
    print(ch.recv())
    print(ch.recv())
```

## 2. Channel

> ⚠️ 未实现（规划中）：`Chan` 类型与 `ch.send`/`ch.recv`/`ch.close`/`ch.collect`/`Chan::new`/`Chan::buffered` 等 channel API 当前编译器不生成，示例暂无法通过 lzc 编译。

```
def pipeline() =
    ch1 = Chan::new()
    ch2 = Chan::buffered(10)

    go:
        ch1.send(1)
        ch1.send(2)
        ch1.close()

    go:
        for msg in ch1:
            ch2.send(msg * 2)
        ch2.close()

    results = ch2.collect()      // [2, 4]
```

| API | 说明 |
|-----|------|
| `Chan::new()` | 创建无缓冲 channel |
| `Chan::buffered(n)` | 创建容量为 n 的缓冲 channel |
| `ch.send(v)` | 发送 |
| `ch.recv()` | 接收 |
| `ch.close()` | 关闭 |
| `ch.collect()` | 收集所有剩余消息 |

## 3. Actor 模型 (`spawn`)

> ⚠️ 未实现（规划中）：`spawn Counter:` 这种 actor 形式当前编译器不实现；已实现的并发写法是表达式形式 `spawn <expr>`（见文件开头说明）。示例暂无法通过 lzc 编译。

```
spawn Counter:
    state : mut int = 0

    def handle(msg) =
        match msg:
            case :inc:
                state += 1
                state
            case :dec:
                state -= 1
                state
            case :get:
                state
            case :reset:
                state = 0
                0

def main() =
    counter = spawn Counter
    print(counter.send(:inc))     // 1
    print(counter.send(:inc))     // 2
    print(counter.send(:get))     // 2
    print(counter.send(:reset))  // 0
```

## 4. async / await

> ⚠️ 未实现（规划中）：`async def` 可声明（编译器生成 `async fn`），但函数体内 `await` 尚未解析；`gather` 亦未实现。示例暂无法通过 lzc 编译。

```
async def fetch_data(url: str)-> Result<str, NetError> =
    response = await http.get(url)
    if response.status != 200:
        return Err(NetError(f"HTTP {response.status}"))
    Ok(response.body)

async def fetch_all(urls: List<str>)-> List<str> =
    tasks = urls.map(|url| fetch_data(url))
    results = await gather(tasks)
    results.filter_map(|r| r.ok())
```

| 关键字 | 说明 |
|--------|------|
| `async` | 声明异步函数 |
| `await` | 等待异步结果 |
| `gather(tasks)` | 并发等待多个任务 |

## 5. 并行策略

> ⚠️ 未实现（规划中）：本节的 `go` + channel、`async` + `gather`、`spawn` actor 等并行策略当前未实现（`spawn <expr>` 表达式形式除外），示例暂无法通过 lzc 编译。

不再使用 `||>>` 等操作符。需要并行时：

- **数据并行**：用 `go` + channel 分片处理
- **任务并行**：用 `async` + `gather`
- **Actor**：用 `spawn`

```
// 数据分片并行
def parallel_map(data: [int], f) =
    ch = Chan::buffered(data.len())
    for chunk in data.chunks(4):
        go:
            for x in chunk:
                ch.send(f(x))
    ch.collect()
```

## 6. 已移除的特性

| 特性 | 状态 | 替代 |
|------|------|------|
| `\|\|>` `\|\|>>` 并行管道 | ❌ 移除 | `go` + channel |
| `\|\|?>` 并行 filter | ❌ 移除 | `go` + channel |
| `\|\|&>` 并行 reduce | ❌ 移除 | `go` + channel |
| `\|\|\|` join | ❌ 移除 | `await gather` |
| `event` 事件系统 | ❌ 移除 | 用 `Chan` + `spawn` 替代 |

## 7. 线程安全

> ⚠️ 未实现（规划中）：当前仅 Rust 单后端，示例中的 Cython/Python 线程安全描述暂不支持。

线程安全由目标语言保证：

- 仅 Rust：`Send`/`Sync` trait 自动检查（当前唯一后端）
- 跨 thread 传递的数据必须满足 Rust 的线程安全要求

## 语法边界

- ✅ `spawn <expr>` 已实现：转译为 `std::thread::spawn(move || { ... })`，`spawn` 后必须接一个**表达式**。
- ❌ `go:` 未实现：编译器无对应 token，无法解析该语法。
- ❌ `Chan` 类型与 channel API（`send`/`recv`/`close`/`collect`/`Chan::new`/`Chan::buffered`）未实现。
- ❌ `spawn Name:` 这种 actor 形式未实现，仅支持表达式形式 `spawn <expr>`。
- ❌ `await` 未实现：`async def` 可声明（生成 `async fn`），但函数体内 `await` 不解析；`gather` 亦未实现。
- ❌ 仅 Rust 单后端，示例中的 Cython/Python 线程安全描述暂不支持。
