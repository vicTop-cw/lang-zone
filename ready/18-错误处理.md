# 错误处理

## 1. 异常定义

异常用 `enum` 定义：

```
enum MyError =
    NotFound(str)
    PermissionDenied(str)
    InvalidInput(str)
```

## 2. 抛出 `raise`

`raise` **已实现**：`raise expr` 转译为 Rust `return Err(expr)`，用于在 `raises` 声明的函数内抛出异常值。`raises` 修饰符将函数返回类型自动包装为 `Result<T, E>`。

```
def might_fail(x: int)-> int raises MyError =
    if x < 0:
        raise MyError.NotFound("x < 0")
    100 / x
```

- 函数体内有 `raise` 就必须写 `raises`
- `raises` 后跟异常类型（必须是 enum）

> 注：返回类型已统一为 `->`（函数类型也用 `->`）。

## 3. 捕获 `try`/`catch`

`try`/`catch`/`else`/`finally` **已实现**，转译为 Rust `match` 表达式（详见 [10-控制流.md](10-控制流.md) §7）：

```
def safe_call(x: int) -> Result<int, MyError> =
    try:
        result = might_fail(x)
    catch MyError.NotFound(msg):
        print(f"Not found: {msg}")
        Err(MyError.NotFound(msg))
    catch e:
        panic(f"Unexpected: {e}")
    else:
        // 没有异常时才执行
        print(f"Success: {result}")
        Ok(result)
    finally:
        cleanup()
```

## 4. 块语义

与 Python 一致：

| 块 | 执行时机 |
|------|------|
| `try` | 始终先执行 |
| `catch` | 匹配到异常时执行 |
| `else` | `try` 无异常时执行（在 `finally` 之前） |
| `finally` | 始终最后执行（无论是否异常） |

## 5. Result 与 `?` 错误传播

除了 `try/catch`，Lang-Zong 也支持 `Result` 类型的错误传播：

```
def read_config(path: str) -> Result<Config, IOError> =
    content = open(path)?           // 出错则提前返回 Err
    parse(content)?

def parse(s: str) -> Result<Config, ParseError> =
    ...
```

`?` 后缀表示：若左侧是 `Err`，则提前返回该 `Err`；若是 `Ok`，则解包继续。

## 6. Option 与错误

`Option` 用于可能缺失的值，`Result` 用于可能失败的操作：

```
// Option — 可能没有值
def find_user(id: int) -> User? =
    if id == 0:
        return None
    User(id)

// Result — 可能失败
def read_file(path: str) -> Result<str, IOError> =
    ...
```

## 7. panic

`panic(msg)` **已实现**，转译为 Rust `panic!("{}", msg)`，立即终止程序。用于不可恢复错误：

```
def get(arr: List<int>, i: int)-> int =
    if i >= arr.len():
        panic("index out of bounds")
    arr[i]
```

对比 `Result<T, E>`（可恢复）与 `panic`（不可恢复）：

| 场景 | 推荐机制 |
|------|---------|
| 调用方需处理失败 | `Result<T, E>` + `?` 传播 |
| 程序必须终止 | `panic(msg)` → `Never` 类型 |

## 8. 与目标语言的衔接

| 语法 | Rust | 状态 |
|------|------|------|
| `panic(msg)` | `panic!("{}", msg)` | ✅ 已实现 |
| `try/catch` | `match (|| { body })() { Err(e) => ..., Ok(v) => ... }` | ✅ 已实现 |
| `Result<T, E>` + `?` | 直接转译为 Rust `Result<T, E>` + `?` | ✅ 已实现 |
| `raise` / `raises` | 无对应（用 `Result` + `?`） | ❌ 未实现 |

> 注：Lang-Zong 仅 Rust 后端。Cython 对照已在早期版本中移除。

## 9. 已移除的特性

| 特性 | 状态 | 说明 |
|------|------|------|
| `event` 事件系统 | ❌ 移除 | 用 `Chan` + `spawn` 替代 |
| 自定义异常继承 | ❌ 移除 | 异常用 `enum` 定义 |

## 10. Never 与 never 不可恢复错误函数

对于**不可恢复**的错误（程序应当直接终止，而非返回 `Result`），Lang-Zong 提供底部类型 `Never` 与内置原语 `panic`：

```lz
# 不可恢复错误助手：调用即终止程序，返回类型 Never（永不返回）
def never(msg: str)-> Never =
    panic(msg)
```

> 书写规范：返回类型用 `->` 标注（函数类型 `(T) -> U` 同样用 `->`），字符串类型为小写 `str`。即规范写法为 `def never(msg: str) -> Never = panic(msg)`，而非 `def never(msg:String) -> Never = ...`（仅需 `String` → `str`）。

### 10.1 语义

- `Never` 是底部类型，没有合法值；标注为 `Never` 的表达式表示「永不返回」。
- `panic(msg)` 立即终止程序（转译为 Rust `panic!("{}", msg)`），其「返回类型」即 `Never`。
- 由于 `Never` 是所有类型的子类型，`never(...)` 可出现在任何类型期望的位置（如 `guard ... else: never(...)`），无需额外处理。

### 10.2 与可恢复错误的分工

```lz
# 可恢复：返回 Result，调用方决定如何处理
def read_file(path: str)-> Result<str, IOError> =
    ...

# 不可恢复：一旦触发立即终止
def assert_nonempty(xs: List<int>) =
    guard len(xs) > 0 else: never("xs must not be empty")
    xs
```

| 场景 | 推荐机制 | 返回类型 |
|------|---------|---------|
| 调用方需处理失败 | `Result<T, E>` + `?` 传播 | `Result<T, E>` |
| 调用方需处理缺失 | `Option<T>` + `??` / `guard let` | `Option<T>` |
| 程序必须终止 | `never(msg)` / `panic(msg)` | `Never` |

### 10.3 实现状态

- `panic(msg)` → ✅ **已实现**（token/parser/codegen 全路径完成，转译 `panic!("{}", msg)`）
- `Never` → ✅ **已实现**：`type_system.rs` 中 `Type::Never => "!"` 映射完成，桥接层 `resolve_type("Never")` 返回 `Some("!")`。`never()` 函数可正常编译使用，codegen 将 `Never` 类型转译为 Rust `!`。

## 语法边界

- ✅ 可恢复错误用 `Result<T, E>` + `?` 传播 / `guard let` 解构 / `match` 分支处理（已实现推荐路径）。
- ✅ 缺失值用 `Option<T>` + `??` / `guard let`（已实现）。
- ✅ `try`/`catch`/`finally` 已实现为表达式：转译为 Rust `match` 表达式，`catch` 分支按序匹配异常类型（见 [10-控制流.md](10-控制流.md) §7）。
- ✅ `raise`/`raises` 已实现：`raise expr` 转译为 `return Err(expr)`，`raises E` 将返回类型包装为 `Result<T, E>`。
- ✅ `panic(msg)` 已实现：转译为 Rust `panic!("{}", msg)`，用于不可恢复错误。
- ✅ `Never` 已实现：`type_system.rs` 中映射为 `!`，桥接层 `resolve_type("Never")` 返回 `Some("!")`。
