# 字面量

## 1. 数字字面量

```
42              // int
0xFF            // 十六进制
0o17            // 八进制
0b1010          // 二进制
1_000_000       // 下划线分组

3.14            // f64
1.0e-3          // 科学计数法
6.022e23
```

## 2. 布尔与空值

```
True
False
None
```

`True` / `False` / `None` 是关键字，首字母大写。

## 3. 列表字面量

```
[1, 2, 3]
[1, 2, 3,]          // 尾部逗号允许
[]                  // 空列表
[[1, 2], [3, 4]]    // 嵌套

// 列表推导式
[x * x for x in 0..10]
[x for x in 0..10 if x % 2 == 0]
```

## 4. 元组字面量

```
(1, "hi", True)     // 多元素元组
(1,)                // 单元素元组（必须有逗号）
()                  // 空元组
```

## 5. 字典字面量

字典用 `{"key": value}` 形式（花括号 + `:` 分隔键值），与集合 `{a, b}` 区分：

```
{}                      // 空字典
{"a": 1}                // 单键值对
{"a": 1, "b": 2}        // 多键值对

// 字典推导式
{x: x * x for x in 0..5}
```

类型标注：

```
d: Dict<str, int> = {"a": 1, "b": 2}
```

> 注意：`{}` 是**空字典**（不是空集合）；空集合字面量不存在，集合至少需要写一个元素（见 §6、§7）。

## 6. 集合字面量

`{` 开头且包含逗号分隔的元素为集合（与字典靠 `key: value` 形式区分）：

```
{1, 2, 3}               // 非空集合

// 集合推导式
{x % 3 for x in 0..10}
```

> ⚠️ 没有空集合字面量：`{}` 已被字典占用，表示空字典。需要空集合请至少写一个占位元素（如 `{0}`），或待标准库提供 `Set<int>()` 等构造。

## 7. 区分规则

| 形式 | 内容 | 结果 |
|------|------|------|
| `{}` | 直接闭合 | 空字典 |
| `{"k": v, ...}` | 键值对 | 字典 |
| `{e1, e2, ...}` | 逗号分隔元素 | 集合 |
| `{e for ...}` | 推导式 | 集合推导式 |
| `{"k": v for ...}` | 键值推导 | 字典推导式 |

> 关键点：`{}` 永远解析为空字典；集合至少需要一个元素。靠是否含 `key: value` 区分字典与集合。

## 8. Atom 字面量

> ⚠️ 未实现（规划中）：当前编译器不解析/不生成此语法，示例暂无法通过 lzc 编译。以 `:` 前缀表示 atom 的设计（如 `:inc`）当前不可用——`{` 后接 `:` 会被解析为字典起始而非 atom，从而解析错误。

以 `:` 前缀表示，是编译期确定的唯一标识符，本质是 `u64` 哈希（规划特性）：

```
:inc
:dec
:ok
:error
```

用途（规划）：

```
match msg:
    case :inc:
        counter += 1
    case :dec:
        counter -= 1
```

## 9. 不再支持的字面量

| 形式 | 状态 | 替代方案 |
|------|------|---------|
| `#2024-01-15#` 日期字面量 | ❌ 移除 | 用标准库 `Date.from("2024-01-15")` |
| `#\| ...` 多行字符串 | ❌ 移除 | 用三引号 `"""..."""` |
| `$\| ...` | ❌ 移除 | 用 `f"""..."""` |
| `&\| ...` | ❌ 移除 | 用 `r"""..."""` |

## 10. Never 类型（底部类型 / 字面量关键字）

`Never` 是**底部类型（bottom type）**：它是所有类型的子类型，且**没有合法的值**。任何被标注为 `Never` 的表达式都表示「永不返回」——例如不可恢复的错误、无限循环、或 `panic`。

在类型系统中，`Never` 等价于 Rust 的 `!` 类型，转译时直接映射为 `!`。

> 命名与书写约定：本项目函数返回类型统一用 `->` 标注（与函数类型 `(T) -> U` 一致），字符串类型为小写 `str`（非 `String`）。因此 `never` 的规范签名是：
> `def never(msg: str) -> Never = panic(msg)`
> 你草稿中的 `def never(msg:String) -> Never = ...` 只需将 `String` → `str`；返回类型已用 `->`，无需改动。

### 10.1 典型用途：不可恢复错误函数

```lz
# 不可恢复错误助手：调用即终止程序，返回类型 Never（永不返回）
def never(msg: str)-> Never =
    panic(msg)
```

- 返回类型用 **`-> Never`**（与所有函数一致，使用 `->` 而非 `:`）。
- `panic` 是内置的不可恢复错误原语，转译为 Rust `panic!("{}", msg)`。
- 因为 `Never` 是所有类型的子类型，`never(...)` 可出现在任何类型期望的上下文中（如同 Rust 的 `panic!`），而不会破坏类型检查：

```lz
def unwrap_or_die(opt: int?)-> int =
    guard let Some(v) = opt else: never("expected Some, got None")
    v
```

### 10.2 与 Option / Result 的对比

| 机制 | 用途 | 返回类型 |
|------|------|---------|
| `Option<T>` / `Result<T, E>` | 可恢复、可传播的失败 | `Option<T>` / `Result<T, E>` |
| `never(msg)` / `panic(msg)` | 不可恢复、立即终止 | `Never` |

### 10.3 实现状态

- `panic(msg)` → ✅ **已实现**：token/parser/codegen 全路径完成，转译为 Rust `panic!("{}", msg)`（见 [18-错误处理.md](18-错误处理.md) §7）。
- `Never` 类型 → ✅ **已实现**：`type_system.rs` 中 `Type::Never => "!"` 映射完成，桥接层 `resolve_type("Never")` 返回 `Some("!")`（见 [18-错误处理.md](18-错误处理.md) §10.3）。
- `never(msg) -> Never` 辅助函数 → 依赖上述两项，均可正常编译使用。

## 语法边界

- ❌ 空 `{}` 是**空字典**，不是空集合；集合至少需要一个元素（如 `{1, 2, 3}`）。**没有空集合字面量**。
- ✅ 字典必须写成 `{"k": v}`（`key` 与 `value` 用 `:` 分隔）；集合写成 `{a, b}`（逗号分隔元素）。靠是否含 `key: value` 区分二者。
- ❌ 旧写法 `{:}`、`{:k: v}`、`{:str:int}` 已移除；类型标注请用 `Dict<K, V>`。
- ❌ 三引号字符串 `"""..."""` 内部不能出现未转义的 `"""`，否则会提前闭合。
- ✅ `()` `[]` `{}` 必须成对配对；缺失任一侧会解析错误。
- ❌ `:atom`（如 `:inc`）当前未实现：`{` 后接 `:` 会被解析为字典起始而非 atom，会解析错误。
- ✅ 数字字面量支持下划线分组（`1_000`）、十六/八/二进制前缀（`0xFF`/`0o17`/`0b1010`）；浮点无 `f` 后缀。
