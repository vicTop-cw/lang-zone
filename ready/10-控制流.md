# 控制流

## 1. if / elif / else

- 块形式：关键字后换行，块体统一缩进 4 空格（详见 [03-缩进规则.md](03-缩进规则.md)）。
- if 表达式（可作为值）：`if` / `elif` / `else` **各自分行书写、同级对齐**；每个分支体可在该分支冒号后同行给出（如 `if COND: A`），但**不可**把 `if` 与 `else` 合并到同一行。
- **冒号留白与缩进规则**：控制流关键字（`if` / `elif` / `else` / `for` / `while` / `loop` / `with` / `match` / `guard` / `defer` / `try` / `catch` / `finally`）后的 `:` 之后必须保留一个空白字符（空格）再写体，且整个控制流构造须按块缩进、多分支分行。**不支持**单行三元写法 `if cond: a else: b`（`if` 与 `else` 不能同行）。

```
if x > 0:
    "positive"
elif x == 0:
    "zero"
else:
    "negative"

# if 表达式作为值：if 与 else 必须分行，不能写成单行三元
def sign(x: int)-> str =
    if x > 0: "positive"
    else: "negative"
```

## 2. match

```
def describe(x: int)-> str =
    match x:
        case 0 => "zero"
        case 1 => "one"
        case _ => "many"

# 解构
match opt:
    case Some(v) => print(f"got {v}")
    case None => print("nothing")

match result:
    case Ok(v) => v
    case Err(e) => panic(e)            # 立即终止并报错

# 守卫
match point:
    case Point(x, y) if x == y => "diagonal"
    case Point(x, y) => "not diagonal"
```

> `panic(msg)` 已实现，转译为 Rust `panic!("{}", msg)`，立即终止程序。用于不可恢复错误（见 [18-错误处理.md](18-错误处理.md) §7）。

## 5. guard（提前返回语法糖）

```
def safe_divide(a: int, b: int)-> Option<int> =
    guard b != 0 else: None        # ← 不写 return，直接写值
    Some(a / b)

# 转译为:
# if b == 0 { return None; }
# Some(a / b)
```

`guard` 是纯语法糖。`guard cond else: expr` 等价于 `if !cond: return expr`。
**注意：else 后面直接写表达式值，不要写 `return`。**

```lz
# ✅ 正确
def first(items: List<int>)-> int? =
    guard len(items) > 0 else: None
    Some(items[0])

# ✅ 也支持缩进块
def validate(x: int, y: int)-> Option<int> =
    guard x >= 0 else:
        None
    guard y >= 0 else:
        None
    Some(x + y)
```

### 5.1 guard let（模式守卫 / 提前返回）

`guard let PATTERN = EXPR else: VALUE` 在 `EXPR` 不匹配 `PATTERN` 时提前返回 `VALUE`。
常用于从 `Option`/`Result` 中解构取值：

```
def describe(opt: int?)-> str =
    guard let Some(v) = opt else: "none"     # opt 为 None 时直接返回 "none"
    if v > 0: "positive"
    else: "non-positive"

def greet(p: Person?)-> str =
    guard let Some(pp) = p else: "no person"
    guard let Some(t) = pp.tag else: f"hi {pp.name}"
    f"hi {pp.name} (tag {t})"
```

转译为 Rust 的 `let...else` 语法：

```rust
fn describe(opt: Option<i64>) -> String {
    let Some(v) = opt else { return "none".to_string(); };
    if (v > 0) { "positive".to_string() } else { "non-positive".to_string() }
}
```

**规则：**
- `else:` 后写**表达式值**（可缩进块），不写 `return`；转译层自动包成 `return VALUE;`
- `PATTERN` 必须是可反驳模式（如 `Some(x)`、`Ok(v)`），不可是裸变量

## 6. return / yield / defer

### 6.1 return

```
def find(nums: List<int>, target: int)-> Option<int> =
    for i, n in enumerate(nums):
        guard n == target else: continue
        return Some(i)
    None
```

### 6.2 yield（生成器内）

```
def count_up_to(n: int) =
    for i in 1..=n:
        yield i
```

`yield` 只能在构建块（`*:` 生成器）内使用，详见 [构建块.md](构建块.md)。

### 6.3 defer（延迟执行）

```
def read_file(path: str)-> str =
    f = File::open(path)
    defer: f.close()            # 作用域退出时自动关闭文件
    f.read()

# 多个 defer → LIFO 顺序执行
def transfer(src: str, dst: str) =
    src_f = File::open(src)
    defer: src_f.close()

    dst_f = File::create(dst)
    defer: dst_f.close()         # 后进先出：dst_f 先关，src_f 后关

    dst_f.write(src_f.read())
```

`defer:` 将一段代码推迟到当前作用域退出前执行。

**规则：**
- 作用域包括函数体、`if`/`for`/`match` 等控制流块
- 多个 `defer` 按 **LIFO（后进先出）** 顺序执行
- 无论正常结束、`return`、`break`/`continue` 还是 `guard` 提前返回，defer 始终保证执行
- 转译为 Rust 的 `struct DeferGuard { FnOnce }` + `Drop`，零额外运行时开销

详见 [21-defer.md](21-defer.md)（完整设计方案）。

## 7. try / catch / finally

> `try`/`catch`/`finally` 已实现。转译为 Rust `match` 表达式：成功走 `Ok(v) => else_body_or_v`，捕捉到异常走对应 `catch` 分支。当前实现解析/代码生成**全路径覆盖**，但 codegen 对 `finally` 块的 `__exit__` 映射为待完善（仅生成空骨架）。推荐优先使用 `Result<T,E>` + `?` 处理可恢复错误（见 [18-错误处理.md](18-错误处理.md)），`try/catch` 适合必须捕获特定异常的场合。

```
try:
    result = fallible_operation()
    result
catch e: IOError:
    print(f"I/O error: {e}")
    default_value
catch e: ParseError:
    print(f"Parse error: {e}")
    fallback
finally:
    cleanup()                 # 无论成功与否都执行
```

转译效果：

```rust
// try { body } catch e: Pat => hanlder catch _ => fallback finally { cleanup }
match (|| -> Result<_, _> { Ok(body) })() {
    Err(e) => { /* 匹配对应 catch 分支 */ }
    Ok(v) => v  // 若无 else_body 则返回 v
}
```

**规则：**
- `try` 块体为表达式，最后一条为 try 块的产出值
- `catch e: Pattern:` 按顺序匹配异常类型（`case _ =>` 兜底）
- `finally:` 块体无论成功/异常均执行
- 推荐使用 `Result<T,E>` + `?` 做轻量级错误传播，仅复杂场景用 `try/catch`

## 9. 与 Rust 对照

| Lang-Zong | Rust |
|-----------|------|
| `if x > 0: a`<br>`else: b`（if 与 else 分行） | `if x > 0 { a } else { b }` |
| `match x: case 0 => ...` | `match x { 0 => ... }` |
| `for i in 0..10:` | `for i in 0..10 { }` |
| `while x > 0:` | `while x > 0 { }` |
| `loop:` | `loop { }` |
| `guard cond else: expr` | `if !cond { return expr; }` |
| `guard let PATTERN = EXPR else: expr` | `let PATTERN = EXPR else { return expr; }` |
| `defer: expr` | `{ let _guard = DeferGuard(|| { expr }); }`（Drop） |
| `try: body catch e: Pat: h finally: f` | `match (|| { body })() { Err(e) => h, Ok(v) => v }; f;` |
| `yield expr` | `__bb.push(pack(expr))`（构建块内） |

## 语法边界

- ✅ `match` 默认分支用 `case _ =>`。
  ❌ `match` 用 `else:`（match 无 else 语法）。
- ✅ 条件链顺序固定：`if` → `elif`* → `else`?。
  ❌ `elif` 出现在 `if` 之前，或 `else` 出现在 `elif` 之前。
- ✅ `guard ... else:` 的 `else:` 不可省略，其后写表达式值（非 `return`）。
  ❌ `guard cond:`（缺少 `else:`）/`guard cond else return x`。
- ✅ 复合语句（`if`/`for`/`while`/`loop`/`with`/`match`/`case`）块体须缩进 4 空格；控制流关键字后的 `:` 之后必须留白（一个空格），`match` 分支 `case PATTERN =>` 可单行（`case 0 => "zero"`，无需缩进）也可换行（`case Some(v) =>` 后缩进体）。
  ❌ 块体不缩进，或省略 `:`。
- ✅ if 表达式的 `if` / `elif` / `else` **分行书写、同级对齐**（分支体可在各自冒号后同行给出）。
  ❌ 单行三元 `if cond: a else: b`（`if` 与 `else` 同行）——不支持。
- ✅ `try`/`catch`/`finally` 已实现为表达式，`catch` 分支按序匹配异常类型、`finally` 块确保清理。
- ✅ `panic(msg)` 已实现，转译为 Rust `panic!("{}", msg)`，用于不可恢复错误。
  ❌ `raise` 未实现——使用 `panic` 或 `Err(x)` + `?`。
