# 变量与绑定

## 1. 基本变量（默认可变 + 拷贝优先）

```
x = 1                        // 类型推断，默认可变（let mut），值默认拷贝
y: int = 2                   // 显式类型，默认可变
mut z = 3                    // mut 为 no-op 兼容（默认已可变）
const PI = 3.14159           // 编译期常量（仍不可变）
```

**Lang-Zong 默认绑定可变更、值语义优先拷贝。** 这与 Rust 相反：

- **Rust**：默认不可变（`let`），移动优先（非 Copy 类型赋值即 move）。
- **Lang-Zong**：**默认可变**（`mut` 关键字冗余但保留为兼容 no-op），**默认拷贝**（赋值/传参自动 `.clone()`）。

## 2. 引用

```
x = 42
ref r = &x                   // 不可变引用（&T）
mut ref m = &mut x           // 可变引用（&mut T）

*m = 99                      // 通过可变引用修改
print(r)                     // 99（r 看到修改）
```

## 3. 堆分配与指针

> ⚠️ 未实现（规划中）：当前编译器不解析/不生成此语法，示例暂无法通过 lzc 编译。Lang-Zong 当前没有 `alloc` / `free` / `ptr` 指针语法（无对应 token，亦无代码生成），以下仅为设计意图。

```
# 分配 n 个 T 的连续内存（规划）
ptr = alloc(int, 100)        # 分配 100 个 int → *mut int（规划）
ptr[0] = 42                  # 下标赋值
ptr[5] = 99
val = ptr[3]                 # 读取

# 指针运算（规划）
p2 = ptr + 5                 # 偏移 5 个元素
*p2 = 99                     # 等同于 ptr[5] = 99

# 切片（规划）
slice = ptr[0..10]           # 前 10 个元素的视图

# 释放（规划）
free(ptr)                    # 手动释放内存
```

**统一语法（规划）：** `alloc(T, n)` / `free(ptr)` / `ptr[i]`。对标 Rust `Box` / `Vec` 底层。

## 4. 所有权模型（copy-by-default + 显式 ^ move）

### 4.1 默认拷贝

```
a = [1, 2, 3]
b = a                        // 默认拷贝：a 仍可继续使用
print(a)                     // OK，a 未被移动
```

非 Copy 类型（如自定义 struct）赋值时自动 `.clone()`，源值保留可用。所有用户
`struct` / `enum` 在转译时自动 `#[derive(Clone)]`。

### 4.2 显式转移所有权：后缀 `^`

需要真正移动（交出所有权）时，用后缀 `^`：

```
b = a^                       // 显式 move，a 此后不可再用
// print(a)                 // rustc 报错：borrow of moved value
```

`^` 在代码生成中直出 Rust move（`let b = a;`），**use-after-move 由 rustc 自动检查**
（编译器本身不做额外的借用分析）。

### 4.3 中缀 `^` = 按位异或（XOR）

`^` 同时是位运算符（XOR），靠**位置**消歧：

- 后缀 `a^` → 转移所有权（move）；**必须紧贴操作数，中间不能有空格。**
- 中缀 `a ^ b` → 按位异或（XOR）。

> ⚠️ 空格改变语义：后缀 move 必须写成 `b = a^`（无空格）；若写成 `b = a ^ c`（有空格），则 `^` 被解析为**中缀按位异或 XOR**，不再是 move，`a` 不会被转移所有权。

```
x = 5 ^ 3                    // 6（XOR，中缀）
y = (someBig)^              // move（注意 ^ 后无操作数，紧贴）
b = a^                      // ✅ 显式 move：a 此后不可用
b = a ^ c                   // ❌ 这是 XOR，不是 move
```

解析器在 `^` 后窥看下一个 token：若它是表达式起始 token（`(`、`[`、`{`、字面量、
标识符、一元前缀 `-`/`!`/`not` 等）则视为中缀 XOR；否则视为后缀 move。

### 4.4 `owned` 形参 + `^` 调用契约

函数可用 `owned` 修饰形参，声明"我要取得该参数的所有权"；调用方**必须**用 `^` 显式转移：

```
def consume(owned p: Person)-> str =
    f"owned: {p.name}"

bob = Person(name: "Bob", tag: None)
consume(bob^)                // OK：显式 move
consume(bob)                 // 编译错误：[lang-zong] 函数 `owned` 形参必须以 ^ 显式转移所有权
```

普通（非 `owned`）形参默认按值**拷贝**传入，调用方无需 `^`。方法 `self` 仍默认借用
（`&self`），除非显式 `mut self` / `owned self`。

## 5. 变量遮蔽

```
x = 1
x = x + 1                    // 遮蔽，新变量 x=2
```

内层作用域可以遮蔽外层变量。

## 6. 与 Rust 对照

| Lang-Zong | Rust |
|-----------|------|
| `x = 1`（默认可变+拷贝） | `let mut x = 1;` |
| `mut x = 1`（no-op 兼容） | `let mut x = 1;` |
| `b = a`（默认拷贝） | `let b = a.clone();` |
| `b = a^`（显式 move） | `let b = a;` |
| `ref r = &x` | `let r = &x;` |
| `mut ref r = &mut x` | `let r = &mut x;` |
| `def f(owned p: T)` + `f(x^)` | `fn f(p: T)` + `f(x)` |
| `5 ^ 3`（XOR） | `5 ^ 3` |
| `const PI = 3.14` | `const PI: f64 = 3.14;` |

## 语法边界

- ⚠️ 必须留意 `^` 的空格：`b = a^`（无空格）是**显式 move**；`b = a ^ c`（有空格）是**按位异或 XOR**——空格改变语义，move 必须紧贴。
- ✅ 默认 **copy-by-default**：赋值/传参对非字面量自动 `.clone()`，`b = a` 后 `a` 仍可继续使用；需真正转移所有权时用 `^`。
- ✅ `mut` 为兼容 no-op：Lang-Zong 默认绑定即可变，`mut x = ...` 与 `x = ...` 行为一致。
- ✅ `const` 绑定不可变（编译期常量）；`ref r = &x` 取不可变引用，`mut ref r = &mut x` 取可变引用。
- ❌ 指针语法 `alloc` / `free` / `ptr[i]` / `ptr + n` 当前未实现，不能使用。
- ✅ 以 `:` 或 `=` 开启的复合语句（如 `if`/`for`/`while`/`loop`/`with`/`guard ... else:`）换行写多行体必须整体缩进（4 空格），未缩进会解析错误。
