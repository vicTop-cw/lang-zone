# 文件与模块结构

## 1. 文件后缀

Lang-Zong 源码文件后缀为 `.lz`。

## 2. `#!bin` 文件指令

> ⚠️ 未实现（规划中）：当前编译器不处理 `#!bin` 指令，源码固定转译为 Rust，示例暂无法通过 lzc 编译。

`#!bin` 必须出现在文件**第一行**（允许前面有空白/注释），一份文件**只能有一条** `#!bin`，否则编译错误。

### 2.1 指定目标转译语言

```
#!bin rust
```

含义：本文件转译为 Rust 源码。

### 2.2 声明宏模块

```
#!bin macro default
```

含义：本文件是宏模块，目标语言使用默认（即 `__toml__.lz` 或全局默认）。

```
#!bin macro python
```

含义：本文件是宏模块，目标语言为 Python。

> ⚠️ 未实现（规划中）：当前仅 Rust 单后端，示例中的 Python 目标暂不支持。

### 2.3 省略 `#!bin`

不写 `#!bin` 表示：

- 本文件是普通源码模块（非宏模块）
- 目标语言由 `__toml__.lz` 指定，若也未指定则使用全局默认 **Cython**

> ⚠️ 未实现（规划中）：当前仅 Rust 单后端，示例中的 Cython 默认目标暂不支持；目标语言固定为 Rust。

## 3. `__toml__.lz` 配置文件

> ⚠️ 未实现（规划中）：当前编译器不读取 `__toml__.lz` 配置文件，目标语言固定为 Rust，示例暂无法通过 lzc 编译。

每个项目根目录可以放置一个 `__toml__.lz`，作为项目级配置。语法为 TOML 子集。

```
[bin]
default = "cython"      // 项目默认目标语言
edition = "2024"        // 目标语言 edition

[dependencies]
numpy = "1.24"
requests = ">=2.28, <3.0"
```

| 节 | 说明 |
|----|------|
| `[bin]` | 项目级转译配置 |
| `[bin].default` | 默认目标语言，可选值：`cython` / `rust` / `python` / `nim` |
| `[dependencies]` | 外部依赖（传递给目标语言的包管理器） |

## 4. 包目录结构

与 Python 一致：包含 `__init__.lz` 的目录即为一个包。

```
myapp/
  __init__.lz              // 标记 myapp 为包
  main.lz
  utils/
    __init__.lz
    math.lz
    strings.lz
  models/
    __init__.lz
    user.lz
```

## 5. 模块与目标语言的衔接

> ⚠️ 未实现（规划中）：当前仅 Rust 单后端，示例中的 Cython/Python 目标层级暂不支持；`.lz` 固定转译为 `.rs`。

Lang-Zong 编译器扫描 `__init__.lz` 确定包结构，转译时生成目标语言的模块层级：

```
Lang-Zong                          Cython（默认）
───────                            ───────────
myapp/                             myapp/
  __init__.lz           →           __init__.pyx
  main.lz               →           main.pyx
  utils/
    __init__.lz         →           utils/__init__.pyx
    math.lz             →           utils/math.pyx
```

若目标语言为 Rust：

```
Lang-Zong                          Rust
───────                            ────
myapp/                             myapp/
  __init__.lz           →           mod.rs
  main.lz               →           main.rs
  utils/math.lz         →           utils/math.rs
```

## 6. 宏模块的引用

> ⚠️ 未实现（规划中）：当前编译器不解析宏模块与 `!` 标记（含 `@mymacros.derive!` 装饰器），示例暂无法通过 lzc 编译。

宏模块以 `#!bin macro` 声明，其它文件通过 `import` 引入后即可使用其中的 `!` 标记：

```
import mymacros                   // mymacros 是宏模块

@mymacros.derive!                  // 使用宏模块中的宏
struct Point =
    x : f64
    y : f64
```

详见 [14-宏与转译期.md](14-宏与转译期.md)。

## 语法边界

- ✅ 源码文件后缀固定为 `.lz`（如 `main.lz`、`__init__.lz`），编译器按此后缀识别模块。
- ✅ 当前仅 Rust 单后端，所有 `.lz` 固定转译为 `.rs` 后由 `rustc` 编译；目录含 `__init__.lz` 即视为包。
- ❌ `#!bin` 指令未实现：编译器不读取该指令，目标语言固定为 Rust，写入不会切换后端。
- ❌ `__toml__.lz` 配置文件未实现：项目级目标语言/依赖配置不生效，目标固定为 Rust。
- ❌ 宏模块（`#!bin macro` 及 `!` 标记、如 `@mymacros.derive!` 装饰器）未实现：当前编译器不解析宏模块，相关示例无法通过 lzc 编译。
- ❌ 多后端目标（Cython/Python/Nim）未实现：示例中的非 Rust 目标层级暂不支持。
