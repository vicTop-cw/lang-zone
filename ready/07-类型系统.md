# 类型系统

## 1. 基本类型

```
x: int = 42              # 整数（对标 Rust i64）
y: f64 = 3.14159         # 浮点（对标 Rust f64）
name: str = "Lang-Zong"  # 字符串
flag: bool = True         # 布尔
data: bytes = b"hello"    # ⚠️ 未实现：无 bytes 类型，无 b"..." 字节串（规划）
nothing: None = None      # 空类型
never_t: Never            # 底部类型：永不返回（见 05-字面量.md §10 / 18-错误处理.md §10）
```

> ⚠️ 未实现（规划中）：当前编译器不解析/不生成此语法，示例暂无法通过 lzc 编译。Lang-Zong 没有 `bytes` 类型，也没有 `b"..."` 字节串字面量（`data: bytes` 与 `b"hello"` 均不可用）。需要字节数据请用 `List<u8>` 或 `str` 等替代。

`Never` 是底部类型（无合法值，等价于 Rust `!`），常用于不可恢复错误函数（如 `never(msg) -> Never`）的返回类型。

## 2. 容器类型

```
nums: List<int> = [1, 2, 3]
point: (int, str) = (42, "hi")
scores: Dict<str, int> = {"Alice": 95, "Bob": 87}
ids: Set<int> = {1, 2, 3}

# 空容器
empty_list: List<int> = []
empty_dict: Dict<str, int> = {}   # ⚠️ 空字典用 {}；{:} 已不再支持
# empty_set: Set<int> = {}        # ❌ 没有空集合字面量：{} 是空字典，不是空集合
```

**字面量区分：** `{}` = 空字典；集合至少需要一个显式元素（如 `{1, 2, 3}`），**没有空集合字面量**。字典写作 `{"k": v}`，集合写作 `{a, b}`。

> ⚠️ 注意：`{:}` 与 `{:k: v}` 等旧字典写法已移除；类型标注请用 `Dict<str, int>` 而非 `{:str:int}`。

## 3. Option 和 Result

```
# 定义
enum Option<T> =
    None
    Some(T)

enum Result<T, E> =
    Ok(T)
    Err(E)

# 使用
def find_user(id: int)-> Option<str> =
    if id == 0: None
    else: Some(f"User_{id}")

# 语法糖：T? ≡ Option<T>
x: int? = None           # 等于 x: Option<int> = None
name: str? = Some("Hi")  # 等于 name: Option<str> = Some("Hi")

def find(id: int)-> str? =       # 返回类型可简写为 str?
    if id == 0: None
    else: Some(f"User_{id}")

# 安全导航
name = user?.profile?.name
name = user?.profile?.name ?? "guest"
```

## 4. 类型注解位置

```
x: int = 1
def add(a: int, b: int)-> int = a + b
data: List<int> = [1, 2, 3]
```

## 5. 函数类型

```
# 函数作为参数/返回值
def apply<T, U>(f: (T) -> U, x: T)-> U = f(x)

# 闭包
|x| x * 2
|x, y| x + y
```

## 语法边界

- ❌ 没有 `bytes` 类型，也没有 `b"..."` 字节串字面量；需要字节数据请用 `List<u8>` 或 `str`。
- ✅ `{}` = 空字典；集合至少需要一个显式元素（如 `{1, 2, 3}`），**没有空集合字面量**。
- ✅ 字典写作 `{"k": v}`，集合写作 `{a, b}`；旧写法 `{:}` / `{:k: v}` / `{:str:int}` 已移除，类型标注用 `Dict<K, V>`。
- ✅ 返回类型用 `->`（如 `def f() -> int =`），**函数类型** `(T) -> U` 同样用 `->`；类型标注一律写在右侧 `x: T`。
- ✅ 容器映射：`List<T>`→`Vec`、`Dict<K,V>`→`HashMap`、`Set<T>`→`HashSet`、`Option<T>`→`Option`、`Result<T,E>`→`Result`；`T?` ≡ `Option<T>`。
- ❌ 没有 `[int]` 老写法、没有具名字段枚举变体、没有关联类型 `type Item`（均规划中）。
