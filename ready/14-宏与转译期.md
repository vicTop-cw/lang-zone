# 宏与转译期

Lang-Zong 的转译期辅助通过 **`!` 标记**统一表达，不再使用 `transtime` / `template` / `quote` 等关键字。

## 1. `!` 标记约定

> ⚠️ 未实现（规划中）：当前编译器不解析整套 `!` 标记/宏模块体系（含 `def name!`/`@name!`/`x!`），示例暂无法通过 lzc 编译。

**任何带 `!` 后缀的标识符都表示转译期辅助**，必须定义在宏模块中，使用前需导入宏包。

| 位置 | 形式 | 说明 |
|------|------|------|
| 函数名 | `def name!(...) = ...` | 转译期辅助函数，操作语法树 |
| 变量名 | `x! : T = ...` | 转译期变量，由宏包创建 |
| 装饰器 | `@name!` | 宏装饰器，编译期展开 |

```
// 必须先导入宏模块
import mymacros

@mymacros.derive!              // 宏装饰器
struct Point =
    x : f64
    y : f64

x! : int = 9                  // 转译期变量
```

## 2. 宏模块声明

使用 `#!bin macro` 声明宏模块（见 [02-文件与模块结构.md](02-文件与模块结构.md)）：

```
#!bin macro default
// 本文件是宏模块，目标语言使用默认

def derive!(ts: Tokens)-> Tokens =
    ...
```

```
#!bin macro python
// 本文件是宏模块，目标语言为 Python
```

## 3. `macro` 关键字

> ⚠️ 未实现（规划中）：当前编译器已识别 `macro` 关键字 token，但不解析/不生成此语法，示例暂无法通过 lzc 编译。

`macro` 声明宏，是操作语法树的特殊函数：

```
macro name(ts: Tokens)-> Tokens =
    // ts 是后续语句块的 Token 流
    // 返回修改后的 Token 流
    ...
```

- 参数必须是 `ts: Tokens`
- 返回值必须是 `Tokens`
- 签名固定，不可自定义

### 3.1 示例：自动打印调用

```
macro log_call(ts: Tokens)-> Tokens =
    return quote:
        print("Calling...")
        $(ts)
        print("Done.")

@log_call
def heavy_computation(x: int)-> int =
    x * x
```

## 4. `comptime` — 编译期求值

> ⚠️ 未实现（规划中）：当前编译器已识别 `comptime` 关键字 token，但不解析/不生成此语法，示例暂无法通过 lzc 编译。

`comptime` 产生一个编译期计算的值，可放在任何需要值的位置：

```
// 模块级
PI : const f64 = comptime: 3.141592653589793

// 函数内
def area(r: f64)-> f64 =
    table = comptime:
        t : mut [f64] = [0.0; 256]
        for i in 0..256:
            t[i] = (i as f64).sqrt()
        t
    table[r as usize] * r * PI

// 函数实参
def draw(scale: f64) =
    sprite.render(comptime: calc_scale())

// 单行
answer = comptime: 40 + 2
```

| 特性 | 说明 |
|------|------|
| 位置 | 任意位置（模块级、函数内、表达式内） |
| 产生值 | 是（编译期计算的值） |
| 可赋值 | 是 |
| 单行 | 支持 `comptime: expr` |

## 5. `@name` 装饰器与 `@name!` 宏装饰器

| 语法 | 含义 | 时机 |
|------|------|------|
| `@name` | 装饰器（函数调用） | 运行时 |
| `@name!` | 宏装饰器（编译期展开） | 转译期 |

### 5.1 普通装饰器

```
def log(f) =
    |x|:
        print("Calling...")
        result = f(x)
        print(f"Result: {result}")
        result

@log
def compute(x: int)-> int =
    x * x
// 等价于  compute = log(compute)
```

### 5.2 宏装饰器

```
@mymacros.derive!
struct Point =
    x : f64
    y : f64
// 编译期展开，自动生成 trait 实现
```

`@name!` 必须**独占一行**，`!` 紧贴装饰器名。

## 7. 已移除的特性

| 特性 | 状态 | 替代 |
|------|------|------|
| `transtime` | ❌ 移除 | 用 `#!bin` 指令 + 宏模块 |
| `template` | ❌ 移除 | 用 `macro` + `!` 标记 |
| `quote` 关键字 | ❌ 移除（作为通用机制） | 仅在 `macro` 体内使用 `quote:` 构建 Tokens |
| `lazy block #name` | ❌ 移除 | 用宏模块替代 |
| `transtime block` | ❌ 移除 | 用宏模块替代 |
| `untyped` 参数 | ❌ 移除 | 宏参数统一为 `Tokens` |

## 8. 宏模块的使用流程

```
1. 创建宏模块文件（#!bin macro）
2. 在宏模块中定义 macro / def name! / 可被引用的 ! 变量
3. 在普通源码中 import 宏模块
4. 使用 @name! / x! / def name! 等标记
```

### 8.1 示例

```
// === mymacros.lz ===
#!bin macro default

macro log_call(ts: Tokens)-> Tokens =
    return quote:
        print("Calling...")
        $(ts)
        print("Done.")

def derive!(ts: Tokens)-> Tokens =
    // 为 struct 自动生成 trait 实现
    ...

// === main.lz ===
import mymacros

@mymacros.log_call
def hello() =
    print("hi")
```

## 9. 三者对比

| | 装饰器 `@name` | 宏装饰器 `@name!` | `macro` |
|---|---|---|---|
| 时机 | 运行时 | 转译期 | 转译期 |
| 操作对象 | 函数值 | Token 流 | Token 流 |
| 关键字 | `def` | `def`（带 `!`） | `macro` |
| 签名 | 自由 | 自由 | `(ts: Tokens) -> Tokens` |
| 能力 | 包装函数 | 生成/修改代码 | 生成/修改代码 |

## 语法边界

- ✅ 函数返回类型用 `->` 书写：`def f(x: T) -> U = ...`；函数类型本身也使用 `->`，如 `(T) -> U`。
- ✅ `@name` 普通装饰器（运行时函数包装）语法形如 `@log` 紧贴 `def` 之前，目前仅靠运行时机制，不进入宏系统。
- ❌ 整套 `!` 标记/宏模块体系（`def name!`、`@name!`、`x!`、`#!bin macro`）未实现：编译器不解析，相关示例无法通过 lzc 编译。
- ❌ `macro` 关键字：编译器已识别其 token，但不解析/不生成 `macro ... =` 定义体。
- ❌ `comptime`：编译器已识别其 token，但不解析/不生成编译期求值块。
- ❌ `lazy`：编译器不解析 `lazy` 关键字（含 `lazy import`）。
- ❌ `quote:` 仅在 `macro` 体内作为 Token 构建手段，因 `macro` 整体未实现，亦不可用。
