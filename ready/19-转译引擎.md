# 转译引擎

## 1. 转译流程

```
source.lz → Lang-Zong 编译器 → target.rs → rustc → 二进制
```

Lang-Zong 将 `.lz` 转译为 Rust 源码，由 `rustc` 编译为二进制。

## 2. 目标语言

**唯一目标：Rust。**

## 3. 编译器架构

```
lang-zong/
├── src/
│   ├── token.rs        # 缩进敏感词法 + Token 定义
│   ├── parser.rs       # AST 生成（递归下降解析器）
│   ├── codegen.rs      # Rust 代码生成
│   ├── bridge.rs       # 桥接注册表：统一路由导入/类型/方法/别名
│   ├── bridge_core.rs  # 桥接核心：Bridge  trait 定义
│   ├── bridge_source.rs# SourceBridge：编译期源码级映射
│   ├── bridge_ffi.rs   # FfiBridge：C ABI 层（预留）
│   ├── bridge_cli.rs   # CliBridge：IPC 进程间通信（预留）
│   ├── mini_toml.rs    # 极简 TOML 解析器（零依赖，为桥接系统服务）
│   ├── type_system.rs  # 类型系统辅助（Never→! 映射等）
│   ├── magic_trait.rs  # 魔法方法→Rust trait 映射注册表
│   └── main.rs         # CLI: lzc hello.lz → hello.rs
├── std/
│   ├── bridge.toml     # 桥接入口配置
│   └── modules/        # 各模块映射表（fs.toml, io.toml 等）
├── ready/              # 语法文档
└── Cargo.toml
```

## 4. 转译示例

### 变量
```
// Lang-Zong
x: int = 42
mut y = 1

// Rust
let x: i64 = 42;
let mut y = 1;
```

### 函数
```
// Lang-Zong
def add(a: int, b: int)-> int =
    a + b

// Rust
fn add(a: i64, b: i64) -> i64 {
    a + b
}
```

### 泛型
```
// Lang-Zong
def first<T>(items: List<T>)-> T where T <: Clone =
    items[0].clone()

// Rust
fn first<T: Clone>(items: Vec<T>) -> T {
    items[0].clone()
}
```

### 结构体
```
// Lang-Zong
struct Point =
    x: f64
    y: f64

// Rust
struct Point {
    x: f64,
    y: f64,
}
```

### match
```
// Lang-Zong
match x:
    case 0 => "zero"
    case _ => "other"

// Rust
match x {
    0 => "zero",
    _ => "other",
}
```

### 管道
```
// Lang-Zong
nums |> filter(|x| x > 2) |> map(|x| x * 2)

// Rust
nums.into_iter().filter(|x| *x > 2).map(|x| x * 2).collect()
```

## 5. 类型映射

| Lang-Zong | Rust |
|-----------|------|
| `int` | `i64` |
| `f64` | `f64` |
| `str` | `String` / `&str` |
| `bool` | `bool` |
| `List<T>` | `Vec<T>` |
| `Dict<K,V>` | `HashMap<K,V>` |
| `Set<T>` | `HashSet<T>` |
| `Option<T>` | `Option<T>` |
| `Result<T,E>` | `Result<T,E>` |
| `(T) -> U` | `fn(T) -> U` |

## 6. 关键转译规则

> ⚠️ 未实现（规划中）：`List<T>` 末尾参数 `rest` 的自动收集（可变参数收集调用者多余实参）当前未实现，参数列表固定，示例暂无法通过 lzc 编译。

| Lang-Zong | Rust |
|-----------|------|
| `def f(x: T)-> U` | `fn f(x: T) -> U` |
| `=` 开启代码块 | `{` 开启代码块 |
| 缩进管理作用域 | `{}` 管理作用域 |
| 表达式体自动 return | 表达式体自动 return |
| `where T <: A + B` | `where T: A + B` |
| `guard cond else: expr` | `if !cond { return expr; }` |
| `List<T>` 末尾参数 `rest` 自动收集 | ❌ 未实现：当前参数固定，不收集调用者多余实参 |

## 语法边界

- ✅ 类型映射已对齐：`int`→`i64`、`f64`→`f64`、`str`→`String`/`&str`、`bool`→`bool`、`List<T>`→`Vec<T>`、`Dict<K,V>`→`HashMap<K,V>`、`Set<T>`→`HashSet<T>`、`Option<T>`→`Option<T>`、`Result<T,E>`→`Result<T,E>`、`(T) -> U`→`fn(T) -> U`。
- ✅ 代码生成规则：函数返回类型直接用 `->`（与 Rust 一致）、`=` 开启块→`{}`、缩进管理作用域、`where T <: A + B`→`where T: A + B`、`guard ... else:`→`if !cond { return expr; }`，均正确。
- ✅ 当前仅 Rust 单后端：`.lz` 固定转译为 `.rs` 后由 `rustc` 编译。
- ❌ 可变参数（`List<T>` 末尾 `rest` 自动收集）未实现，参数列表固定。
