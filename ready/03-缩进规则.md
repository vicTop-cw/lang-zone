# 缩进规则

## 1. 基本规则

- **4 空格** 为一个缩进层级；Tab 视作 4 个空格（lexer 将 `\t` 计为 4 列），但同一文件内不要混用 Tab 与空格，避免缩进层级错位
- 同一文件内缩进必须一致
- 缩进决定作用域，回退缩进即闭合块

## 2. 块开启符

以下符号/关键字后跟换行 + 缩进，开启一个缩进块：

| 块开启符 | 示例 | 说明 |
|---------|------|------|
| `:` | `if x > 0:` | 条件/循环/异常等控制流块 |
| `=` | `def hello() =` | 函数体、类型定义体 |
| `match x:` | — | match 块 |
| `case ... =>` | — | match 分支 |
| `=:` | `x =:` | 变量构建块（无参闭包，尾部表达式自动返回） |
| `~:` | `f ~:` | 调用构建块（构造参数包并应用） |
| `*:` | `f *:` | 生成器调用构建块（惰性产出多个参数包） |
| `guard let ... else:` | — | guard 块 |

> 构建块专用符号 `=:` / `~:` / `*:` 前后必须留白，符号后必须换行并缩进。完整规则见 [构建块.md](构建块.md)。

## 3. `=:` 变量构建块（Variable Build Block）

`=:` 后换行缩进，表示用一个**无参闭包**计算一个值并绑定到左侧变量（块内默认 `unsafe`，允许指针语法，作用域限定块内）。

### 3.1 基本形式

```
x =:
    let y = read_int()
    if y > 3:
        return 7          // 提前返回
    y                       // 块尾表达式作为构建值
```

- 块内可执行任意逻辑（变量赋值、条件判断、循环等）
- 块尾表达式自动作为返回值赋给左侧变量；也可用 `return <expr>` 显式提前返回
- 支持 `guard let ... else:` 守卫
- ❌ 块内不允许 `yield`（`yield` 仅允许在生成器构建块 `*: ` 中）

### 3.2 指针语法作用域

块内默认 `unsafe`，可使用指针 / `Box::into_raw` 等；指针语法作用域严格限定在块内，块外仍为安全代码：

```
v =:
    let p = &raw as *const i32
    *p
```

> 完整规则见 [构建块.md](构建块.md)。

## 4. `~:` / `*: ` 调用与生成器构建块

`~:` 调用构建块用于为（通常带泛型参数的）函数调用构造参数包并应用；`*: ` 生成器调用构建块逐步产出多个参数包（惰性迭代器）。

### 4.1 调用构建块 `~:`

```
sum ~:
    (1, 2, 3)              // 元组 → 位置实参
```

- 块体尾部表达式 / `return <params>` 作为**参数包**，须满足 BuildParams 约束（元组 / 字典 / 调用 / 标识符(BuildParams) / `KwArg` / `move` / `try`）
- 元组按被调函数参数个数位置解包，字典按参数名命名解包，其余整体作为单参数
- ❌ 块内不允许 `yield`

### 4.2 生成器调用构建块 `*: `

```
for r in process *:
    yield (1, "a")
    yield (2, "b")
    return                // 停止信号（IterStopException）
```

- 通过 `yield <params>` 逐步产出参数包；每个 `yield` 载荷须满足 BuildParams 约束；裸 `yield` 合法（无参调用）
- `return`（留白）或块体正常结束 → `IterStopException`，停止产出
- 必须至少包含一个 `yield`

> 完整规则、代码生成与语义检查见 [构建块.md](构建块.md)。

## 5. 缩进回退闭合

缩进块由**缩进回到块开启符同级或更浅**时闭合，无需 `end`：

```
def compute(x: int) =
    if x > 0:
        print("positive")
    else:
        print("non-positive")
// ↑ 缩进回到 def 同级，函数体结束
```

## 6. 续行

表达式需要跨行时，满足以下任一条件即可续行：

- 在括号 `()` `[]` `{}` 内部
- 在中缀操作符之后
- 在 `=` / `:` 之后换行并缩进

```
let total = 1 +
            2 +
            3

let result = [
    1, 2, 3,
    4, 5, 6,
]
```

## 7. 空行与空块

- 空行不影响语义
- 空块用 `()` 或省略函数体表示：

> ⚠️ 未实现（规划中）：当前编译器无 `pass` 关键字，`pass` 不是保留字，示例暂无法通过 lzc 编译；空块请用 `()` 或省略。

```
def noop() =
    ()          // 空块用 () 表示，或省略函数体
```

## 语法边界

- ✅ 一级缩进固定 **4 个空格**；TAB 视作 4 个空格，但同一文件内**不要混用** Tab 与空格。
- ✅ 复合语句（`if`/`elif`/`else`、`for`/`while`/`loop`、`match`/`case`、`guard ... else:`、`with ... as`、函数与类型定义体）开启后，换行体必须**缩进**一级。
- ✅ 控制流关键字后的 `:` 之后必须保留空白（一个空格）再写体，且控制流构造须按块缩进；if 表达式的 `if` / `elif` / `else` 分行书写、同级对齐。❌ 不支持单行三元 `if cond: a else: b`（`if` 与 `else` 不可同行）。
- ✅ `match` 分支 `case PATTERN =>` 两种写法等价：单行 `case 0 => "zero"`（无需缩进）与换行 `case Some(v) =>` 后接缩进体。
- ✅ `def f()-> T =`、`struct S =`、`enum E =`、`trait`、`impl` 等以 `=` 开启的定义体，其换行语句必须缩进，回退到同级即闭合。
- ✅ 构建块 `=:` / `~:` / `*:` 已实现（见 [构建块.md](构建块.md)）；旧的 `name :` Callable 调用块、`KwArgs:` / `Args:` 包块、`out` 关键字已移除。
- ❌ 没有 `pass` 关键字，空块用 `()` 或省略函数体，不要写 `pass`。
- ❌ 续行可发生在括号内部、中缀操作符之后、`=`/`:` 之后；返回类型用 `->`，函数类型也用 `->`。
