# 注释

Lang-Zong 只支持两种注释形式，移除了 `#|` / `$|` / `&|` 多行字符串前缀。

## 1. 单行注释

以 `//` 开始，直到行尾。

```
// 这是单行注释
x = 1  // 行尾注释
```

## 2. 多行注释

以 `/*` 开始、`*/` 结束，**不支持嵌套**：遇到第一个 `*/` 即闭合，其后的内容会被当成代码，从而引发错误。

```
/*
   这是多行注释
   可以跨越多行
*/
```

> ⚠️ 不支持嵌套：下方写法会出错——第一个 `*/` 闭合外层注释，残留的 `c */` 被当作代码解析，导致错误。

```lz
/* a /* b */ c */   // 第一个 */ 即闭合；c */ 成为代码 → 解析错误
```

## 3. 文档注释（约定）

文档注释是**约定**而非语法强制：在 `def` / `struct` / `class` / `enum` / `trait` 定义前一行以 `///` 开头的注释，会被工具识别为文档：

```
/// 计算阶乘。
/// n 必须 >= 0。
def factorial(n: int)-> int =
    if n <= 0:
        1
    else:
        n * factorial(n - 1)
```

## 4. 禁用的形式

以下注释形式**不再支持**，如在源码中出现视为语法错误：

| 形式 | 状态 |
|------|------|
| `# ...` 行注释 | ❌ 移除（`#` 已**预留给 Rust 风格宏语法**，lex 阶段不再作为注释消费；当前未实现的 `#...` 会由 lexer 兜底跳过，不影响解析） |
| `#| ...` | ❌ 移除 |
| `$| ...` | ❌ 移除 |
| `&| ...` | ❌ 移除 |

## 5. 注释与缩进

注释不参与缩进语义，但**多行注释必须与所在缩进层级对齐**或更深，以避免歧义：

```
def f() =
    // 正确：注释与代码同级缩进
    x = 1
    /* 正确：
       多行注释缩进对齐 */
    y = 2
```

## 6. 语法边界

- ✅ 单行注释以 `//` 开始，直到行尾；行尾注释 `x = 1  // 注释` 合法。
- ✅ 多行注释 `/* ... */`，**不支持嵌套**：遇到第一个 `*/` 即闭合，其后内容按代码解析（易报错）。
- ❌ `# ...` **不是注释**（已预留给 Rust 风格宏语法）；当前 `#...` 由 lexer 兜底跳过，但绝不可当作注释使用。
- ❌ `#| ...` / `$| ...` / `&| ...` 多行字符串前缀**已移除**，出现即语法错误。
- ✅ 文档注释 `///` 仅是工具约定，非语法强制；多行注释应与所在缩进层级对齐或更深。
