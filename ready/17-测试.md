# 测试

> ⚠️ 未实现（规划中）：`test` / `suite` / `assert` / `throws` / `ignore test:` 等测试语法当前编译器无对应 token，不生成任何测试框架，全文示例暂无法通过 lzc 编译。当前请用普通 `def` + `print` 验证行为。

## 1. 语法

`test` 关键字后跟测试名称，以 `:` 结尾。支持两种写法：

### 1.1 引号形式

```
test "add works":
    assert add(1, 2) == 3
```

### 1.2 无引号形式

```
test add works:
    assert add(1, 2) == 3
```

两种形式完全等价。无引号形式中，测试名称 = `test` 之后、本行最后一个 `:` 之前的所有内容（trim 后）。

## 2. 示例

```
// 单个测试
test factorial should work:
    assert factorial(0) == 1
    assert factorial(5) == 120
    assert factorial(10) == 3628800

test edge cases:
    assert throws(|: factorial(-1))

// 测试套件
suite "math tests":
    test add:
        assert add(1, 2) == 3
    test sub:
        assert sub(5, 3) == 2

suite "string tests":
    test trim:
        assert trim("  hi  ") == "hi"
    test split:
        assert split("a,b,c", ",") == ["a", "b", "c"]
```

## 3. 断言

| 断言 | 说明 |
|------|------|
| `assert expr` | expr 为 True |
| `assert expr == expected` | 相等比较 |
| `assert throws(lambda)` | lambda 抛出异常 |
| `assert not throws(lambda)` | lambda 不抛异常 |

```
test divide:
    assert divide(10, 2) == 5
    assert throws(|: divide(1, 0))
    assert not throws(|: divide(1, 1))
```

## 4. 测试套件 `suite`

`suite` 用于分组测试：

```
suite "math tests":
    test add:
        assert add(1, 2) == 3
    test sub:
        assert sub(5, 3) == 2
```

## 5. 词法规则

`test` 关键字触发特殊词法模式：

1. 跳过 `test` 后的空白
2. 若下一个字符是 `"`，进入引号模式读取字符串
3. 否则进入自由文本模式：从 `test` 后到本行**最后一个 `:`** 之前的所有字符为测试名称
4. `//` 注释及其后的内容不参与 `:` 的查找
5. 行末必须有 `:` 作为终止符，否则编译错误

```
test 名称包含 ：冒号 ： // 这里的冒号不行 被注释了 //
//          ↑ 这个 ：是终止符   ↑ 注释内的 ：被忽略
```

## 6. 跳过测试

使用 `ignore test:` 块声明要跳过的测试名称列表：

```
ignore test:
    ["test_slow", "test_flaky", "test_experimental"]

test slow_test:
    ...
```

测试运行时会打印被跳过的测试个数。

## 7. 与目标语言的衔接

> ⚠️ 未实现（规划中）：当前仅 Rust 单后端，且测试框架未生成，下表中的 `test`/`suite` 转译目标均暂不支持。

`test` 和 `suite` 转译为目标语言的测试框架：

| 目标语言 | `test` | `suite` |
|---------|--------|---------|
| 仅 Rust 后端（测试框架未实现） | — | — |
| Rust（测试框架未生成） | — | — |

```
// Lang-Zong
test add works:
    assert add(1, 2) == 3

// Cython（默认）
def test_add_works()->
    assert add(1, 2) == 3

// Rust
#[test]
fn add_works() {
    assert_eq!(add(1, 2), 3);
}
```

## 语法边界

- ❌ 整个测试语法未实现：`test` / `suite` / `assert` / `throws` / `not throws` / `ignore test:` 当前编译器无对应 token，不生成任何测试框架，示例均无法通过 lzc 编译。

- ✅ 当前验证方式：用普通 `def` 定义函数，配合 `print` 输出结果进行手动验证。
