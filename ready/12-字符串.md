# 字符串

## 1. 单行字符串

| 前缀 | 转义 `\n` | 插值 `{...}` | 说明 |
|------|:---:|:---:|------|
| `"..."` | 是 | 否 | 普通双引号 |
| `f"..."` | 是 | 是 | 插值双引号 |
| `r"..."` | 否 | 否 | 原始双引号 |

> ⚠️ 未实现（规划中）：当前编译器不支持单引号字符串（包括 `'...'`/`f'...'`/`r'...'`/`'''...'''`/`f'''...'''`/`r'''...'''`），字符串字面量只能用双引号。

```
name = "Lang-Zong"
version = 0

s1 = "Hello, World!"
s2 = f"Hello, {name} v{version}"
s3 = r"C:\Users\{name}\data"      // {name} 原样输出
```

## 2. 三引号字符串

| 前缀 | 转义 `\n` | 插值 `{...}` | 说明 |
|------|:---:|:---:|------|
| `"""..."""` | 是 | 否 | 普通三双引号 |
| `f"""..."""` | 是 | 是 | 插值三双引号 |
| `r"""..."""` | 否 | 否 | 原始三双引号 |

> ⚠️ 未实现（规划中）：当前编译器不支持三单引号（`'''...'''`/`f'''...'''`/`r'''...'''`），多行字符串只能用 `"""..."""` 形式。

```
doc1 = """多行
字符串
示例"""

doc2 = f"""Hello, {name}!
Version: {version}"""

doc3 = r"""C:\Users\
{name}\data"""              // {name} 原样输出
```

## 3. 与 Python 的关键区别

不加 `f` 前缀的字符串 `{name}` **原样输出**，不会插值：

```
s = "Hello, {name}"           // 字符串内容就是字面 "Hello, {name}"
s = f"Hello, {name}"          // 插值，值为 "Hello, Lang-Zong"
```

## 4. 字符串操作

```
s = "Hello, Lang-Zong!"

first = s[0]                  // 'H'
slice = s[0..5]               // "Hello"
upper = s.to_upper()          // "HELLO, LANG-ZONG!"
len = s.len()                 // 17
has = s.contains("Lang")      // True
```

## 5. 已移除的形式

| 形式 | 状态 | 替代 |
|------|------|------|
| `#| ...` | ❌ 移除 | `"""..."""` |
| `$| ...` | ❌ 移除 | `f"""..."""` |
| `&| ...` | ❌ 移除 | `r"""..."""` |

## 6. 转义字符

在非 `r` 前缀的字符串中，以下转义生效：

| 转义 | 含义 |
|------|------|
| `\n` | 换行 |
| `\t` | 制表符 |
| `\r` | 回车 |
| `\\` | 反斜杠 |
| `\"` | 双引号 |
| `\0` | 空字符 |
| `\x41` | 十六进制字节 |
| `\u0041` | Unicode 码点 |

## 8. 插值内支持完整表达式

f-string 中的 `{...}` 不是简单文本替换，而是被**重新词法分析 + 解析**为真正的 AST 表达式。
因此插值内可直接使用任意运算符，它们会被正确转译：

```
opt: int? = None
u: User? = Some(User(name: "Ada"))
print(f"{opt ?? 0}")
print(f"{u?.name ?? "unknown"}")
print(f"{data |> transform}")
```

f-string 内若需输出字面花括号，用 `{{` / `}}` 转义，例如 `f"{{name}}"` 输出文本 `{name}` 而非插值。

> 这意味着 `??` / `?.` / `|>` 等运算符在字符串插值中同样生效，无需额外转义。

## 语法边界

- ✅ 字符串字面量仅支持双引号形式：`"..."` / `f"..."` / `r"..."` / `"""..."""`。
- ✅ f-string 内 `{...}` 为插值表达式，`??`/`?.`/`|>` 等运算符同样生效；字面花括号用 `{{` / `}}` 转义。
- ✅ `r"..."` / `r"""..."""` 内 `{name}` 原样输出，不插值。
- ❌ 不支持单引号字符串：`'...'` / `f'...'` / `r'...'` / `'''...'''` / `f'''...'''` / `r'''...'''`。
- ❌ 不支持字节串 `b"..."` / `b'...'` / `b"""..."""`，也不存在 `bytes` 类型。
- ❌ 三引号字符串内部不能出现 `"""`（会提前结束字符串）；`#|` / `$|` / `&|` 已移除，用 `"""..."""`/`f"""..."""`/`r"""..."""` 代替。
