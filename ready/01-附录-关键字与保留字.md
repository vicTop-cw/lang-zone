# 附录 — 关键字与保留字

## 1. 关键字汇总

### 1.1 按类别分组（含实现状态）

> **状态图例**
> - ✅ **已实现**：词法已识别，且解析器接受、代码生成可用。
> - ⚠️ **未实现（token 已识别但未解析/未生成）**：词法把其当关键字，但当前编译器不消费，会出现解析错误。
> - ❌ **无 token（未实现）**：当前版本完全不是关键字，不能作为标识符保留字使用；属规划/保留名，写入源码即报错。

| 类别 | 关键字 | 状态 |
|------|--------|------|
| 声明 | `def` `struct` `enum` `trait` `impl` `const` `mut` `ref` `owned` `let` | ✅ 已实现（`let` 仅用于 `guard let` 与顶层绑定） |
| 导入 | `import` `from` `as` | ✅ 已实现 |
| 控制流 | `if` `elif` `else` `match` `case` `for` `in` `while` `loop` `break` `continue` `return` `guard` `with` `defer` `where` | ✅ 已实现 |
| 异常 | `try` `catch` `finally` `panic` | ✅ 已实现（`panic` 转译 Rust `panic!`，`try/catch/finally` 转译 Rust `match+Result`） |
| 并发 | `async` `await` `spawn` `select` `yield` | ✅ 全部已实现（`async def` 生成 `async fn`，`await expr` 生成 `{expr}.await`，`spawn expr` 生成 `std::thread::spawn`，`yield` 构建块内使用）；`select` ⚠️ 未解析（token 已识别但 parser 不消费） |
| 模块 | `Self` | ✅ 已实现（`impl`/`trait` 内指代自身类型） |
| 宏/转译期 | `macro` `comptime` | ⚠️ 未实现（token 已识别但未解析） |
| 其他 | `block` `until` `do` `assert` `test` `suite` | ❌ 无 token（未实现） |
| 异常（旧名） | `raises` | ⚠️ 未实现（token 已识别但未解析） |
| 并发（旧名） | `go` | ❌ 无 token（未实现） |
| 类型/类（旧名） | `class` `type` | ❌ 无 token（未实现） |
| 模块（旧名） | `Type` | ❌ 无 token（未实现） |
| 字面量 | `True` `False` `None` `Some` `Ok` `Err` | ✅ 已实现 |
| 逻辑 | `and` `or` `not` `is` | ✅ 已实现 |
| 文件指令 | `#!bin` | ❌ 未实现 |

```

```

**❌ 无 token（非关键字；属规划/保留名，不能当标识符保留，写入即词法错误）**

```

```

## 2. 保留字

保留字暂不为当前版本赋予语义，但禁止作为标识符使用，为未来扩展预留：

```
abstract    base        extern      internal    override
pass        protected   pub         sealed      unsafe
```

## 3. 魔法方法前缀

以双下划线包围的方法为魔法方法，始终公开：

```
__init__    __new__     __del__     __copy__    __move__
__eq__      __ne__      __hash__    __str__     __repr__
__bool__    __int__     __float__   __call__
__add__     __sub__     __mul__     __div__     __mod__     __pow__
__neg__     __pos__     __abs__     __invert__
__iadd__    __isub__    __imul__    __idiv__
__getitem__ __setitem__ __delitem__ __len__     __contains__
__iter__    __next__
__enter__   __exit__
__getattr__ __setattr__ __delattr__
```

## 4. 软关键字

以下标识符在特定上下文中作为关键字，其他位置可作为普通标识符：

| 标识符 | 触发上下文 |
|--------|----------|
| `match` | 出现在表达式起始 |
| `case` | `match` 块内的分支 |
| `Self` / `Type` | 方法首参数位置 |

## 5. 语法边界

- ✅ **已实现关键字（✅）** 可直接使用；`mut` 虽为关键字但是兼容 no-op，不改变绑定可变性。
- ⚠️ **未实现关键字（⚠️，token 已识别但未解析）**：写入源码会被词法识别为关键字并触发解析错误——既不能当标识符，也暂不可用。
- ❌ **保留字 / 规划名（❌，无 token）**：写入源码即词法错误，绝不可作为标识符（变量名、函数名、类型名等）。
- ✅ 已释放的旧名（`val` / `var` / `end` / `of` / `when` / `then` / `event` / `toml` / `transtime` 等）可作普通标识符使用。
- ❌ `Self` / `Type` 在方法首参位置有特殊含义，不要在其他位置当作普通类型名滥用。
