# 泛型

> **核心规则：所有类型参数统一使用尖括号 `<>`，不使用方括号 `[]`。**
> `List<int>` `Dict<str, int>` `Set<int>` `Option<T>` `Result<T, E>` — 全部使用 `<>`

> ⚠️ **未实现 / 有缺陷（规划中）**：以下特性当前编译器**能解析但生成不可编译的 Rust**，或尚未实现，示例暂无法通过 `rustc` 编译，请勿在生产代码中使用：
> - `T()` 以约束构造（如 `where T <: Default = T()`）— codegen 生成 `T()`，Rust 中应为 `T::default()`，当前不可编译。
> - 函数类型作为参数 `(T) -> U` — codegen 生成 `(T) -> U`，Rust 中应为 `fn(T) -> U` 或 `Box<dyn Fn>`，当前不可编译。
> - `T <: Any` 约束 — codegen 生成 `T: Any`，但未导入 `std::any::Any` 且要求 `'static`，当前不可编译。
> - 可变参数 `rest: List<T>` 自动聚合（如 `make_list(1, 2, 3, 4)`）— 尚未实现。

## 1. 基本泛型

```
def identity<T>(x: T)-> T = x
def pair<A, B>(a: A, b: B)-> (A, B) = (a, b)

struct Box<T> =
    value: T

enum Option<T> =
    None
    Some(T)

enum Result<T, E> =
    Ok(T)
    Err(E)
```

## 2. where 约束

> ⚠️ **硬约束**：`where T <: Bound` 必须与 `def`/`struct` 签名写在**同一行**、`=` 之前。换行到下一行会触发解析错误 `Expected Eq, got Newline`。

```
# 单约束（✅ 可编译：codegen 生成 `where T: Ord`）
def max<T>(a: T, b: T)-> T where T <: Ord =
    if a > b: a
    else: b

# 多约束（✅ 可编译：codegen 生成 `where T: Clone + Ord`）
def clone_and_sort<T>(items: List<T>)-> List<T> where T <: Clone + Ord =
    items

# 构造器约束（❌ 有缺陷：codegen 生成 `T()`，Rust 应为 `T::default()`，不可编译）
def make_default<T>()-> T where T <: Default =
    T()

# 函数约束（❌ 有缺陷：codegen 生成 `(T) -> U`，Rust 应为 `fn(T) -> U`，不可编译）
def apply<T, U>(f: (T) -> U, x: T)-> U where T <: Any =
    f(x)
```

## 3. 约束符号

| 约束 | 含义 | Rust 对应 | 编译状态 |
|------|------|----------|---------|
| `T <: Clone`   | 可克隆 | `Clone` | ✅ 可编译 |
| `T <: Copy`    | 值语义 | `Copy` | ✅（推断） |
| `T <: Ord`     | 可比较 | `Ord` | ✅ 可编译 |
| `T <: Hash`    | 可哈希 | `Hash` | ✅（推断） |
| `T <: Default` | 无参构造 | `Default` | ✅ 约束可生成（但 `T()` 调用见 §2 缺陷） |
| `T <: Any`     | 无约束 | `std::any::Any`（需 `'static`，当前未导入） | ❌ 不可编译 |
| `T <: A + B`   | 多约束 | `A + B` | ✅ 可编译 |

## 4. 泛型方法

```
struct Box<T> =
    value: T

    def map<U>(self: Box<T>, f: (T) -> U)-> Box<U> =
        Box(f(self.value))

b = Box(42)
s = b.map(|x| f"num: {x}")  // Box("num: 42")
```

> ⚠️ 上例中 `f: (T) -> U` 为函数类型参数，当前 codegen 生成 `(T) -> U` 属非法 Rust（见 §2），故该示例暂不可编译。泛型方法本身（去掉函数类型参数）可用。

## 5. 泛型与可变参数（❌ 未实现）

> ⚠️ 未实现（规划中）：可变参数 `rest: List<T>` 自动聚合（`make_list(1, 2, 3, 4)` 将余下实参收集为 `List<T>`）当前编译器不支持，示例不可编译。

```
def make_list<T>(head: T, rest: List<T>)-> List<T> where T <: Any =
    [head] + rest

make_list(1, 2, 3, 4)    // [1,2,3,4]
```

## 6. 与 Rust 对照

```
# Lang-Zong
def max<T>(a: T, b: T)-> T where T <: Ord =
    if a > b: a
    else: b

# Rust
fn max<T: Ord>(a: T, b: T) -> T {
    if a > b { a } else { b }
}
```

## 语法边界

- ✅ 类型参数统一用尖括号 `<>`，**不要**用方括号 `[]`（如 `List<T>` 而非 `List[T]`）。
- ✅ `where T <: Bound` 必须与 `def`/`struct`/`impl` 签名在**同一行**、`=` 之前；多约束用 `A + B`。
- ✅ 约束名（Clone / Ord / Default / Hash 等）直接映射到同名 Rust trait，可编译通过。
- ✅ 泛型 `struct` / `enum` / `trait` / `impl` 及泛型方法均可正常定义与使用。
- ❌ `T()` 以约束构造值（`where T <: Default = T()`）— codegen 生成非法 `T()`，暂不可编译。
- ❌ 函数类型作为参数 `(T) -> U` — codegen 生成非法 `(T) -> U`，暂不可编译。
- ❌ `T <: Any` — 生成未导入的 `T: Any`，暂不可编译。
- ❌ 可变参数 `rest: List<T>` 自动聚合尚未实现，不要使用。
