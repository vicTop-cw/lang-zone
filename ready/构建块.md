# 构建块（Build Block）

## 1. 概述

构建块（Build Block）是 Lang-Zong 中用于"延迟求值 + 结构化构造参数"的语法设施。其**本质为无参闭包**：

- 每个构建块在代码生成阶段被转译为 `(|| unsafe { ... })()` —— 一个不接收参数的 Rust 闭包并立即调用。
- 块体内部默认处于 `unsafe` 上下文，因此**允许使用指针语法**（`*` 解引用、`&` 取址、`Box::into_raw` / `Box::from_raw` 等）；指针语法的作用范围**严格限定在构建块内部**，块外仍为安全代码。
- 块体即一个缩进作用域，回退缩进即闭合（见 [03-缩进规则.md](03-缩进规则.md)）。

共有三种构建块，对应专用符号 `=:`、`~:`、`*:`，统称"构建块专用符号"。

## 2. 通用语法规则

### 2.1 专用符号

| 符号 | 名称 | 用途 |
|------|------|------|
| `=:` | 变量构建块（Var） | 计算一个值并绑定到左侧变量 |
| `~:` | 调用构建块（Call） | 为（通常带泛型参数的）函数调用构造参数包并应用 |
| `*:` | 生成器调用构建块（Gen） | 逐步产出多个参数包（惰性迭代器） |

### 2.2 强制留白规则（词法 / 语法层强制）

1. **符号前后必须留白**：`=:` / `~:` / `*:` 之前必须是空白（空格 / Tab / 换行），之后也必须空白，且其后**必须换行并缩进**开启块体。
   - 词法层 `is_build_ws` 校验：若符号前或符号后的第 3 个字符位置非空白，词法器直接产出 `LexError`，编译报错：
     `构建块符号 'X:' 前后必须留白（符号前需空格，符号后需换行缩进）`。
   - 解析模块在收集到 `LexError` 令牌时整体拒绝编译。
2. **符号后必须换行 + 缩进**：解析器 `parse_build_block_body` 在符号后执行 `skip_newlines(); expect(Indent)`，缩进块即块体作用域。

正确示例：

```
x =:
    compute_something()

f ~:
    (a, b, c)

g *:
    yield (1, 2)
```

错误示例（触发 `LexError`）：

```
x=:            // 符号前无空白
x =:foo        // 符号后未换行缩进（应为换行 + 缩进）
```

### 2.3 公共语义

- 块体是一个独立的缩进作用域（词法缩进决定，回退闭合）。
- 支持控制流：`if` / `elif` / `else`、`for` / `while` / `loop`、`match` / `case`、`with ... as`、`guard let ... else:`。
- 支持**提前返回** `return <expr>` 与 **guard** 语句（见 §6）。
- 指针语法仅在块内可用（块内 `unsafe`）。

## 3. 变量构建块 `=:`（Var）

### 3.1 形式

```
name =:
    <任意逻辑：变量赋值、条件判断、循环等>
    <尾部表达式作为返回值>
```

- 左侧 `name` 接收块体尾部表达式的值（`let name = (|| unsafe { ... })();`）。
- 块内可执行任意逻辑（变量赋值、条件判断、循环等）。
- 块体**尾部表达式**自动作为返回值赋给左侧变量；也可用 `return <expr>` 显式提前返回。
- 支持 `guard let ... else:` 守卫。
- ❌ 不允许 `yield`（`=:` 内部使用 `yield` 将被语义检查拒绝）。

### 3.2 示例

```
total =:
    let s = 0
    for i in 0..10:
        s = s + i
    s                       // 尾部表达式返回值

safe_val =:
    let p = &raw_addr as *const i32
    let v = *p              // 指针语法仅在块内可用
    if v < 0:
        return 0           // 提前返回
    v
```

### 3.3 代码生成

```
let NAME = (|| unsafe {
    <块体>
})();
```

## 4. 调用构建块 `~:`（Call）

### 4.1 形式

```
callee ~:
    <块体：构造参数包并作为尾部表达式 / return 返回>
```

- 适用于**带泛型参数的函数调用**（如 `f[T, U] ~:`），或任何需要以"参数包"形式组织实参的调用。
- 返回值必须是**参数包**（满足 `is_valid_build_params`）：
  - **元组** `(a, b, c)` → 按被调函数参数个数位置解包为位置实参；
  - **字典** `{name: v, ...}` → 按被调函数参数名命名解包为关键字实参；
  - **函数调用 / 方法调用 / 标识符（实现了 `BuildParams` trait 的对象） / `KwArg` / `move(...)` / `try(...)`** → 作为单个参数整体传入。
- 支持 `return <params>` 提前返回与 `guard`。
- ❌ 不允许 `yield`。

### 4.2 语义检查（BuildParams 约束验证）

解析器 `validate_build_block` 对 `~:` 执行：

1. 禁止 `yield`（递归扫描嵌套控制流体）；
2. 必须产生返回值（`return <params>` 或尾部表达式）；
3. 返回值须满足 `is_valid_build_params`：元组 / 字典 / 函数调用 / 方法调用 / 标识符 / `KwArg` / `move` / `try`，否则报错：

   > 调用构建块(~:) 的返回值必须是元组 / 字典 / 结构体构造，或实现 BuildParams trait 的表达式

> 已知边界：`build_block_payload` 仅检查**顶层** `return` 或尾部表达式；若 `return` 出现在 `if` / `for` 等嵌套体内，当前版本不会被捕获（见 §8）。

### 4.3 示例

```
// 位置参数包（元组）
sum ~:
    (1, 2, 3)

// 命名参数包（字典）
configure ~:
    { host: "localhost", port: 8080 }

// 带泛型
make_vec[int] ~:
    (10, 0)

// BuildParams 对象整体作为单参数
register ~:
    MyConfig{ timeout: 30 }
```

### 4.4 代码生成

块体在 `in_build_call` 上下文中生成，尾部表达式 / `return` 值经类型擦除为 `__Pack`（见 §7）；闭包返回 `__Pack` 后，按被调函数参数名 / 个数动态解包：

```
{
    let __p = (|| unsafe {
        <块体：尾部表达式 → __Pack>
    })();
    match __p {
        __Pack::Tuple(v) => callee(*(Box::from_raw(v[0])), *(Box::from_raw(v[1])), ...),        // 位置解包
        __Pack::Dict(m)  => callee(k = *(Box::from_raw(*m.get("k").expect(...))), ...),         // 命名解包
        __Pack::Single(p) => callee(*(Box::from_raw(p))),                                       // 单参数
        _ => unreachable!()
    }
}
```

## 5. 生成器调用构建块 `*: `（Gen）

### 5.1 形式

```
callee *:
    <块体：通过 yield 逐步产出参数包>
```

- 返回一个**惰性迭代器**，对每个 `yield` 产出的参数包调用 `callee`（等价 `__bb.into_iter().map(|__p| callee(<__p 解包>))`）。
- 通过 `yield <params>` 逐步产出"构建参数包"；`yield` 的载荷同样须满足 `is_valid_build_params`（元组 / 字典 / 调用 / 标识符(BuildParams) / `KwArg` / `move` / `try`）；**裸 `yield`（无载荷）也合法**，对应无参调用。
- `return`（留白，不带值）→ 自动返回 `IterStopException`，作为迭代停止信号（类比 Python `StopIteration`）；块体正常结束同样以 `IterStopException` 收尾。
- 必须至少包含一个 `yield`（含裸 `yield`），否则语义检查报错。

### 5.2 语义检查

解析器 `validate_build_block` 对 `*: ` 执行：

1. 必须至少包含一个 `yield`（`collect_yields` 递归扫描 `while` / `for` / `loop` / `guard` / `with` / `if` / `match` 体）；
2. 每个 `yield` 载荷（若有）须满足 `is_valid_build_params`，否则报错：

   > 生成器构建块(*:) 的 yield 必须是元组 / 字典 / 结构体构造，或实现 BuildParams trait 的表达式

### 5.3 示例

```
// 逐步产出多个位置参数包
for r in process *:
    yield (1, "a")
    yield (2, "b")
    yield (3, "c")
    return                  // 停止信号（IterStopException）

// 裸 yield → 无参调用
tick *:
    yield
    yield
    return
```

### 5.4 代码生成

```
{
    let mut __bb: Vec<__Pack> = Vec::new();
    (|| unsafe {
        <块体：yield → __bb.push(__Pack); return / 正常结束 → IterStopException>
        IterStopException
    })();
    __bb.into_iter().map(move |__p| match __p {
        __Pack::Tuple(v) => callee(*(Box::from_raw(v[0])), ...),
        __Pack::Dict(m)  => callee(k = *(Box::from_raw(*m.get("k").expect(...))), ...),
        __Pack::Single(p) => callee(*(Box::from_raw(p))),
        _ => unreachable!()
    })
}
```

## 6. 控制流：提前返回与 guard

- **提前返回**：`return <expr>` 在三种构建块中均可用。
  - `=:` 中 `return` 直接作为闭包返回值；
  - `~:` 中 `return` 的值经类型擦除为 `__Pack`；
  - `*:` 中 `return`（带值）先求值再发出 `IterStopException` 停止产出；`return`（留白）直接发出 `IterStopException`。
- **guard**：`guard let ... else:` 在块内可用，守卫失败时走 `else` 分支（可含 `return` / `yield`）。
- 指向性：提前返回只退出当前构建块闭包，不影响外层函数。

## 7. BuildParams trait 与 IterStopException

生成的 Rust 代码在 prelude 中注入：

```rust
pub trait BuildParams { type Args; fn into_args(self) -> Self::Args; }
pub struct IterStopException;
pub enum __Pack { /* Tuple(Vec<*const ()>), Dict(...), Single(*const ()) */ }
```

- **`BuildParams`**：当调用块 / 生成器块的载荷是实现了该 trait 的对象时，整体作为单参数传入（对应 `__Pack::Single`）。`into_args()` 用于把对象展开为被调函数所需实参（由调用方约定）。
- **`IterStopException`**：`*: ` 生成器块中 `return`（留白）或块体正常结束时的停止信号；生成的 `map` 闭包以 `IterStopException` 收尾即终止迭代。
- **`__Pack`**：构建块参数包的**类型擦除统一表示**，以裸指针承载各字段，配合块内 `unsafe` 解包。元组 → 位置实参、字典 → 命名实参、其余 → 单值（BuildParams 语义）。

## 8. 语法边界

- ✅ 专用符号 `=:` / `~:` / `*:` **前后必须留白**，符号后必须**换行并缩进**；否则词法层 `LexError` 编译失败。
- ✅ 三种构建块均转译为无参 `unsafe` 闭包，指针语法仅限块内。
- ✅ `=:` 与 `~:` **禁止 `yield`**；`*: ` **必须至少含一个 `yield`**。
- ✅ `~:` / `*: ` 的返回值 / `yield` 载荷须满足 `BuildParams` 约束（元组 / 字典 / 调用 / 标识符(BuildParams) / `KwArg` / `move` / `try`）。
- ⚠️ `validate_build_block` 对 `~:` 仅检查**顶层** `return` / 尾部表达式；嵌套在 `if` / `for` 等体内的 `return` 当前不被捕获（若实际返回非参数包，运行期类型擦除解包可能 panic）。
- ❌ `Args` / `KwArgs` / `out` 关键字**已移除**（旧 `name :` / `KwArgs:` / `Args` 参数包语法不再支持，改用 `=:` / `~:` / `*:`）。
- ❌ 字典 key 与函数参数名不匹配时不做编译期校验：缺 key 运行期 `expect` panic，多余 key 忽略。
- ❌ 不校验 `__Pack` 解包后的具体类型，类型安全由使用者保证（块内 `unsafe`）。

## 9. 与旧设计的差异（迁移说明）

| 旧设计（已移除） | 新设计 |
|------------------|--------|
| `KwArgs:` / `Args:` 参数包块 | `~:` 调用构建块（字典 / 元组参数包） |
| `name :` Callable 调用块 | `~:` 调用构建块 / `*: ` 生成器调用构建块 |
| `out <expr>` 提前返回参数包 | `return <expr>` |
| `Args` / `KwArgs` / `out` 关键字 | 已移除，无对应关键字 |
