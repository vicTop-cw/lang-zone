# 函数

## 1. 基本语法

```
def add(a: int, b: int)-> int =
    return a + b

def add(a: int, b: int)-> int =
    a + b                     # 表达式体，自动 return

def greet(name: str) =
    print(f"Hello, {name}")    # 无返回值
```

## 2. 参数默认值

```
def power(base: int, exp: int = 2)-> int =
    if exp == 0: 1
    else: base * power(base, exp - 1)

power(3)        # 9 (exp=2)
power(3, 3)     # 27
```

## 3. 可变参数（末尾 List<T> 自动压栈）

> ⚠️ 未实现（规划中）：当前编译器不收集多余实参——参数是固定位置匹配，`rest: List<int>` 仅作为普通形参接收一个列表实参，并不会把多余实参自动压栈。下列示例暂无法通过 `lzc` 编译，仅展示预期语法。

```
def sum(nums: int, rest: List<int>)-> int =
    total = nums
    for n in rest:
        total += n
    return total

sum(1, 2, 3, 4)          # 预期 1 + 2 + 3 + 4 = 10
sum(1)                    # 预期 1

# 泛型可变参数
def concat<T>(first: T, rest: List<T>)-> List<T> where T <: Any =
    [first] + rest
```

规则（规划）：最后一个参数是 `List<T>` → 自动收集多余实参。

## 4. 方法（self）

```
struct Rectangle =
    width: f64
    height: f64

    def area(self: Rectangle)-> f64 =
        self.width * self.height

    def scale(self: Rectangle, factor: f64) =
        self.width *= factor
        self.height *= factor
```

## 5. 返回值语法

```
# 表达式体 → 自动 return 最后一行
def double(x: int)-> int =
    x * 2

# 块体 → 需要显式 return
def max(a: int, b: int)-> int =
    if a > b:
        return a
    return b

# 提前返回
def safe_div(a: int, b: int)-> Option<int> =
    if b == 0:
        return None
    Some(a / b)
```

## 6. 函数类型

```
# 函数作为参数
def apply<T, U>(f: (T) -> U, x: T)-> U = f(x)

# 函数作为返回值
def make_adder(n: int)-> (int) -> int =
    |x| x + n

add5 = make_adder(5)
add5(3)                   # 8
```

## 7. 与 Rust 对照

```
# Lang-Zong
def add(a: int, b: int)-> int =
    a + b

# Rust
fn add(a: i64, b: i64) -> i64 {
    a + b
}
```

| Lang-Zong | Rust |
|-----------|------|
| `def name(...)-> Type` | `fn name(...) -> Type` |
| `return x` | `return x` |
| 表达式体自动 return | 表达式体自动 return |
| `(T) -> U` | `fn(T) -> U` |

## 语法边界

- ✅ 返回类型用 `->`：`def f(x: int) -> int = ...`（函数类型 `(T) -> U` 同样用 `->`）。
  ❌ `def f(x: int)-> int = ...`（函数返回类型不能用 `:`）。
- ✅ `where` 约束与签名同一行、位于 `=` 之前：`def concat<T>(first: T, rest: List<T>)-> List<T> where T <: Any = ...`。
  ❌ `where` 写在 `=` 之后或换到下一行。
- ✅ 每个参数必须写类型：`def f(a: int, b: str)-> ...`；`self` 默认 `&self`。
  ❌ `def f(a, b) = ...`（参数省略类型）。
- ✅ 复合语句体：单行表达式跟在 `=` 后，或换行缩进块。
  ❌ 可变参数自动收集未实现：`rest: List<T>` 当前不会把多余实参压栈，仅作普通形参。
