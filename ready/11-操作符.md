# 操作符

Lang-Zong **不开放自定义操作符符号**（移除了 `*fix` 全家族），仅保留内置操作符。

## 1. 保留的操作符

### 1.1 管道与组合

| 操作符 | 名称 | 说明 |
|:---:|------|------|
| `\|>` | 管道（函数线程） | 左侧表达式作为**第一个实参**传给右侧函数：`a \|> f` ≡ `f(a)`，`a \|> f(x)` ≡ `f(a, x)` |
| `<\|` | 反向管道 | `f <\| a` 等价于 `f(a)` |
| `~>` | 函数组合（左结合） | `f ~> g` 等价于 `|x| g(f(x))` |
| `<~` | 函数组合（右结合） | `f <~ g` 等价于 `|x| f(g(x))` |

```
// 管道 = 函数线程：左侧作为首参传给右侧函数（右侧必须是普通函数）
def double(x: int)-> int = x * 2
def add_one(x: int)-> int = x + 1
def add3(a: int, b: int, c: int)-> int = a + b + c

5 |> double |> add_one            # add_one(double(5)) = 11
1 |> add3(2, 3)                   # add3(1, 2, 3) = 6
arr |> map(f) |> filter(p)        # filter(map(arr, f), p)  （map/filter 为接收容器的自由函数）

// 函数组合（未实现，见下方标注）
def add1(x: int)-> int = x + 1
def mul2(x: int)-> int = x * 2

pipeline = add1 <~ mul2        // pipeline(x) = add1(mul2(x))
g = mul2 ~> add1               // 等价
```

> ⚠️ 未实现（规划中）：`<|`、`~>`、`<~` 当前无对应 token、解析器不消费，下列组合示例无法通过 `lzc` 编译。仅 `|>` 管道已实现。返回类型一律用 `->`（如 `def add1(x: int) -> int = ...`），函数类型 `(T) -> U` 同样用 `->`。
> 其它 `|*>` `|?>` `|>>` `|&>` `|@>` 等管道变体已移除。

### 1.3 Option 相关

| 操作符 | 说明 |
|:---:|------|
| `?`（类型后缀） | `T?` 等价于 `Option<T>` |
| `?.` | 安全导航 |
| `??` | null 合并（默认值）：`a ?? b` ≡ `a.unwrap_or(b)`（`a` 为 None 时取 `b`） |
| `?` | 传播运算符（Rust `?`）：`expr?` 在 `Result`/`Option` 上提前返回 |

```
name = user?.profile?.name ?? "Anonymous"     # 安全导航 + null 合并
len = parse_int(s)?                            # ? 传播错误（Result/Option）
```

## 2. 已移除的操作符

| 操作符 | 状态 | 替代 |
|:---:|------|------|
| `++` / `--` | ❌ 移除 | `+= 1` / `-= 1` |
| `\|*>` `\|?>` `\|>>` `\|&>` `\|@>` | ❌ 移除 | 用 `go` / `async` + channel |
| `\|\|>` `\|\|>>` 等（并行操作符） | ❌ 移除 | 用 `go` / `spawn` |
| `<:`（约束运算符，如 `where T <: Bound`） | ✅ 实现中 | 泛型上界约束，详见 [08-泛型.md](08-泛型.md) |
| `^:` `@:`（参数包构建符号） | ❌ 移除 | 用 `=:` / `~:` / `*:` 构建块（见 [构建块.md](构建块.md)） |
| `?` `->` `!` `=?` 条件链表达式 | ❌ 移除 | 用 `if`/`elif`/`else` |
| `*fix` 自定义操作符声明 | ❌ 移除 | 不支持自定义符号 |

## 3. 优先级

从高到低：

| 优先级 | 操作符 | 说明 |
|:---:|:---:|------|
| 10.0 | `.` `::` | 成员访问、路径 |
| 9.0 | `?.` `??` | 安全导航、null 合并 |
| 8.0 | `!`（宏标记后缀） | 转译期标记 |
| 7.0 | `-`（前缀） `not` `~`（前缀） | 一元 |
| 6.0 | `*` `/` `%` | 乘除模 |
| 5.0 | `+` `-` | 加减 |
| 4.0 | `<<` `>>` | 位移 |
| 3.5 | `&` | 位与 |
| 3.0 | `^`（位异或）/ `^`（所有权后缀，看上下文） | 位异或 / 所有权 |
| 2.6 | `\|` | 位或 |
| 2.55 | `\|>` `<|` | 管道（`<|` 未实现） |
| 2.05 | `~>` `<~` | 函数组合（⚠️ 未实现） |
| 2.0 | `==` `!=` `<` `<=` `>` `>=` | 比较 |
| 1.5 | `and` | 逻辑与 |
| 1.0 | `or` | 逻辑或 |
| 0.5 | `:=` `=` `+=` 等 | 赋值（`=` `+=` `-=` `*=` `/=` `%=` 已实现；`:=` ⚠️ 未实现） |

> `^` 在表达式后缀位置是所有权转移，在双操作数中缀位置是位异或，由上下文区分。

## 4. 空白规则

### 4.1 infix 操作符两侧空格可选（风格建议加空格）

词法器会把 `a+b` 拆成 `a`、`+`、`b` 三个独立 token，空格并非必需，仅为可读性风格建议：

```
a + b              // ✅ 推荐（风格）
a+b                // ✅ 可解析，与上面等价（仅风格不同）
```

### 4.2 suffix 操作符 `^` 必须紧贴（前缀 `^` 不存在）

`^` 仅作后缀所有权转移运算符（`x^`），前缀 `^x` 不是有效语法：

```
x^                 // ✅ 后缀所有权转移（move）
^x                 // ❌ 错误：无前缀 `^` 语法

-x                 // ✅ 前缀负号必须紧贴
-not x             // ❌ 前缀不能有空格
```

### 4.3 类型注解 `:` 周围空格可选（风格建议 `x: int`）

词法器把 `x:int` 拆为 `x` `:` `int` 三个 token，`x:int=1` 可正常解析，`:` 前后是否加空格不影响：

```
x : int = 1        // ✅ 推荐（风格）
x :int = 1         // ✅ 可解析，与上面等价
x:int=1            // ✅ 同样可解析
```

### 4.4 语句块 `:` 可松可紧

```
if x > 0:          // ✅
    print("ok")
if x > 0 :        // ✅ 也允许
    print("ok")
```

### 4.5 分号

当前语法**不使用 `;` 分隔语句**——语句靠换行分隔。词法器虽产出 `;` token，但解析器不消费它，因此 `a=1; b=2` 会报错：

```
a = 1
b = 2              // ✅ 用换行分隔语句

a = 1; b = 2       // ❌ 错误：当前语法不以 `;` 作语句分隔符
```

## 5. 魔法方法映射

操作符通过魔法方法实现，自定义类型可实现对应魔法方法：

| 操作符 | 魔法方法 |
|:---:|------|
| `+` `-` `*` `/` `%` `**` | `__add__` `__sub__` `__mul__` `__div__` `__rem__`（取模，非 `__mod__`） `__pow__`（幂运算） |
| `+=` `-=` 等 | `__iadd__` `__isub__` 等 |
| `-x` `+x` `~x` | `__neg__` `__pos__` `__invert__` |
| `==` `!=` `<` `<=` `>` `>=` | `__eq__` `__ne__` `__lt__` `__le__` `__gt__` `__ge__` |
| `[]` 索引 | `__getitem__` / `__setitem__` |
| `()` 调用 | `__call__` |
| `len()` | `__len__` |
| `in` | `__contains__` |
| `iter()` | `__iter__` / `__next__` |

详见 [13-数据类型.md](13-数据类型.md)。

## 语法边界

- ✅ 多字符符号必须连写（内部无空格）：`??` `?.` `==` `<=` `::` `**` `<<` `>>` `+=` 等。
  ❌ `a ? ? b`（`??` 被拆成两个 `?` → 错误）；`a < = b`、`a . b` 同理。
- ✅ `^` 作后缀 move 须紧贴操作数：`x^`。
  ❌ `x ^`（有空格）→ 被解析为位异或 `x ^ ...`。
- ✅ 中缀运算符两侧空格可选（风格建议加空格）：`a+b` 与 `a + b` 等价。
  ❌ 认为 `a+b` 非法（实际可解析）。
- ✅ 类型注解 `:` 周围空格可选：`x:int` 与 `x : int` 等价。
- ✅ 当前用换行分隔语句，`;` 非语句分隔符：`a=1; b=2` 会报错。
- ⚠️ 未实现（无 token，使用即报错）：`<|` `~>` `<~`（组合/反向管道）、`:=`（海象）、`**= &= |= ^= <<= >>=`（多数复合赋值）；`^` 前缀写法不存在。
